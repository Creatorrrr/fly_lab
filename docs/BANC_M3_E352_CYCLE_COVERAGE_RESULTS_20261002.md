# E352 완전 보행 주기 누락 진단

공식 보행 주기 수는 이전과 같다: C에서 RM1회, 나머지5다리0회. B/I에는 인정된 연속 전진 구간이 없다. 여섯 원본/보존 NPZ를 한 번씩 읽고 표준 geometry analyzer 및 source phase/접촉 시간을 검산했으며, 원본 신체·신경·GPU는 추가 실행하지 않았다.

C의 인정 구간0.5–0.86초와1.18–1.495초에서 LF 출력 embedding 위상의 순진행량은 각각0.793131/0.631926회전이다. 범위는0.868381/0.631926회전으로 한 회전에 미달한다. 전체1초의 순진행량2.116655회전, 역행 총량0.143834회전, 최대5ms 증분0.239100회전이었다. 이는 신경 위상 직접 측정이나 실제 발의 회전 수가 아니다.

모든 다리에 whole-window 설명용 peak-pair가 있으나 대부분 비이동/짧은 구간을 가로지른다. 이를 공식 주기로 더하지 않았다. 필터 구간이 다르므로 공식 event와 동일한 사건이라고도 단정하지 않는다. 속도 교차 주변 native1750표본에서 지원 다리 수3개72.57%,2개21.37%,0개1.37%였으며 접촉·부착 하중 동시성은 인과나 생물학적 stance 증거가 아니다.

이 자료는 불규칙한 출력 타이밍을 분리해 볼 근거다. 다음 E353은 같은 형상·신체·다른 action을 유지하고 기존 reference frequency2.382760007990865Hz로만 일정하게 진행시키는 단일 대조를 설계한다. 아직 body 실행/학습 후보를 승인하거나 원인을 확정하지 않았다. Astra 설계 리뷰와 Sol 구현, ROOT 리뷰 후 실행을 결정한다.
