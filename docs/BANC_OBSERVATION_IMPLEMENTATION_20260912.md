# BANC 관측·재생 및 실행 비용 개선 결과

2026-09-12. [M1 실행 계획](BANC_OBSERVATION_GAIT_IMPROVEMENT_PLAN_20260912.md)에 등록한 일곱 필수 기준을 검증했다. 보조 표시 목표 30FPS는 이번 Chrome 검증 창에서 확인하지 못했으며 아래에 별도로 기록한다. 원본 main `a3b9fa4`는 `verification/banc-observation-m1-20260912/baseline`에 보존했고, Draft PR `56382f7`을 기반으로 `codex/banc-observation-improvement`에서 작업했다. 원격 게시·병합은 수행하지 않았다.

## 현재 변경

- 5ms마다 실제 물리 상태·관절 명령·부착·힘줄·운동신경 출력·목표 신경 입력·실제 접촉점 상대 접선 속도를 기록한다.
- 신경 계산과 기록 재생을 분리하고, 계산 요청이 끝난 뒤 재생·탐색에 진입한다. 복원 epoch, 누락 및 버퍼 퇴출을 표시한다.
- 내보내기에 최초 전체 물리 적분 상태와 명령 적용 구간을 포함한다. 초기 표본 퇴출이나 기록 공백이 있으면 명령 재실행 불가로 표시하며, 데이터 완전성과 수치 검증 통과를 구별한다.
- packed CUDA의 RK4 원소별 연산을 통합한다. 기존 CSR의 덧셈 순서와 FTZ는 유지하고, Torch 원소별 연산의 subnormal 보존·반올림을 명시적 PTX로 보존한다. tanh는 설치된 환경에서 실제 Torch와 비교했다.
- 감각 포트의 동일 계산·고정 색인을 재사용하고, 포트 순서를 유지해 감각 입력을 누적한다. 같은 길이의 운동 pooling을 묶고, 무릎의 고정 ID 및 작업 배열을 재사용한다. 명령은 5ms 동안 한 번 설정하되 매 0.1ms 물리·외력·유한값 검사는 유지한다.

뉴런 158,706개와 연결 11,584,852개, 신경·감각·운동 방정식, dt 및 물리 설정은 유지한다. 실제 메시 영상은 별도 mjData에서 기록한 관절 상태를 렌더한다. 보행 제어에 CPG나 루트 보정을 추가하지 않는다.

각 headless 시간은 같은 시작 상태와 0.5모델초, 5쌍 교차 순서로 측정했다. 초기화·컴파일·상세 비교용 복사·PNG·브라우저 시간은 제외한다. 서로 다른 실행의 절대 시간만 비교해 단일 변경의 효과라고 주장하지 않는다. 행 재배치·restrict·unroll·streaming 후보는 효과가 작아 적용하지 않았다.

최종 일반 보행은 원본 2.57203초 → 후보 2.18363초(후보 범위 2.17919~2.19815초), 목표 보행은 2.53948초 → 2.12008초(2.11226~2.12082초)다. 일반 보행의 15% 문턱 여유는 작으며 모든 환경·매 실행에서 같은 비율을 보장하지 않는다. 실제 계산은 벽시계 1초당 약 0.23모델초로 여전히 실시간보다 느리다. 기록 재생의 부드러움과 신경 계산 속도를 구별한다. 원자료는 `e2-final-general`, `e2-final-target`에 있다.

과거 연산 통합의 수치 실패와 이번 exceptional-value 실패는 삭제하지 않았다. CuPy가 붙이는 FTZ를 확인한 뒤 pointwise의 subnormal 처리만 수정했다. tanh 비교는 조밀한 구간·무작위 비트·subnormal·signed zero·NaN·Inf 등 2,097,164개 입력이 포함된다. 해당 CUDA/Torch 버전에서의 검증이며 모든 버전의 보장은 아니다.

## 수치와 실제 신체 관측

- `e1-final-general`, `e1-final-target`: 최종 코드에서 각각 10모델초, 2,000개 제어 경계, 원본/분리 readout/통합 readout/기록 on의 운동·전체 물리 배열 및 마지막 전체 상태가 비트 단위로 같다. 기록 명령만 재입력한 물리 미래도 같다. 중간 후보의 `e1-general`, `e1-target` 결과도 보존했다.
- `e1-final-legacy`: 실제 기존 `banc-757d5d9fe381` 체크포인트(신경 dt 필드가 없으며 0.1ms로 복원)를 사용했다. 3.5초 상태 이후 0.3초, 60개 제어 경계와 전체 미래 및 명령 재실행이 최종 코드에서도 비트 단위로 같다.
- `e3-general`, `e3-target`: 실제 FlyBody 메시를 별도 mjData에서 렌더한 50fps 영상 각각 501프레임. 기록된 다리 분절 위치와 재구성 위치의 최대 차이는 0mm다. 루트나 관절을 실행 중인 모델에 다시 주입하지 않았다.
- 가장 큰 5ms 미끄러짐 주변 105ms를 0.1ms 간격으로 별도 관측했다. 원래 물리 미래는 비트 단위로 같으며, 일반 보행의 해당 구간 최대치는 15.99→42.26mm/s, 목표 보행은 17.25→48.62mm/s로 더 큰 순간 사건을 발견했다. 후자는 서로 다른 다리의 구간 최대치이며 전체 10초의 최대치 추정이 아니다.

| 10초 관측 | 일반 BANC | 목표 BANC | 별도 FlyGym hybrid 비교 |
|---|---:|---:|---:|
| 수평 순변위 / 경로 mm | 5.86 / 53.36 | 5.69 / 27.48 | 25.64 / 201.88 |
| 순변위 / 경로 | 0.110 | 0.207 | 0.127 |
| 누적 절대 yaw rad | 11.27 | 7.27 | 39.89 |
| 42관절 RMS 추종 오차 rad | 0.01128 | 0.03639 | 0.00311 |

FlyGym 비교는 동일 초기 물리 상태와 신체 모델, 0.1ms 물리 및 5ms 명령 갱신을 확인했다. 제어기와 힘줄·부착 정책, 속도·조향 과제가 다르며 이 비교 자체도 크게 회전한다. 따라서 이를 정상 직진 보행의 정답이나 BANC보다 자연스럽다는 근거로 쓰지 않는다. 목표 BANC의 10초 말단은 목표까지 1.067mm에서 정지 입력 중이며, 전체 구간 통계에는 접근과 감속이 함께 들어 있다.

하중이 실린 실제 접촉점에서 미끄러짐이 발생하고 명령 재실행이 같은 물리를 만든다는 사실은 화면 지연만으로 보이는 끌림을 설명하는 가설에 반대되는 근거다. 신경 회로·운동 매핑·부착·접촉 중 하나의 단독 원인은 아직 확정하지 않았다. 목표 보행의 왼쪽/오른쪽 중간다리 coxa yaw RMS는 0.16061/0.17232rad로, 이 관절의 명령 범위와 기계적 제약을 우선 조사할 근거가 된다.

추가 `e3-*-limits`에서는 전체 명령 물리 재실행의 비트 일치를 유지하며 목표 실험을 이동 요청 1,406개/정지 요청 594개로 나눴다. 이동 요청 중 LM/RM coxa yaw 목표의 58.25%/70.06%가 실제 관절·actuator 제어 범위 `[-0.5, 0.3]rad`를 벗어난다. 요청 최솟값은 약 -0.832rad다. MuJoCo의 제어 범위 제한이 있으므로 요청각과 실제각의 차이를 곧바로 서보 고장이라고 해석하면 안 된다. 또한 현재 발 부착의 lift veto는 제한 전 요청각으로 계산한다. M2의 첫 후보는 이 두 관절의 **실현 가능한 명령과 부착 예측의 일치**이며, 신경 방정식·이득·마찰을 함께 변경하지 않는다. 먼저 범위 제한 전후의 부착 예측과 같은 물리 상태의 차이를 분리하고, RMS만 줄어드는 것을 보행 개선으로 판정하지 않는다. 이 문서에서 M2를 실행하거나 성공으로 판정하지는 않았다.

하중 기준을 0.01/0.02/0.05 BW로 바꿔도 이동 구간의 평균 미끄러짐과 지지 비율은 크게 변하지 않았다. 목표 이동 구간에서 발별 p95 미끄러짐은 0.02 BW 기준 1.38~2.39mm/s이며, 정지를 섞은 전체 10초 통계보다 크다. 자세한 발별 값과 구속 토크는 `e3-target-limits/result.json`에 보존했다.

원본 재출발은 2모델초에 1.5633213mm 이동했다. 추가로 이번 왼쪽 목표 정지 상태에서도 새 목표 지정 시 몸·신경·어댑터를 보존하고 2초에 2.2806734mm 이동했다. 여섯 조건은 이전에 노출된 회귀 집합이며, 동일 seed 궤적을 독립 일반화 증거로 세지 않는다.

실제 화면에서는 BANC 계산 7.555초에서 기록 1×/0.25× 재생과 탐색을 수행한 뒤 저장 파일이 완전히 같았다. 처리 중인 수동 50ms 요청 뒤 기록 재생은 7.605초에서 계산을 멈췄고, 자동 진행 중 복원은 7.555초의 저장 상태와 완전히 일치했다. 상단 기본 실험은 3.960초를 유지했다. 실제 내보내기는 41,627,617바이트, 0~1,215 tick의 연속 1,216표본이다. 초기 전체 물리 상태와 적용 구간을 포함하며 `eligible=true`, `verified=false`를 구분한다. 원자료는 `e4-browser/`에 있다.

Chrome 검증 창은 실제 그림과 새 표본 모두 약 1회/초였고, 모델 계산이 없는 정적 대조 페이지도 같았다. **30FPS 표시 목표는 미확인**이며 이번 측정으로 부드러운 화면 출력이나 특정 백그라운드 제한 원인을 확정하지 않는다. 낮은 그리기 빈도에서 기존의 0.1초 dt 제한이 1× 재생을 느리게 만들던 결함은 수정했다. 실제 1×는 1초, 0.25×는 0.25초의 기록 시각 진행을 확인했고, 큰 프레임 간격과 숨김 시간 정지는 단위 검사로 검증했다. 다른 자동화 탭을 만드는 동작은 원래 탭의 visibility를 바꾸지 않아 실제 숨김 검사로 세지 않았다. 생성된 50FPS 실제 메시 영상의 인코딩 빈도를 브라우저 FPS로 세지 않는다.

콘솔에는 비동기 listener 응답 채널 오류가 있었으며 같은 오류가 애플리케이션 RPC가 없는 정적 대조 페이지에서도 반복됐다. 확장 기능 계열 오류로 추정되지만 정확한 확장 기능은 특정하지 않았다. 애플리케이션 고유 오류는 관측하지 않았으며 오류 없는 콘솔이라고 주장하지 않는다.

전송 비교는 같은 현재 코드·시작 상태에서 50모델ms씩 5쌍을 측정했다. PNG 왕복 중앙값 0.33698초/69,689바이트, 5ms 상태 스트림은 0.34618초/194,560바이트였다. 상세 상태는 응답량이 2.79배이고 왕복 시간이 약 2.73% 길었다. 상태 11개를 브라우저에서 선택해 표시하고 내보낼 수 있다는 효과이며, 전송량 감소나 신경 계산 가속의 근거로 쓰지 않는다. 15% 개선은 별도 headless 비교 결과다.

실행 서버는 `http://127.0.0.1:8770/`에 준비했다. 기존 기본 실험과 BANC 목표 시작 체크포인트를 각각 복원했으며 **BANC 패널의 BANC 재생**으로 신경 보행을 진행한다. `--restore-banc-checkpoint`로 두 세션을 함께 준비할 수 있다. 실제 메시 대조는 `http://127.0.0.1:8772/comparison.html` 및 `verification/banc-observation-m1-20260912/e4-comparison/`에 있다. 검증용 8771 서버는 종료했다. Codex 패널 열기는 큐에 등록됐으며 현재 사용자가 보고 있는 창에 표시됐다고 단정하지 않는다.

최종 검사는 Python 83개(실제 MuJoCo 신체·CUDA 포함), JS 22개, 새 Python 파일 전체 Ruff, Python 구문 검사와 HTML 빌드다. 시간 모델·신경 입력·마찰·관절 범위를 바꾸지 않았다. 신경 계산은 약 0.23모델초/실제초이며 실시간이나 자연 보행·생물학적 자율성을 추가 주장하지 않는다. M2 신경/운동 모델 변경은 이번 이정표에서 실행하지 않았다.

## 보존한 실패·선택 이력

24-bit 연결 표현은 수치 검증을 통과했지만 전체 실행이 일반 6.11%/목표 6.03% 느려 기각했다. RK4 순차 누적 버퍼 후보는 작업 메모리를 약 2.54MB 줄였지만 일반 1.15% 개선/목표 0.07% 악화로 속도 효과가 일관되지 않아 보류했다. 원본 대비 15% 미달 결과를 삭제하거나 성공으로 바꾸지 않았다.

근육 moment는 두 곱셈과 선행 +0부터의 float64 누적 순서를 유지해 묶었다. synthetic vector 2,160개와 연속 decode 768개 비교에 이어 전체 5쌍 미래도 일치했다. 재프로파일의 남은 감각 비용을 확인해, 실제로 3,604개 ID가 모두 서로 다른 감각 scatter의 직접 누적 경로(중복 ID는 기존 add.at 유지), 실행 중 사용하지 않는 무릎 방향 미분 생략, NaN와 signed zero를 보존하는 스칼라 범위 제한을 함께 적용했다. 물리 위치·속도와 실제 신경 감각 식은 유지하며 개별 변경의 전체 속도 효과를 따로 입증했다는 주장은 하지 않는다.
