# E220 결과: 새 반응과 canonical 전달의 조합, float64 근육 계산 필요

E219의 ID 로드 경로 오류를 부모가 복구한 별도 E220은 여섯 비교를 완료했고 독립 검산을 통과했다. 원본 E219 실패 소스·증거·비용은 보존했다. 원본 프로세스 1회, 재시도·solver·CUDA·신경·물리 실행은 0이다.

기존 두 기준과 E218 후보의 command/activation/tendon은 사전에 정한 허용오차 안에서 복원됐다. 부모는 독립적인 EMA 필터 및 명시적 float32 연산으로 모든 raw·지표·판정·파일 hash를 검산했다. E218의 57.057365% 조건부 오차 감소가 재확인됐다. 새 반응과 새 전달식은 함께 연결해야 하며, 이 실험의 결과로 여섯 경우 중 새 후보를 선택한 것은 아니다. canonical 통합 대상은 E219 이전부터 고정됐다.

float32 rate 출력 뒤 float64 전달은 기준을 통과했지만 전체 readout float32는 시작 최대오차 기준을 넘었다. 그 실패를 수치 허용오차로 덮지 않는다. native 구현에서는 기존 packed CSR의 float32 연산을 유지하면서 새 반응의 내부 rate/기억과 canonical 근육 계산은 float64로 명시하고, CSR로 나갈 때와 기존 motor readout에서는 float32로 변환하는 계약을 검증한다. 실제 RK stage의 재귀 변화는 이 끝점 비교에서 검증하지 않았다.
