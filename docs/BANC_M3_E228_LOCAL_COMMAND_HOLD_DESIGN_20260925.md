# E228: 동일 단절 직전 RF·RH 명령 유지의 신체 인과 비교

## 질문과 범위

E227에서 반력의 역할이 시간에 따라 바뀌었다. 사건25의 RF 음의 반력 비중은 직전5.8%에서 단절 중80.7%로 증가했고, RH는 직전 제동과 단절 중 추진에 관여했다. 모든 adhesion은 꺼져 있으므로 추가 차단은 개입이 아니다. 실제 Sol/medium의 독립 저장 자료 검토도 RF 명령 유지와 RH 보상 대조를 권고했다. 검토 계산0.188초/명령0.9초, 별도 소스 읽기 시간은 미계측이며0으로 주장하지 않는다.

가설A: RF의 국소 관절 명령 변화가 단절의 수정 가능한 기계적 원인이다. 가설B: RH의 직전 제동·보상 또는 다리 간 상쇄가 더 중요한 제한이다. 가설C: 두 명령 변경 모두 개선하지 못하거나 해석이 불충분하다. 사건25 하나만 탐색한다. 신경망·감각 피드백을 재생/검증하지 않으며, 시각·시간 기반 관절 유지가 최종 자율 제어라는 주장을 하지 않는다. F1–F8나 기존 사건/주기 검출 기준을 바꾸지 않는다.

## 고정 비교

1. E227의 `event-start-25/` 신체 상태(control1607,8.035초)를 정확 복원한다. E224 effector의 동일 world/seed/parameters와 body 모델을 사용한다. 신경망은 생성하지 않는다. 신체는 한 번 구성하고 각 arm 시작 전에 같은 snapshot을 복원한다. 복원 직후 snapshot과 해당 물리행이 원본과 정확히 같아야 한다.
2. 순서가 고정된 세 arm: `sham`, `rf_hold`, `rh_hold`. 각각 원본 control1608–1647의40명령(0.2초/2000native steps)을 진행한다. sham의 물리행과 native6필드는 E225/E227 기록과 dtype/shape/bytes까지 정확히 같아야 한다. 먼저 sham이 완전하고 건강하게 일치해야 두 개입을 허용한다. 추가 반복이나 결과에 따른 arm 선택은 없다.
3. RF는 joints21–27, RH는35–41이다. hold arm의 **control1620–1635**에서 해당7개 관절 목표만 원본 control1619의 값으로 유지한다. 즉 물리(8.095,8.175]초의80ms 동안 유지하고 control1636부터 원래 명령으로 복귀한다. 원래5ms/50step/`interpolate=True` 경로를 쓴다. 다른 관절, 모든 복부·말단 힘줄, adhesion, 강성/물리 파라미터는 원본 그대로다. 사후 gain 조정·시간 이동·clipping·phase 보정은 없다.
4. 변경 전의 control1608–1619는 세 arm 모두 원본과 정확히 같아야 한다. 적용 명령 전체를 원자료로 남기고 변경이 고정 leg/hold 구간에만 있는지 검증한다. 실제 qpos/ctrl/native 최초 차이 시점을 저장한다. 중심 차분 속도가 한 행 앞에 차이를 보일 수 있으므로 이를 물리 차이의 최초 시점으로 혼용하지 않는다.
5. E227의 같은 shadow 반력 관측기와100us nonfinite/nonfoot/upright<.9/body fault guard를 쓴다. 건강 중단은 측정된 결과로 보존한다. 기술·자원 실패도 실제 clock/부분표본/명령/오류를 보존하고 재시도하지 않는다. 기술 실패가 발생하면 뒤 arm을 실행하지 않는다. 한 개입의 건강 중단은 정해진 다른 개입을 건너뛸 이유로 사용하지 않는다.

## 측정과 판정

시작 포함41물리행과2000native 표본/arm이 완전 결과다. 지면 힘은 기존 E227의 고정11필드를 쓴다. 원자료: 실제/요청 명령, qpos/qvel/ctrl/body/feet/힘줄/adhesion, native접촉6필드, force11필드, 시작·완료한 최종 body-only snapshot, clockledger·run result·manifest.

고정 phase는 `lead` control1608–1619, `hold`1620–1635, `recovery`1636–1647, 추가 `during_break`1623–1630이다. 각 제어행 i에 대응하는 native 표본은 (i−1)*5ms<t≤i*5ms다. E226의 pre 창은 control1607을 포함하지만 이번 재현은 control1607 **이후**부터 시작하므로 그 창 전체를 재현했다고 주장하지 않는다. 이 국소 창은 최종 gait evaluator의 변경이 아니다.

원래 trace control0의 수평 방향을 모든 arm에서 고정한다. 제어행의 thorax 위치에 기존 `np.gradient(position,.005)`를 적용한 초기 방향 속도를 계산한다. Gaussian 필터·보행 사건 재검출 없이 동일 창의 실제 변위, 최소 전방 속도, 후진거리 `sum(max(-v,0))*.005`, 후진시간, 최종 yaw 변화를 보고한다. 미분 양끝 영향이 있는 첫·마지막 행을 제외한 **control1620–1646**에서 속도 요약을 계산하고, 변위는1607→1647이다. 전체41행의 속도 원자료도 보존한다.

각 phase에 대해 지지≥.02BW에서 native 부호를 먼저 나눈 다리별 양/음/순 수평 반력 시간합과 지지시간을 계산한다. RF 감소와 함께 RH/RM 등 다른 다리의 보상도 빠짐없이 기록한다. 힘은 post-integration shadow 순간값이며 직전 solver impulse나 개별 근육 힘이 아니다. unsupported slip은 null/유효 표본수로 보존한다. 관절 추종·slip·upright·nonfoot도 비교한다.

**국소 개선 지지**는 해당 arm이 완전·건강하고, sham 대비 후진거리≥25% 감소, 최소 초기 방향 속도≥0.5mm/s 증가, 전체 전진 변위 손실≤0.02mm를 모두 충족할 때만 붙인다. 이 수치는 이번 진단의 사전 판정이며 기존 F1–F8을 대체하지 않는다. RF hold가 위 기준과 `during_break` RF 음의 지지 반력≥20% 감소를 함께 충족하면 RF 명령 경로의 기계적 기여를 지지한다. RF 반력만 줄고 후진이 개선되지 않으면 RF 제동 순위만으로 원인을 설명할 수 없다. RH hold의 같은 신체 개선 기준 결과를 경쟁 설명으로 함께 보고한다. 두 arm 성공도 RF 단독 원인·한 근육 원인·신경 개선을 입증하지 않는다. 미완료/건강 실패에는 전체 창 점수를 붙이지 않는다.
