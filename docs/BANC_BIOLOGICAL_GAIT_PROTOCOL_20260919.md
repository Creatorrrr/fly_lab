# BANC M2 생물학적 보행 검증 프로토콜

작성일: 2026-09-19. 새 보행 지표를 계산하기 전에 고정한다. 대상은 이미 채택한 M2이며, 이번 작업에서는 제어기·신경망·물리 파라미터를 조정하지 않는다. 목표 도달 검증과 생물학적 보행 검증은 별개다.

## 질문과 판정 범위

1. 여섯 다리가 반복적인 보행 주기를 만들고, 좌우 대응 다리가 대체로 반 주기 차이로 움직이는가?
2. 지지와 회복 동작의 지속 시간, 발 궤적, 속도와 주기의 관계가 실측과 양립하는가?
3. 안정성과 미끄럼 개선을 넘어, 실제 신경·감각·근육 기전을 검증할 자료가 있는가?

판정은 `consistent`, `inconsistent`, `insufficient_evidence`로 구분한다. 논문에 없는 임의의 수치 허용폭을 생물학적 합격 기준으로 만들지 않는다. 운동학의 일부가 일치해도 신경·근육 기전까지 검증했다고 결론 내리지 않는다. 양의 생물학적 동등성 판정에는 독립적인 여러 개체의 원자료, 속도·실험 조건 일치, 사전 동등성 한계와 재현 실험이 필요하다.

- E76 최종 manifest의 263개 파일과 현재 코드의 해시가 일치함을 확인했다. Git HEAD는 작업 시작 시 `9eaa83b`이다.
- 기존 개발(6,-3), 전방(8,0), 좌회전(6,-6), 우회전(6,6), 후방(-6,0), 확인(8,3), 확인(5,-7) 기록을 모두 분석한다. 똑같은 궤적을 내는 seed 반복과 UI 재생은 독립 표본으로 세지 않는다.
- 별도 CUDA 세션에서 seed 42, 전방 상대 목표 (20,0) mm, 10 model seconds를 한 번 실행한다. 먼 목표는 도착 감속의 영향을 줄이기 위한 것으로, 시간 내 도착하지 않는 것은 이 실험의 실패 기준이 아니다. 실제 신경 실행 장치, CPG 미사용, 신체 충돌·수치 오류와 전체 원자료를 기록한다.
- 기존 UI의 실험을 바꾸지 않는다. 새 실행은 공개/배포하지 않는 별도 기록 실험이다.

## 실측 근거

- [DeAngelis et al. 2019](https://elifesciences.org/articles/46409): 좌우 대응 다리의 평균 위상차는 약 0.5 cycle이며, 속도에 따른 협응은 연속적이다. 정지·그루밍을 제외하기 위해 전진 속도 0.5 mm/s 기준을 사용한다. 지지 시간은 속도에 따라 크게 변하며 회복 시간의 변화는 상대적으로 작다.
- [Chun et al. 2021](https://elifesciences.org/articles/65878): 수정된 tripod 협응과 속도에 따른 기하학을 분석한다. 엄격하게 세 발만 접지한 시간 비율을 보편적 합격 기준으로 삼지 않는다. 이 연구와 전자의 gait 분류 해석 차이도 남긴다.
- [NeuroMechFly v2 공개 3D 실측](https://doi.org/10.7910/DVN/3MCEYR): CSV 37개 좌표 샘플, 120 Hz, 시간 폭 0.3초, 한 video_id. [논문](https://www.nature.com/articles/s41592-024-02497-y)의 단일 짧은 보행 기록이다. 37개 점은 36개 시간 간격이다. 파일 MD5를 공개 catalog와 대조한다. 좌표의 물리 단위를 임의로 mm로 간주하지 않고 다리 길이로 정규화한다.
- 이 NMF 자료는 보행 템플릿 개발에 쓰인 자료이므로 독립 검증 집단으로 간주하지 않는다. 로컬 FlyBody ball clip도 참고 궤적이며 독립 자료가 아니다.
- DeAngelis의 대규모 공개 Dryad 자료는 metadata를 확보했으나 API download는 HTTP 401, 공개 웹사이트 download는 HTTP 403을 반환했다. Chun Dryad metadata도 열람 불가를 반환했다. 접근 불가 자료를 분석한 것처럼 보고하지 않는다.

## 분석 방법

시간·축·다리 순서를 명시적으로 확인한다. 모델은 200 Hz 제어 경계 기록이며 발끝은 tarsus5 origin의 대용치다. 물리 x 축이 전방이다. 각 발의 body-frame 좌표는 `(foot_ui - thorax_ui) @ basis`로 구한다. 실측은 이름으로 LF/LM/LH/RF/RM/RH를 매칭한다. 좌우 모두 전방 좌표의 부호를 동일하게 유지한다.

초기 0.5초를 제외하고 첫 brake request 이전, 최대 10초를 전체 분석 구간으로 한다. 멈춘 마지막 자세를 보행 주기로 세지 않는다. 전진 속도는 Gaussian 표준편차 20 ms로 평활하고 >0.5 mm/s인 연속 구간을 사용한다. 0.3초보다 짧은 구간은 위상 분석에서 제외하며 제외된 시간도 보고한다. 회전 영향은 평활된 절대 yaw rate <0.5 rad/s인 부분집합을 추가로 보고한다. 이 회전·길이 조건은 분석 설정이며 실측의 보편적인 합격 한계가 아니다.

발 전후 좌표를 다리 길이로 나누고, 각 연속 구간에서 평균을 빼 Hilbert phase를 구한다. 양 끝 20 ms를 제외하고 진폭 <다리 길이의 1%는 위상에서 제외한다. 0.5%와 2% 진폭 설정도 함께 계산한다. phase 차이는 원형 평균, resultant length, antiphase로부터의 원형 거리로 요약한다. 샘플 간 자기상관을 무시한 p-value 또는 200 Hz 샘플을 독립 개체로 취급한 신뢰구간은 만들지 않는다.

별도로 발 전후 좌표를 25 ms 이하 Savitzky–Golay 평활 후 anterior extrema를 검출한다. 최소 간격 40 ms와 다리 길이 2% prominence를 사용한다(1%, 4%도 민감도 분석). 연속 AEP 사이의 최소 위치를 PEP로 삼아 AEP→PEP 후퇴 시간과 PEP→AEP 회복 시간을 산출한다. 이것은 **운동학적 stance/swing 대용치**이며 실제 접촉 이벤트와 다를 수 있다. 각 다리에서 완전한 주기가 3개 미만이면 반복 위상에 대한 강한 판정을 유보한다. 긴 주기를 보기 좋게 잘라내지 않는다. 경계와 기록 공백을 연결한 주기는 만들지 않는다.

원래 하중 접촉은 별도로 duty와 전환 횟수를 보고한다. adhesion 반력이 포함된 normal load를 순수 지지력으로 해석하지 않는다. 접촉 chatter를 한 걸음으로 세지 않는다. 기존 native-substep slip 검증 결과는 기존 품질 성과로 보존한다. 단순 exact-tripod 비율은 기술 통계에만 남긴다.

실측 0.3초 기록에도 같은 정규화·위상·event 계산을 적용하되, 짧은 길이와 매우 적은 주기 때문에 모집단 범위/속도 의존성의 추정에는 사용하지 않는다. joint-angle 절대값은 축·중립각 정의가 다른 모델끼리 직접 등치하지 않는다. 대신 축 정의에 의존하지 않는 femur–tibia 내각의 범위와 정규화 발 궤적을 비교한다.

## 무결성과 산출물

합성 antiphase/in-phase/상수/공백/순서 데이터를 이용해 분석기의 오류를 확인한다. 입력 해시, 프로토콜 해시, 분석 소스 해시, 모든 구간의 시간 범위·제외량·표본 수를 JSON에 보존한다. 실제 측정과 외부 근거, 비교 불가능한 항목을 구분한 한국어 보고서와 그림을 만든다. 결과에 맞춰 M2나 이 프로토콜의 기준을 조정하지 않는다.
