# 모델 카드 · FLY LAB A 0.1.0

## 용도

신경 모델과 몸의 폐루프를 관찰하고, 설계한 개입이 계산 상태와 경로에 영향을 주는지 확인하는 프로토타입. 실제 생물의 행동, 질환, 약물, 광유전학 효과를 예측하는 검증된 모델이 아니다.

## 무엇이 실제 자료인가

SEISMIC 저장소에 포함된 hemibrain v1.2.1 EPG/PENa/PENb/PEG 연결표의 일부 행을 사용한다. bodyId, 세포형, instance, 좌우와 PB index 주석, ROI별 연결량은 원자료에서 온다. A에 포함된 98개 ID는 전체 뇌가 아니며, 그들 사이의 모든 연결조차 포함한 것이 아니다. 3개 연속 행 구간을 편의상 추출한 **편향된 발췌**다.

상세 계수: EPG 45, PENa 19, PENb 21, PEG 13. ROI 행 192개를 같은 방향성 뉴런 쌍으로 합산해 177개 연결을 만들고, count 합은 3,747이다. 수치는 공개 표에 있는 시냅스 count이며 ANN 학습 가중치나 전도도가 아니다.

## 무엇이 설계인가

| 부분 | 설계 가정 |
|---|---|
| 세포 신호 | 0~1 연속 활성도. 활동전위/전압/칼슘 아님 |
| 시간상수 | 실제-ID 노드 대부분 0.11 s, PEG 0.28 s; 실측 적합 아님 |
| 연결 부호 | A에서는 발췌 연결 모두 양수로 사용; 수용체별 부호 미검증 |
| 연결 스케일 | sqrt(count), 수신 노드별 합으로 정규화, 전달 gain 0.30 |
| 방향 선호 | `(indexFix-1) mod 8`을 8방향으로 임의 대응. 해부학 주석에 근거한 표시/모형 가정이며 실측 선호 각도 아님 |
| 방향 관측기 | HD 16개 보조 노드와 스칼라 각도 상태; 회전율 적분+시각 기준 보정 |
| 누락 회로 입력 | 방향 bump와 설계한 바이어스를 외부 입력으로 주입. 누락 생물학적 입력을 복원한 것은 아님 |
| 조향 | GOAL 16, PFL3-L/R 각16, DN2의 설계한 방향 차 읽기 |
| 감각/높이 | SENSE4, ALT2; 실제 해당 세포형이라는 의미 없음 |
| 탐색 | seeded 목표 갱신과 좌우 냄새차, 근접 회피의 명시적인 정책 |
| 몸 | 운동학적인 3D 속도/회전·높이 제어. 몸은 실제 스캔이 아닌 도식 |

## 계산 개요

각 뉴런의 이전 활성도를 a_i, 정규화한 연결량을 w_ji라 할 때 실제-ID 부분의 재귀 입력은 다음과 같다.

```
w_ji = sqrt(count_ji) / sum_k sqrt(count_ki)
recurrent_i = graphGain * sum_j(w_ji * a_j)
```

각 노드는 목표값과의 차이를 지수 누설로 갱신한다.

```
a_i(t+dt) = a_i(t) + [clip(target_i + stimulus_i,0,1) - a_i(t)] * [1-exp(-dt/tau_i)]
```

실제-ID 노드의 target에는 방향 bump, 약한 재귀 입력, 느린 적응이 들어간다. 억제된 노드는 정확히 0으로 유지한다. 이 동역학은 훈련된 SEISMIC 모델의 가중치를 가져온 것이 아니라 **이번 프로그램을 위해 별도로 설계한 모델**이다.

EPG 출력은 주석으로 지정한 8개 방향 bin에 먼저 평균하고 circular population vector로 heading을 읽는다. 개체별 세포 수가 다른 것을 단순 총합으로 잘못 가중하지 않기 위해 bin 평균을 사용했다. 표시한 confidence는 이 벡터의 방향 집중도이며, 통계적으로 보정된 확률이나 정확도가 아니다.

조향은 항상 `yawRate = clip(3.5*(DN_R-DN_L),-3,3)`를 통해 나온다. 실제-ID EPG 활성은 heading 해독 및 전진 drive에 영향을 준다. 실제 연결 재귀 전달을 끄면 다른 상태/경로가 나오는지 테스트했다. 그러나 HD와 기타 보조 계산은 그대로 남으므로 **연결 전달 차단이 전뇌를 제거한 조건은 아니다.**

## 감각 모형

시각은 64방향의 단일 원거리 기준 반응이다. 물체의 실제 렌더링 영상, 광류 회로, T4/T5, 복안 광학은 사용하지 않는다. 월드의 표시 기준 기둥은 그 방향성 cue를 시각화한 것일 뿐, 유한 거리의 기둥에 대한 실제 망막 영상과 동일하지 않다.

자기 회전 입력은 몸 yawRate에 잡음을 더한 이상화된 센서다. 좌우 냄새는 머리 주변 두 점에서 Gaussian 농도장을 표본화한 것이다. 장애물 회피는 9개 거리 광선과 접촉을 사용한다. 거리 광선은 실제 초파리에게 그러한 센서가 있다는 주장이 아니다.

몸/환경의 정답 좌표는 SensorAdapter가 관측을 만들 때만 쓴다. NeuralController는 그 좌표나 true yaw를 직접 받지 않는다. 목표 높이는 하향 센서에 대한 명령이므로 바닥이 아닌 장애물 위에서는 그 위로 올라갈 수 있다.

## 몸과 공간

x-z는 수평, y는 높이. mm/s/rad 단위는 설계 공간의 단위이며 몸 크기·속도·공기역학 파라미터를 실제 개체에 적합한 것이 아니다. 날개 주기와 보행 다리 궤적은 보기에 알맞은 애니메이션이다. 이 모델을 실제 날갯짓 주파수나 보행 힘 측정에 사용하면 안 된다.

구형 장애물과 경계에서 몸의 중심 위치를 보정한다. 정확한 몸통/다리 메시 충돌과 유체 계산은 없다. 몸의 heading을 회피 방향으로 몰래 덮어쓰는 기하학적 조향은 하지 않는다. 겹친 장애물·특이 환경에서 접촉 보정은 물리적으로 정밀하지 않을 수 있다.

## 학습·예측 범위

온라인 시냅스 학습, 강화학습, JEPA, 미래 장면 예측, 좌표 기반 세계 지도, 물체 영속성, 경로 계획은 없다. 느린 적응 상태는 동역학 일부이지 학습 알고리즘이 아니다. HD는 보조 관측기이므로 본 모델의 암전 실험을 순수 커넥톰 기반 ring attractor의 생물학적 입증으로 해석해서는 안 된다.

## 검증 해석

단위 테스트는 코드·수치·재현성을 검증한다. 대조 실험은 이 코드에서 개입이 인과적 차이를 만드는지 검증한다. 실제 파리 영상, 생체 뉴런 기록 또는 생물학적 개입 데이터에 대한 적합성 검증은 수행하지 않았다. 따라서 이 프로그램의 지표를 생물학적 추정치로 보고하면 안 된다.

B/C로 확장할 때에는 회로 경계 입력, 수용체별 부호, 신호 모델, 물리 파라미터, 실제 행동/신경 기록에 대한 독립 검증을 추가해야 한다.
