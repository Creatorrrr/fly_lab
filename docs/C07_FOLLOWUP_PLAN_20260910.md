# C0.7 후속 구현: 단일 관절 신경–근육 폐루프

이 범위는 M2의 국소 장치와 원인 규명이다. 기존 C0.7 ZIP·원자료와 앱의 42관절 목표각 프로파일을 보존한다.

1. 원본 14자유도 모델의 다른 관절을 keyframe 자세에 둔 상태와 파생 1자유도 장치를 전 범위에서 비교한다. 힘줄 길이 유한차분, site 경로의 독립 해석 미분, MuJoCo 모멘트암을 대조한다. 오류 기준은 해석/원본 1e-9, 유한차분 1e-8이다. 부호 전환점을 계산하고 제공된 0002 동작 clip의 범위와 비교한다. 한 clip을 생리적 가동 범위로 간주하지 않는다.
2. 새 `flylab.single-joint.v1` 실험 프로파일에서 BANC v888의 실제 빠른 굴근/신근 운동뉴런을 각각 하나의 Hill actuator에 연결한다. 원 논문이 빠른 Fe–Ti 근육을 모델링한 범위에 맞추고, SETi와 accessory motor는 신경 계산에 남기되 이 장치의 직접 출력에서 제외한다. ID·출처·역할을 manifest에 기록한다. BANC 전체 그래프를 계산한다.
3. `u = rate / (100 Hz + rate)`를 초기 모집 가설로 고정한다. 근육 자체의 활성화 지연을 유지하고 추가 position servo/CPG는 넣지 않는다. 관절 관측→수용체 proxy→BANC의 기존 v2 claw/hook 방향 가설과 club 집단→신경 계산→두 근육 출력→물리의 순서를 명시한다. 신경 0.1ms, 물리 0.01ms, 제어/감각 1ms이며 모든 시계와 필터/지연 상태를 저장한다. 실제 감각 발화 tuning과 운동단위 모집 곡선을 측정했다는 의미는 아니다.
4. 시간 구간을 명시한 실제 뉴런 자극·억제, 피드백 차단/방향 교환/지연, 운동 출력 차단, 관절 외력을 지원한다. 모멘트암 반전은 매 물리 step에 감시하여 해당 실험을 중단하고 실패 상태를 보존한다. 힘줄을 자동 수정하거나 각도/활성도를 사후 조정해 성공으로 바꾸지 않는다.
5. 실행 전 대조와 gate를 고정한다. 기본/피드백 차단/방향 교환/추가 지연/굴근 자극/신근 자극/두 운동뉴런 억제/운동 차단/양방향 외력/미사용 출발각을 검사한다. 기술 gate는 신경·물리 실행, 유한성, 활성 범위, 힘 투영, 시계 일치, 차단 의미, exact restore/replay다. 상대 운동 방향, 감각→운동 영향, 외란 회복은 별도 결과로 평가한다. 연결됐다는 이유로 안정화 효과를 PASS 처리하지 않는다.
6. 단위는 upstream model force/torque로 유지한다. SI 변환을 확정할 근거와 직접 측정 근육 파라미터는 부족하며, 미확정 사항을 별도 기록한다. 이 결과로 전신 근육 보행이나 완전한 가상 초파리 완료를 주장하지 않는다.
