## 움직이지 않는 이유

현재 geosmin v1에서는 감각 입력과 감각 뉴런 발화가 발생해도, 몸의 전진·회전에 연결된 DNp09·DNa02·MDN 출력군이 발화하지 않았다. 직접 출력 자극으로 몸이 움직이고 연결 차단으로 멈췄으므로, 이번 정지는 몸 표시나 운동 연결의 단순 단선으로 설명되지 않는다. 어느 중간 회로·세포 파라미터가 원인인지는 이번 검사만으로 확정하지 않았다.

기본 LIF는 휴지막전위 −52mV, 발화 문턱 −45mV다. 시냅스 입력이 없는 세포에 일정한 `drive_mV`를 주면 7mV보다 작은 입력만으로는 문턱에 도달하지 않는다. v2 기본 배치의 후각 입력은 약 5.48–5.73mV이며 무배경 초기 상태에서 발화 0이라는 관측과 일치한다. 복안·DoOR 모델에서도 포트 개수나 비영 입력만으로 운동 출력이 보장되지는 않는다. `channels.max_input`은 마지막 시점의 포트 간 최대값이고, 추가 상류 진단의 `peak_input_features`는 전체 실행 중 특징의 최대 절댓값이다.

따라서 C_STRICT는 **C 신경 출력만 몸에 적용하는 모드**이며, 어느 감각 프로파일에서나 반드시 걷게 만드는 설정은 아니다. 현재 FAFB 경로는 하행뉴런 발화율을 공학적 운동 명령으로 변환하고 CPG 보행기로 전달한다. 전체 신경·근육계의 생물학적 복원과 동일하지 않다. 안정적인 자연 탐색을 위한 감각 인코딩·출력군·회로 모델 보완은 아직 남아 있다.

## 수정한 결함

1. **감각 차단 캠페인의 잘못된 포트명**: 평균/4지점 프로파일에도 `odor_left/right` 또는 `danger`를 고정하던 준비 도구를 실제 선택된 바인딩 기반으로 변경했다. 감각 차단 선택자를 엔진과 사전 검사에서 공유하며, 잘못된 포트는 물리 작업/출력 파일 생성 전에 거절한다. DoOR 전용 프로파일에 일반 먹이/위험 의미를 임의로 배정하지 않는다.
2. **위험 감각 차단 검증 누락**: 양측 위험 포트 중 일부 원시 기록이 빠져도 대조로 통과할 수 있던 검사를 보완했다. 모든 선언된 위험 포트의 비활성·0 값을 요구한다.
3. **Windows 기록 재생 인코딩**: 한글 환경 ID가 포함된 UTF-8 이벤트·캠페인 기록을 시스템 기본 인코딩으로 읽던 문제를 수정했다. cp949 환경을 재현한 회귀 검사로 확인했다.
4. **감각 프로파일 목록**: 특정 프로파일을 명령행으로 지정해 서버를 시작하면 `bindings.json`이 목록에서 사라지던 문제를 수정했다.
5. **실험 상태 표시**: 계산 전, 감각 입력 0, 감각 입력은 있으나 운동 출력 0, 운동 뉴런 활성은 있으나 최종 명령 0, 연결 차단·고정 몸 등을 구분해 표시한다. DoOR 물질 미지정과 후각 지점의 농도 0도 안내한다. 이 표시는 계산이나 명령을 변경하지 않는다.
6. **재현 도구**: `tools/verify_c_strict.py`에 실제 신경·몸을 사용한 프로파일별 입력/운동 차단·직접 자극·먹이 진단을 추가했다. 기술 실행 성공과 과제 성공을 별도로 기록한다.
