# E279: 실제 전달 진단은 완료, 보행 후보는 미채택

E277의 동일 계수를 실제 CUDA 전체 BANC와 FlyBody에 연결해 초기 0.5초를 확인했다. 중립 동작은 기존 E150 원본과 정확히 일치했다. 후보는 넘어짐·몸통 접촉 없이 실행됐지만 시작 구간 최대 관절 명령 오차가 **0.0408695 rad**로 고정 상한 **0.04 rad**를 넘었다. 정해 둔 대로 추가 보행 실행을 중단했다.

학습 당시 조건부 최대 오차의 여유는 약 0.00000390 rad뿐이었다. 작은 실제 전달 차이가 경계를 넘었고 15개 위반이 여섯 다리에 분포했다. 이는 초기에 큰 구현 불일치가 있었다는 설명을 지지하지 않는다. 다만 학습 오차 개선 20% 및 LM 개발 기준도 E277에서 이미 실패했으므로, 여유만 늘리는 수정으로 보행이 해결된다고 볼 수 없다. 기존 기준을 유지하고 마지막 학습 방향과 제약이 학습을 어떻게 제한했는지 검토한다.

실행 경로에서 발견한 디스크/메모리 비교 오류는 수정했다. tuple/list 저장 표현만 맞췄으며 수치 허용오차·배열 dtype/bytes·상태 필드를 완화하지 않았다. 생성 검사 26개와 Ruff, root 원자료 검산을 통과했다. 구현·첫 수정은 gpt-6-sol/high, 첫·두 번째 검토와 잔여 저장 표현 수정은 root가 수행했다.

원본 실행 38.6761초, 누적 7823.2756/7905초, 잔여 81.7244초다. E278의 사전 과학 실행 실패와 비용도 보존했다. 최종 F1–F8 및 자연스러운 생물학적 보행은 미완료이며 후보를 제품에 채택하지 않았다.
