실제 gpt-6-sol/high 구현 → 부모 FIRST → 같은 Sol 첫 수정 → 부모 SECOND를 거쳐 조건부 학습 한 번을 완료했다. 두 결함(네 신경 배열 검증, 오류 종료 시 원자료 보존)을 수정했고 부모 생성 decoder/adjoint 및 활성 벌점 기울기 검산, 집중 시험 2개와 Ruff가 통과했다. 원본 결과의 독립 검산도 통과했다.
