# E150 차단 검증의 출력 범위 오류 수정

E150 원본은 10초 main 및 저장 상태 clone 0.1초를 완료했지만, 이어진 motor-cut 첫 제어에서 검증 코드가 중단되어 전체 실험은 incomplete다. 이 판정과 원자료를 유지한다. 10초와 clone의 별도 저장자료 감사는 2,872개 검사를 통과했으며 전체 E150 성공으로 바꾸지 않는다.

부모 FIRST 리뷰에서 힘줄 이름이 정확히 6개여야 한다는 조건을 요구했고, 부모 SECOND 리뷰에서도 이 가정을 놓쳤다. 실제 `BancWalkingSession`은 모든 신체 힘줄에 0.2를 초기화하고 96개 다리 근육 adapter가 여섯 LTM만 갱신한다. 따라서 `abdomen_pitch`, `abdomen_yaw`의 기존 자세 유지값 0.2도 실제 출력에 남는다. 이는 부모 요구와 리뷰의 오류다.

부모 잔여 수정은 검증기만 바꾼다. 여섯 다리 LTM의 차단값은 정확히 0, 복부 두 값은 원래 0.2, 전체 이름 집합은 정확히 이 8개여야 한다. 모든 값의 유한성, bank 및 두 activation의 0, 42개 neutral target, 실제 neural/physics clock, 건강 조건은 유지한다. 새 힘줄 추가나 복부 값 변경은 실패다. 신경망·신체·행동 출력·실험 기준은 바꾸지 않는다. 생물학적 복부 제어를 구현했다는 의미도 아니다.

실제 실행 소스는 `verification/banc-natural-gait-m3-20260919/e150-executed-source/`에 원래 SHA와 함께 보존했다. 현재 검증기 소스는 실행 후 수정본이므로 과거 source gate로 추가 원본 실행을 허용하지 않는다. 30개 생성 테스트와 저장된 첫 cut 행의 형식 검증은 통과했지만, 아직 수행하지 않은 나머지 cut/restart를 성공으로 주장하지 않는다.

추가 확인은 별도 E151 동결 후 이미 사용한 1초 checkpoint에서 동일한 4 cut + 16 restart만 실행한다. E150 main을 재실행하거나 후보를 다시 선택하지 않는다. E150 전체의 incomplete와 F4/F5 미달은 유지한다.
