# E327: 실제 신체에서는 보행 개선 기준을 통과하지 못함

E326에서 시작 자세 제약을 만족했던 동일 효능 변화 하나를 현재 BANC SSP 신경망과 실제 MuJoCo 신체의 감각 되먹임에 연결했다. 원본 실행은 유효하지만, 전진량·미끄러짐·연속 전진 구간·유효 주기 기준을 통과하지 못해 후보를 기각한다. 자연스러운 보행 및 M3 F1–F8은 미달이다.

명령 형태 손실은 기준 곡선까지의 거리이며 실제 관절 궤적의 자연스러움, 곡선의 반복 순회, 전진 협응을 직접 측정하지 않는다. 이번 결과에서 형태 오차 감소가 보행 개선을 보장하지 않았다는 점은 확인됐다. 반면 이 단일 비교만으로 감각 되먹임의 특정 연결이나 근육이 실패 원인이라고 단정할 수 없다. 유효 주기 0은 고정 평가기가 요구하는 전진 구간 안의 결과이며 다리 자체가 정지했다는 뜻도 아니다.

새 `SSPEfficacyTrial`은 E29 선택 가중치에 E326의 실제 f32 효능을 적용한 네트워크를 생성한다. 원래 전체 상태·신경 동역학·신체·adapter·감각 입력 경로를 유지하고, 변경 가중치에 대응하는 별도 네트워크 identity와 전체 체크포인트 정보를 남긴다. 실제 감각 입력을 사용했으며 저장된 감각 명령을 재생하지 않았다.

사용자 지정대로 actual gpt-6-sol/xhigh가 네 파일을 구현하고 현재 세션이 FIRST와 SECOND를 검토했다. 수정이 필요한 결함이 없어 R1은 없었다. 생성 CPU 7개 테스트와 독립 오류·비용·게시 검사 35개, 작은 실제 CUDA 네트워크의 새 효능 순방향 및 복원 재현 검사를 통과했다. 전체 신체 복원은 생성 fake 검사만 수행했으므로 실제 원본 복원·회로 차단 성공으로 주장하지 않는다.

단일 신체를 300 control / 6,000 neural tick / 15,000 physics step, 실제 시뮬레이션 1.5초 실행했다. 부모가 종료 후 원자료를 별도로 계산하여 2,015개 항목을 확인했다. 전체 CSR·원래 상태·시계·원장·source/input/output hash·고정 판정이 일치한다. 독립 감사는 3.6439555초이며 원본 모델·신체·CUDA 호출 0이다.

원본 감독 비용 57.66263619996607초를 한 번 합산했다. 누적 **9034.148870999521 / 9060초**, 잔여 **25.851129000478977초**, 활성 원본·예약 0이다. 같은 원본의 재시도, 새 theta, 최적화, 한도 증가는 없다. 이번 실험에 필요한 80초 감독 예약보다 잔여가 작으므로 추가 신체 검증을 이 배정 안에 시작하지 않는다. 저장 자료로 명령·실제 관절·접촉·전진 구간을 분리하는 E328 진단을 이어가며 기존 F1–F8, M2, UI, F6 비노출을 유지한다.
