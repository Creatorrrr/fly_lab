# BANC 보행 품질 M2: E76 최종 결과

2026-09-13 KST. **E76의 세 번째 후보를 `M2 보행 보정`으로 반영했다.** Q1/Q2/Q4–Q7 및 사용자 승인 개정 Q3를 통과했다. 개발 조건의 실제 하중 접촉점 미끄러짐은 M1보다 32.6%, 비교 가능한 확인 조건에서는 42.1% 감소했다. 원래 Q3의 두 조건 평균은 여전히 비교 불가이며 계산하지 않았다. 아래 E34와 후속 실패 기록은 당시의 판단으로 보존한다.

## 적용된 모델과 검증 결과

[M2 설정](../configs/banc-walking/m2-calibrated-v1.json)은 동결된 E76 p03와 바이트 단위로 동일하다(SHA256 `d3664dedd79d8dd97ee0355156ec4c5a31347c6112883aa60daef7fc08830b66`). E34의 신경 적응 gain 8 / tau 0.3초, 관절 출력 응답 90ms, coxa yaw의 기존 30ms 응답에 **여섯 다리에 공통인 coxa roll 변환 gain 1.15**를 적용했다. 나머지 여섯 축 배율은 1이다. 실측 근력의 복원이 아니라 고정된 신경–몸 인터페이스의 공학적 보정이다.

전체 BANC 158,706개 뉴런·11,584,852개 연결과 CUDA 계산, 신경 0.25ms / 물리 0.1ms / 감각·운동 5ms를 유지한다. 감각·회로·몸의 구조와 부착 정책을 새로 바꾸지 않았다. 외부 CPG, 다리 움직임 각본, 몸통 위치 보정, 주기적 신경 초기화는 사용하지 않는다. 복부의 기존 고정 긴장도는 남아 있으며 모든 신체 출력을 BANC가 생물학적으로 생성한다는 의미는 아니다.

## 실행과 보존

개선판은 [8771 화면](http://127.0.0.1:8771/)에서 실행한다. BANC 패널의 **다음 목표 실험 설정 → M2 보행 보정 → BANC 목표 보행 실험 만들기 → BANC 재생**을 사용한다. 상단의 일반 재생·감각 자율 보행과 별도의 실험이다. M2 초기 저장 상태는 `banc-d38451c7f2aa`, 10.005초 도달 후 상태는 `banc-8712942239b5`이며 `verification/banc-gait-quality-m2-20260912/e76-ui-artifacts/banc-walking-checkpoints/`에 있다.

다음 선택값과 현재 모델을 구분한다. 실제 복원된 숫자 설정에서 현재 이름을 판정하고, M1 선택 상태에서 M2 저장을 복원해도 **현재 모델: M2 보행 보정**으로 표시한다. 일반 BANC 기본값·이전 RPC·저장 형식은 유지했다. 기존 일반/목표 M1 각각 10모델초에서 control별 운동 출력·전체 물리 및 최종 전체 상태가 동결 소스와 정확히 일치했다.

기존 **8770 실행 서버와 제어 연결은 그대로 보존**했다. 그 제어 webview가 이번 CUA 목록에 노출되지 않아 두 번째 연결은 409로 거부됐다. 최신 RAM을 복사했다고 주장하지 않는다. 기존 저장 파일 15개만 별도 검증 폴더로 복사해 hash를 확인했고, 새 서버를 8771에 띄웠다. 구 서버가 새 HTML을 제공하더라도 기존 M1 요청을 사용할 수 있도록 이전 RPC 호환 분기를 유지했다. 커밋·푸시·병합은 하지 않았다.

[실제 메시와 측정 자세 비교](http://127.0.0.1:8774/comparison.html)는 기록만 재생한다. 444프레임, 50FPS 실제 MuJoCo 메시의 분절 위치 오차는 0이며, 별도 105ms 고빈도 구간의 명령 재실행도 정확 일치했다. 이 영상·5ms 표시값은 v2 품질 판정을 대신하지 않는다. 일반 정적 파일 서버의 MP4 탐색 문제는 byte-range를 지원하는 별도 로컬 영상 서버로 해결했다.

## 한계와 재현 근거

이는 **고정 평지 목표에서의 미끄러짐·도달·정지 개선**이다. 생물학적으로 자연스러운 tripod 협응, 실제 후각·복안만으로 목표 발견, 새로운 지형·외란·다른 개체에 대한 일반화는 검증하지 않았다. Q3 두 목표도 이미 노출된 회귀 조건이다. 정확한 목표 방향·거리 감각과 보정된 신경 입력을 사용한다. 계산 속도는 약 0.238모델초/실제초로 여전히 실시간보다 느리다.

E76은 사전에 기록한 최대 11개 신규 후보 중 최초 적격인 세 번째 점에서 중단했다. yaw/pitch 1.15 두 실패와 미실행 8개를 그대로 남겼다. 탐색 GPU 120.205모델초 / 553.6795실제초, v2 CPU 86.2221실제초, 전체 탐색 719.4405실제초다. 후속 검증 비용과 원자료는 별도 파일에 남기며 기존 E1–E75 실패를 성공 기록으로 고치지 않았다.

검증 폴더 `verification/banc-gait-quality-m2-20260912/`의 주요 근거:

- `e76-calibration/plan.md`, `selection.json`, `p03/quality/quality.json`: 사전 규칙·선택·개발 전체 물리 측정.
- `e76-q3-summary.json`, `e76-q3-fullstep/`: 승인 Q3 두 조건과 상대 비교 경계.
- `e76-q4-remaining/all-six-results.json`, `e76-q4-restart/restart_result.json`: 여섯 방향·재출발.
- `e76-q5/development/checks.json`, `e76-q6-timing/result.json`: 저장 미래·인과 차단·교대 비용.
- `e76-legacy-target/result.json`, `e76-legacy-general/result.json`: 기존 두 경로의 10초 동등성. 이 두 실행의 command replay 옵션은 꺼져 있으며 전체 native replay 근거와 구분한다.
- `e76-ui-artifacts/ui-trace.json`, `ui-numerical-result.json`, `e76-native/result.json`: 실제 UI 기록·초기/미래 재현·native 영상.
- `e76-final-manifest.json`: 최종 설정·관련 제품 소스·판정 자료 hash와 검사 목록.

제품 통합 검사는 Python 13개, 기록·재생 JavaScript 22개가 통과했다. 관련 Python 정적 검사와 JS 문법 검사, HTML 빌드도 통과했다. 재현 시 새 출력 경로를 사용하고, `tools/verify_c_banc_observation.py` / `tools/analyze_c_banc_substep_quality.py`의 사전 명령은 각 실행의 spec·source snapshot을 따른다.

## E34 및 E35–E75의 보존된 중간 기록

아래는 E34 판단 당시의 기록이다. 당시 목표는 **미완료**였고 E34는 기본 모델로 채택하지 않았다. 사용자 승인 Q3 개정 후에도 뒤쪽 목표의 도달·정지 실패가 남았다. 이후 E76의 최종 결과가 위에서 이를 대체하며, 아래 원래 Q3 비교 불가와 후보별 실패를 삭제하지 않는다.

## 구현과 직접 효과

전체 BANC 158,706개 뉴런과 11,584,852개 연결을 계속 계산한다. E34는 신경 적응 gain 8 / tau 0.3초와 관절 출력 응답 90 ms를 사용하며, 여섯 thorax–coxa yaw 관절의 응답은 기존 30 ms로 유지한다. [후보 설정](../configs/banc-walking/e34-candidate.json)에 명시적으로 저장했다. 새로운 옵션을 생략하면 기존 M1 연산과 모델 식별·체크포인트 형식을 유지한다.

외부 CPG, 시간에 따른 다리 각본, 몸통 위치 보정은 사용하지 않는다. 부착 규칙과 최대 힘은 원래 모델과 같지만 관절 목표·감각 피드백이 달라져 실제 부착 시퀀스는 달라질 수 있다. E34는 근육 생리를 실측해 복원한 모델이 아니다. 목표 감각은 정확한 방향·거리의 이상적 입력이다.

미끄러짐은 실제 하중이 0.02 BW 이상인 발 접촉점의 상대 접선 속도를 각 다리에서 평균한 뒤 여섯 다리를 같은 비중으로 평균한 값이다. .5초 이후부터 첫 제동 명령 직전까지, 최대 10초의 고정된 이동 창에서 **모든 0.1 ms 물리 단계**를 측정했다. 두 모델의 기록된 미래와 종점 접촉값이 정확히 일치하는 재실행으로 검증했다. 5 ms 종점만 측정하면 빠른 접촉 충격을 놓치는 편향이 있어, 그 결과와 개정 전 평가기 모두 따로 보존했다.

E34 검증 당시 소스에서 옵션 누락 시 보관한 M1과 **목표 보행 10초와 일반 보행 10초 각각** 2,000개 제어의 운동 출력·전체 물리 상태·최종 전체 저장 상태가 비트 단위로 일치했다. 당시 관련 단위/물리 테스트 44개가 통과했다. 후속 변경의 검사는 아래에 구분하며 테스트 통과를 보행 품질이나 생물학적 타당성으로 해석하지 않는다.

Q6는 같은 초기 물리 상태에서 워밍업 후 순서를 번갈아 다섯 쌍 측정했으며, 각 모델 안에서 반복된 신경·물리 미래도 정확히 같았다. 다른 실험은 함께 실행하지 않았다. 약 0.24모델초/실제초의 계산 속도와 50 FPS 기록 영상 재생은 서로 다른 값이다.

[로컬 비교 페이지](http://127.0.0.1:8773/)에는 M1/E34 실제 메시 영상, 같은 시각 이동, 1×/0.25× 재생, 품질 지표와 후방 실패 궤적이 있다. 브라우저에서 재생과 탐색·정지를 직접 확인했다. E34 423프레임의 렌더된 분절 위치는 기록된 실제 위치와 오차 0 mm였으며, 별도 MuJoCo 데이터에서 표시만 재구성했다. M1 영상의 원자료(`e1-target`)와 수치 기준선(`e1-final-target`)은 2,001개 전체 qpos/qvel/ctrl/목표/부착 상태가 정확히 같음을 확인했다. 비교 페이지는 신경 계산이나 물리 적분을 실행하지 않는다.

8773은 이번 비교 파일 폴더만 제공하는 로컬 서버다. 기존 8770 시뮬레이션과 8772 비교 서버는 재시작하지 않았다. 소스 변경을 커밋·푸시·병합하지 않았다.

Q3는 처음 고정한 두 목표를 모두 노출한 상태다. 앞으로 후보 선택에 이 결과를 사용하면 같은 목표를 새 독립 확인이라고 부르지 않는다. 기존 모델의 실패를 제외한 평균, 실패 뒤의 0 보충, 관측창 단축으로 Q3를 통과시키지 않았다.

## 남은 결정

뒤쪽 선회는 원래 30초 도달·정지 기준을 유지해야 한다. 첫 10초 실제 yaw 변화는 M1 3.374 rad, E34 1.688 rad로 후보가 약 절반이었다. 이는 기록된 폐루프 결과의 차이이며 특정 필터 하나가 원인이라는 분리 실험은 아니다. E34의 개선율만으로 현재 기본 경로를 교체할 수 없다. 다음 개발은 느린 근육 응답과 선회 운동의 상충을 해결하는 구조를 대상으로 하며, 실패한 후보의 시간상수 격자를 확대하지 않는다.

이 보고서의 최초 결정 시점에는 M1이 두 확인 목표 모두 정상 완주한다는 전제가 틀렸으므로 Q3 수정안 합의를 요청했다. **비교 가능한 조건에서는 30% 품질 개선을 그대로 요구하고, 기준선이 실패한 조건은 후보의 도달·정지 성공을 별도로 요구**하는 안이다. 사용자는 이후 이를 승인했으며 아래 재개 기록부터 적용했다. 원래 Q3 미충족 기록과 개선율의 범위는 보존하고, 승인 자체를 목표 완료로 판정하지 않는다.

실험별 사전 가설·실패·자원·보관 경로는 [목표 계획](BANC_GAIT_QUALITY_GOAL_PLAN_20260912.md)에 남겼다. 원자료는 `verification/banc-gait-quality-m2-20260912/`의 `e34-fast-coxa`, `e34-fullstep`, `e34-q3`, `e34-q3-fullstep`, `e34-q4-matrix`, `e34-legacy-target-parity`에 있다. 기존 8770 세션은 보존했다.

## 후속 선회·감각 개선 검증

E34를 동결한 뒤 선회 입력과 누락된 감각 입력을 분리 시험했으나, 원래 공동 목표를 통과한 새 후보는 나오지 않았다.

| 시험 | 결과 | 채택 |
|---|---|---|
| E35 단일 DNg105 추가, 후방 5초 | 올바른 yaw 0.631→0.881rad, 거리 8.724→8.026mm, 정상 자세 | 선행검사만 통과 |
| E36 큰 방향 오차에서만 DNg105 추가 | 31.5초 최소 거리 2.355mm, 도달·정지 실패 | 거부, 새 항법 코드는 연구 기록에 보존 후 철회 |
| E39 E34 + 앞다리 한계 감각 | 미끄러짐 36.6% 감소, 첫 도달 7.245초로 늦어지고 이동 속도 기준 실패 | 거부 |
| E40 M1 + 같은 앞다리 한계 감각 | 이동·도달·정지 기준 통과, 미끄러짐 9.6% 증가 | 거부 |

현재 감각 입력에서 제외된 hair plate 뉴런을 조사했다. [Pratt 등(2026)](https://www.nature.com/articles/s41467-026-69333-z)의 CxHP8 식별 근거인 ventral prothoracic nerve와 로컬 기관·앞다리 coxa·좌우 주석을 교차 확인하여 좌우 8개씩을 선택했다. 이름만 CoHP8이지만 다른 부위·신경 주석을 가진 9개는 포함하지 않았다. 원본 SNpp45/SNpp52/CoHP8 유형과 ACH 예측, 신경 연결을 유지했다. 실험으로 확인된 NT라는 주장은 하지 않는다.

새 `front_hair_plate` 옵션은 측정된 앞다리 coxa 관절 위치를 기존 물리 방향 보정으로 전방 변위로 바꾸어 입력한다. 0.5rad 범위·144 입력 강도·20ms 필터·1제어 지연은 명시적인 공학적 모델이며, 논문의 회전·내전 결합 튜닝을 복원한 것이 아니다. 입력 강도 18의 선행검사는 반응 문턱에 못 미쳤고, 관측된 억제 전류를 근거로 한 차례 144로 보정한 시험에서 양측 반응이 확인됐다. 이 신경 반응을 보행 개선으로 판정하지 않았다.

옵션은 기본적으로 꺼져 있다. E39 정식 경로의 첫 400개 운동 출력·401개 위치/yaw와 2초 전체 물리 상태는 선행 시험과 정확히 일치했다. 새로운 단위검사를 포함한 28개 테스트, 실제 저장 adapter의 복원, 고정 신체에서 8회 감각 미래 재현, 별도로 명시한 합성 고입력 상태의 복원·감각 차단·범위 거부 검사도 통과했다. 전체 신경망 저장 미래에 대한 새 Q5 통과를 뜻하지 않는다. 미끄러짐 평가는 같은 고정 v2 평가기에서 모든 물리 단계를 재실행했다.

새 옵션과 소스는 후속 연구를 재현할 수 있도록 남겼지만, E39/E40 설정은 채택 후보가 아니다. 이 단계에서는 일반화 판정 변경안이 사용자 답변 대기 중이었으며, 승인으로 간주하거나 목표를 완료 처리하지 않았다. 이후 실제 승인과 후속 결과는 아래에 구분한다.

E40 소스의 회귀 검증에서는 관련 단위·물리 테스트 **59개**가 통과했다. 해당 기본 경로와 보관 M1 소스의 목표 보행 10초씩, 2,000개 제어 출력·전체 물리 상태·전체 최종 체크포인트도 정확히 일치했다(`e40-legacy-parity`). E35–E40 실험과 분석 작업은 모두 종료했고 기존 8770 세션을 재시작하지 않았다.

후방 선회 기록을 추가로 감사한 결과, 뒤쪽 방향 선택 문턱에서 명령이 반복 반전된다는 설명은 기각했다. M1/E34의 선회·제동·감각 차단 요청과 encoder hash는 처음 12.125초 동안 같았다. 처음 선회 요청을 끈 시각은 M1 12.13초, E34 27.575초였다. E34는 그 전까지 같은 방향을 계속 요청했으므로, 초반 실패는 반복 방향 전환으로 설명되지 않는다. 이 비교만으로 신경 적응과 근육 응답 중 하나에 원인을 귀속할 수는 없다. 원자료 해시·전환 목록·재현 스크립트는 `rear-direction-audit.json`과 `rear_direction_audit.py`에 보존했다. 추가 물리 실행이나 기본 모델 변경은 없었다.

정확한 Q3 변경 문구와 변경되지 않는 기준은 [사용자 승인 수정안](BANC_GAIT_QUALITY_Q3_AMENDMENT_DRAFT_20260913.md)에 정리했다. 원래 두 조건 평균은 여전히 계산 불가이며, 승인 후에도 뒤쪽 목표의 Q4 실패가 해소되기 전에는 후보를 채택할 수 없다.

승인 전에는 목표를 **blocked / 사용자 결정 대기**로 기록했다. 완료 처리는 하지 않았다. 원래 고정 M1의 물리 실패를 다시 확인했고, 동일한 Q3 판정 변경 대기가 세 연속 목표 턴에서 해소되지 않았다. 그 사이 독립적으로 수행한 E35~E40과 후방 방향 감사 결과는 보존했다. 대기 이유는 작업 시간이나 뒤쪽 선회 개발의 어려움이 아니라, 원래 Q3에 필요한 유효한 고정 기준선이 없고 이를 사후 변경할 승인이 없다는 점이었다. 이 시점의 담당 연구자는 완료 상태였고 기본 실행 소스와 8770 세션을 보존했다.

## 사용자 승인 후 재개

사용자가 “승인할게 계속 해줘.”라고 명시하여 [Q3 개정](BANC_GAIT_QUALITY_Q3_AMENDMENT_DRAFT_20260913.md)을 적용하고 같은 M2 개발을 재개했다. 원래 Q3 미충족 기록은 유지한다. E34는 승인된 Q3에서는 두 확인 조건을 통과하지만, 뒤쪽 목표 Q4가 실패하므로 최종 채택하지 않는다. 다른 기준과 누적 실험 이력·자원은 바꾸지 않았다.

E41은 기존 두 변경을 분리해 뒤쪽 선회를 비교했다. 네 경우 모두 초기 신체 전체 상태가 정확히 같고, 처음 11.175초의 encoder 요청도 같았다. 신경 적응만 바꾼 경우(8/.3, 모든 관절 30ms)는 13.56초, 근육 응답만 바꾼 경우(M1 신경, yaw 30ms/나머지 90ms)는 26.49초에 안정 도달하여 정지까지 통과했다. 기존 M1은 20.3초, 두 변경을 합친 E34는 실패했다. 이 결과는 신경 변경 단독을 느린 선회의 원인으로 보는 설명을 지지하지 않으며 두 변경의 폐루프 상호작용을 보여준다.

E42는 근육 응답만 바꾼 설정을 개발 목표에서 검사했다. 실제 미끄러짐은 43.2% 줄었으나 첫 도달 11.79초, 이동 속도 52.3%, 접근 속도 55.3%로 Q2가 실패했다. 따라서 뒤쪽 목표 성공만으로 채택하지 않았다. 전체 95,000개 물리 단계가 원기록의 미래와 정확히 일치했다.

E43은 signed 관절 목표의 증가 응답은 90ms로 유지하고 neutral 쪽 해제는 30ms로 처리하는 명시적 옵션을 구현했다. 반대 요청은 정확한 영점 교차까지 해제한 뒤 새 방향의 증가 응답을 적용한다. 이는 생리적 근육 모델이 아닌 공학적 목표 동역학이다. 기존 yaw 6축, 기본 옵션 누락 시 계산, 저장 offset, 즉시 운동 차단 경계를 보존한다. 단위검사 7개가 해석적 해답·분할 적분·부호 대칭·유계·복원·차단·yaw 산식 보존을 확인했고 관련 묶음 30개도 통과했다. 개발 도달·정지는 성공했지만 첫 도달 7.32초와 이동 속도 약70.3%로 Q2가 실패했다. 품질·속도 공동 목표를 통과한 개선으로 판정하지 않는다.

E43의 최종 전물리단계 결과는 미끄러짐1.779370196mm/s, 기준선 대비26.4%감소로 Q1도 실패했다. 평균 지지는114.2%, 접근 속도88.8%지만 이동 속도70.3%와 첫 도달7.32초로 Q2가 실패했다. 원기록과의 물리 미래는 정확히 재현됐다. E43은 구현 오류로 무효 처리한 실행이 아니라, 가설의 최종 효과가 기준에 못 미친 유효한 실패다.

E44는 반대 부호 요청에만 빠른 해제를 적용했다. 개발 조건 미끄러짐은1.591142404mm/s로34.2% 감소했고, 첫 도달6.42초·접근 속도101.2%로 Q1/Q2를 통과했다. 그러나 뒤쪽 목표는31.5초 후5.78147mm가 남아 Q4에 실패했다. 따라서 E44도 최종 채택하지 않았고 E34를 최선 보존 후보로 유지했다. 새로운 필터의 단위 계약을 포함한 관련68개 검사는16.030초에 통과했으며, 이를 보행 품질의 최종 성공으로 해석하지 않는다.

E45는 과거 오른쪽 선회에 유리했던 중간다리 IN08/IN19 입력을 E34의 큰 오른쪽 선회에 추가했다. 같은 전체 시작 상태에서5초 yaw가0.63051→0.49933rad로 감소하고 방향차가 커졌다. 따라서 기존 짧은 실험의 효과가 E34로 전이되지 않은 것으로 기록하고, 정식 항법 옵션으로 도입하지 않았다.
