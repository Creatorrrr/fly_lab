## 종료 감독 실패는 보존함

원본 child는 exit0·88.908844초로 완전한 관측을 저장했지만, driver는 종료 직후 `unexpected_live_descendant`로 실패했다. 최종 정리의 terminated/alive/errors는 모두 빈 목록이었고, 부모의 PID+생성시각 감사에서도 원래 소유 프로세스34개가 모두 absent였다. 최초 순간 검사에 잡힌 PID는 당시 코드가 기록하지 않았으므로 정확한 OS 원인은 단정하지 않는다.

원본 driver 판정은 **실패 그대로** 보존했다. 원본을 재실행하지 않았다. 새 힘 값의 분석 전 `BANC_M3_E185_SAVED_RAW_REVIEW_ADDENDUM_20260924.md`에 정확재현·완전한 원자료·실제 강제종료0·남은 프로세스0·resource오류0·기존 예산 준수 조건을 고정하고, 별도 gate 아래 저장 자료 분석만 수행했다. 이 검토가 원래 driver를 PASS로 바꾸지는 않는다.

실행 후 부모는 감독 코드가 자연 종료와 실제 강제종료를 구별하도록 보완했다. 순간에 관측된 PID도 기록하며, 최종 정리에서 PID를 하나도 종료하지 않고 남은 PID/오류가 없을 때만 자연 종료로 처리한다. 실제 종료한 자식이 있으면 계속 기각한다. 이 후속 수정은 합성 회귀로만 검증했으며 새로운 native 실행은0이다. 원본 실행 소스는 `e185-parent-final-source/`에 보존했고 소진된 원래 source gate를 재사용하지 않는다.
