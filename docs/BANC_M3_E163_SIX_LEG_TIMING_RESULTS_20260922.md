# E163 여섯 다리 출력·제동 시점 진단 결과

2026-09-22. 저장 자료 진단은 유효하게 완료했다. **후반부 신경 리듬의 상대 관계는 강하게 유지되지만, 전진 속도 저하는 주기당 두 위상에 반복된다.** 이 결과는 보행 원인이나 개입 효과의 입증이 아니며 후보를 채택하지 않는다. M3 전체 F1–F8은 미완료다.

원본 분석 1회/자동 재시도 0, 신체·신경·물리·fit 0이다. 부모 설계 → 실제 Sol/medium 첫 구현 → 부모 첫 리뷰 → 같은 Sol 첫 수정 → 부모 두 번째 리뷰 → 부모 잔여 수정 순서로 진행했다. 마지막 저장 중 자원 한도를 넘는 경우의 성공 기록과, 실패한 사후 해시 확인을 성공처럼 표시하는 문제를 부모가 수정했다. 생성 자료 30개 테스트, 독립 오류 경로, 원본 저장 자료 207개 수치 비교를 통과했다. 검증 수를 별도 보행 실험 수로 세지 않는다.

## 확인한 관계

모든 15개 E1 쌍 중 12개가 세 고정 창의 시간 일관성 기준을 만족했다. LM–RH, LH–RF, RF–RH는 초기 결집 부족 또는 창 사이 위상 이동 때문에 미달이다. **[5,10) 후반 창에서는 15개 쌍 모두 R≥0.99306**이다. 안정적인 관계가 곧 추진에 적합한 관계라는 뜻은 아니다. 정확한 tripod를 새 완료 기준으로 추가하지 않았다.

위상은 first minus second modulo 1, 여섯 다리가 모두 실제 peak 사이인 query만 사용했다. 창별 공통 표본 수는 80/100/185다. E1의 다리 대응은 E37 직접 MN 투사에 근거한 소프트웨어 할당이며, E1 자체의 실측 effector annotation은 아니다.

기존 E152의 속도 하향 crossing 46개와 ±.1초 창을 정확히 재현했다. [5,10)에서 사건의 1차 원형 결집 R은 .08996–.10101인 반면 2차 R은 .90153–.91131이다. 이는 한 주기의 서로 반대되는 두 부근에 속도 저하가 모이는 기술 통계다. 겹치는 창과 반복 사건은 독립 생물학 표본이 아니다.

signed force 자료는 **1–2초뿐**이다. 온전한 ±.1초 native 창을 가진 사건은 1.280/1.540/1.725초의 3개다. 이 세 사건에서 전진 방향 음의 힘 적분은 사건 전 RF가 평균 .01417919 BW·s, 사건 후 LF .00687728/RM .00586905 BW·s였다. 부호별 적분은 100µs 원자료에서 나눈 뒤 합산했으며 블록 평균에 먼저 부호를 적용하지 않았다. 이 작은 초기 표본을 후기 또는 모든 정지의 근육별 원인으로 확대하지 않는다.

## 다음 개발 판단

E93 목적함수에는 세 좌우 쌍만 있고 동측 위상은 없다. 다만 같은 coupling 경로의 E59/E61/E62 실패와 E106 timing-only 실패가 이미 존재한다. E107에서는 own-leg reference shape만 바꿔도 모든 다리의 적격 주기가 회복됐으며 추가 reference timing은 필요하지 않았다. 따라서 E163의 동측 차이를 이유로 같은 coupling fit을 곧바로 반복하지 않는다.

다음 설계는 **현재 신경 리듬과 해부학적 연결을 유지하면서, 각 다리 출력 파형의 남은 오차를 줄일 전달 가정**을 검토한다. 기존 양수 EMA 혼합·활동 수준별 단조 전달과 구별되는 활동 상승 응답이 있는지 과거 구현을 먼저 대조한다. 새 파형 전달은 같은 MN의 현재·과거 상태만 사용해야 하며, 외부 phase/time/teacher가 최종 실행에 들어가면 안 된다. 구체적인 식·초기 제약·후기 비교·단일 solver·자원은 다음 첫 평가 전에 별도로 고정한다. 보행 품질은 이후 실제 전체 BANC/FlyBody와 F1–F8로 확인한다.
