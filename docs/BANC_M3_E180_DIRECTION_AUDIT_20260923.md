# E180 방향 점검: 근육 자산 범위와 실제 폐루프 평가

부모 설계 검토와 실제 gpt-6-sol/medium의 독립 읽기 감사 결과다. 원본 신경·운동 배열이나 새 모델 실행 없이 소스와 기존 결과 문서를 대조했다.

## 근육 모델을 여섯 다리에 바로 적용할 수 없는 이유

설치된 `flygym/compose/fly/musculoskeletal.py:3-18,90-98`은 왼쪽 앞다리만 근육으로 구동하는 별도 FlyMimic 모델을 선택한다. `best_combined_arm_damping_stiff_cvt3.xml:517-543`에는 LF 공간 힘줄 15개와 muscle 일반 액추에이터 15개가 있다. 다른 다리의 관절은 존재하지만 대응 근육 경로가 없고 잠금 제약이 있다. 현재 FlyBody 위에 더하는 모듈이 아니다.

`flylab/c/muscles.py`는 이 자산에서 LF tibia 굴근/신근 두 개를 남긴 1자유도·접촉 없는 고정 실험기다. 길이는 mm, 시간은 s이며 힘은 원본 모델 단위다. SI 환산과 생리적 힘 교정은 미완료다. 원본의 빠른 활성 시정수 때문에 이 fixture는 물리 간격도100us에서10us로 줄인다. 현재 여섯 다리 42개 위치 서보와 동일한 물리 계약으로 취급할 수 없다.

MuJoCo의 근육은 활성뿐 아니라 힘줄 길이·속도, 정상 길이와 최대 힘에 의존한다. 원본 두 근육의 상수만 가져오면 여섯 다리의 기하와 힘 전달이 정의되는 것은 아니다. [MuJoCo 공식 근육 모델 설명](https://mujoco.readthedocs.io/en/stable/modeling.html#muscles).

## 이미 시험한 기계적 변화

`docs/BANC_GAIT_QUALITY_GOAL_PLAN_20260912.md:209-216`의 M2-E24/E26은 활성 의존 강성을 시험했지만 전진 유지에 실패했다. 같은 문서383-385의 E58은 강성과 목표를 유지한 채 전체 감쇠를 C0*(1+s)로 바꿨다. 두 원본의 고정14개 물리 구간 대조에서 slip은 한쪽6.754% 감소, 다른 쪽5.203% 증가하여 사전 기준에 미달했다. 임의 감쇠 크기나 관절 부분집합 탐색으로 확대하지 않았다.

같은 문서408의 실제 서보 힘 분해에서는 큰 신경 항과 자세 복원 항이 대부분 상쇄됐다. 이것은 지지 평형일 수 있으며, 복원 항을 제거하면 기존 각도 명령을 잘못된 큰 힘으로 바꾸게 된다. 이 증거만으로 직접 토크 전환의 이득을 주장하지 않는다.

## 선택한 다음 방법

범위를 제한한 소스 검색에서는 E150 계열을 실제 물리 보행 목적함수로 적합한 도구가 확인되지 않았다. E169는 현재 폐루프에서 얻은 *저장* bank를 사용한 조건부 SOCP이며 물리 실행0이다. E150/E177은 완성된 후보의 실제 전달 검사, E162는 저장 명령의 신체 단독 비교였다. 저장 명령 오차와 실제 보행의 목적함수는 구별된다. 전체 저장소의 모든 시도를 부재로 증명했다는 주장은 아니다.

따라서 [별도 E180 사전 설계](BANC_M3_E180_NATIVE_OBJECTIVE_DESIGN_20260923.md)에 작은 모집 전달 변화와 실제 paired 3초 폐루프 평가를 정했다. 기존 양수/근육 합/개별 MN 하한과 fixed19를 보존하기 위해 원래 해부학적 pool 방향의1% 볼록 결합 한 값을 사용한다. 직접 gain을 임의로 곱하면 기존 기울기 예산 경계를 넘을 수 있으므로 별도 gain wrapper는 만들지 않는다. 이 변경은 학습된 모집 보정 강도에 대한 한 번의 공학적 개입이며 생물학적 근육 복원이나 최적화 완료가 아니다.

진단이 긍정적일 때도 같은 후보의 원래10초 F3–F5, F6/F7/F8과 실제 통합은 남는다. M2/UI/F6 및 이전 실패는 유지한다. 사용자가 지정한 gpt-6-sol을 실제 호출하고, 구현은 high, 이 소스 감사는 medium을 사용했다.
