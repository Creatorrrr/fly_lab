# E323: 전체 구간 미분은 실행됐지만 제안 방향은 기각

CUDA 초기화 순서를 고친 전체158706 BANC의 1.5초 조건부 신경 계산을 완료했다. 원래 감각 입력 300control을 사용했으며 신체 또는 최적화는 실행하지 않았다. 감독155.43890399998054초, 원본 누적8735.791969599613/9060초다. 저장 결과의 독립 NumPy 감사997개 검사가 통과했다.

추가 저장자료 분석에서 gradient L1=4737.0089, L2=400.7993이었다. 현재 미분이 예측하는 float32 효능의 인접 표현 한 쌍 차이조차 중립 손실의 약38.84% 규모다. 이는 선형화의 유효 범위가 아주 좁을 가능성을 시사하지만, 새 1ULP 실험이나 chaos의 증명은 아니다. 이전 E24/E25 장구간1ULP 실패와 E315 국소1ms 통과를 함께 보존한다. 이번 ±후보는 q 차이0.01rad에 각각0.10/0.12초부터 도달했다.

다음 검토는 같은 1.5초 미분에 더 작은 숫자만 넣는 반복이 아니라, 실제 기록의 내부상태에서 짧은 구간을 각각 시작하는 조건부 미분이다. 이 방식은 연속된 긴 미분의 민감도와 국소 미분의 실행 가능성을 구분하기 위한 것이다. 훈련 때 사용한 상태 재설정은 최종 자율 실행에 넣지 않으며, 제안된 고정 가중치는 별도로 재설정 없는 전체 실행과 신체 기준을 통과해야 한다.
