# E266: 기존 반대 위치 감각 입력의 전류 균형 가능성

M3/F1–F8은 그대로다. E265는 상수 보정 뒤의111970 입력 잔차가 여섯 SNpp50 감각 항의 시간 변화에 의해 지배됨을 보였다. 읽기 전용 소스 감사에서 port85는 LH SNpp50 23세포에 실제 기하학적 굴곡 `clip(flexion/pi,0,1)`을 복제하고, port86은 LH SNpp51 4세포에 보수 특징을 전달함을 확인했다. 이 극성은 기존 전이 가설이며 BANC 튜닝 실측이 아니다. 좌표/필터 구현 오류는 없었고, E246의 필터 표현 통과 및 E262의 작은 양의 반환을 보존한다.

정적 연결 확인에서 SNpp51의128621→111970 기존 간선8191320(원래2contacts/양수)이 현재에도5.9999998484e−5로 약화되어 있다. 기존 여섯 SNpp50 간선만 복원한 후보와 구별되는 가정은 **반대 위치 집단도 원래 같은 rate 단위로 복원하면 추가 전류의 시간 변동이 상쇄될 수 있다**는 것이다. 같은 방향의 흥분성 연결이고 두 집단의 실제 발화도 단순 보수 관계일 필요가 없으므로, 이 정적 가능성을 먼저 판별한다. 감각 극성을 뒤집거나 신경을 새로 연결하지 않는다.

## 고정 저장자료 비교

E265 B의101개 endpoint에서 일곱 기존 입력의 rate/mask와 원래 bundle의 endpoints/count/sign을 사용한다. 현재 W0, 기존 여섯 복원 W6, 일곱 모두 `sign*contacts*.03`으로 복원한 가상 W7의 선택 가중치를 저장한다. `.03`은 기존 모형 단위변환이며 생리 실측값이 아니다. W7은 전체 회로에 적용하지 않는다.

각 endpoint에서 J6=sum((W6−W0)*r_B*mask_B), J7=sum((W7−W0)*r_B*mask_B), Jopp=J7−J6를 float64로 계산한다. 원래 E264와 같은 startup1..99 평균을 한 번씩 빼 K6와 K7을 구한다. 평균과 한번만 반올림한 bias32도 기록하지만 실제 drive에는 주입하지 않는다. K7을 줄이는 창·gain·계수·튜닝 최적화는 없다.

H266은 이 **원래 count 비율 그대로의 반대 집단 복원**이 추가 입력의 시간 변동을80% 이상 줄이는 데 충분하다는 제한된 가설이다. startup `RMS(K7)/RMS(K6)≤.2`이고 `maxabs(K7)≤maxabs(K6)`일 때 지지한다. RMS(K6)≤1e−12면 inconclusive, 유효하고 조건미달이면 refuted, 입력/자원/게시 실패는 not_tested다. K6/K7의 모든 부호·분포와 사전 controls43/56/70, J6/Jopp의 공분산을 함께 보존한다. 비율을 분산 설명률로 부르지 않는다.

지지하면 W7의 실제 전체 신경 초기 재현·물리적 양방향 감각 반응을 검증하는 별도 후보 설계 대상으로 남긴다. 반박되면 이 원래 count 복원 방식은 다음 GPU 후보로 올리지 않는다. 후자는 모든 opponent 회로나 교정을 부정하지 않는다. 조건부 전류 계산만으로 새로운 회로의 rate, q19, 신체 또는 보행을 예측하지 않는다.
