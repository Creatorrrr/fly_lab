## 구현·실패 보존

부모 설계 → actual gpt-6-sol/high 구현 → 부모 FIRST → 같은 Sol 첫 수정 → 부모 SECOND와 잔여 수정 순서다. FIRST에서 E169가 저장하지 않은 startup 시간 별칭과 부분 원형 손실 가능성을 바로잡았다. 시간은 실제 E103 출처에서만 읽으며 기존 loaded 배열을 대체하지 않았다. 서로 다른 출처가 정상 통과하고 출처·mask·target 손상, 부분 불완전 행, 시간 초과, 늦은 게시 실패가 기각되는20개 생성시험이 통과했다. 수학 함수19개 및 상수6개의 AST 비교도 통과했다. 부모의 최종 수정은 불필요한 lint 주석 제거뿐이며 시험한 코드와 AST가 같다.
