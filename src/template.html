몸의 물리와 뇌의 모델을 구분합니다.

FlyGym 2.1.0 NeuroMechFly 모델과 MuJoCo 3.9.x를 사용하는 Python 어댑터입니다. 42개 능동 관절의 목표각과 6개 발의 접착 입력은 공개 HybridTurningController가 계산합니다. 몸의 위치를 이동식으로 덮어쓰지 않습니다. 접촉·중력·관절 액추에이터가 이동을 만듭니다. 제작 환경에서 실제 물리 실행은 검증하지 못했습니다.

신경 데이터 범위는 A와 같습니다.

hemibrain 발췌 98개 실제 ID·177개 연결과 72개 설계 노드를 유지했습니다. 이들은 전체 뇌도 완전한 부분 회로도 아닙니다. 모든 활성도는 0–1 모델값이며 실측 신경 신호가 아닙니다. PFL3·DN·HD 등은 명시적인 보조 계산 노드입니다.

감각과 제어의 한계

64개 광선은 실제 MuJoCo 형상에서 밝은 벽 표식을 감지하며, 가림도 광선 충돌로 결정합니다. 복안 광학·영상 신경망은 아닙니다. 9개 근접 거리도 MuJoCo 광선이며, 후각은 가우시안 장, 자기 회전은 이상화한 운동 감각입니다. 상위 신경망에는 XYZ나 실제 yaw를 전달하지 않습니다.

저수준 HybridTurningController의 고유감각·반사에는 시뮬레이터의 자세와 접촉 값이 사용됩니다. 이는 알려진 공학적 제어 발판이며 뇌 전체로 보행이 자연 발생한다는 주장이 아닙니다. 고정 방향 과제와 목표 기준도 설계 요소입니다.

표시와 단위

프런트엔드 몸 표면은 도식적입니다. 다리 연쇄 위치와 실제 관절각은 물리 계산값입니다. 무차원 활성도와 접촉력(BW), 각도(rad), 시간(s), 거리(mm)를 분리합니다. 액추에이터 출력은 보정되지 않은 엔진 단위이며 SI 토크로 표시하지 않습니다.

실행 수명과 현재 범위

신경 5 ms, 물리 0.1 ms, 기록 10 Hz입니다. 이 설정은 실시간 성능 보장이 아닙니다. 브라우저 요청이 있을 때만 계산하며 숨겨진 탭에서 요청이 멈춥니다. 비행·공기역학·학습·전뇌 모델·24시간 서비스는 구현하지 않았습니다. 네이티브 카메라는 별도 OpenGL 기능이며 없어도 기본 관찰은 가능합니다.

세부 출처, 버전, 한계와 실기동 검증 스크립트는 ZIP의 docs/와 tools/에 있습니다.
