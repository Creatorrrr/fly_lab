# E161 RM 접지 해제 시점의 저장 자료 분해

E160의 고정40ms 후보는 원래99 시작 최대오차 기준을 넘었으므로 채택하지 않았다. 다음 후보를 임의의 중간 τ로 다시 고르지 않는다. E157에 이미 기록된 접촉 Jacobian과 E150 출력으로 RM의 수직 운동 기여 및 하중 해제 시점을 먼저 확인하고, 별도 Sol/medium 읽기 전용 감사가 기존 감각/중계/운동 경로를 확인한다. 목적은 다음 인과 개입 위치를 좁히는 것이며, 진단 완료를 M3 또는 자연 보행 완료로 세지 않는다.

## 정의와 범위

신체/신경/StateStore/fit을 실행하지 않고 이미 보존한 E157의1–2초 전체10,000 native 단계와24,420개 양의 접촉, E150의 activation/moment와 제어 기록만 읽는다. 대상은 기존 RM group65–79와 실제 구동7관절이며, 전체 다리의 수직 분해도 비교용으로 보고한다. world 좌표는 Z-up이다.

접촉별 수직 속도 기여는 relative_jacobian[:,2,dof] × qvel[dof]다. root6, 해당 다리의7개 구동관절, 나머지 자유도로 분해하고 합이 직접 Jz·qvel과 절대1e−10 안에서 일치하는지 검사한다. 수평 접선 투영을 사용하지 않는다. 잔여 자유도에는 수동 발마디 등이 포함되므로 LTM 기여라고 단정하지 않는다. LTM의 위치 moment가0이어도 물리 영향0을 뜻하지 않는다.

접촉 normal_load_bw로 가중한 native leg 평균과 전체 집계를 저장한다. 접촉이 없는 속도는0이 아니라 unavailable/NaN 및 유효 mask로 표현한다. 각 native/leg의 양의 접촉 하중합은 기존 normal_load_bw와1e−8 이내로 맞아야 한다. 없는 접촉을 새로 만들어 보간하지 않는다.

고정 부분집합은 각 다리에 대해 support≥.02BW, support+net forward force<0, 그리고 RM에 대해서 추가로 위 조건+하중가중 coxa-roll AP 기여>0이다. E152의 기존 interrupted(20ms Gaussian control speed≤.5mm/s를 native50개로 반복)도 별도로 표시한다. 분류 문턱을 결과에 맞춰 조정하지 않는다. 수직 총합이 작을 때 각 항목을 비율로 나누지 않는다.

RM의 하중 해제 이벤트는 .02BW 이상에서 미만으로 내려가는 첫 native 단계다. 바로 앞100단계(10ms)가 모두 지지, 이후100단계가 모두 비지지일 때 안정된 전이로 분류한다. ±200단계(20ms)의 온전한 창이1–2초 자료 안에 있어야 정렬 집계에 포함한다. 모든 원시 전이를 저장하고 제외 이유를 남긴다. 해제는 하중 문턱의 전이이며 발이 지면에서 완전히 떨어졌다는 기하학적 증거가 아니다.

RM의 근육별 명령 변화는 .02 × moment[row,group] × (activation[t,group]−activation[t−1,group])/.005로 정의한다. t는 해당 native 단계의 저장 control_tick(201–400)이다. 이를 같은 접촉의 Jz7과 곱한 값은 **현재 기하에서 명령 변화율을 투영한 진단량**이며 실제 근육별 수직 속도/힘 또는 조작 효과가 아니다. 실제 수직 속도 분해와 별도 이름으로 저장한다. RM group65–79의15개 기여를 모두 보이고 선택한 근육만 보고하지 않는다. group78 LTM은 별도 activation/tendon 출력으로 기술하며 이 위치 moment 투영으로 평가하지 않는다.

각 해제 창에는 실제 root/7관절/잔여/총 수직 속도, AP/slip/force/load, 원래7개 목표·실제 qvel,15개 activation·명령 변화율 투영을 저장한다. 모든 창은 같은 방법으로 집계하며 결과가 없으면0건으로 명시한다. 후보 파라미터/phase/출력 변경이나 모델을 만들지 않는다.

## 유효성·구현·실행

부모가 설계하고 실제 Sol/medium이 새 분석 도구와 생성 테스트를 첫 구현한다. 고정된 저장 배열의 선형 분해·이벤트 정렬만 수행하므로 medium을 사용한다. 부모 첫 리뷰 → 같은 Sol 첫 수정 → 부모 두 번째 리뷰/잔여 수정 순서를 유지한다. 부모는 별도 수식/원자료 검산 및 기존 신경 경로 검토를 병행한다. 소유 파일은 tools/analyze_c_banc_m3_unload_timing.py와 tests/test_c_banc_unload_timing.py다.

원본 저장 분석은 source gate 후1회, 자동재시도0. CPU1/GPU0, 모델·StateStore·physics·neural·fit은0. 내부35/외부45/감독55초, 출력128MiB, 여유1GiB를 둔다. 최근 원본 실행 보수누적2638.685963초를 올림한2639초에서 감독55초를 더한 사전2694초다. 이전 실험의2925초 배정은 종료된 원본 실행의 상한이며 실제 사용량을 지우거나 새로0으로 만들지 않는다.

원시 유도 배열을 closure/하중 비교 assert 이전에 저장하고, NaN availability 및 원래 데이터의 시간/index/leg/DOF mapping을 검증한다. 입력/재사용 소스/과거 실패/M2를 전후 해시 확인하고 실제 source gate에 동결 입력을 사용하는 검사를 먼저 수행한다. 생성된 shape/전이/좌표/가중 평균/수치 불일치 사례로 검증하며 원본 자료로 미리 출력 수치를 시험하지 않는다.

분석 도구의 유효성은 데이터/수식/창 정의 일치로 판정한다. 그 PASS는 생물학적 기전, 실제 제동 감소 또는 F1–F8의 PASS가 아니다. 다음 물리 개입은 수직 기여와 기존 경로 감사 결과를 함께 검토한 뒤 별도 설계한다. M2/UI/F6는 그대로 보존한다.
