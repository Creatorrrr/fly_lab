## 2. 1차: 환경 편집과 실험 모드 명료화

**사용자 결과:** 장면에 먹이·위험원·장애물을 놓고, 무엇이 현재 초파리를 움직이는지 확인할 수 있습니다.

구현 작업:

1. 환경 패널에 종류 선택, 장면 위치 지정, 배치 미리보기와 적용, 좌표 입력, 물체 목록을 추가합니다. 카메라 조작과 배치 조작을 구분합니다.
2. 냄새원 강도와 장애물 반경을 설정합니다. 기존 생성 명령에 강도를 전달하고 검증하는 경로를 추가합니다. 냄새장의 공간 감쇠식은 화면 기능 추가와 분리해 유지합니다.
3. ID 기반 개별 이동·수정·삭제 API를 추가합니다. 기존의 추가 물체 전체 제거도 제공합니다. 모든 변경은 서버가 수락한 ID·좌표·설정을 화면에 반영합니다.
4. 편집은 계산이 완료된 제어 경계에서 적용합니다. 장애물 변경은 새 물리 모델을 만든 뒤 현재 적분·CPG 상태를 옮겨 검증하고 교체합니다. 실패하면 현재 실험을 유지합니다.
5. 장면 범위, 장애물의 몸·벽 침범, ID, 반경·강도, 물체 수를 서버에서 검증합니다. 현재 한도는 냄새원 합계 24개, 장애물 12개입니다.
6. 환경 배치 저장·불러오기와 편집 되돌리기를 제공합니다. 되돌리기는 현재 시점에서 환경 변경을 역적용하며, 시간을 되돌리는 체크포인트 복원과 구분합니다. 새 명령도 이벤트 기록과 리플레이에 포함합니다.
7. 실제 실행 모드와 다음 새 실험의 설정을 별도로 표시합니다. C_SHADOW의 B 구동, C_ASSISTED의 보조 적용, C_STRICT의 C 출력 적용을 명령 출처와 함께 보여줍니다. 새 실험 전 현재 상태를 체크포인트로 보존합니다.

완료 기준:

- 실제 브라우저에서 세 종류를 추가·수정·삭제하고 서버의 물체 ID·좌표·설정이 일치합니다.
- 냄새원 편집은 대응 센서값을 바꾸고, 장애물 편집은 실제 광선·접촉 형상에 반영됩니다.
- 잘못된 배치나 모델 재구성 실패 시 기존 세계·신경·물리 상태가 유지됩니다.
- 편집 뒤 저장·복원·리플레이에서 환경과 실행 상태가 일치합니다.
- 현재 모드와 새 실험 설정이 혼동되지 않으며, 제어 모드가 조용히 전환되지 않습니다.

## 3. 2차: 신경 모니터·개입·기록을 한 흐름으로 연결

**사용자 결과:** 특정 신경 집단을 관찰하고 자극하거나 억제한 뒤, 정확히 어떤 집단에 무슨 일이 일어났는지 확인하고 저장할 수 있습니다.

구현 작업:

1. **관측 집단 / 개입 집단 / 기록 집단**을 각각 표시합니다. 집단 이름, 전체 ID, 개수와 저장된 프리셋을 제공합니다. DNp09·DNa02·MDN 프리셋은 현재 검토된 포트의 실제 ID를 사용합니다.
2. 검색 결과에 없던 구독 뉴런도 ID 일괄 조회로 세포형을 표시합니다. 구독 변경은 이미 예약된 개입 대상이나 시작된 기록 집단을 변경하지 않습니다.
3. 기존 바이너리 발화 이벤트로 래스터를 그립니다. 전압·발화율 그래프에 개입 시작과 끝을 표시하고, 그래프에 표시할 뉴런을 지정할 수 있게 합니다. 막전위의 임계 통과를 보고 발화 이벤트를 새로 추정하지 않습니다.
4. 모델 시간, 실제 경과 시간, 최신 관측 tick, 지연·수신 공백을 표시합니다. 영역 요약은 필요한 집단과 갱신 주기를 제한합니다. 최대 구독 512개와 고정 크기 표시 버퍼를 유지합니다.
5. 개입 목록 API와 화면에 예약·활성·만료·취소 상태, 대상, 입력 세기, 시작·끝 tick, 잔여 모델 시간을 표시합니다. 기존 전체 해제와 함께 serial 기반 개별 취소를 제공합니다.
6. 자극을 `모델 입력 자극(mV)`로 표시하고, 새 발화 억제와 연결 출력 차단의 효과를 구분합니다. 취소·만료는 이후 입력/전달을 바꾸며 이미 발생한 발화나 지연 큐의 도착을 지우지 않습니다.
7. 기록 시작 전에 대상 집단과 기록 범위를 확정하고 화면·manifest에 표시합니다. 신호 100Hz, 몸 10Hz, 운동 명령 200Hz 및 선택 발화 이벤트 기록을 유지합니다.

완료 기준:

- 뉴런 선택 변경·개입·개별 취소·자동 만료가 같은 모델 tick 기준으로 화면·엔진·기록에 일치합니다.
- 전압·발화율·래스터가 서버 원자료와 일치하고 다른 구독의 신호가 섞이지 않습니다.
- 기록 중 화면의 관측 집단을 바꿔도 고정 기록 집단과 행 수가 유지됩니다.
- 일시정지·재생·재접속·체크포인트 복원 후 개입 상태와 대상이 정확하게 표시됩니다.
- 새 취소·편집 명령을 포함한 리플레이가 같은 런타임과 프로파일에서 원래 상태를 재현합니다.

## 4. 3차: 감각–신경 포트 확장과 출력 진단

**사용자 결과:** 각 환경 요소가 어느 신경 집단에 어떤 가정으로 입력되는지 확인하고, 지원되는 채널을 대상으로 C 신경의 반응을 실험할 수 있습니다.

진행 순서:

1. 현재 냄새 입력·하행 출력으로 감각값 → 입력 세기 → 대상 뉴런 발화율 → 운동 출력 → 실제 이동을 추적합니다. 기존 지속 회전의 원인을 감각 정보 부족, 신경 동역학, 출력 불균형·포화, 몸 제어로 나누어 조사합니다. 먼저 원인을 확인하고 수정 대상을 정합니다.
2. 좌우 냄새 정보의 보존, 위험 냄새, 근접/시각, 접촉 순으로 필요한 감각 경계와 후보 집단을 검토합니다. 이 순서는 구현 우선순위 제안이며, 후보의 생물학적 대응이 확인되었다는 뜻은 아닙니다.
3. 원 논문·공식 데이터 주석과 현재 FAFB v783 ID를 대조합니다. 좌우 측, 입력/출력 방향, 포트 단위, gain/cap, 필터·지연, 불확실성을 기록합니다. 뇌 스냅샷에 없는 말초/VNC 신경을 포함된 것으로 가정하지 않습니다.
4. 입력 대상의 근거와 ID를 확보한 채널부터 별도 binding 프로파일로 추가합니다. 미해결 채널은 미연결 상태를 유지합니다. 직접 하행 뉴런 자극이나 공학적 대체 입력은 해당 입력 종류로 명시합니다.
5. 감각 packet은 기존 감각 경계를 유지합니다. 몸의 실제 좌표·절대 방향·먹이까지의 정답 경로를 신경 입력에 추가하지 않습니다.
6. 정지 출력 후보와 후진 출력은 별도로 검토합니다. 음수 전진 명령만으로 후진 성공을 판정하지 않고 몸의 전방 축에 투영한 실제 이동을 확인합니다.

완료 기준:

- 모든 추가 포트에 실제 ID·출처·단위·가정·버전과 해시가 있습니다. 다른 포트의 기존 체크포인트를 호환되는 것으로 조용히 읽지 않습니다.
- 환경 변화가 해당 감각 채널과 대상 뉴런의 입력을 바꾸는지 확인합니다. 감각 차단 대조를 포함합니다.
- 자극·억제의 신경 효과, 운동 명령 변화, 실제 행동 변화가 별도로 보고됩니다.
- 특정 뉴런에 자극이 전달되는 것과 자연 회피·접근 행동의 성공을 별개로 판정합니다.

이 단계는 자료 검토 결과에 따라 지원 범위가 달라집니다. 포트 추가만으로 C_STRICT의 안정적인 자연 탐색이 완성된다고 약속하지 않습니다. UI·기록 개선은 이 연구의 완료를 기다리지 않고 전달할 수 있습니다.

## 5. 4차: 과제별 행동 검증과 재현 가능한 비교 화면

**사용자 결과:** 먹이 접근·위험 회피·장애물 회피와 신경 개입의 효과를 같은 조건에서 비교하고, 성공·실패의 근거를 확인할 수 있습니다.

구현 작업:

1. 대조 비교 화면에 실행 기간, 개입 시점, 대상, 세기, 시드, 반복 조건을 제공합니다. 원래 관찰 중인 실험은 보존하고 같은 체크포인트에서 대조군·개입군을 실행합니다.
2. 첫 진단 행렬은 시드 7/19/42와 기준·좌/우 먹이·좌/우 위험원·정면 장애물 조건입니다. 각 모드는 따로 집계하고 미연결 감각 조건은 미지원으로 표시합니다. 이 단계는 진단용이며 전체 행동 승인 기준이 아닙니다.
3. 지원되는 과제가 짧은 검사에서 통과하면 여러 시작 방향·마찰·긴 지속 시간으로 확대합니다. 과제별 요구 시간과 수치 기준은 대조 기준선을 측정한 뒤 최종 평가 전에 고정합니다.
4. 전진/후진 실제 변위, 먹이 영역 진입·체류, 위험 영역 체류, 충돌 지속 시간, 회피 뒤 전진 재개, 제자리 회전·고착, 넘어짐, 관측 공백을 저장합니다. 총 이동 거리나 회전량 하나로 성공을 판정하지 않습니다.
5. 신경 반응·적용 명령·궤적을 같은 시간축으로 보여주고 감각 차단, 신경–몸 연결 차단, 보조 제어 유무를 대조합니다. C_ASSISTED의 보조 회피 결과를 C_STRICT 신경 회피 결과에 합산하지 않습니다.
6. 초기 상태·환경·graph/binding 해시, 개입과 편집 이벤트, 기록 집단, 원시 신호·궤적, 판정 기준을 함께 내보냅니다. 실패한 실행도 별도 디렉터리에 보존합니다.

완료 기준:

- 개입 전 대조군/개입군이 일치하며 기록이 누락된 실행은 불완전으로 판정합니다.
- 동일 런타임·백엔드·프로파일에서 다시 실행한 상태가 정해진 수치 기준을 충족합니다. 백엔드 간 오차 기준은 별도로 적용합니다.
- 각 결과에 `기술 경로 통과`, `과제 행동 기준 충족`, `미지원/불완전/실패`가 구분됩니다.
- C_STRICT 자연 행동은 해당 모드·과제의 실제 기록으로만 승인합니다.

## 6. 성능·호환성 관리

각 차수에서 같은 초기 체크포인트의 계산 시간, UI 포함 응답 지연, 신호·기록 누락을 확인합니다. 기본 관측 상태와 최대 512개 관측, 기록 동시 사용을 나눠 측정합니다. 배치 미리보기와 신호 차트가 정지 화면의 기존 형상 캐시를 불필요하게 다시 만들지 않도록 합니다.

비교는 이전 버전과 같은 장비·동일 조건·교대 반복으로 수행합니다. 데스크톱 부하 변동을 함께 기록하고, 허용할 성능 예산은 기능별 초기 측정 뒤 정합니다. UI 갱신 빈도 조절과 물리/신경 적분 주기 변경을 구분하며, 처리율을 맞추기 위해 계산 tick이나 기록 행을 버리지 않습니다.

Apple GPU 물리 이식은 별도 기술 단계입니다. 현재 실제 탐색은 MJX의 plane–mesh margin/gap 미지원으로 물리 실행 전 차단됐습니다. 진행 조건은 현재 모델을 변형 없이 올릴 수 있는 경로 또는 동등성을 검증할 별도 구현의 확보입니다. 그 뒤 수치·접촉·복원·행동을 확인하고, 단일 장면에서 실제 속도 이득이 있는 경우 채택합니다.

현재 참고 기준선: [최신 최적화·검증 보고서](C_RUNTIME_OPTIMIZATION.md), [154개 회귀와 실제 검증 상태](../verification/c_remaining_20260909/final_checks.json), [실제 서버 비교](../verification/c_remaining_20260909/live_comparison.json), [Apple GPU 물리 차단 원자료](../verification/c_remaining_20260909/mjx_explicit_jax_probe.json). 기존 자연 행동과 출력의 한계는 [C 최초 검증 보고서](C_VALIDATION.md)에 남아 있습니다.
