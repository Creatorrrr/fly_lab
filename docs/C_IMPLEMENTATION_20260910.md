## 실제 54조건 파일럿

seed 7/19/42 × 기준선·좌우 먹이·좌우 위험·정면 장애물 × 세 모드에서 각각 10모델초를 실행했다. 54조건, 총 540모델초의 기술적 실행은 모두 PASS다. 모드별 과제 판정은 다음과 같다.

| 모드 | PASS | FAIL | INCOMPLETE | NOT_EVALUATED | NOT_APPLICABLE |
|---|---:|---:|---:|---:|---:|
| C_STRICT | 0 | 3 | 6 | 6 | 3 |
| C_SHADOW | 7 | 0 | 5 | 6 | 0 |
| C_ASSISTED | 0 | 3 | 6 | 6 | 3 |

C_STRICT와 C_ASSISTED의 세 기준선은 자연 전진 기준에 미달했다. 먹이 미도달은 30초 판정 기한보다 짧은 10초 관측이므로 INCOMPLETE다. 위험 과제는 대응 대조군이 필요해 NOT_EVALUATED이고, 실제 장애물 접근이 없으면 NOT_APPLICABLE이다. C_SHADOW의 통과는 B가 몸을 구동한 결과다. 이 표에서 C의 자연 과제 지원을 승인하지 않는다.

계획의 선행 기준에 따라 180조건 고정 평가와 120초 내구성 평가에는 진입하지 않았다. 별도 10개 초기 위치·방향·마찰 조건 생성, 위험 회피의 짝지은 전용 판정, 검토된 정지 뉴런 집단 및 다리 고유수용성 포트도 아직 완성하지 않았다. 파일럿 실패 원인을 해결하지 않은 채 이 항목들을 완료로 표시하지 않는다.

파일럿은 해당 폴더에 동결한 소스로 실행했다. 뒤이어 진단 메타데이터·부가 표시·진행 저장·패키징 등을 수정했으므로 이를 최종 소스로 540초를 재실행한 결과로 바꾸어 말하지 않는다. 최종 신경·몸 상태는 별도 이전 버전 교대 비교와 최종 소스 검사로 확인한다.

긴 실험에서는 상세 고착 창을 매 진행 갱신마다 다시 직렬화하는 비용도 확인했다. 최종 코드는 각 조건의 상세 결과를 파일로 유지하고, 진행 파일에는 요약과 SHA256을 기록한다. 같은 53개 완료 조건의 진행 데이터는 **9,897,019 → 31,292바이트, 99.68% 감소**했다. 원시 신호·궤적은 줄이지 않았다. 이는 진행 저장량 측정이며 물리 시뮬레이션 전체 속도가 같은 비율로 개선됐다는 뜻이 아니다.

## 최종 기존 동역학·성능 비교

기존 평균 후각, 가상 에너지 끔 상태에서 같은 물리 체크포인트를 사용해 이전 커밋과 현재 코드를 교대로 실행했다. 조건별·버전별 5회, 총 40회다. 매 실행에서 0.3모델초를 진행하며 초기화·JIT 예열·최종 파일 내보내기는 시간에서 제외했다. 신경·몸·센서·인코더·명령·선택 스파이크·기록 청크는 정확히 일치했다. 버전 및 명시적인 부가 진단 필드만 정규화했으며 새 감각 모델의 상태를 제외하도록 허용하지 않았다.

| 조건 | 이전 중앙 시간 | 현재 중앙 시간 | 이전/현재 | 현재 모델/실제 시간 |
|---|---:|---:|---:|---:|
| C_SHADOW | 1.490초 | 1.514초 | 0.984 | 0.198 |
| C_STRICT | 1.571초 | 1.555초 | 1.010 | 0.193 |
| C_ASSISTED | 1.408초 | 1.444초 | 0.975 | 0.208 |
| 기록 켬 | 1.727초 | 1.734초 | 0.996 | 0.173 |

모든 비교의 **상태·기록 동일성은 PASS**, 추가 처리율 개선은 **NOT_APPROVED_NO_CLEAR_THROUGHPUT_GAIN**이다. 반복 분포가 겹치며 현재 코드가 더 빠르다고 결론 내릴 수 없다. 원자료에는 최소/최대와 nearest-rank p95를 보존했다. 반복 수가 5이므로 이 p95는 해당 다섯 값의 최댓값이며 모집단 상위 지연을 보장하지 않는다.

실험 후반의 OS 표본 19개에서 worker RSS 최대 관측값은 1,192,672KiB였다. GPU 할당량이나 실제 메모리 최고점 측정은 아니다. 같은 표본의 1분 load average는 29.14~60.63으로 높았다. 다른 사용자 프로세스를 중지하지 않았고, 이 부하에서의 짧은 결과를 실시간 처리율 보장으로 사용하지 않는다. 독립 캠페인은 종료한 뒤 비교했으며 화면 렌더링 비용은 이 측정에 포함되지 않았다.

신뢰성 수정은 정확도 검증을 근거로 반영했다. 기존 Metal 신경 가속과 CPU 물리의 중첩 경로를 유지하며, 추가 가속이 입증됐다고 표시하지 않는다. 새 시각 프로파일·가상 생리 모델·별도 연구 엔진의 성능은 이 표의 범위가 아니다.

## 최종 소스와 전달 자산

검증된 소스·고정 FAFB 자료 ZIP을 별도 디렉터리 `clean_checkout_v2`에 풀고 새 `.venv-repro-c` 환경에서 **205개 회귀검사 전부 통과**했다. 이 추출 소스의 독립 전체 스냅샷·실제 MPS 계산도 통과했다. 이 205개는 기존 204개와 누적 합산하지 않는다. 최종 코드와 추출해 검사한 비문서 소스·의존성·자료 파일도 해시로 비교했다.

진행 파일을 줄인 최종 캠페인 코드는 실제 MPS/MuJoCo에서 두 조건을 각 0.05초 실행해 별도로 확인했다. 완료된 캠페인의 재개도 원자료 해시 검사 후 성공했고, 전체 상세 결과는 조건별 파일에 남았다. 이 추가 0.1모델초를 기존 파일럿의 540초와 혼동하지 않는다.

사용자 실험은 마지막 `final-c04-delivery-20260910` 체크포인트에도 40.230초로 보존했다. 업그레이드 직후와 전달 직전의 체크포인트 값은 정규화 없이 전부 동일했다. 테스트용 8770 서버와 검증용 브라우저는 종료하고 사용자 8766 서버를 유지했다.

배포 파일은 `artifacts/releases/FLY_LAB_C_0.4.0_20260910.zip`, 외부 인덱스는 같은 파일명 뒤의 `.index.json`이다. 검토 진입점은 [증빙 목록](C_EVIDENCE_INDEX.md)과 [기계 판독 인덱스](C_EVIDENCE_INDEX.json)다. 최신 원자료와 문서에서 참조하는 이전 검증 자료, 고정 FAFB 자료, BANC 연구 자료와 사용한 날개 자산·라이선스를 포함한다. Python 가상환경·Git 메타데이터는 배포하지 않는다. 외부 호스팅에 업로드한 것은 아니다.

## 완료로 표시하지 않은 부분

C_STRICT의 안정적인 자연 먹이 접근·위험 회피·장애물 탐색은 아직 승인되지 않았다. 기본 관찰 화면의 C_SHADOW는 B가 몸을 구동한다. 전뇌 계산, 신경의 직접 자극으로 몸이 움직임, 자연 과제 통과, 실제 생물학 재현은 서로 다른 결과다.

전신 신경계·모든 말초 감각·모든 근육·정밀 수용체·다중 구획·학습 행동·신경 제어 비행까지 완성한 상태가 아니다. 이번에는 해당 연구를 실행할 수 있는 일부 모델·데이터·물리 실험 경로를 구현했고, 미확정 매핑을 임의로 채워 성공으로 표시하지 않았다. 기본 LIF·CPG와 별도 연구 모델을 혼용하지 않는다.

C의 0.1ms와 0.05ms 신경 dt를 0.025ms 결과와 비교했을 때 선택 뉴런의 발화 개수가 다른 경우가 있었다. 따라서 CPU/MPS 일치 PASS를 시간 간격 수렴이나 생물학적 적합성으로 해석하지 않는다. 수신 임계점 근처의 reset 차이로 최종 전압 비교가 크게 달라질 수 있으므로 raw spike times도 함께 보존했다.

CUDA 실장비는 없다. Apple Metal 장치 자체의 JIT는 실행됐으나 MuJoCo의 변경하지 않은 모델을 MJX로 옮기는 단계에서 plane–mesh margin/gap가 지원되지 않아 실제 GPU 물리는 시작하지 못했다. 모델 충돌을 생략해 GPU 물리 통과로 바꾸지 않았다.

- `cns_tibia_v2/report.json`: 실제 BANC→선택 관절, 제어기 우회·차단·복원 검증.
- `head_contact_v1.json`: 실제 충돌 엔진에서 처방한 겹침의 머리 접촉 감지. 보행·회피 평가는 아님.
- `flight_rig_v2/report.json`: 실제 날개 유체력 차이·자산 경로 변경 후 복원. 안정 비행 아님.
- `pilot_54x10_v2/`, `pilot_interpretation.json`: 54조건·540모델초 원자료와 과제별 해석.
- `campaign_progress_storage_v1/report.json`: 원자료를 유지한 진행 파일 크기 비교.
- `final_runtime_benchmark_v1/report.json`, `performance_interpretation.json`: 40회 기존 동역학 비교·실측 시간 및 성능 해석.
- `numerics_v1/report.json`, `mjx_probe_v2/report.json`: 장치 일치·dt 세분화·GPU 물리 BLOCKED.
- `browser_job_readback.txt`, `user_upgrade_comparison.json`: 실제 브라우저 독립 실험과 사용자 실험 이전/이후 상태 비교.
- `browser_validation_v1.json`, `user_final_state_comparison.json`: 화면 검증의 범위와 전달 직전 사용자 상태 동일성.

초기 `recovery_native_v1`의 진단에서는 control_tick 필드에 신경 tick을 적는 메타데이터 오류가 있었다. v2에서 제어 tick/model tick/물리·신경 시간을 분리해 바로잡고 재검증했다. 최초 사용자 migration preflight는 관측 epoch 증가까지 동일성을 요구해 FAIL이었다. v2에서는 epoch가 정확히 한 번 증가하고 나머지 동적 상태가 그대로인지 검사했다. 이런 정정은 원자료 삭제나 실패 로그 덮어쓰기로 처리하지 않았다.
