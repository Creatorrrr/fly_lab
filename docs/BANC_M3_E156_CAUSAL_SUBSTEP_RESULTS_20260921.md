# E156 결과: 물리 단계별 모집 전달은 미끄럼을 줄이지 못함

부모 설계 → 실제 `gpt-5.6-sol/high` 첫 구현 → 부모 첫 리뷰 → 같은 Sol 첫 수정 → 부모 두 번째 리뷰와 잔여 수정 → 원본 1회 실행 → 부모 독립 검산 순서로 완료했다. 이 단계의 구현·측정은 유효하지만 **후보 효과는 기각**이다. M3의 자연 보행 목표는 완료되지 않았다.

## 신체 단독 비교

E150의 동일한 저장 BANC 운동 출력과 t=1초 신체 checkpoint에서 출발해 t=2초까지 비교했다. 기준군은 이미 전체 native 접촉과 qpos/qvel/ctrl의 정확 재생을 확인한 E154 기록이다. 새 기준군 실행은 없었다. 후보는 기존 5/10/40ms 모집 bank와 고정 10ms 근육 활성의 중간 상태를 0.1ms마다 전달했다. 시정수, 이득, 근육 기하, 신경 가중치와 5ms 최종 명령은 유지했다.

| 같은 1초 창 | E154 기준 | E156 후보 | 사전 기준 판정 |
|---|---:|---:|---|
| native 하중 가중 미끄럼 | 1.841493 mm/s | 2.051880 mm/s | 기준의 80% 이하 필요, 실제 111.425%로 실패 |
| 부호 있는 전진 | 1.667930 mm | 1.844695 mm | 기준의 90% 이상, 통과 |
| 수평 순변위/경로 | 0.580846 | 0.536665 | 감소 0.044180 ≤ 0.05, 통과 |
| 여섯 무릎 운동폭 비율 | 1 | 0.998826–1.003541 | 모두 0.9 이상, 통과 |
| native 비발 부위 접촉 | 0 | 0 | 통과 |
| native 최소 upright | 0.983507 | 0.983912 | 0.9 이상, 통과 |
| 전진 속도 > 0.5 mm/s 비율 | 72.5% | 72.0% | 기술 통계 |
| 가장 긴 연속 전진 | 0.195초 | 0.195초 | 기술 통계 |

전진량은 10.598% 늘었지만 미끄럼도 11.425% 증가했다. 고정 효과 기준은 모두 만족해야 하므로 `advance_to_closed_loop=false`다. 이 후보를 전체 BANC 폐루프나 제품 보행에 채택하지 않는다. 이 짧은 신체 대조는 F1–F8 또는 생물학적 타당성 검증을 대신하지 않는다.

## 검증과 자원

단계 A는 27개 생성자료 테스트와 20개 부모 독립 수식 검사를 통과했다. 단계 B는 같은 Sol의 첫 수정 후 22개 테스트, Ruff·format·compile·CLI를 통과했다. 부모 두 번째 리뷰는 물리 좌표 전진·공통 무릎 기하·201경계 속도 미분·200구간 노출·지원 접촉의 누락 slip 거부를 별도 수식으로 검증했다. 반환된 NaN과 완료된 적분 기록의 보존, 마지막 manifest 이후 시간 초과의 실패 처리를 재현했다.

부모 잔여 수정은 실제 42개 관절 구동기와 나머지 40개 구동기의 인덱스, 중립 명령, 모델 차원과 시작 clock을 기록하는 보강이다. 물리 명령이나 효과 기준은 바꾸지 않았다. 최종 소스 검사도 통과했다.

원본은 PID 23564, exit 0, 재시도 0으로 종료했다. 신체 1개·shadow 1개, 초기 안정화 2000회와 실험 적분 10000회, shadow forward 10000회, 전체 저장 2000구간의 helper endpoint 검산을 수행했다. 신경 모델·신경 진행·GPU·추가 적합은 0이다. 감독 시간은 39.245952초이며, 이전 사용 2535.612067초를 올림한 2536초에서 보수 누적 **2575.245952 / 사전 배정 2621초**다. 원본 output은 약 56.0MB로 512MiB 한도 이내다. FlyGym의 기존 좌우 haltere actuator 설정 경고는 stderr에 보존했고, 실험의 MuJoCo 수치 경고와 body fault 검사는 통과했다.

부모의 원본 독립 검산 **4011항목**은 입력·소스·보존 파일의 해시 확인을 포함한다. 핵심 수치 검산은 다음과 같다.

- 전체 2000개의 bank·원본 활성·모집 활성·최종 관절 명령을 별도 배열 수식으로 재구성했다.
- 선택된 10000×42 중간 명령을 재구성하고, 실제 적용 ctrl의 관절 부분과 정확히 대응함을 확인했다.
- 모든 물리 단계의 비관절 ctrl과 모든 control의 전체 최종 ctrl이 저장된 원래 명령과 정확히 같았다.
- 실제 신체 좌표에서 전진·수평 경로·기하학적 무릎 운동폭·Gaussian20ms 연속성을 scalar 수식으로 다시 계산했다.
- 모든 지원 접촉의 native 하중·미끄럼으로 고정 효과 판정을 재현했다.

모든 검산은 통과했으며, 물리 실험은 추가로 실행하지 않았다. 전체 목표에서 E150의 F4/F5 미달과 원본 incomplete, 별도 E151 차단/재시작 증거, F6 미노출 상태는 그대로다. 활성 UI와 기존 M2를 변경하지 않았다.

## 사후 관측과 다음 질문

기준군은 control 직후 첫 1ms에 하중×미끄럼 합의 54.606%가 집중됐다. 후보에서는 그 비율이 19.697%로 줄었지만, 뒤의 4ms 하중 가중 미끄럼이 **1.029633 → 2.052513 mm/s**로 늘었다. 첫 1ms만 보면 개선처럼 보이지만, 전체 5ms를 합산하면 악화다. 새 시간 전달은 순간적인 미끄럼 집중을 다른 물리 단계로 분산했고 연속 전진을 회복하지 못했다. 이는 저장된 접촉의 기술적 관측이며 특정 신경·근육의 생물학적 원인 증명은 아니다.

따라서 같은 전달법을 이득·시정수 sweep으로 반복하거나 폐루프에 승격하지 않는다. 다음 설계에서는 **보행 중단 구간에서 하중을 받는 다리의 실제 접촉점에 어떤 관절 운동이 제동·전진 성분을 만드는지**를 다룬다. E155의 RM 분석은 5ms 끝점에 한정되므로, 이번에 확인한 시간 분포를 고려하면 전체 0.1ms 구간으로 결론을 확대할 수 없다. 추가 관측은 실제 접촉점·관절별 기여·하중을 같은 시간에 맞춰야 하며, 새 원본 실행 전 입력·최대 비용·측정량을 별도로 고정한다. 외부 위상, 궤적, root 보정 없이 신경 출력과 신체 전달 사이의 구체적인 수정 근거를 얻는 것이 다음 단계다.
