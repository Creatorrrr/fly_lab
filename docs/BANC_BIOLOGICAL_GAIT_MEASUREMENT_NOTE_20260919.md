# 속도 관측 교정 및 탐색 분석의 경계

원래 고정 프로토콜은 유지한다. `analysis-v1` 결과를 삭제하거나 생물학적 실패의 근거로 사용하지 않는다. 이 노트는 첫 계산에서 드러난 관측 오류와 추가 탐색 분석을 기록한다. 모델 파라미터와 기존 M2 채택 기준은 바꾸지 않는다.

## 속도 측정 교정

처음에는 trace의 `body.speed`를 속도 입력으로 사용했다. 이 값은 5 ms 경계의 순간 속도이며 구간 평균이 아니다. 새 전방 기록의 0.5–1.5초를 0.1 ms마다 별도 물리 재생하여 검증했다. 200개 제어 구간의 최종 물리 상태가 기록과 byte 단위로 일치한다.

| 1초 구간의 전진 속도 적분 | mm |
| --- | ---: |
| 0.1 ms native body-origin Jacobian | 0.833367 |
| 0.1 ms 좌표 미분 | 0.832992 |
| 5 ms 저장 좌표 미분 | 0.833663 |
| 5 ms 순간 `body.speed` | 0.245865 |

Native 3차원 속도 적분과 실제 좌표 변화의 오차는 0.000205 mm다. body-origin과 body-COM의 차이는 이번 큰 불일치의 원인이 아니다. 순간 속도를 항상 같은 제어 위상에서 뽑으면 평균 운동을 대표하지 못하는 관측 편향이 확인되었다. 따라서 생물학적 비교의 속도는 **저장된 몸통 좌표의 중앙차분을 같은 시점의 몸통 전방 축에 투영한 뒤 Gaussian 20 ms로 평활한 값**으로 교정한다. 원래 >0.5 mm/s, 연속 0.3초, 회전 0.5 rad/s 등의 조건은 그대로 유지한다. `analysis-v1`은 superseded이며 수정 분석을 따로 보존한다.

시간 집계는 샘플 수 × dt 대신 마스크의 시간 적분을 사용하여 실측 37개 좌표의 시간 폭을 0.3초로 보존한다. 위상 끝점 제거는 최소 20 ms가 되도록 샘플 수를 올림한다. 이는 120 Hz와 200 Hz의 반올림 차이에 대한 명시적 처리다.

## 추가 탐색 분석

초기 결과에서 이동 조건을 만족하는 긴 구간이 부족했다. 이를 주기가 없다는 뜻으로 바꾸지 않는다. 왜 반복 보행 검증이 어려운지 보기 위해, **속도 조건을 적용하지 않은 전체 pre-brake 구간**에서도 같은 발 궤적 분석을 별도로 수행한다. 출력에는 `exploratory_all_prebrake`를 명시한다. 이는 정지·후진·회전을 포함할 수 있어 속도를 맞춘 실측 검증을 대체할 수 없다. 원래 적격 구간의 결과와 별도 JSON/그림으로 보존한다. 측정된 위상 관계나 주기가 이상해도, 이 탐색 결과만으로 모집단 수준의 생물학적 부적합을 통계적으로 확정하지 않는다.

원래 프로토콜, 위 교정, 그리고 탐색 분석을 구분한 채 최종 결론을 작성한다. 결과를 좋게 만들기 위한 제어기 재조정은 수행하지 않는다.
