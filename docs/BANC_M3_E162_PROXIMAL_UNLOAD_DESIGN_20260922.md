# E162 RM proximal 출력의 단일 효능 대조

E161의 실제 저장 기하에서 interrupted RM 제동의 femur-pitch 기여는−1.408681mm/s였고, group70 trochanter extensor의 명령 변화율 투영은−.965596mm/s였다. 하중 감각5개 직접 연결의 표적인 tibia flexor는 해당 구간에서 아래쪽 투영을 보여, 이를 lift 입력으로 단순 복원하는 근거가 부족하다. 이번 가설은 **RM group70의 효능을 제한하면 복귀 중 아래쪽 출력과 제동이 줄어 지속 전진 구간이 늘어난다**는 것이다. 경쟁 설명은 이 출력이 필요한 지지를 제공하므로 제한하면 균형·전진·운동폭이 악화된다는 것이다. 아직 어느 쪽도 실제 개입으로 검증되지 않았다.

## 고정 변화와 비교

E150의 기존 2001 제어 경계와 모든 신경·근육 원자료를 사용한다. 정확히 group70 하나의 activation 효능만 일정 배율 g로 바꾸고, 나머지95개·LTM·rest·moment·신체·지면·제어/물리 dt는 유지한다. 초기 tick0 명령은 복원된 관측이므로 그대로 둔다. tick1–2000은 q_candidate=q_E150−λ×.02×moment[:,70]×activation[:,70], g=1−λ다. 신경 출력의 외부 위상/CPG/궤적/root 교정은 추가하지 않는다. 이 단계는 저장 신경 출력의 신체 대조이며 전체 신경 폐루프 효과나 F2 완료를 대신하지 않는다.

λ는 실행 전에 하나의 결정식으로 정의한다. 최대 감쇠25%인 [0,.25]에서 **원래99개 시작 표본의 q RMS≤.02rad/max≤.04rad를 모두 만족하는 가장 큰 λ**를 계산한다. 비교 목표는 기존 actual-startup-original99-raw.npz의 original_E100_E103_command다. E150 현재 명령을 Q, 원래 비교 목표를 T, D=−.02×moment[:,70]×activation[:,70]라 하면 |Q−T+λD|≤.04의 선형 구간들과 mean((Q−T+λD)²)≤.02²의 이차 부등식 구간을 해석적으로 교차한다. 이차근은 cancellation을 피하는 식을 쓰며 모든 제약의 활성 경계를 기록한다. 고정 수치 여유로 양의 상한에 (1−1e−12)를 곱한다. 교차구간의 상한이0이면 λ=0으로 기록하고 신체에 진입하지 않는다. g는 항상 .75 이상이므로 해당 두 MN의 양의 출력 기여를0으로 만들지 않는다.

25% 상한은 효과를 구별할 제한된 공학적 개입 크기이며 생물학에서 측정된 값이 아니다. 원래99개는 이미 개발에 노출된 자료이고 이번에는 λ 선택에도 쓰므로, 통과를 독립 확인이라고 부르지 않는다. 선택 노출1회와 원시 부등식/계산 λ/실제99개 오차를 보존한다. 시작/LTM/F1–F8 문턱은 그대로며 후보 λ를 결과에 따라 재선택하지 않는다. 별도 감쇠 sweep·fit은 없다.

## 실행·판정

실제 source gate와 원본 입력 계약 점검 후 원본 process1회, 자동재시도0이다. 시작 양립성 q/LTM RMS≤.02/max≤.04를 실제 후보 배열로 다시 확인한다. 양의 λ이고 통과하면 같은 시작 신체에서10초·100,000 native 단계의 저장 명령 대조1회를 실행한다. 원래 E150 10초와 E154의1–2초 signed contact를 비교군으로 고정한다. native 속도·실제 하중/미끄러짐·힘의 좌표·시간·오류/부분 실행 기록은 검증된 E158–E160 경로를 재사용하며 그 소스 해시를 동결한다. 초기 준비 2000 physics steps와 scientific100000, shadow forward100000을 분리 기록한다. 추가 신경 계산·fit은0이다.

다음 전체 신경 폐루프 단계로의 진입 조건은 기존 E158과 같다: F3 수치 건강/전진, E150 대비 전진 및 net/path 각각≥.95, native slip≤E150, longest forward bout≥.3s, 다리마다 적격 완전주기≥1, RM1–2초 backward impulse magnitude≤E150의.9, 네 무릎 폭은 F5 하한 이상이다. 이것은 개발 진입 기준이며 최종 F4의10주기·좌우 위상/R·CV나 F6/F7/F8을 대체하지 않는다. 비교 지표를 충족하지 못한 유효 실행은 candidate 미채택이며 전체 목표는 계속 미완료다. 기술 실패와 건강성 측정 종료를 구분하고 원시자료를 수치 assert보다 먼저 저장한다.

부모가 설계하고 기존 실제 Sol/high 에이전트 /root/m3_sol_e132_lf_constrained가 첫 구현한다. 해석적 수치 제약을 native 물리·부분 오류 보존 경로에 연결하는 구현이므로 high를 쓴다. 부모 첫 리뷰→같은 Sol 첫 수정→부모 두 번째 리뷰/잔여 수정이다. 소유 파일은 tools/verify_c_banc_m3_rm_proximal_unload.py와 tests/test_c_banc_rm_proximal_unload.py다. 생성 자료로 닫힌식 경계·0변화·초기 관측 보존·부분 물리/저장 실패를 확인한다. 원본 λ/배열/신체는 gate 전에 계산·실행하지 않는다.
