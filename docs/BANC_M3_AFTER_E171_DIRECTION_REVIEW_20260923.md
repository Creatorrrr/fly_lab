# E171 이후 방법 선택

전체 목표는 같은 BANC 후보가 실제 폐루프 자연 보행 F1–F8을 모두 통과하는 것이다. E171은 저장 신호에서 얻은 두 무제한 최소제곱 해가 지나치게 큰 signed 계수와 심한 startup 확대를 사용한다는 사실을 확인했다. 명목43.98%/53.65% 감소는 수치 해상도 판정과 물리 제약을 통과하지 못했고, 어떤 제약 하나가 주원인인지는 분리하지 못했다. 이 결과로 신경 신호가 충분하다거나 전체 BANC가 불가능하다고 결론내리지 않는다.

다음은 작은 singular value를 더 포함하거나 cutoff를 여러 번 조정하는 탐색 대신, **기존 계수 크기 한도2를 유지한 저장 affine 표현력**을 확인하는 bounded 진단을 설계한다. 다음 E172의 후보 비교는 static/history 두 가족이며, 각 가족에서 계수를[-2,2]로 제한하고 history의 alpha+beta endpoint도[-2,2]로 제한한 낙관적 공간을 검토한다. signed 계수는 생물학적 후보가 아니며, 원래 양수·근육 예산·startup·velocity 보호가 있는 E169/E170 가족을 포함하는 진단용 superset으로만 사용한다. 원래 물리 후보의 조건은 완화하지 않는다.

이 공간에서 전체 command RMS20% 감소의 유한 witness를 찾을 수 있으면, 극단적 계수 없이 표현되는 저장 신호가 있다는 제한된 근거가 된다. 그때 같은 계수의 부호/근육 예산/startup/velocity 위반을 보고 어떤 전달 또는 초기화 문제를 구분할 다음 비교가 필요한지 선택한다. 신뢰할 수 있는 bounded dual upper가20% 달성을 배제하면 현재 고정 특징과 계수 규모의 한계라는 좁은 결론을 얻고, 새로운 BANC 세포·근육 동역학 특징을 검토한다. solver 또는 수치 검증이 미달하면 inconclusive로 남긴다.

두 가족 각각 최대 한 번, 총2회 새 최적화로 범위를 제한하는 설계가 적절하다. 저장 command QR만 목적에 사용하고 velocity/startup은 같은 계수의 평가만 수행한다. 원래 feature/recurrence/신경/몸체/F6를 새로 노출하지 않는다. signed 진단을 runtime에 연결하지 않는다. 최종 실제 BANC 후보에는 원래 provenance, 양수/근육 보호, 외부 CPG·교사·위상·root 보정 금지 및 모든 F1–F8 검증이 그대로 필요하다.

아직 E172의 solver·정확한 행렬/dual·자원 한도·source gate는 동결하지 않았고 추가 fit은0이다. 다음 턴에서 부모가 이 유한 비교를 구체화하고, 실제 gpt-6-sol/high가 FIRST 구현을 맡는 기존 절차를 적용한다. E171 gate는 소비된 상태다. 누적3049.0294185999082초와 V1 실패를 보존한다.
