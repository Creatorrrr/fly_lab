데이터·모델·검증 범위

FAFB v783의 전체 포함 뉴런에 LIF를 적용합니다. 화학 연결 가중치는 시냅스 수 × 0.275mV × 전달물질 부호입니다. ACh는 양수, GABA·glutamate는 음수이며, 미확정·신경조절성 출력은 현재 프로파일에서 0으로 가립니다. 해당 뉴런의 상태 계산은 계속합니다.

현재 자연 입력은 이상화한 냄새장을 ORN_DM1 집단에 연결합니다. 실제 복안·냄새 수용체 반응·VNC 전체는 재현하지 않습니다. 조향·전후진은 문헌과 실제 ID를 검토한 공학적 출력 해석이며, 회피 보조가 꺼진 C_STRICT의 안정적 탐색은 별도 검증 대상입니다.

CPU 수치 검사, 실제 물리 실행, CUDA 일치성, 생물학적 타당성은 별도로 판정합니다. CUDA 실장치 검증은 NVIDIA 환경이 필요합니다.
