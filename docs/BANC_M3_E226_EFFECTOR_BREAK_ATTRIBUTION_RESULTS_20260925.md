# E226: 실제 짧은 후진과 지지 중 회수 운동을 확인

E225의 저장된 8.315초 자료에서 전체 단절26개, 사전 지정 주요 단절10개를 분석했다. 주요 단절은3초 이후0.3초 이상 전진에 이어진25–50ms 구간이다. **실제 초기 방향 속도가 음수로 바뀌며, 회전·상하 움직임의 투영만으로 설명되지 않는다.** 관절 추종 오차는 작고, 일부 발이 하중을 받으며 회수 방향으로 움직인다. 특정 다리나 근육이 제동 원인이라는 인과 결론은 아직 없다.

전진 성분이 음수라고 몸체가 완전히 정지한 것은 아니다. 단절 중에도 수평 속력은2.85mm/s이며 뒤·옆 방향 이동이 포함된다. 속도 필터/중앙차분은 진단용 비인과 연산이고 원래 F4 계산은 그대로다.

단절 중 평균 하중은 LM0.236 / RF0.298 / RH0.243BW에 집중돼 있다. RH 말단의 몸 기준 전후 속도는 평균 +2.545mm/s로 회수 방향이고, 회복기에는 LF/LH/RM 쪽으로 지지가 이동한다. 주요 사건10개 중 후기 사건에서는 RH tarsus depressor, LF tibia extensor, RF sternotrochanter extensor 등의 명령 변화가 상위에 나타난다. 이 순위는 고정 anatomical moment를 통한 **각도 명령 변화량**이며 힘이나 인과 기여 순위가 아니다.

발말단 원점의 운동, 접촉점 slip, 하중은 서로 다른 양이다. 무하중 발과 관측 없는 slip은 null/유효 표본 수로 보존했다. 예를 들어 단절 RH의 slip 평균은8개 유효 사건에서2.201mm/s이고, LH는2개 사건만 유효하다. 지원 표본이나 유효 사건 수가 다른 평균을 동일한 독립 실험으로 취급하지 않는다.

## 검토와 자원

실제 gpt-6-sol/high 구현 뒤 부모 FIRST에서 한 발의 결측이 다른 발의 유효 slip 평균까지 지우는 오류와 전체 주요사건 요약 누락을 발견했다. 같은 Sol이 첫 수정했고 부모 SECOND에서7개 생성 검사(2.27초)/Ruff를 통과했다. 부모 잔여 코드 수정은 없었다.

저장 분석1회는 내부1.5288383초 / 감독4.4934381초, 출력64,894,150bytes, 최대개별RSS897,175,552bytes로 완료됐다. 소유 프로세스25752 / 22152 / 30924는 모두 종료됐다. 원본 신경·CUDA·물리·fit·solver 실행은0이다. 부모 독립 원자료 검산은1188개 항목을 통과했으며 내부0.7617618초 / 프로세스1.4052949초였다. 검사 개수는 보행 반복 수가 아니다.

자원 용어를 보수적으로 정리한다. E226 감독 파일의 `cumulative_after_s`는 dynamics만 증가시키도록 작성됐지만, 이전 E186/E219/E220의 원본 자료 분석도 단계의 실험 누적에 포함됐다. 따라서 E226의 주 분석4.4934381초도 **원본 자료 실험 누적에 더하여 5990.496209299676 / 6004초**, 잔여13.503790700324316초로 기록한다. 원본 신경·물리 실행0이라는 사실은 그대로다. 원래 감독 파일과 사전 설계는 수정하지 않고 별도 부모 회계 정정 근거를 남긴다. 부모 검산·구현 검사 비용은 별도 기록한다.

## 다음 개입 판단

E185/E186의 다른 후보에서는 slip이 큰 LF가 실제로는 전진 방향 반력을 냈고, RM/RH 등이 제동에 관여했다. 그러므로 현재 RH의 회수 운동만으로 해당 근육을 약화하는 것은 근거가 부족하다. 다음은 E224의3초 신체 checkpoint와 E225의 고정 실제 명령으로 **신체만 정확히 재현**하여 수평 반력을 관측하는 진단이 적절하다. 관절/몸체/native 기록이 원래와 일치해야 힘 결과를 해석하고, 전 다리와 모든 지정 사건을 보존한다. 기록 명령은 진단에만 쓰며 새 자율보행 성능으로 주장하지 않는다.
