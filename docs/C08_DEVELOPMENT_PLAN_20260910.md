**다음 개발의 중심 목표는 감각이 운동뉴런과 근육을 거쳐 몸의 반응을 바꾸는 것을 먼저 입증하고, 이를 지속 보행과 자연 행동으로 확장하는 것이다.** 현재는 선언된 대규모 연결망 계산, 조작·기록·복원, 단일 관절의 직접 신경 자극까지 구현됐다. 감각 피드백에 의한 국소 운동, BANC 지속 보행, 양방향 먹이 탐색과 자연 정지·회피는 성공하지 못했다.

### 3.2 성능·재생: 개선 적용됨, 실시간은 미달

입력/결과 버퍼와 개입 마스크 재사용, BANC 롤백 진단 복사 축소, FAFB 반사 계산의 Numba 처리, 렌더 주기와 독립적인 재생 요청이 반영됐다.

0.3모델초, 버전별 3회 중앙값이며 브라우저·네트워크는 제외됐다. 시간 감소로 표현하면 9.7~13.0%다. 전신 계산의 실시간 달성이나 긴 실행의 처리율 보장은 아니다. 특히 단일 관절 장치는 물리 dt가 10µs이므로 위 보행 엔진 성능을 그대로 적용할 수 없다.

해결된 최적화 실패도 구분한다.

- 첫 Numba 보간 구현은 마지막 비트 차이로 물리 동등성에 실패했다. NumPy 보간을 유지한 최종 구현은 통과했다.
- 첫 기록 비교는 상대 저장 경로 60곳을 실제 결과 차이로 계산했다. 원래 FAIL은 보존됐고, 저장 경로와 시간 계측 필드만 정규화한 재평가에서 5조건 모두 동등했다. 신경·몸·신호·기록 데이터까지 임의로 제외한 비교가 아니다.
- 재생 예약 단위 검사 6/6, 기존 B 제어기의 물리 경로 14/14가 통과했다.
- 실제 브라우저의 FAFB/BANC 재생·정지·원래 0.05초 상태 복원 기록도 통과했다. 일시정지는 이미 제출된 계산을 취소하지 않으며 후속 예약을 멈춘다. 40ms는 배치 조절 목표로서 지연 상한 보장이 아니다.

### 6.3 구현 순서와 산출물

1. **입출력 관측 확장.** 실제 0.1ms 발화 시각과 1ms 전압 표본을 분리해 저장한다. Fast/FETi뿐 아니라 검토된 느린/보조 motor와 활성 presynaptic 경로를 관측한다. 포트별 입력·지연·발화·입력 전류·모집 활성·힘·토크를 같은 시간축으로 연결한다.
2. **고정 입력과 replay 진단.** 이미 관측한 q=1.2/1.862/2.2rad와 18/36/72mV는 탐색용 기준선으로 유지한다. 자유 관절의 실제 q/v 재생, 감각 집단별 입력, 감각 출력 차단을 기존 probe에 추가한다. 단순 구조적 경로 존재와 실제 전류 기여를 구분한다.
3. **기계·생리 근거 정리.** 모델 길이·질량·시간의 차원으로 힘/토크 환산을 추적하고 중력·관성·외력으로 교차 검증한다. 실측 Fmax와 추정/최적화 파라미터를 구분한다. 데이터가 없으면 SI/생리 교정 완료를 유보하고 해당 공학 모델의 유효 범위를 명시한다.
4. **최대 3개 원인별 후보.** 수용체 transduction, 운동단위 동역학/모집, 근거 있는 하행 상태 중 관측이 지지한 변경만 후보로 만든다. 각각 모델 해시·근거·불확실성을 가진 새 프로파일로 저장한다. 근육 내부의 모터 식별자와 실제 BANC ID의 대응을 계속 검증한다.

### 6.4 모멘트암 반전 처리

현재 q≈0.61344rad의 반전은 파생 장치를 만드는 변환 오류가 아니다. 원본의 힘줄 site 경로에서도 일치했다. 새 guard는 82.25ms에 최초 반전을 검출하며 그 전 궤적을 바꾸지 않았다.

따라서 선택지는 근거를 확보한 뒤 결정한다.

- 해부학적 부착/경유 경로 오류가 확인되면 새 tendon routing 프로파일로 수정하고 전 범위를 재검증한다.
- 원본 모델의 사용 범위가 제한된 것이라면 근거가 있는 범위를 별도 제한 프로파일로 선언한다. 제공된 단일 0002 clip만으로 원래 관절 가동 범위를 축소하지 않는다.
- 반전이 해당 구조의 실제 기하 특성이라면 고정된 “항상 신근” 가정의 적용 범위부터 수정한다. 단순히 힘 부호를 뒤집지 않는다.
- 근거가 부족하면 원본+guard를 유지하고 생리 교정은 미완료로 남긴다.

현재 공식 FlyGym 구현도 LF 다리만 근육 구동하며 다른 다리·일부 접촉 감각에는 제한이 있다. 원 논문도 Fmax/수축 속도 등을 모두 직접 측정한 것은 아니라고 설명한다. 따라서 upstream 모델을 가져온 사실이 전신 근육이나 생리 교정을 대신하지 않는다. [FlyGym 근육 모델 문서](https://neuromechfly.org/tutorials/6_muscle_imitation/), [FlyMimic 논문](https://arxiv.org/html/2509.06426v1)

### 6.5 첫 실험 묶음과 통과 기준

이 절의 추가 수치는 **실행 전 고정할 공학적 제안 기준**이다. 실측 생리 범위라는 뜻이 아니며 기존 실패를 통과로 바꾸기 위한 재평가에 사용하지 않는다.

|---|---|

| 확인용 자세 | 1.4/2.0rad를 우선 후보로 두고 이전 사용 이력을 점검한 후 확정. 탐색·선택에 사용한 값은 확인용이라고 부르지 않음 |
| 최종 대조 | 2자세 × 외력 ±방향 × 회로 4상태 × 외력 유/무 = 32조건. 최종 후보와 원 기준선 각각 0.3초, 총 19.2물리 모델초 |
| 공통 입력 | 원래 외력 크기·발생 구간과 감각/신경/물리 dt 유지. 변경이 필요하면 별도 버전으로 기준선도 재실행 |
| 무작위성 | 결정적 조건을 여러 번 반복해 독립 생물 표본처럼 세지 않음. 노이즈를 도입할 때만 별도 시드·정밀도 계획 추가 |

통과 조건은 다음을 모두 충족해야 한다.

1. 기술 gate, 인과적 시계, 오류 감시, 정상 복원/잘못된 복원의 원자적 거절이 통과한다.
2. 감각이 해당 조건에서 예측되는 motor 모집과 토크를 만든다. 모든 자세에서 두 빠른 motor가 함께 발화할 것을 강제하지 않는다.
3. 정상과 절단 대조의 관절 차이가 max(0.0001rad, 반복/수치 오차의 10배)를 넘고, 감각 출력 절단 또는 운동 차단에서 예측된 효과가 사라진다.
4. 외력에 대한 편차는 각 회로의 동일한 무외력 궤적을 빼서 계산한다. 회복 구간 적분절대오차가 open 대비 **20% 이상 감소**하고, 최대 편차가 open의 1.05배를 넘지 않는다. 양 외력 방향·확인용 자세 모두 충족해야 한다.
5. 기준 역학만의 회복, 모터 지속 직접 자극, guard를 넘는 궤적을 성공으로 합산하지 않는다.
6. 모멘트암·단위·모집·수용체 모델의 근거 및 미확정 범위를 보고한다. 기술적 피드백 효과와 생리 교정 완료는 별도 판정한다.

신경 발화만 늘고 동적 효과가 없으면 M2는 실패다. 반대로 강제 하행 자극에서만 피드백 효과가 생기면 국소 evoked 폐루프의 제한적 성과로 보존하고 자연 구동은 미해결로 남긴다. 모든 후보가 실패하면 확장을 멈추고 가장 구분력이 큰 가설의 자료·모델을 보완한다.

## 8. M4 — 자연 감각 기반 양방향 행동

### 8.1 먹이 좌우 편향: 원인 위치부터 찾기

센서값 → transduction → 감각 뉴런 → 중간 회로 → 하행 readout → 몸의 순서로 같은 시간축 기록을 남긴다. 세계의 목표 좌표나 정답 방향은 평가기만 사용하고 신경 입력·운동 decoder에 넘기지 않는다.

1. 입력이 완전히 같은 좌우 대칭, 좌/우 교환, 한쪽만 입력, 농도 유지/변화 조건을 고정한다.
2. 좌우 감각 파형·선택 뉴런 수·cell type 구성·발화율·시냅스 전류·출력 gain을 단계별 비교한다. 실제 해부학적 비대칭과 구현의 좌표/부호 오류를 구분한다.
3. 최초 편향 지점에 맞춰 한 계층씩 후보를 만든다. 전체 그래프 대칭화, 한쪽 신경 제거, 최종 yaw 상수 보정으로 해결하지 않는다.
4. 고정 입력에서 조건에 따른 양방향 응답을 먼저 확인한 뒤 먹이 위치·초기 방향·농도·시드를 바꾼 물리 캠페인으로 진행한다.

기존 좌편향 probe는 이미 개발에 노출된 자료다. 확인용 조건은 사용 이력을 확인해 분리한다.

## 9. M5 — 내부 상태·ResearchLIF·지연 보상과 기억 통합

### 9.1 현재 구현의 정확한 경계

현재 CEngine의 대사는 이동 비용과 근접·저속 조건의 가상 섭취를 기록한다. hunger 값이 감각 처리나 신경 활동을 바꾸지는 않는다. food.strength는 냄새 세기인 동시에 대사의 가용량으로 사용된다.

ResearchLIF의 reward_stdp_v1은 현재 reward와 현재 pre/post 관계를 곱한다. 자극 쌍이 끝난 뒤 도착한 보상을 독립적으로 연결할 eligibility 상태는 없다. 가중치가 달라졌다는 단위 검사만으로 선호·기억·학습이 구현됐다고 판정할 수 없다.

### 9.2 구현 순서

1. **음식 스키마 분리.** odor_emission, remaining_mass, nutrient_density와 명시적 섭취/접촉 조건을 분리한다. 기존 strength 프로파일은 기존 의미로 읽는 legacy 경로를 유지하고 새 음식량을 자동 추정해 생물량이라고 표시하지 않는다. 냄새만 있는 원천과 냄새가 약한 영양원을 각각 대조할 수 있게 한다.
2. **Research backend 통합.** 신경 Protocol과 CEngine 생성/저장/복원/개입/기록을 연결한다. 연구용 backend 선택 시 지원하는 적분·수용체·gap·가소성 옵션을 capability로 알린다. 기존 MetalLIF shader가 새 생리 기능을 자동 지원한다고 가정하지 않는다.
3. **수용체·조절성 경로.** 실제 ID와 출처가 있는 표적·효과·시간상수부터 명시한다. mask_zero인 조절성 뉴런을 일괄 흥분성 화학 시냅스로 바꾸지 않는다. tonic 상태와 phasic 보상 효과를 구분한다.
4. **eligibility 상태.** 기존 시냅스의 선정된 부분에만 pre/post trace와 독립된 eligibility를 만들고 지연 보상이 이를 조절하게 한다. 상태·가중치·포화·reward/eligibility clock·RNG·보류 이벤트를 저장한다.
5. **허기–섭취 연결.** 같은 환경에서 초기 에너지 상태만 바꿔 탐색·접근·섭취와 포만 후 변화를 비교한다. 운동 능력 저하와 선호 변화를 분리한다. 실제 섭식이라고 부르려면 구기 동작·접촉·이송 모델도 필요하다.
6. **냄새 연합학습 한 과제.** CS+/CS− 냄새를 교차 배정해 보상, 무보상, 시간 비상관 보상, 가소성 동결, 조절 경로 절단을 대조한다. 학습 뒤 보상을 끄고 선호를 측정한다.

### 9.3 비교·완료 기준

- 새 생리 기능을 끈 Research backend가 기준 모델과 기존 수치 허용오차·발화·복원 검사를 통과해야 한다. 기능별 변경은 작은 회로에서 검증한 뒤 전체 그래프로 확대한다.
- 음식량·냄새·영양량을 각각 바꾸는 대조에서 의도한 항목만 변한다. 소모·섭취·에너지 회계가 저장·복원 후에도 일치한다.
- 허기 효과는 이동 능력과 노출량을 맞춘 상태에서 재현되며 조절 경로 절단으로 약화돼야 한다. “에너지 감소” 로그 자체는 완료 기준이 아니다.
- 기억은 무보상 probe, CS 배정 교환, 가소성 동결 및 시간 비상관 보상 대조로 확인한다. 냄새 감각과 운동을 잃어 생기는 차이는 기억으로 인정하지 않는다.
- washout은 막전위·rate·감각 필터 등 비학습 상태가 기준 수준으로 돌아오는 시간을 측정해 정한다. 정상 지연 시험과 “학습 가중치 유지/비학습 상태 동일화” 진단을 모두 둔다.
- checkpoint 복원 뒤 같은 지연 probe에서 결과가 유지되고, 학습 가중치를 기준선으로 돌리면 기억 효과가 줄어야 한다.
- 선호 지수는 PI=(CS+ 영역 체류 시간−CS− 영역 체류 시간)/(두 영역 체류 시간의 합)으로 정의한다. 두 영역을 선택할 노출·이동 기회가 부족하면 무효로 처리한다. 첫 정량 목표는 학습 전후 PI 변화 0.15 이상, 짝지은 대조 차이의 95% 구간이 0 초과로 제안한다. 개발용 최대 8개 시드는 시간·분산·노출 설계에만 쓰고, 확인은 별도의 16개 시드와 냄새 배정 교환으로 고정한다. 구간 추정은 시드별 짝지은 차이를 단위로 하며 방법을 실행 전에 기록한다. 확인 중간 결과로 표본 수를 늘리거나 조기 성공을 선언하지 않는다. 정밀도가 부족하면 미판정으로 끝낸다. 이 기준은 생체 효과 크기나 개체 수를 주장하지 않는 공학 과제의 기준이다.

지연 보상·학습을 켠 상태의 대규모 계산은 현재 MetalLIF 성능 표를 적용할 수 없다. MPS 경로에서 메모리와 실행 시간이 기준을 넘으면 기능별 sparse state와 관측 비용을 먼저 줄이고, 정확성 기준을 희생해 성능을 맞추지 않는다.

| E5 다리/행동 | M3/M4 | 해당 하위 장치, 과제 기준, 초깃값·시드·노출 기회 | 단기 기본 조건에서 실패하면 대규모 행동 행렬 시작하지 않음 |
| E6 학습/비행 | M5/M6 | 독립 과제와 대조, 모델별 저장 상태·시간·메모리 | 성립한 앞 단계의 범위 안에서만 진행. 전체 확장 일정 확약 없음 |

전뇌 MPS 물리 작업은 우선 한 프로세스로 실행한다. 현재 장치에서 실제 메모리 최고값과 처리율을 잰 뒤 병렬 처리 수를 정한다. 최초 실험 묶음의 벽시계 상한은 60분으로 제안하고, 초과하면 부분 결과와 남은 사례를 저장해 계산 비용을 재산정한다. 단순히 느리다는 이유로 생물학적 가설을 기각하지 않는다. 외부 자료 다운로드 실패도 자료 확보 문제와 모델 실패를 구분한다.

FlyGym 추가 계측·기계 교사·접촉·감각 계약 검사는 [보강안 FG1–FG6](/Users/chasoik/Projects/FLY_LAB/docs/C08_FLYGYM_REFINEMENT_20260910.md#9-추가-작업의-범위검증중단-조건)에 범위와 상한을 분리했다. 기존 E2–E4 및 M4/M5 확인 예산을 자동으로 늘리지 않으며, 기록 운동학이나 기계 교사 성공으로 기존 신경 피드백·보행 기준을 대체하지 않는다.

확인용 데이터를 후보 선택에 사용하면 그 자료를 탐색 집합으로 이동하고 다음 확인 설계를 별도로 남긴다. 기존 실험 ID·임계값·실패 결과를 덮어쓰지 않는다. 판정기 수정이 필요하면 수정 이유와 버전을 남기고 기준선과 후보를 모두 같은 새 판정기로 재평가한다.

실험마다 최소한 다음 다섯 판정을 분리한다.

| 판정 | 예시 |
|---|---|
| 실행 | planned / completed / aborted / not_run |
| 유효성 | valid / invalid / pending |
| 가설 | supported / refuted / inconclusive / not_tested |
| 채택 | adopt / reject / defer |
| 단계 결과 | pass / fail / pending / blocked |

원인 규명 실험의 성공은 운동 개선 단계의 성공과 다를 수 있다. 기존 단일 관절 작업의 guard 검출, 고정 자세 신근 반응, 기준 역학에 의한 회복이 그 예다.

## 12. 검증·기록·사용 화면의 공통 요구

- 각 원자료에 소스, graph, binding/physiology, body, receptor, integration dt, control dt, backend/runtime, seed, evaluator 해시를 연결한다.
- 기존 기록 도구와 campaign runner를 확장한다. 새 실험마다 별도 프레임워크나 중복된 상태 저장 체계를 만들지 않는다.
- M2는 0.1ms 발화 이벤트와 1ms 관절 표본을 분리한다. 장시간 실험은 선택 신호를 연속 기록하고 전체 상태는 경계 checkpoint로 저장해 메모리·디스크 비용을 제한한다.
- UI의 관측 512개 제한은 전체 계산 뉴런 수와 구분해 표시한다. 선택 수 제한을 이유로 전체 신경 계산을 줄이지 않는다.
- 개입은 요청 시각·적용 모델 시각·종료 시각, 실제 ID/edge, 차단 의미를 저장한다. “억제”와 “시냅스 출력 차단”, 근육 출력 차단을 구분한다.
- 기술 실행, 생리 교정, 행동, 인과 효과를 별도 표시한다. 한 관절 기술 PASS로 전신 보행이나 자연 행동을 완료 표시하지 않는다.
- 새 joint/leg/flight profile은 화면에서 구동 방식과 검증 범위를 확인할 수 있어야 한다. 기존 사용자의 환경·개입·checkpoint를 자동 변환하지 않는다.
- 변경에 맞는 기존 회귀와 실제 물리 검사를 실행한 뒤에만 해당 범위의 결과를 갱신한다. 문서·로그·코드 통과만으로 실제 행동을 승인하지 않는다.

## 13. 바로 이어서 개발할 작업 순서

1. **M1 비교기·물리 계측과 M2 진단 확장.** 기존 최적화의 성공을 보존하고, native 단계별 계측·상대 경로 비교 수정·관절/좌표 대조·q/v replay·motor/presynaptic 관측을 리뷰 가능한 코드로 만든다. 같은 단일 관절의 기계 교사를 추가해 신경 모집과 물리 제어 가능성을 구분한다.
2. **M2 원인 분리 실험과 자료 교정.** 18/72mV 자유 관절 실패를 기준선으로 두고 입력 시간, 수용체, 운동단위, 부호/수용체, 하행 상태를 구분한다.
3. **선택한 단일 관절 후보의 동적 확인.** 양 외력 방향과 미사용 자세에서 정상/절단 차이 및 회복 개선을 확인한다. 실패하면 확대를 멈추고 원인별 후보를 다시 판단한다.
4. **한 다리 접촉과 근육 기반 보행.** 검증된 국소 모델을 다관절·양측·6다리로 확장하고 기존 보행 기준을 유지한다.
5. **자연 행동 및 내부 상태·학습.** M4 고정 감각 분석과 M5 스키마/API 준비는 앞 단계 중에도 가능하지만, 행동 완료는 각 단계의 대조 실험으로 판단한다.
6. **공간 기능·비행.** 신경·물리·감각의 앞 단계가 성립한 범위에서 독립된 기능별 검증을 진행한다.

가장 먼저 완성할 산출물은 **감각 피드백을 끊으면 예측된 운동 기능이 사라지고, 정상 피드백에서는 검증된 관절·다리 반응이 회복되는 모델**이다. 이를 다음 전신 확장의 근거로 사용한다.
