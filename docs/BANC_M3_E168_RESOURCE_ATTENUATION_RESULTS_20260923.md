# E168 사용량 의존 전달 상태: 고정 가족 기각

E168은 유효하게 완료했으나 후보를 채택하지 않았다. 같은 운동뉴런의 활성 이력에 따라 전달 효율을 낮추고 휴지 중 회복시키는 고정 70ms 상태만으로는, 기존 전달 보호와 초기 자세를 유지하면서 정해 둔 명령 오차 감소 조건을 만족하지 못했다. 전체 BANC의 자연 보행 목표와 F1–F8은 미완료다.

## 결과

| 항목 | E150 기준 | E168 반환 후보 | 고정 조건 |
| --- | ---: | ---: | --- |

| 전체 명령 속도 RMS, rad/s | 1.946643261158 | 1.944823962365 | 기준 이하 |

명령 오차 감소는 약 1.04%로, 사전 20% 조건에 미달했다. LM과 RM의 속도 오차도 기준보다 커져 다리별 비악화 조건을 만족하지 못했다. lambda의 정확한 [0,1] 범위, 기존 MN/근육별 하한·상한, 고정 근육, 비음수 활성, decoder 재구성과 LTM 시작 조건은 통과했다. 작은 계수 위반을 잘라내거나 조건을 조정하지 않았다.

솔버 종료 상태는 `InsufficientProgress`다. 반환 margin은 **−0.237035882645**, 실제 변수 box와 cone projection을 반영한 보수적 dual 상한은 **−0.237035870094**다. 부모의 독립 스칼라 계산도 **−0.237035870094**를 얻었다. 기각 판정의 근거는 이 독립 검산한 보수적 상한이다. 현재 저장 신호·고정 70ms 식·기존 보호·startup·오차 조건을 함께 둔 가족에만 적용되며, 모든 사용량 의존 전달 모델이나 생물학적 기전의 반증은 아니다. E167의 독립 시점별 낙관적 구간은 해의 존재를 보장하지 않았으며, E168은 시간 상태와 공통 계수를 적용하면 해당 여유를 충분히 사용할 수 없음을 확인했다.

## 구현 및 검증

부모가 설계했고 실제 **gpt-6-sol/high**가 최초 구현과 첫 수정을 담당했다. 부모 FIRST 리뷰에서 발견한 입력의 손실 변환 및 오류 시 원시자료 누락, 완료된 자원 계산량의 누락을 같은 Sol이 수정했다. 부모 SECOND 리뷰에서 잔여 차단 결함은 발견하지 않았다.

생성 데이터 테스트 23개와 프로젝트 Ruff/format이 통과했다. 부모는 별도 수치 비교 208개, 실제 NPZ shape/dtype 대조 90개와 상태 NPY 헤더를 확인한 뒤 원본을 실행했다. NaN·복소 입력은 변환 전에 원형을 저장하고 거부하며, 후속 계산 실패 시 이미 완료된 상태와 계산량을 보존한다.

원본 종료 후 부모가 자원 상태, 양수 branch 기여, 활성과 명령, 모든 물리 판정, 선형/SOC 행과 보수적 dual 상한을 독립 검산했다. **118개 검산 통과**, 보존·소스 해시 **3,441개 일치**. 원본 결과를 다시 적합하거나 수정하지 않았다.
