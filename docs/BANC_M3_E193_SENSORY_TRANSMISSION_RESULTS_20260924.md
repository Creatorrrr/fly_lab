# E193 감각 전달 관측 결과

**원본 관측은 유효하며, 속도 감각 입력이 현재 신경 모델에서 거의 발화로 이어지지 않는 구간을 확인했다. 보행 개선이나 그 원인의 확정은 아니다.** 동일 E150 모델의 3초에서 241포트·3604감각 세포를 관측했다. 실제 CUDA 전체 BANC 158706뉴런, 600제어·12000신경·30000물리 단계를 수행했다. 신체 물리는 기존 CPU MuJoCo 그대로다.

원래 E185와 trace 601행, native recruitment 601행, contact 30000행 및 시작/최종 상태가 정확히 같았다. 부모 독립 검산 52607항이 통과했고 특징·request·20ms 필터·30ms 속도 lowpass 재구성의 최대 절대 오차는 모두 0이었다. 반환 감각 drive와 다음 신경 경계의 drive도 float32 bit-exact였다. 관측기 추가가 보행을 바꾼 증거는 없다.

지원되는 hook 타입 SNpp39/41만 따로 보아도 123개 중119개가 정확히 0이었다. 전체 감각 세포에서 cap의95% 이상 출력은 없었고 output_mask는1이었다. 따라서 현재 구간은 높은 출력의 포화로 설명되지 않는다. 반면 위치 특징은 여섯 다리에서 변했고 일부 claw 발화도 변했다. 감각 전체가 끊겼다는 설명은 맞지 않는다.

속도 특징의 p95−p5 범위는 hook에서 다리별 약0.0071–0.0292, club에서0.0036–0.0127이었다. 공통 gain18을 적용한 입력은 신경 모델 threshold7.5에 비해 작다. recurrent current와 adaptation까지 포함한 실제 endpoint 순입력도 hook/club 대부분에서 비양수였다. 모든 단계의 기록은 존재하지만 실제 출력이 약한 구간이다. 한 궤적의 이 결과로 전체 회로의 고장이나 특정 감각 계수의 정답을 결정하지 않는다.

촉각 특징은 모든 포트에서0이었다. 관측된 비바닥 접촉량도0이므로 평지 실행에서 이 항은 누락으로 판정하지 않는다. 외부 drive가0인 세포에서도 재귀 입력에 따른 발화가 일부 있어 특징0과 신경 출력0을 같은 것으로 취급하지 않는다. 미해결 claw/hook 타입에0을 주는 기존 가설도 유지하며 임의로 타입을 다시 붙이지 않았다.

## 후속 판단에 필요한 속도 관측 문제

결과 해석 중 수행한 **사후 일관성 점검**에서, 연속 각도 차이를5ms로 나눈 값의 RMS는 다리별2.46–6.60rad/s였지만 경계 속도의 양끝 평균 RMS는0.094–0.280rad/s였다. 유한 차분은 순간 속도의 정확한 대체가 아니므로 이것만으로 기하 공식의 오류를 확정하지 않는다. 기하 속도와 원래 knee joint qvel의 크기는 비슷했다.

현재 체크포인트에는 `continuous_joint_activation`이 없고 기본값은false다. `BancWalkingParameters`의 직렬화가false일 때 필드를 생략하며, 해당 경로는5ms 동안 최종 관절 명령을 유지한다. 따라서 tracking servo가 주기 초반에 움직이고 경계에서는 감속한 상태를 읽는 설명이 가능하다. 아직 native100µs의 실제 각도/속도 시계열로 확인하지 않았다. 다음 판단은 기존 body replay 경로로 이를 대조할 수 있는지 확인하는 것이며, 감각 gain 증가·유한 차분 대체·기존 continuous 옵션 재시험을 자동 선택하지 않는다.
