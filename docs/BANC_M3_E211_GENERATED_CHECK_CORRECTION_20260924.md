# E211 생성 수학 대조의 오차 기준 수정

원본 적합 전 생성 Clarabel1회는 Solved를 반환했으나 좌표별 atol1e-5 검사에서 실패했다. 저장된 pytest 출력의 두 번째 좌표는 .1500145720737724로, 분석해 .15와의 차이1.4572074e-5다. 이 실패를 통과로 바꾸거나 삭제하지 않는다. `parent-e211-generated-receipt.json`과 원래 source SHA를 보존한다. 원본 solve는 아직0회다.

좌표 atol1e-5는 solver의 목적/제약 tol1e-8에서 도출된 값이 아니었다. 이 생성 문제는 y=(.1,.1), c=(.8,.2), R=.25*sqrt(2)에 대해 f=||x-y||², g=||x-c||²-R²이다. 정확한 해 x*=(.45,.15), f*=.125, KKT multiplier1이고, 모든 x에서 `f(x)+g(x)-f*=2||x-x*||²`가 성립한다. 따라서 |f-f*|와 |g|<=1e-8로부터 얻는 좌표 벡터 norm 보장은1e-4이며1e-5가 아니다. 기존 좌표 검사는 수렴 설정보다100배 작은 이차 오차를 요구했다.

부모 SECOND 후 잔여 테스트 수정을 수행한다. 검증은 실제 반환값을 판정 전에 모두 기록하고 다음을 확인한다: Solved, strict box0..1, 목적 |f-.125|<=1e-8, |g|<=1e-8, 위 KKT 항등식 float64 잔차<=1e-14, 이에 따른 ||x-x*||<=sqrt(1e-8). 저장된 solver primal/dual objective와 residual도 보고한다. 첫 다리 startup 절대오차>.25이고 전신 norm이 허용되는 대조는 유지한다. 원본 문제·solver 설정·물리 proxy·F1–F8을 변경하지 않는다.

이 수정의 사전 범위는 **추가 생성 문제1회**뿐이다. 기존 생성 실행1회를 포함해 생성 총2회를 기록하고 원본은 여전히 최대1회/원본 retry0다. 첫 실패의 전체 raw는 테스트가 assertion 이후에 출력하도록 작성되어 충분히 남지 않았다는 한계도 보존한다. 추가 실행은 판정 전에 x/s/z와 목적/설정/분석해를 출력하여 원자료로 검산한다. 추가 생성 비용은 별도 계상한다. 실패가 반복되면 이 원본 적합을 시작하지 않고 원자료를 보존하여 원인을 조사한다.

이 문서는 기존 E211 freeze의 생성 실행1회 한도만 명시적으로 총2회로 수정한다. 원본 한도·모델·학습·최종 합격 기준·미사용 확인상태는 변경하지 않는다. 해당 문서 해시는 부모 source review에서 확인한다.
