# E243: 고정 입력 표현의 시간 구간 간 차이 진단

E242는 수치적으로 유효했지만 뒤4초에서7개 사전 기준이 실패했다. 앞6초의 q RMS .04209rad와 뒤4초 .09568rad 사이 차이, 특히 LM/LH/RM 악화를 원래 자료로 설명해야 한다. H243a는 뒤 구간이 학습한 신경 입력/기억 중심에서 멀어져 보간 성능이 떨어졌다는 설명이다. H243b는 비슷한 입력에서도 요구 관절명령이 달라 표현이 운동 정보를 충분히 분리하지 못했다는 설명이다. 두 설명은 동시에 성립할 수 있고 이 진단으로 인과를 확정하지 않는다.

E241 parameters/prototypes/basis descriptor/targets/groups/canonical-original와 E242 candidate/metrics/부모검산을 동결한다. 새 모델·계수·중심·정규화·교사 자료를 만들지 않는다. E242의 계수, 기존80%/비악화/startup 기준과 기각 결과를 보존한다. 뒤4초는 이제 관찰된 개발 자료다. 이후 설계가 이 정보를 사용하면 같은 구간을 독립 검증이라고 다시 부르지 않는다. F6 두 초기자세는 계속 미노출이다.

## 사전 계산

1. 원래 free343 MN의 각 control0..2000 descriptor9개(x3/fast3/slow3)에 대해 자신의64개 중심까지 거리제곱/(2sigma²)를 구한다. 최소 거리·최근접 중심번호·그 중심의 실제 학습 control·정규화 RBF 가중치의 entropy와1/sum(p²)·원래 gate·순간 rate target(cap·gate·sum(p·beta_owner))을 저장한다. RBF는 원래 코드처럼 logits 최대값을 뺀 softmax다. 이 순간 target은 RK 적분된 rate나 새 신경 실행이라고 부르지 않는다. 전체64가중치/모든 거리행렬을 파일로 복제하지 않는다.

2. 원래 해부학적 민감도 w_m=.02·cap_m·pool[owner,m]·norm(moment[leg7,owner])를 다리별 합1로 정규화한다. 각다리에서 가중 최소거리·entropy/effective count, 최근접중심의9좌표 거리 기여를 계산한다. 0민감도 MN은 다리 집계에0가중치로 포함하며 다리 전체0/비유한이면 오류다. 원본 moment/pool/owner는 바꾸지 않는다.

3. TRAIN1..1200, 보조 구간100..1200, 관찰된 뒤 구간1201..2000의 분포를 모두 보고한다. 다리별 학습 p95 최소거리보다 뒤 구간이 큰 비율은 설명용 통계이며 통과 기준이 아니다. x/fast/slow 각3좌표의 거리 기여를 나누어 기록한다. 고정 계수의0/1 경계 근접(1e-8) 비율은 표현 용량에 대한 보조 통계다.

4. 원래 민감도 및 sigma로 가중한 다리 descriptor를 사용해, 각 control1..2000에서 TRAIN1..1200 중 최근접 control을 찾는다. 자기 자신과 절대 시간차20control이하(100ms)는 양쪽 구간에 동일하게 제외한다. 각 열은 원래 MN/좌표 순서이고 scale은 sqrt(w_m/(2sigma²_m))다. 동률은 가장 이른 학습 control을 고른다. 원래 명령/후보 명령/최근접 학습 control의 교사 q 차이를 비교한다. 이는 저장 입력의 이웃 관계를 보는 진단이며 KNN 정책·새 후보·성능 향상으로 채택하지 않는다. endpoint descriptor에는 전체 신경·신체 상태가 없으므로 이웃 목표 불일치가 원래 회로 전체의 정보 부족을 증명하지 않는다.

5. 원래와 후보의 q/속도 RMS·최대오차를6다리와 전체에 대해1초 구간10개로 보고한다. q는 c1..200,201..400 등이며 속도는 같은c의 c−1 차분/.005다. 이미 저장된 E242 TRAIN/뒤구간/startup RMS가 같은 계산으로 재현되어야 한다. 첫 row0는 초기 held 명령으로만 유지한다.

## 판정과 다음 행동

수치 정합성·동결값·행 정렬이 맞으면 유효한 진단이다. 설명별로 거리 증가/좌표 기여/이웃 목표 차이/다리별 오차가 일치하는지 수치로 보고하고, 지지하지 않는 경우도 남긴다. 하나의 임의 임계값으로 원인을 확정하지 않는다. 자동 coefficient 재fit·후보 명령 재생·신경 실행은0이다. 새 표현이나 자료 수집은 이 결과를 근거로 별도 설계하고, 독립 확인의 노출 상태를 명시한다. F1–F8/기존M2·E150·활성UI는 변하지 않는다.
