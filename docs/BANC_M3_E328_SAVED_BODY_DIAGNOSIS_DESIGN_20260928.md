# E328: 저장된 신체 자료로 명령·접촉·전진 실패를 구분

M3 finite-goal과 F1–F8은 그대로다. E327은 유효하게 실행됐지만 실제 보행 후보로 기각됐다. 이 결과를 통과로 바꾸거나 새 원본 시뮬레이션을 실행하지 않고, 다음 개발이 다룰 손실과 측정 대상을 좁히는 저장 자료 진단이다. E327 결과를 이미 본 뒤 작성한 탐색적 분석이며 독립 확인 실험으로 부르지 않는다.

질문은 세 가지다. (1) 유효 주기 0은 고정 전진 구간 조건이 먼저 실패한 결과인가? (2) 명령 곡선까지의 거리가 줄어도 실제 관절 추종과 무릎 운동 범위는 어떻게 달라졌는가? (3) 하중 가중 미끄러짐 악화는 어떤 다리와 어느 시간 구간에 집중됐는가? 이 비교는 원인 위치를 제안할 관측 증거이며 특정 신경 연결의 인과 증명이 아니다.

중립 E318과 E327의 hash가 고정된 `trace.json`, `control-raw.npz`, `native-contact.npz`만 읽는다. 기존 `analyze_c_banc_biological_gait.py`의 전진 속도, moving mask, 0.3초 구간 조건, 기하학적 무릎 및 원래 평가 결과를 그대로 재사용한다. 원본 E327 감사의 결과와 기본 집계가 일치해야 한다. 원본 모델, StateStore/GraphStore, torch/CuPy, 신체 구성, 미분, theta 변경, 학습, F6 접근은 0이다.

각 arm에서 [.5,1.5) 시계와 samples를 검증한다. 전진 moving run 각각의 시작·끝·길이와 eligible 여부, 실제 관절 minus 명령의 다리별 RMS, 무릎의 p95–p05 운동 범위를 보고한다. 관절 명령 및 측정 배열의 다리·관절 순서는 실제 trace 생성 소스와 일치하는지 검토한다. 명령 형태 손실을 실제 관절 손실로 바꾸지 않는다.

Native load≥.02 및 원래 시간 선택에 따른 다리별 support 비율, 하중합, 가중 slip, 전체 분모에 대한 slip 기여도를 계산한다. 시간 bin은 [.5,.75), [.75,1), [1,1.25), [1.25,1.5) 네 개로 고정한다. 다리별 및 시간별 기여도 합은 각각 기존 총 slip을 재현해야 한다. 지원 하중이 없는 값은 null이며 0으로 가장하지 않는다. 선택된 support의 invalid slip·비유한 값·누락/불연속 clock은 거부한다. 공식 cycle/phase/보행 통과 기준은 수정하지 않는다.

Actual gpt-6-sol/high가 새 분석 도구와 의미 있는 생성 계산 검사를 구현한다. 현재 세션 FIRST → 결함이 있으면 같은 Sol R1 → 현재 세션 SECOND → 잔여 수정은 현재 세션 순서다. 기존 source는 불변이며 두 소유 파일만 수정한다. 생성 검사는 단순 집계, support 없음, invalid support, bin 경계 및 기간 실패를 다룬다. Sol/root 생성 CPU 각각 30초, 저장 자료 분석 supervisor 15초/host 1GiB/output 10MiB, 원본 추가 비용 0이다. 모든 실패 비용을 유지한다.

분석 완료 조건은 자료 hash와 시계의 검증, 공식 평가와 집계 재현, 질문 세 가지에 대한 측정 결과와 한계 기록이다. 이것은 보행 개선 성공 조건이 아니다. 다음 방법의 선택은 접촉·전진·주기를 실제 측정하는 목적과 검증을 요구하며, 추가 실행은 남은 자원과 구체적인 새 계약을 검토한 뒤 결정한다. 누적 원본 9034.148870999521/9060초 및 잔여 25.851129000478977초를 보존하며 자동 증액하지 않는다.


검토 전 보완: 현재 trace에는 flat42 실제/명령 관절 배열만 있고 이름이 없다. 소스 또는 저장 metadata에서 다리별 관절 순서가 입증되지 않으면 global 추종 RMS만 보고하고 다리별 추종 값은 unavailable로 남긴다. 기하학적 무릎과 발 접촉은 이름이 있는 별도 body/feet 경로로 계산한다. 새 신체를 생성해 이름을 조회하지 않는다. 이 보완은 분석 입력을 본 뒤의 관측 한계 명시이며 평가 조건 변경이 아니다.
