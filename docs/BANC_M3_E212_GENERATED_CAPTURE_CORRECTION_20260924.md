# E212 생성 대조의 반환값 저장 수정

첫 생성 BVLS 호출은 status1/success였으나 반환 저장 코드가 실제 SciPy OptimizeResult에 없는 `grad` 속성을 읽어 실패했다. 부모 FIRST 요청과 SECOND 검토에서 이 잘못된 API 가정을 놓쳤다. 이는 구현/검증 실패이며 과학적 capacity 실패가 아니다. `parent-e212-generated-receipt.json`의 실패와 벽시간1.404915399994934초를 보존한다. 첫 호출의 완전한 원시 파일은 저장되지 않았으므로 검산 완료로 간주하지 않는다. 원본 호출은 아직0이다.

부모가 설치된 SciPy의 lsq_linear.py와 bvls.py 실제 반환 코드를 확인하고 없는 속성만 제거했다. 실제 반환되는 unbounded_sol의 네 구성도 저장한다. gradient는 이미 별도 certificate에서 2 C^T r로 계산해 derived 파일에 기록하므로 이를 원시 solver 속성으로 부르지 않는다. 목표·box·solver tolerance/반복수·F1–F8은 변경하지 않는다.

원본 실행 전에 수정된 저장 경로를 확인하는 추가 생성 BVLS1회를 사전 허용한다. 생성 호출은 기존1+추가1=총2, 원본최대1/원본재시도0/원본예산90초는 그대로다. 새 생성 결과는 다른 독립 디렉터리에 저장하고 첫 실패를 덮어쓰지 않는다. 추가 생성도 실패하면 그대로 보존한 뒤 재설계한다. 이는 사용자가 위임한 개발의 검증 코드 수정이며 목표 기준 완화가 아니다.
