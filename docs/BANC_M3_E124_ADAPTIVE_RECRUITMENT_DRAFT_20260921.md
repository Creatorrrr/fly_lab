# E124 설계 초안: 활동 적응을 포함한 조건부 모집과 실제 보행 전환

2026-09-21 KST · 부모 설계 메모 · 아직 실행 계약 동결 전

E123의 전체 BANC 기능 진단은 첫 코드 리뷰 후 Sol/xhigh 첫 수정 중이다. 이 문서는 그 기능이 유효하게 검증된 뒤의 개발 방향이며, E123 성공이나 새로운 보행 후보의 선택을 뜻하지 않는다. E123 원본 실행·실패·자원 한도, 기존 F1–F8과 초기99, 과거 형태 기준은 변경하지 않는다.

## 현재 도구의 경계

`tools/banc_m3_context_response.py`는 실제로 저장한 source rate와 residual current로 운동뉴런 입력을 구성하고, 비적응 발화 forcing에 대한 일차 시간 응답을 계산한다. `tools/banc_m3_causal_recruitment.py`의 `linear_response`는 구간별 선형 forcing, `endpoint_response`는 제어 끝점의 근육 EMA를 표현한다. 활동 적응 상태 z가 없으므로 이 기존 도구에 gain 변수만 더해도 새로운 native 회로의 후보 응답을 계산할 수는 없다.

현재 E121과 E113의 `recruitment-signals.npz`는 각각2000 제어 끝점의446 관측 뉴런에 대해 rate/recurrent_current/drive/adaptation과96근육 activation을 보존한다. metadata에는391MN/55source의 명시 ID와 실제 tau/a/threshold/cap/gain이 있다. 전류 표본은 native 미세 시점 전체를 제공하지 않으므로 조건부 재구성에는 시간 표본화 오차가 남는다. 저장 rate를 정답 잔차로 더해 gain0 fidelity를 인위적으로 완벽하게 만드는 방법은 독립 재구성의 대안으로 채택하지 않는다.

## 다음 구현의 중심

기존 노드·연결·입력과 근육 pool/moment/rest/EMA를 유지하고, 운동뉴런의 r/z를 함께 적분하는 독립 조건부 응답을 추가한다. 식은 native 모델 그대로다.

`dr/dt = (max(cap*tanh(a*(I(t)-threshold-z)/cap),0)-r)/tau`

`dz/dt = (gain*r-z)/0.3`

I(t)는 해당 실제 기록에 속한 입력 표본에서 정하며, 어떤 표본간 가정을 쓸지는 실행 전에 고정한다. 외부 시계·위상·teacher·저장 명령은 최종 네트워크에 넣지 않는다. 후보는 기존96근육의391MN gain만 조절하고 범위[0,8]을 유지한다. 이 범위와 단일 적응시간상수는 공학적 모델의 제한이며 실측 성체 생리 파라미터가 아니다.

시간 적분과 감도 계산은 동일한 RK4 단계에서 함께 진행한다. 각 MN이 정확히 한 근육 gain에 속하므로 고정 입력 아래에서는 각 MN당 하나의 gain 감도만 적분하면 된다. v=dr/dgain, w=dz/dgain에 대해 `dv/dt=(-phi_prime*w-v)/tau`, `dw/dt=(r+gain*v-w)/0.3`이며, 근육·관절·발 기하학의 미분은 기존 고정 decoder에 연결한다. 이를 전체 재귀 신경망의 기울기로 부르지 않는다. 독립 DOP853/유한차분과 CPU/CUDA 비교가 필요하다.

## 실제 적합에 앞선 판별

E123의 신경 구현 진단이 유효해야 한다. 이후 사용할 실제 문맥·초기 상태·전류 보간·native 하위 적분 간격·원본99와 형태 평가 창·숫자 기준·자료와 소스 해시·계산 횟수·자원을 동결한다. 기존 E110/E113 두 문맥을 편의상 버리거나 후속 E121을 미사용 확인 자료로 이름 붙이지 않는다. 최신 E121 문맥을 추가할 때 원래 문맥의 결과를 함께 유지한다.

먼저 gain0의 독립 재구성이 원래 실제 rate·activation·request와 충분히 일치하는지 검증한다. 시작 시 저장된 실제 신경·근육 상태를 사용하고, t0의 이미 유지 중인 신체 명령을 decoder의 rest와 같다고 가정하지 않는다. 평가 표본은 원래99를 그대로 쓴다. E123의 실제 gain1 짧은 기록은 다른 적응 상태를 사용한 수치·전달 검토에 재사용할 수 있지만, 전체 회로의 표본 전류를 계산하는 비용도 별도 기록한다. 모형 재구성 오차와 후보 효과를 구분할 수 없는 경우 적합으로 넘어가지 않는다.

재구성·미분이 유효하면 근육 gain의 공동 변화를 제약 적합한다. 원래 시작99의 관절 RMS.02/max.05rad, 힘줄 RMS.01/max.03 및 기존 상대/절대 형태20% 판정을 유지한다. 적합 내부의 여유 기준과 원래 최종 기준을 섞지 않는다. 모델을 바꾸었으므로 과거 정적 가중치 LP의 국소 실패를 새 변수의 불가능성으로 일반화하지 않는다. 반대로 새 감도 방향이나 손실 감소만으로 보행 개선을 주장하지 않는다.

## 실제 보행으로 돌아가는 조건

하나의 동일 gain 벡터가 고정된 조건부 전달·형태·시작 기준을 충족한 경우에만, E121의 기존 calibration과 `MotorAdaptationTrial`로 전체158706 BANC·감각·신체를 연결한 원래10초 개발 시작을 실행한다. 원래 몸통 고정 전방 투영, 순변위/경로, native 건강성, 실제 Thorax-local 전진 적격구간의 여섯 다리 주기와 LR, 관절폭/반복성으로 F3–F5를 평가한다. 실패하면 기준을 낮추지 않고 원자료로 다음 가설을 결정한다.

최종 채택에는 같은 후보의 제품 통합/신경 단독 구동과 차단·저장, 미노출 두 자세, 여섯 목표와 정지·재시작·M2 미끄럼 회귀, 원자료·영상·M2 복원이 남아 있다. 조건부 적합 또는 테스트 완료는 전체 목표 완료가 아니다.

이 구현은 결합 동역학·미분·CUDA·저장·강한 시작 제약이 얽히므로 Sol/xhigh로 배정한다. 부모 상세설계→Sol 구현→부모 첫 리뷰→같은 Sol 첫 수정→부모 재리뷰와 잔여 직접 수정 순서를 유지한다. 아직 E124 원본 응답/적합/LP/신경·물리 실행은0이며, 자원 계약과 입력 해시를 고정하기 전에는 이를 시작하지 않는다. E123의 기존60초/누적988초 한도를 사후에 늘리지 않는다.
