# E143 — 저장된 운동뉴런 출력에서 근육별 가중 평균의 표현력 한계

E142 실제10초는 전진13.2473mm이지만 연속전진 최대.185초, 적격 완전주기0, F4/F5 및 엄격초기99 미달이었다. 반복적인 작은 조건부 손실 개선이 실제 걸음으로 이어지지 않았다. 다음 신경·구동 개입을 고르기 전에 현재 각 근육의 균등 평균을 양의 가중 평균으로 바꾸는 것만으로 표현 가능한 운동 범위를 확인한다. 이는 해부학적으로 같은 근육의 기존 운동뉴런만 묶는 읽기 변환 가설이며 새로운 연결·외부 위상·실행용 교사를 만들지 않는다.

H143 질문: 현재 E142에 기록된391개 MN 출력의 같은 근육 안에서 비음수·합1의 정적 가중 평균만 바꾸어 기존 E85 다리 내 참조 형태에 접근할 여지가 있는가? 경쟁 설명은 근육 안의 신호 다양성/범위 자체가 부족해 어떤 정규화 가중치로도 주요 명령 오차가 남는다는 것이다. 고정 출력 자료의 조건부 표현력만 다루며, 실제 폐루프에서 뉴런 출력은 달라질 수 있다. 참조 형태의 완전한 재현을 자연 보행의 새로운 필요조건으로 만들지 않는다.

중재는 실제 모델 변경이나 적합이 아닌 가능한 출력의 수학적 상·하한 계산이다. 실제 E142 2000×391 rate를 동일10ms EMA로 정확히2000회 갱신해 b[t,j]를 얻는다. 초기 adapter.activation과 network.rate가 모두0임을 검증한다. 고정 pool로 재조립한96활성·42요청·6힘줄은 기록과 각각 최대절대오차1e-10 이내여야 한다. 해부학 roster·membership·pool 지원집합, 비음수·행합1, 실제 control clock과 shape/finite를 확인한다. 원자료를 저장한 다음 수치 주장을 판정한다.

각 근육g의 가능한 활성은 min_j b[t,j]부터 max_j b[t,j]까지이며 j는 그 근육의 기존 MN이다. 고정 moment M과 rest를 유지해 qlo = rest + .02*(amin @ M_positive.T + amax @ M_negative.T), qhi는 min/max를 바꿔 계산한다. 실제 균등평균 출력이 구간 안임을 확인한다. 동일하게 diff(b)/.005의 근육별 min/max에서 1999개 인접 명령속도의 한계를 계산한다. 정적 가중치와 선형 EMA·미분이 교환하므로 두 식은 모든 허용 정적 가중치에 대한 필요조건이다. 시각마다, 관절마다 서로 다른 극값을 허용한 낙관적 상한이며 하나의 정적 가중치가 그 구간의 모든 목표를 동시에 만들 수 있다는 충분조건은 아니다. tendon은 단조 .2*tanh(a_ltm/10) 구간을 기록하지만 새 tendon 목표를 정하지 않는다.
