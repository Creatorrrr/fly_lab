# BANC 보행 교정 실험 결과 — 2026-09-10

**보행 개선은 검증되지 않았다. 세 교정 후보는 모두 미채택이며, 실행 중인 v2 모델을 유지했다.** 운동단위별 관측, 발 부착 해제 후보, 재현 가능한 비교 도구를 추가했다. 새 v3는 `EXPERIMENTAL_NOT_VALIDATED`로 표시하며 보행 프리셋이나 생리 교정 완료 모델로 취급하지 않는다.

기준선은 `45309118cb4ae3c452bad289a729efdc15cfa176`의 BANC v2다. 전체 BANC 158,706개 뉴런, 기존 연결·부호·마스킹, MPS 신경 계산, MuJoCo 물리 계산을 유지했다. 신경/물리 dt는 0.1ms, 제어 dt는 5ms다. 모델 내 이동을 평가했으며 계산 처리율 개선 실험은 아니다.

순이동은 수평 시작점–끝점 거리다. 전진은 매 물리 구간 시작의 몸 전방축을 기준으로 누적한 부호 있는 이동이다. 기존 판정 기준인 **10초, 순이동 ≥5mm, 전진 ≥5mm, 고착 없음**을 유지했다. 모든 조건에서 최초 고착은 3초에 검출됐다. 이동 경로 길이 증가나 작은 자세 변화를 성공으로 합산하지 않았다. 등록한 중단 규칙에 따라 추가 후보 탐색과 미사용 조건의 확대 실험은 실행하지 않았다.

변경 사항은 다음과 같다.

- [neuromuscular.py](/Users/chasoik/Projects/FLY_LAB/flylab/c/neuromuscular.py): 선택 가능한 v3 프로파일을 추가했다. 391개 운동뉴런의 실제 ID·cell type·발화율·출력 기여를 유지한다. 출력 후보는 기존 근육 집단 평균을 `sum(100*r/(100+r))`로 바꾼다. 단위는 힘이 아닌 등가 Hz이며, 같은 최대 용량을 가진 운동단위라는 공학 가정이다. 빠른/느린 운동단위의 실측 힘 차이를 교정한 모델이 아니다. 알려지지 않은 세포형을 느린 운동뉴런으로 임의 분류하지 않는다.
- [body.py](/Users/chasoik/Projects/FLY_LAB/flylab/body.py): 실제 관절 Jacobian에서 발끝의 수직 목표 변위와 현재 속도를 읽는 관측 함수를 추가했다. 몸통 위치를 이동시키거나 물리 시계를 진행하지 않는다. 현재 평평한 바닥에 대한 1차 근사이며 실제 미래 발 높이가 아니다.
- 발 부착 해제 후보는 신경 신호가 부착을 요청하더라도 관절 목표가 발을 0.02mm 넘게 올리는 것으로 추정되면 해제한다. 요청·적용·해제 사유와 물리 부착력을 별도로 기록한다. 시계 기반 보행 위상, 사전 보행 CPG, 숨은 몸통 구동은 추가하지 않았다.
- [compare_c_banc_gait.py](/Users/chasoik/Projects/FLY_LAB/tools/compare_c_banc_gait.py): 동일 조건 비교, 세 후보의 개별 대조, 전체 운동뉴런 신호, 5ms 물리 궤적, 초기/최종 체크포인트, 실행 소스와 판정 결과를 저장한다. 프로토콜과 실제 실행의 주요 수치가 다르거나 판정 기준이 바뀌면 거절한다. 기존 데이터 바인딩과 서버를 변경하지 않는다.

이번 결과는 출력 변환과 부착 정책만으로 보행이 해결되지 않았음을 보여준다. 기준선의 1–10초 구간에서 주 굴근 운동뉴런 30개 중 1개만 3회, 보조 굴근 71개 중 1개만 1회 발화했다. 신근은 12개 중 5개가 총 348회 발화했다. 운동단위별 출력 후보에서는 같은 구간에 두 굴근 집단의 발화가 모두 0회였다. 따라서 평균에 의한 출력 희석을 제거해도 없는 굴곡 신호를 만들어 내지는 못했다.

DNg100 조건에서 부착 해제만 적용하면 1–10초 구간의 LM 제어 표본 약 2.39%, RH 약 1.11%에서 해제가 발생했다. LH/RM에는 등록한 상승 조건이 발생하지 않았다. 이 특정 해제 규칙이 충분하지 않았다는 결과이며, 접촉·부착 문제가 없다는 뜻이나 부착 명령이 항상 실제 고정을 뜻한다는 주장은 아니다.

실제 보행을 위한 다음 원인 분리는 감각 입력의 방향·크기와 운동단위의 모집 특성을 다뤄야 한다. 특히 현재 신경 동역학은 모든 세포에 같은 LIF 파라미터를 쓴다. 빠른 운동뉴런의 무발화만을 실패 원인으로 단정하거나 발화하도록 강제하는 것은 적절하지 않다. 운동단위별 흥분성·힘·고유감각 반응 차이는 실험에서 관측되어 있으며, 이번 동일 용량 가정은 이를 대신하지 않는다. [운동단위 모집 연구](https://elifesciences.org/articles/56754)
