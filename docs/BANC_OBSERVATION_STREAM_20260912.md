# BANC 관측·기록 재생과 수치 보존 최적화

기준 소스: `a3b9fa487c012b9088f2f2b22e425ff71a006c25`.

## 변경 범위

- `WalkingTrace`는 제어 경계마다 실제 신체 상태를 5ms 간격으로 복사한다. qpos/qvel/ctrl, 다리 관절 목표·측정·추종 오차, 운동뉴런 출력, 발 부착·힘줄 요청, 접촉 진단과 모델 시각을 포함한다. 기본 6,000표본(약 30모델초)의 제한 버퍼다. 누락·오래된 표본 제외·새 epoch를 명시하며, 내보내기가 전체 실행 기록을 보장하지 않는다.
- 발 미끄러짐은 실제 MuJoCo 접촉점에서 두 물체의 상대속도를 구한 뒤 접선 성분을 계산한다. 압축 하중으로 가중 평균한다. 0.02 BW 이상을 분석용 지지 표본으로 선택한다. 이는 생물학적 보행 기준이 아니다. 부착 반력이 하중에 포함되고, 5ms 미만의 접촉 사건을 놓칠 수 있다. 비지지 표본은 미끄러짐 0이 아닌 `null`이다.
- 관측에서는 mj_step, mj_forward, 상태 보정이나 신경 입력 변경을 하지 않는다. 기록 오류는 별도 표시하며 검증 CLI에서는 실패한다. 기록 버퍼는 모델 체크포인트에 넣지 않는다. 새 세션·복원은 새 epoch로 표시해 서로 다른 미래가 섞이지 않는다.
- 새 BANC 화면은 요청마다 PNG를 기다리는 대신 각 5ms 측정 자세를 받아 별도 재생 시계로 표시한다. 신체 표면은 기존 도식 렌더러이고 다리는 실제 물리 분절 위치다. 1배·0.25배 기록 재생, 탐색 슬라이더, 발별 진단, JSON 내보내기를 제공한다. 자세·접촉 보간이나 미래 외삽은 하지 않는다. 실제 MuJoCo 메시 PNG는 별도 정적 확인 버튼에 남겼다.
- `banc_walking_advance`의 `stream:true`는 PNG를 생성하지 않고 계산에서 반환한 관측 프레임을 재사용한다. 기존 stream 미지정 RPC와 정적 메시 조회는 보존했다.
- `advance_readout`은 전체 뉴런의 오류 플래그와 선택 운동 출력을 한 패킷으로 CPU에 가져온다. 전체 상태 유한성/음수 검사와 제어 경계에서의 중단 의미를 유지한다. GPU 계산 완료 전 CPU가 버퍼를 읽는 비동기 최적화는 하지 않는다. 같은 dtype 입력을 기존 drive 버퍼로 직접 복사하고 읽기 인덱스를 재사용한다.
- CPG 불변 검사는 CPG 필드만 읽어 해시한다. 매번 전체 MuJoCo/RNG 체크포인트를 만들지 않는다. 발 접촉 조회의 사용되지 않는 중복 힘 계산도 제거했다.

신경 방정식·가중치·RK4 연산 순서·시간 간격·CUDA 희소 커널·감각/근육 매핑·부착 규칙·물리 적분은 변경하지 않았다. 기존 0.1ms 저장 상태는 기존 간격으로 복원한다. 일반 BANC와 목표 BANC의 Coxa/LTM 설정도 그대로다.

## 실행과 화면

```powershell
.\.venv\Scripts\python.exe build_c.py
```

기존 서버 실행 명령으로 새 코드를 시작하고 페이지를 새로 연다. 운영 중인 8770 서버나 사용자의 체크포인트는 이 변경 작업에서 재시작/수정하지 않았다. BANC 재생으로 기록을 채운 뒤 **기록 1배 재생** 또는 **0.25배 재생**에서 저프레임 인상과 실제 운동을 비교한다. 기록 재생은 모델 진행을 멈추고 저장된 자세만 표시한다. **실제 메시 확인**은 정적 PNG이며 새 연속 화면과 구별한다.

## 검증한 것과 아직 검증하지 않은 것

CPU 신경 수치 대조, 입력/차단/복원, 선택 밖 뉴런의 NaN 검출, 실제 MuJoCo 접촉점 상대속도, 기록 유무에 따른 실제 FlyBody의 적분 상태·미래 비트 일치, RPC의 중복 frame/PNG 호출 금지, 제한 버퍼·누락·epoch 재생을 검사했다. 관련 Python 검사 결과는 33 passed / 5 skipped / 11 subtests passed였다. CUDA/BANC 실자료가 필요한 검사는 환경 제약으로 생략했다. 이는 실제 BANC 전체 보행 품질 판정이나 GPU 가속 측정값이 아니다.

실제 BANC CUDA 장치와 준비된 bundle에서 다음 게이트를 실행한다. 새 출력 디렉터리가 필요하다.

```powershell
.\.venv\Scripts\python.exe tools/verify_c_banc_observation.py --graph data/acquisitions/banc888-windows-20260910/bundle --device cuda --seconds 10 --out verification/banc-observation-new
```

목표 보행은 같은 명령에 `--target 6 -3`을 추가한다. 구형 간격 대조는 `--neural-dt 0.0001`을 사용한다. 장시간 실행 중인 원래 세션에는 접근하지 않고 별도 세션에서 수행한다.

산출물은 초기 전체 체크포인트, `trace.jsonl`, `trace.json`, `reference-signals.npz`, 독립 재생용 `replay.html`, 발별 하중/미끄러짐 평균·95백분위/지지 전환과 추종 오차의 `gait-summary.json`, 수치·시간 결과 `result.json`이다. 전체 미래 상태와 각 제어 시점 물리/운동 출력을 비트 비교한다. 관절 목표·부착·힘줄 입력을 같은 시각에 넣는 신경 계산 없는 물리 재실행도 비교한다.

타이밍은 현재 런타임의 분리 읽기/통합 읽기를 순서를 바꾸어 비교하며, 기록 추가 비용도 별도로 측정한다. 초기화/복원/컴파일, PNG, 브라우저·네트워크는 제외한다. 이전 소스 전체 대비 측정값이 아니다. `PASS`는 수치·관측·명령 재생 검증에만 사용한다. 자연스러운 보행은 반드시 기록 영상과 접촉/운동 지표를 추가 검토해야 한다. 실제 CUDA 게이트를 실행하기 전에는 가속 배수나 전체 BANC 비트 일치를 주장하지 않는다.
