# 저장 입력으로 재현된 startup 출력 차이

E237은 실제 입력과 학습 때 입력을 각각 같은 초기값·동결 반응식으로 처음부터 끝까지 재생했다. 두 경우 모두 원래 기록을 재현했고, 부모 독립2036검산도 통과했다. 실제 관절 명령 최대 오차는1.4988010832439613e−15rad이며 실제 decoder float32 입력과 근육 활성·힘줄 출력은 byte exact다. 전체7920stage의 effector 최대오차8.5265e−14, 기억1.1102e−16이다. 학습 반응의 경계율 최대오차2.2737e−13, 관절명령3.9968e−15rad다.

E235에서 직접drive는 같고 내부E/I가 약18ms부터 달랐으며, 이번 결과는 그 입력 변화가 동결 free-effector 식 안에서 startup 관절명령 차이를 재현함을 보여준다. 단순 float32 읽기나 RK 구현을 고쳐 해결할 차이라는 근거는 없다. 어느 감각 연결이 변화를 일으켰는지, 이것이 장시간 주기 미달의 유일한 원인인지까지 증명한 것은 아니다.

학습에서 제외한48개 운동뉴런도 control6부터 출력이 달라졌다(최대.0052928924561 rate units). 이48개의 원래 관절 투영은0이다. 별도 readout 조합으로 free입력 효과와48개 출력 효과를 분리했고 관절/활성/힘줄 전체 차이와 합이 정확히 일치했다. 힘줄 기준은 실제/학습 모두 통과했다. “고정 계수”를 “고정 출력”으로 잘못 해석했던 부모 E236 전제와 실패는 그대로 보존했다.

실제 gpt-6-sol/high 구현→부모FIRST→같은Sol첫수정→부모SECOND 이후 발견한 전제 오류는 사용자 요청대로 부모가 E237에서 수정했다. 생성CPU7검사/Ruff 통과 후 단일 저장분석17.7394157초, peak process RSS1072652288B, 출력4802973B; PID41920/45724/45828 모두 종료, 강제종료·재시도0. 실제 신경/신체/CUDA/fit0, 두입력×1980ticks는 CPU 수식 계산이다. E236 실패1.370345초를 포함해 원본 보수누적6137.263854399662/6215초, 잔여77.736145600338초다. 독립 저장검산2.7356286초/프로세스2.9515431초는 별도다.

다음 개선 후보는 E85 보행 신체가 실제로 만든 감각 입력 아래에서 BANC E/I를 수집하고, 같은 움직임의 목표와 짝지어 학습하는 것이다. 기존 E208 signed-input 관측기 재사용 가능성을 소스에서 확인했지만 실제 동등성은 다음 실행에서 먼저 검증해야 한다. 기존 정적 교사 decoder 및 재귀학습 실패도 유지하며, 데이터 정합만으로 교사 제거 후 안정성이 보장되지는 않는다.

새 보행 후보 채택0, 자연스러운 보행/F1–F8은 아직 미완료다. F6 미사용 초기상태, E150 최선, M2와 UI는 유지했다.
