# C 0.5.0 — 자연 행동과 뇌–VNC–다리 개발 결과

요청한 개발 순서 1번과 2번을 분석하고 [작업 계획](C_SENSORIMOTOR_PLAN_20260910.md)을 작성한 뒤 구현했다.
**전뇌 출력 보완과 BANC 다리 폐루프는 실행 가능하다. 자연 탐색과 자율 보행의 완료 기준은 아직 충족하지 못했다.**
실제 데이터·MPS·MuJoCo로 실행했으며, 아래 PASS는 각 검사 범위에만 적용된다.

## 현재 사용할 수 있는 화면

* 기존 실험: <http://127.0.0.1:8766/>. C 0.5로 갱신하고 사용자 실험 **60.670초, C_SHADOW, MPS**를 복원했다. 재생은 일시정지 상태다.
* BANC 다리 실험: <http://127.0.0.1:8771/>. C_STRICT, MPS, 158,706개 포함 뉴런, 다리 운동뉴런 391개를 관측하도록 준비했다.
* 기존 실험의 `checkpoint-209a7c54e5f1`과 갱신 후 `checkpoint-315c927d30d0`의 신경·몸·센서·인코더·B 제어기·환경·개입·구독·모델 시간이 같았다. 재초기화하거나 새 모델로 자동 변환하지 않았다.

기본 FAFB 화면의 C_SHADOW는 여전히 B 제어기로 몸을 움직인다. 새 보행 가설을 실험하려면 C_STRICT와 해당 프로파일을 선택하고 **새 실험**을 누른다. BANC는 별도 그래프 서버이므로 FAFB 프로파일 선택만으로 전환되지 않는다.

## 1번: 자연 입력에서의 행동

기존 DNp09만 읽는 전진 출력에서 누락되던 DNg100·DNg97를 별도 프로파일에 연결했다. 실제 FAFB ID와 세포형을 검사하며, 목표 좌표나 정답 방향을 운동 출력에 넣지 않는다. 기본 프로파일과 기존 LIF 계산은 유지했다.

| 추가 항목 | 구현과 한계 |
|---|---|
| 전진·조향 출력 | 집단 평균 발화율을 명령으로 변환하고 명령 상한을 적용한다. 이득은 공학적 가정이며 실제 속도를 보장하는 서보가 아니다. |
| 정지 게이트 | 정지 입력이 전진·후진·조향을 줄이도록 구현했다. 정지 값만으로 후진이 발생하던 새 프로파일의 문제를 방지한다. **실제 정지 뉴런 집단은 아직 미연결**이다. |
| 약한 감각 입력 | 지속 전류가 발화 문턱에 못 미치는 조건을 재현하고, Poisson 입력을 선택 가능한 가설로 추가했다. 배경 구동이나 운동 명령을 몰래 더하지 않는다. |
| 신경 방정식 | 기존 방식, 발화 후 시냅스 전류 초기화, Poisson 전압 사건 방식을 구분한다. 각 프로파일·모델·실효 Metal 소스의 신원을 저장한다. |
| 정량 판정 | 보행·후진·좌우 조향·정지와 재개·먹이 접근, 위험원 대조 평가를 제공한다. 관측 누락과 실험 기회 부재를 구분한다. |
| 실험 조건 | 위치·방향·마찰·시드를 달리하는 120조건 파일을 준비했다. **120조건 전체를 실행한 것은 아니다.** |

### 실제 자연 감각 실험

FAFB 139,255개 뉴런, `bindings-walking-poisson-reset-current-v3.json`, C_STRICT, 시드 42로 각각 30모델초 실행했다. 이 경로의 관절 보행에는 기존 CPG 어댑터를 사용한다.

| 조건 | 먹이 접근 판정 | 실제 관측 |
|---|---|---|
| 왼쪽 먹이 | PASS | 4.510초에 반경 2mm 진입. 30초 순변위 17.542mm. 이후 벽 접촉 16.59초 및 고착 검출. |
| 오른쪽 먹이 | FAIL | 최근접 거리 5.774mm, 순변위 3.916mm. 회전하면서 이동했으나 먹이에 도달하지 못함. |
| 왼쪽 먹이·감각 차단 | FAIL | 순변위 약 0mm, 먹이 진입 없음. |
| 오른쪽 먹이·감각 차단 | FAIL | 순변위 약 0mm, 먹이 진입 없음. |

왼쪽의 한 번 진입은 안정적인 탐색이나 일반적인 냄새 추종의 증명이 아니다. 방향 편향과 감각에 의해 단순히 이동이 시작되는 효과를 추가로 구분해야 한다. 입력 방식 4개를 시험한 탐색 과정도 보존했으며, 최신 번호의 프로파일을 가장 우수한 모델로 자동 선정하지 않았다.

정면 장애물 10초와 왼쪽 위험원·위험원 제거·위험 감각만 차단한 대조 3개를 각각 10초 실행했다. 모두 접근 기회가 발생하지 않았다. 장애물은 `NOT_APPLICABLE`, 위험원 대조 종합은 `NOT_VALIDATED`다. 위험 영역에 머문 시간이 0이라는 이유로 회피 성공을 선언하지 않는다.

### 직접 신경 개입 진단

자연 감각을 차단하고 선언된 출력 뉴런을 직접 자극한 별도 5조건, 합계 22모델초다. 자연 행동과 구분한다.

| 검사 | 판정 | 측정 |
|---|---|---|
| 전진 10초 | FAIL | 순변위 22.514mm, 전방 누적 22.529mm지만 벽 고착으로 보행 기준 실패. |
| 후진 2초 | PASS | 몸 전방 축에 대한 누적 이동 −2.577mm. |
| 좌회전 2초 | PASS | 실제 몸 회전 −1.102rad. |
| 우회전 2초 | PASS | 실제 몸 회전 +1.077rad. |
| 출력 억제 후 재개 | PASS | 사전 순변위 7.692mm, 정지 측정 구간 경로 0.032mm, 해제 후 순변위 7.835mm. |

마지막 검사는 지속 자극 중 전진 출력군의 새 발화를 억제했다가 해제하는 검사다. 자연 정지 명령 회로나 행동 선택 회로를 구현했다는 뜻은 아니다.

## 2번: BANC 뇌–VNC–다리 폐루프

같은 BANC v888 개체의 주석으로 **감각 3,604개 → 포함 신경망 전체 → 운동 391개 → 근육 표적 → 42개 관절 액추에이터**를 연결했다. FAFB 뉴런 ID와 섞지 않는다. BANC의 선언된 뉴런 목록을 모두 계산하지만 전체 해부학적 신경계의 완전성을 주장하지 않는다.

* 실제 MuJoCo 관절각·각속도·다리 접촉 힘을 관찰한다. 한 제어 주기(5ms) 지연과 필터 상태를 저장한다.
* FeCO claw/hook/club, campaniform, tactile bristle 주석을 사용한다. 현재 claw는 무릎각, hook/club은 속도 크기, 나머지는 다리 하중·접촉의 집단 대리 신호다. **개별 수용체의 선호 각도·방향·진동 선택성은 아직 모델링하지 않았다.**
* 17종 근육 표적 주석의 발화율을 상대 관절 위치로 변환한다. 힘–길이 곡선·모멘트암·운동단위 모집을 측정 자료로 재현한 근육 모델은 아니다.
* **41/42 DOF**에 출력이 연결된다. 오른쪽 중간 다리 `rm_coxa_pitch`는 일치하는 주석이 없어 중립으로 유지한다. 누락을 임의의 뉴런 ID로 채우지 않는다.
* BANC 구동 중 기존 보행 CPG를 진행하지 않는다. 초기 중립 자세와 FlyGym 위치 액추에이터는 사용한다. 별도의 진동기나 보행 위상을 넣지 않았다.
* 전체/다리별/수용체별 감각 차단, 운동 연결 차단, 뉴런 자극·억제·출력 차단, 실시간 관측, 기록·복원을 주 실행기에 통합했다.

실제 MPS·MuJoCo 6조건 단기 검사에서 물리 오류 없음, 감각 입력과 차단, 운동 차단의 0 오프셋, 무릎 굽힘·폄 방향, CPG 상태 불변, 체크포인트 복원 후 동일한 신경·몸·감각·근육 계산을 확인했다. **BANC 10초 자율 보행은 순변위 0.141mm로 FAIL**이었다. 연결을 완성하는 것과 보행 리듬이 나타나는 것은 다른 완료 조건이다.

## 검증과 원자료

* 최종 전체 검사: **217개 PASS**. 소형 회로·서버·저장·UI 코드 계약 검사와 실제 Apple MPS, 실제 몸의 초기 자세/복원 검사를 포함한다. 217건의 보행 실험을 뜻하지 않는다.
* 전체 FAFB CPU/MPS 비교: 3가지 신경 방정식에 동일한 0.1초 Poisson 입력. 전체 뉴런의 막전위·시냅스 전류·지연 큐가 일치하고 발화 수·불응기 상태와 선택 이벤트도 같았다. 최대 발화율 오차 0.0000306Hz. 장시간 수치 일치나 CUDA 검증을 대신하지 않는다.
* 브라우저: BANC 초기화, 50ms 물리 진행, 다리 감각만 차단할 때 후각 유지, 391개 운동뉴런 관측과 발화 이벤트, 감각 복구, 0.150초 체크포인트 복원을 확인했다. API 재조회와 체크포인트도 저장했다.
* 초기 위치는 **안정화 전 초파리 자산의 원점**이며 화면의 몸 위치는 흉부다. 초기 자세 변환은 실제 흉부의 강체 변환과 비교했고 최대 잔차 0.0000526mm였다. 다른 초기 자세의 물리 체크포인트는 거절한다.

원자료 루트: `verification/c_sensorimotor_20260910/`.
현재 소스·프로파일의 체크섬은 루트의 `C05_CHECKSUMS.sha256`, 새 검증 원자료의 파일 인덱스는 이 원자료 루트의 `evidence_index.json`이다. 기존 `C_CHECKSUMS.sha256`은 이전 버전 기록으로 유지했다.

## 재실행

현재 작업 폴더에서 실행한다. 아래 출력 이름은 이미 존재하면 새 이름을 사용한다.

```sh
.venv/bin/python tools/verify_c_neural_variants.py --out verification/my-c05-neural
.venv/bin/python tools/verify_c_sensorimotor.py --seconds .3 --out verification/my-c05-banc-loop
.venv/bin/python tools/run_c_campaign.py \
  --bindings data/fafb783/bindings-walking-poisson-reset-current-v3.json \
  --spec verification/c_sensorimotor_20260910/poisson_food_spec.json \
  --out verification/my-c05-food
.venv/bin/python tools/prepare_c_sensorimotor_campaign.py --out verification/my-fixed-120.json
```

별도 BANC 서버를 시작할 때는 사용하지 않는 포트를 지정한다.

```sh
.venv/bin/python run_c.py --port 8781 --mode C_STRICT --backend exp_lif_mps \
  --graph data/acquisitions/banc888-v2-20260909/bundle \
  --bindings data/banc888/bindings-neuromuscular-v1.json \
  --artifacts artifacts/my-banc
```

새 프로파일은 `tools/build_c_walking_profile.py`와 `tools/build_c_banc_sensorimotor.py`로 재생성한다. 다단계 출력 진단은 `tools/prepare_c_control_assays.py`, 완료한 위험원 대조의 재평가는 `tools/assess_c_hazards.py`를 사용한다. 대용량 BANC bundle은 이 작업 폴더에 존재하며 소스 Git에 자동 포함되는 파일은 아니다. 이전 0.4 배포 ZIP과 그 증빙 인덱스는 당시 버전의 기록이다.

## 다음 개발 순서와 완료 기준

1. **방향 편향의 원인 분리.** 좌우 ORN→DNg100/DNg97→DNa02의 시간별 반응을 입력 크기·방향·시드별로 비교한다. 감각 변환, 신경 방정식, 운동 이득을 한 번에 바꾸지 않는다. 먹이 위치와 초기 방향을 바꾼 별도 평가 조건에서도 좌우 접근이 모두 성공하고 감각 차단 대조와 구분되어야 한다.
2. **자연 정지와 회피 회로.** 문헌의 정지 회로를 현재 스냅샷의 실제 ID·연결과 검토해 연결한다. 움직이던 개체의 정지·재개, 실제 장애물/위험원 접근 기회가 있는 대조를 통과해야 한다. 현재 직접 자극 결과를 자연 정지 성공으로 대체하지 않는다.
3. **VNC 리듬과 감각 선택성.** 개별 FeCO의 방향·선호각, 근육 쌍의 신경 입력·위상·동시 수축을 계측하고 동역학 가설을 비교한다. 저자 공개 VNC 발화율 모델은 현 LIF와 방정식이 다르므로 독립 구현/교차 검증이 필요하다. 사전 보행 궤적 없이 다리 위상과 접촉 전환이 발생해야 한다.
4. **근육 모델 교정과 미연결 관절.** 힘·모멘트암·운동단위 모델로 현재 위치 목표 대리를 보완한다. `rm_coxa_pitch`의 실제 주석을 검토해 근거 있는 연결만 추가한다. 무릎 외 관절의 실제 방향·힘·접촉 반응도 검증해야 한다.
5. **고정 조건 종합 평가.** 위 원인별 검사가 성립한 뒤 준비한 120조건을 별도 실행하고 실패를 포함해 집계한다. BANC에서 10초 5mm 전진·고착 없음부터 통과시킨 뒤 시간과 지형 범위를 늘린다. 현재 1번과 2번의 최종 행동 목표는 이 단계까지 완료되지 않았다.

근거는 [보행·정지 회로](https://www.nature.com/articles/s41586-024-07854-7), [BANC 뇌–신경삭 자료](https://www.nature.com/articles/s41586-026-10735-w), [FeCO 감각 선택성](https://pmc.ncbi.nlm.nih.gov/articles/PMC8665017/), [VNC 모델 저자 코드](https://github.com/smpuglie/Pugliese_2026/tree/5626b7312ffbbe768793a148cec82f93d7530fce), [LIF 참고 구현](https://github.com/philshiu/Drosophila_brain_model/blob/main/model.py)이다. 문헌의 뉴런 식별 근거와 이 코드의 이득·근육·감각 가정을 구분한다.
