# E260 고정 감각 입력의 억제 연결 대조 결과

실행은 유효하고 사전 H260은 지지됐다. 같은 감각 이력 아래 여섯 연결 복원으로 생긴 muscle44 활성 감소는 기존111970→47329 연결을 제거하면 잔차 2.820096%로 작아졌다. 그러나 연결 제거만으로 MN47329 평균 rate가 3.108748배가 됐고 근육 활성의 평균 차이는 33.325964300였다. 이 결과는 인위적 연결 제거에 따른 조건부 신경 반응이다. 연결 삭제를 보행 후보로 채택하지 않는다. E257 보행 기각과 M3 미완료를 유지한다.

B/C는 E257 처음101행의 MN391·기존82/core24 rate/drive/adaptation·bank를 bitexact로 재현했고 muscle44 활성도1e−10 이내다. 모든 팔의 시작/끝 전체 신경 상태, 현재 incoming1204개, 관측 합집합1239개, 실제 packed CUDA32 current와 독립32lane 재구성, 생성 drive와 원래 순서, decoder 파라미터·재구성을 확인했다. 과거 control100 전체 신경 reference는 없으므로 그 전체 상태의 과거와의 exact를 주장하지 않는다.

## 구현과 검토

실제 gpt-6-sol/high가 두 파일을 구현했다. 부모 FIRST에서 f64에 저장된 정확한 f32 patch 비교 오류와 늦은 저장 실패 뒤 성공 해석이 남는 오류를 지적했다. 같은 Sol 첫 수정 후 부모 SECOND: pytest14, Ruff, CLI5, 실패 주입4, 독립 생성 산술1833검사를 통과했다. 부모 제품 잔여 수정0이다.

첫 부모 원자료 감사는 inverse tau 기대식을 1/tau32로 잘못 계산하여 실패했다. 기존 코드의 canonical_timescales는 f64 tau의 역수를 먼저 계산한 뒤 f32로 반올림한다. 원래 저장 inverse32 및 이 canonical 식과 실제 tensor가 bitexact임을 확인했다. 원본 감사 소스·실패 영수증·시간을 보존하고 v1 감사만 고쳤다. 실험·가설·문턱·제품 소스는 변경하지 않았고 원본 재실행0이다. v1 부모 독립79,648검사가 통과했다.
