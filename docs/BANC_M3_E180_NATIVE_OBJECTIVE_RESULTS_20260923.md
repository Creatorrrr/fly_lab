## 실제 변경과 검증

학습된 양수 모집 기울기와 원래 해부학적 pool 기울기의 고정 볼록 결합만 바꿨다. fixed19 근육,391 MN의 소유 관계, 신경 연결·동역학, 감각, moment/rest, 몸체와 초기 상태는 유지했다. 새 근육 힘 법칙이나 외부 CPG·위상·root 보정은 없다. 저장 자료 사전 재구성 최대 오차는 관절4.72e-15rad, 활성8.53e-14였다. 사전 확인 후에도 실제 폐루프의 초기 보호를 다시 검사했다.

기존 모델의601개 control,391 MN rate/filter/96근육 activation,30,000개 native 접촉은 E150의 같은 prefix와 일치했다. 부모7235개 대조가 통과한 뒤 후보를 실행했다. 부모의 별도56개 원자료 검산은 양쪽 bank 갱신, 양수 branch 활성, 실제42관절 명령, 초기 전체 상태와 고정 기울기 변경, 직접 Gaussian convolution의 전진 구간, 실제 하중 가중 slip을 확인했다.

현재 세션이 설계하고 실제 `gpt-6-sol/high`가 첫 구현과 첫 수정을 수행했다. 부모 FIRST/SECOND 리뷰 뒤 남은 스트림 기록 순서·실행 장치 기록·CLI 시간/오류 처리는 부모가 마무리했다. 합성 테스트14개, 독립 생성 검산18개, Ruff 검사와 포맷 검사가 통과했다. 감사에는 별도 `gpt-6-sol/medium`을 사용했다. 다른 모델로 바꿔 실행하지 않았다.

구현: `tools/probe_c_banc_m3_native_objective.py`, `tests/test_c_banc_native_objective.py`. 원본 freeze·소스 gate·모든 구현 단계와 실패·원자료는 `verification/banc-natural-gait-m3-20260919/`에 보존했다. 결과 경로는 `e180-native-objective-baseline`, `e180-native-objective-candidate`, 독립 판정은 `parent-e180-baseline-review.json`, `parent-e180-raw-review.json`, `parent-e180-final-review.json`이다.
