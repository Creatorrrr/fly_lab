# E122 제안: 신경 리듬이 연속 지지·회수 동작으로 전달되지 않는 구간 확인

2026-09-21 KST · 부모 설계 방향 · 다음 실제 모델/보정은 아직 실행하지 않음

E121의 단일 전체 BANC/CUDA·신체10초 개입은 전진만 부분 개선했다. E113의 목표20포트→MN872개 기존 연결 값을64배 증폭 전 값으로 되돌리자 순전진9.775797→10.516212mm, 순변위/경로.564800→.584337이 됐다. 원래99 초기 명령은 E113과 정확히 같고 저장 미래와 native 건강성도 통과했다. 그러나 최장 연속 전진은.2→.3초, 전진 적격 완전 주기는 여섯 다리 모두0이다. LH 무릎폭39.083276°와 계산 불가능한 모든 주기 CV 때문에 F5도 미달이다. F3의 한 개발 조건 통과를 F1–F8 완료나 자연 보행 검증으로 올리지 않는다.

실제20포트 기록에서는 IN19A003 index83877이2.325초부터16개 control sample에서 rate>1을 보였고, peak는2.335초의27.645275였다. 기존 E113 대비 명령과 신체 좌표가 처음 달라지는 시점도2.325초다. 이 단일 개입의 부분 전진 효과는 확인했지만, 원래 E113의20포트 전체 시계열은 없으므로 그 입력을 만들어 비교하지 않는다. E121 rate에64배 가중치를 대입한17356.810271과 실제 가중치의271.200160은 같은 관측 rate에서의 전류 산술 비교다. 변경 전 신경 응답을 예측한 값이 아니다.

다음 질문은 **규칙적인 신경 리듬이 존재하는데도 신체의 전진이 매 주기 끊기는 이유가 요청한 다리 내부 파형에 있는지, 신체 추적·지지 접촉 과정에 있는지**다. E121의 여섯 source는21–22개 주기와.419–.428초 평균 주기, 신경 LR/source screen을 통과했다. 신경 주기를 물리 F4의 완전한 전진 주기로 대체하지 않는다. 적격 전진 구간 밖의 진동도 별도로 기술하되 원래 F4/F5 판정은 그대로 둔다.

## 다음 분석의 범위와 결정

1. E121과 E113의 실제200Hz 신체 좌표·요청/측정 관절·96근육 활성·391MN rate 및100us native 접촉을 같은0.5–10초 창으로 비교한다. 원래0–.5초와99개 초기 제약은 별도 보존한다. 이미 검증된 E85 동일 신체 교사 기록은 가능한 지지·회수 동작의 비교로만 사용한다.
2. 기존 `AnatomicalRecruitmentAdapter`의 선형 pooling과10ms 활성 필터를 기록된 MN rate에 적용한 **decoder 재표현**을 한 번 검산한다. 실제 기록 activation과42개 요청을 재구성해야 하며, 차이가 있으면 신경 생리를 바꾸기 전에 기록 시점·축·순서를 확인한다. 신경망/물리 진행이나 새 후보 응답으로 세지 않고, decoder 계산 수와 비용을 별도 기록한다. 원래 neuron·muscle·leg 순서를 해부학 metadata로 확인한다.
3. 요청과 실제 관절의 추적 오차, 실제 발의 전후 운동·들림, native 하중 지지·slip 및 몸통 좌표에서 계산한 전진 속도를 함께 연결한다. 접촉은 원래0.02BW 기준이며 Gaussian20ms 속도와5ms 관측의 시간 해상도를 명시한다. 발마디 끝 원점은 실제 접촉점의 대용이므로 그 이동을 접촉점 힘·추력의 부호로 단정하지 않는다. 통계적 동시 관계만으로 특정 MN이나 근육을 실패의 인과원인으로 지정하지 않는다.
4. 먼저 요청 자체에 지속 전진에 맞지 않는 운동·상보 모집이 있는지와 실제 신체가 요청을 따라가지 못하는지를 구분한다. 전자의 근거가 우세하면 기존 MN의 모집 작동점/활동 의존 시간 응답을 다루는 다음 단일 개입을 설계한다. 후자이면 접촉·구동의 구체적 오차를 해결하는 단일 대조를 설계한다. 근거 없이 동일1572개 static efficacy fit의 반복 수·범위를 늘리거나 외부 위상·시간 ramp·root 보정을 추가하지 않는다.

E120의 startup 제약은 기존 두 문맥과 국소 가중치 범위의 결론이다. E121의 다른 후기 문맥 전체에 그대로 확대하지 않는다. 초기0.5초가 동일한 E121 증거와, 실제 후기 요청·추적·지지 동작을 연결하여 이전의 시간 응답 제안 중 무엇을 구현할지 결정한다. 새로운 적응·가소성·근육 상태는 이 분석만으로 성체 초파리의 검증된 생리라고 부르지 않으며, 구현 전 근거와 허용 변수·CPU/CUDA 방정식·저장/차단 조건을 별도로 고정한다.

## 개발·검증 계약

부모가 구체 입력 SHA, 재표현 횟수, 비교 창과 최대 벽시간을 동결한 뒤 Sol이 분석 도구와 필요한 오류·축 검사를 구현한다. 이 단계는 여러 기록과 해부학적 출력 분해를 연결하지만 새 CUDA 동역학을 추가하지 않으므로 Sol `high`를 우선한다. 기존 에이전트의 effort를 실행 중 바꿨다고 기록하지 않는다. 실제 새 신경 동역학·CUDA·제약 적합 단계는 난도를 다시 평가한다.

부모 첫 리뷰의 첫 수정은 같은 Sol, 두 번째 리뷰 후 잔여 수정은 부모가 맡는다. 첫 단계는 저장 기록과 decoder 대수만 사용하며 새 BANC/물리/fit/LP/F6 실행은0이다. 한정 분석 후 결과에 근거한 실제 구현을 이어 간다. 최종 모델 하나의 원래 F1–F8, 미사용 두 자세, 여섯 목표·정지/재시작·M2 대비 slip, 영상/통합과 M2 복원은 모두 남아 있다. E121은 보존된 F3 부분 후보이며 아직 제품 M3로 채택하지 않는다.
