# E200 기술 복구: 초기 유지 명령과 생성 명령 구분

E200 첫 원본 PID24800은 입력 정합에서 종료됐다. NNLS와SVD 이전이므로 H200은 미결이며 과학적 기각이 아니다. 원본 error.json, 실행 당시 소스·freeze, 감독0.6570768999954453초를 그대로 보존한다. 누적5032.14239719971/5144초다.

부모 사전 설계가 E150의 초기 유지 명령 row0까지 새 adapter가 생성한 명령으로 간주했다. 부모 진단은 유일한 위반 행이0, 그 차이0.32668292642150043rad이고 실제 생성된 rows1..2000의 차이는2.3314683517128287e-15rad임을 확인했다. 재사용 원천 `fit_c_banc_m3_onset_recruitment.py:1176`은 원래부터 target_residual[1:]만 검사한다. E197 raw의 같은 row0 차이도 보존돼 있다. 새로운 데이터나 학습 결과에 맞춰 허용오차를 늘리지 않는다.

수정은 command reconstruction의 비교 범위를 생성된1..2000행으로 명시하고 row0 차이는 별도 보고하는 것이다. 전체 native activation/clocks/availability의 검사는 유지한다. target_indices1824개와target/B/Y/NNLS/SVD/20% 방법 기준, KKT1e-9와 생성 명령 허용오차1e-12, F1–F8은 변경하지 않는다. 사용되지 않는 초기 유지 명령을 projection 입력에 추가하지 않는다.

동일 actual gpt-6-sol/medium이 E200의 **첫 실제 코드 수정**을 수행하고 부모가 재리뷰한다. 처음 두 소스 리뷰에서 이 부모 설계 오류를 발견하지 못한 사실도 유지한다. 합성 시험에는 초기 유지 명령이rest와 다르지만1..2000행이 정확한 실제 경계를 추가한다. 부모 원본 검산은 원래부터 selected rows만 대조한다.

v2는 명시적인 기술 재실행 한 번이다. E200 전체로 원본 시도2회·수동 기술 재실행1회·자동 재시도0이며 첫 시도 비용을 지우지 않는다. 별도 출력 e200-silent-muscle-capacity-v2를 사용한다. 새 원본은 CPU1/GPU0/내부15/외부20/감독30초로 남은111.8576028002899초 안에 예약한다. 첫 시도와 합쳐E200 감독 상한은30.6570768999954453초다. 임의 추가 재시도는 없다. 새 신경/물리/런타임 학습/F6/UI 변경은0이다.
