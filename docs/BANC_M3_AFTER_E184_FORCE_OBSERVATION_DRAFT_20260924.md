# E184 이후: 다리별 추진·제동과 몸통 운동을 분리하는 관측

E184는 두 기록 모두 전진 임계선 하향 통과 11개, 최장 전진 .215초를 재현했다. 사건 직후에는 평균 약 2.5개 다리가 지지 중이고 미끄럼이 3.1∼3.2mm/s로 증가했다. 전반적인 MN 출력 소실은 관찰되지 않았다. LF의 높은 접촉 비율과 미끄럼은 관측 대상이며, 힘의 방향을 기록하지 않았으므로 제동 원인이라는 결론은 아직 없다. 같은 theta grid를 반복하지 않는다.

이 초안은 후속 구현을 위한 사전 결정이며 original 실행 허용 source gate는 아니다. 부모가 다음 설계를 확정한 뒤 실제 `gpt-6-sol/high`가 구현한다. 부모 FIRST → 같은 Sol 첫 수정 → 부모 SECOND → 남은 부모 수정 순서를 유지한다. F1–F8, 실제 BANC 신경 구동, 해부학적 provenance, M2와 UI, 미사용 F6 초기상태를 보존한다.

## 제안하는 최소 실험

E182 theta0 기준을 동일 full BANC 158706/CUDA·동일 시작 상태로 **3초 한 번** 재현하고, 기존 native observer의 별도 MjData에서 지면 반력만 추가 관측한다. 제어·연결·가중치·근육 변환·adhesion·관절·물리 설정은 바꾸지 않는다. 추가 신호가 기존 궤적을 바꾸지 않았다는 직접 비교가 첫 유효성 조건이다. LH+.125를 또 실행하거나 새 theta를 탐색하는 단계가 아니다.

현재 `FlyGymBody._contact_forces`는 접촉 frame의 전치로 힘을 world 좌표에 옮기고 geom1/geom2에 따라 부호를 바꾼다. 같은 의미를 shadow 데이터에서 사용하여 발별/다리별 바닥 반력 벡터, 몸통 forward 성분, 평면 heading 성분을 보존한다. 단위는 body weight로 정규화하고 원래 모델 force 단위도 기록한다. adhesion의 normal 성분을 추진력으로 혼동하지 않는다. 합성 접촉에서 두 geom 순서와 회전된 frame의 부호·합계를 먼저 확인한다.

기존 observer는 실제 적분 상태를 shadow로 복사한 뒤 `mj_forward`를 수행한다. 여기에 기록한 힘은 **적분 뒤 상태에서 재계산한 순간 반력**이다. 100µs 합으로 얻는 값도 그 표본의 수치 적분 근사이며 직전 solver가 적용한 정확한 충격량이라고 부르지 않는다. 실제 적분을 구동한 힘이 추가로 필요하면 pre/post 시점과 integrator 의미를 별도로 검증한다. 실제 신체 MjData를 수정하거나 두 번 step하지 않는다.

몸통의 왕복 운동과 전체 신체 이동도 구분한다. 검증된 fly body ID/질량과 shadow의 관성 중심 위치에서 전체 질량 중심 위치를 계산하고, native thorax 위치·forward basis와 함께 보존한다. 질량 ID 중복/누락과 질량 합은 현재 body.mass와 비교한다. 초기 0시점에 접촉 관측이 없으면 결측으로 둔다. 목적은 원래 thorax 기반 F4를 바꾸는 것이 아니라, 힘과 관측 좌표가 다르게 움직이는 이유를 파악하는 것이다.

## 고정 비교와 결과 결정

기존 E181 입력/과학 기준의 진짜 해시 gate를 유지하고 별도의 관측용 source gate로 추가 observer만 명시한다. 옛 실험이 통과한 것처럼 꾸미거나 임의의 gate 객체를 생성하지 않는다. E182 baseline 전체 원자료 inventory, E184 baseline 사건 8개와 원래 모든 사건 11개, 원래 source/config/model hash를 고정한다.

600제어/30000 native/12000 neural step의 완전한 시계, 실제 CUDA, 기존 startup 99조건 및 native 건강 조건을 유지한다. 새 force clock도 원래 native와 같아야 한다. 기록된 command/MN/activation/접촉/신체 상태를 E182와 전 구간 비교한다. 변경 없는 신경 값은 동일성, 신체·접촉 값은 사전에 고정할 엄격한 수치 오차로 판정한다. 이 오차를 결과를 본 뒤 넓히지 않는다. 원래 J, 순전진, slip, .215초 전진 길이를 재현하지 못하면 해당 force 비교는 유효하지 않다.

유효한 경우 E184의 사전 고정 사건과 네 구간에서 여섯 다리의 양/음 forward force와 적분 근사, 질량 중심/몸통 속도를 모두 보고한다. 모든 다리·사건을 보존하며 사후 한 다리나 lag만 골라 원인을 확정하지 않는다. 경쟁 설명은 다리 간 반력이 서로 상쇄됨, 전체 추진력이 부족함, 몸통 좌표의 왕복 운동과 전체 이동이 다름이다. 하나가 구분되면 해당 기존 신경 경로나 근육·신체 전달에서 한정된 인과 개입을 설계한다. 계측만으로 보행 개선이나 생물학적 타당성을 통과시키지 않는다.
