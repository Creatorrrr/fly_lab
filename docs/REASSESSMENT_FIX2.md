# FLY LAB B fix_2 · 수정 및 원자료 재평가

검토일: 2026-09-09. 대상은 사용자가 제공한 `FLY_LAB_B_fix_1.zip`와 추가 `verification.zip`이다.

## 결론

요청한 세 코드 문제를 수정했다. **비물리 회귀 테스트 95개가 통과**했고, 첨부된 실제 물리 기록을 새 판정으로 다시 분석했다. **8개 탐색 기록이 강화한 고착·보행 재개 검사를 통과**했으며, **33개 고유 조건의 최종 결과와 30쌍 비교가 원자료와 일치**했다. 따라서 이전 검토의 “로컬 물리 검증 원자료 누락” 지적은 해소한다.

이는 새 물리 실험을 실행했다는 뜻이 아니다. **이번 턴의 새로운 FlyGym/MuJoCo 실행은 0건**이다. 코드 회귀, 첨부 원자료 검증, 원자료에 대한 새 규칙 적용을 명확히 분리했다. Sprite의 Python 3.13.7 응답과 준비용 체크포인트 `v2`는 확인했지만, 수정 프로젝트의 원격 네이티브 실행은 수행하지 않았다. 원격 설치 실패를 새로 주장하거나 기존 기록을 이번 실행으로 바꾸지 않는다.

판정: **첨부된 범위의 B 검증 근거는 확인되었으며 C 개발의 기준선으로 사용할 수 있다.** 다만 fix_2를 신규 네이티브 검증 완료판, 모든 환경에서 고착이 없는 모델, 생물학적 디지털 트윈 또는 전체 뇌 검증판으로 표현하지 않는다.

## 1. 정확히 바꾼 것

### R1 — 고착 감시 공백 및 전진 재개 판정

`tools/navigation_checks.py`를 신설하고 `tools/verify_navigation.py`에서 사용한다. 표본 개수 31에 의존하던 코드를 **모델 시간 3.0초의 이동 창**으로 바꿨다. 기존의 `all(front < 3.5 or contact)` 조건은 제거했다.

- 실험에서 이동이 요구되고 `motorCoupled=True`인 동안에는 거리·접촉·회피 플래그가 잠깐 바뀌어도 계속 감시한다.
- 3초 창의 x-z 위치 범위 대각선이 **1mm 미만**이면 FAIL이다. 1mm 자체는 이전 기준 그대로다.
- 제자리 회전량이 커도 작은 위치 범위에 머물면 FAIL이다. 짧은 후진의 반복도 실제 범위를 넓히지 못하면 FAIL이다.
- 구동값 0을 “의도적인 정지”라고 추측하지 않는다. 고장 난 제어기가 0을 출력할 수도 있기 때문이다.
- 의도적인 정지는 `motorCoupled=False` 또는 명시적인 `motionExpected=False`로만 제외한다. 다시 켜면 3초의 새 관찰 창을 쌓는다.
- 표본 간격이 0.15초를 넘는 구간은 연속 감시를 입증하지 못하므로 `INCOMPLETE`로 기록한다. 짧은 기록에서 평가할 창이 없으면 `NOT_EVALUATED`이며 PASS가 아니다.
- 새 궤적에는 회피, 후진 복구, 운동 연결, 운동 명령을 추가로 저장한다. 캠페인도 후속 분석용으로 이 필드들을 저장한다.

`walking resumes after avoidance`는 이제 플래그 해제만으로 통과하지 않는다. 회피/복구가 해제된 뒤 **최대 2초 이내**, 회피가 다시 시작하기 전 구간에서 **수평 순변위 ≥1mm, 몸 방향으로의 부호 있는 누적 이동 ≥1mm**를 함께 요구한다. 순수 후진과 작은 왕복 진동만으로는 통과하지 못한다. 이는 명시적인 공학적 검증 기준이지 생물학적 상수는 아니다.

내비게이션 시험의 “보행 재개”는 적어도 한 번의 실제 재개가 입증되어야 통과한다. 모든 개별 회피 에피소드가 항상 성공했다는 뜻은 아니며, 중단·관측 종료 에피소드도 결과 JSON에 남긴다. 전체 이동 고착 검사는 이와 별개로 계속 적용한다.

**중요:** 회피 상태기를 새로 튜닝한 것이 아니다. 전방 4mm에서 영구 회전하는 합성 반례는 이제 검증기가 잡지만, 그 상황 자체를 새로운 제어법으로 해결한 것은 아니다.

### R2 — 장애물 후보 누락

`tools/run_physics_campaign.py`에서 후보를 `0, ±45, ±90, ±135, 180도`로 완성했다. 가장 가까운 각도부터 고르는 우선순위와 실제 선택 각도 기록을 유지한다. 후보를 전부 거절했을 때의 오류는 “8개 후보에서 찾지 못함”으로 한정하여 연속 공간 전체에서 불가능하다고 과장하지 않는다.

반례 `[23.35, 0.8, 17.35]`, yaw 93.9도는 +135도에서 합법적인 위치를 찾는다. 대칭 반례는 -135도에서 해결한다. 네 코너 × 72방향 검사도 추가했다. **측면 배치를 전방 충돌 회피 실험으로 재분류하지 않는다.**

### R3 — 복원 범위와 원자적 실패 처리

`flylab/brain.py`의 `restore()`와 JavaScript 참조 모델의 `restore()`에 다음 범위를 적용했다.

| 상태 | 허용 범위 |
|---|---|
| `contactTime` | 0~1 |
| `recoveryTime` | 0~0.4초 + 1e-12 수치 허용치 |
| `turnMemory` | −2π~+2π |
| `avoidSide` | 정확히 −1 또는 +1 |
| `prevContact` | 정확히 0 또는 1 |

각도·시계·활성도·RNG·자극 배열도 대입 전에 검증한다. 문자열·불리언을 활성도 숫자로 암묵 변환하지 않고, 중복 자극도 거절한다. **뒤쪽 필드 검증이 실패해도 기존 활동 배열·RNG·타이머는 변경하지 않는다.**

정상 0.2.1 체크포인트와 활성 회피·활성 후진 상태는 유지한다. 새 형식으로 임의 변환하거나 잘못된 타이머를 조용히 잘라 넣지 않는다. 이번 패치는 동적 상태 형식을 바꾸지 않으므로 `appVersion=0.2.1`을 유지하고 패키지 이름/문서로 fix_2를 식별한다. 이전 0.2.0 상태를 받아들이는 변경은 하지 않았다.

### R5 — 패키지 무결성

fix_1에 없던 `.gitignore`를 새로 추가했다. 이것은 분실된 원본의 바이트를 복원했다고 주장하는 것이 아니라 fix_2용 설정 파일이다. 새로운 체크섬 목록을 생성해 패키지에 실제로 포함된 파일과 대조한다. 원래 ZIP은 `verification/source_inputs/FLY_LAB_B_fix_1.zip`에 그대로 보존했다.

## 6. 33조건·30쌍의 재평가

최종적으로 3개 seed × 11조건 = 33개 고유 조건이다. **최초 33회 + 장애물 seed 7의 1회 재시도 = 34회**라는 이력이 맞다.

- 원래 `campaign/report.json`은 FAIL이다. 전방 5mm 장애물이 허용 범위를 벗어나던 seed 7 기록이 남아 있다.
- `obstacle_retry_seed7/`의 별도 기록은 +45도 방향으로 배치해 성공한 시험이다.
- `campaign_final_report.json`은 원래 32개 성공과 이 재시도 1개를 연결한다. 원래 실패 파일을 바꾸지 않았다.
- 개별 신경 CSV(177열)와 물리 CSV(135열)는 각각 101행이며, 100개 궤적 표본의 시간·좌표·좌우 구동값과 일치한다. 유한성, 신경 상태 범위, 최종 tick, 초기 상태 해시, 개입 tick도 검사했다.
- 30쌍의 동일 초기 조건과 개입 전/후 경로·yaw 차이를 재계산했고 최종 보고서와 일치한다. 개입 전 분리는 전부 0이다.
- 운동 차단 세 조건은 3초 이후 좌우 구동값이 모두 0이며, PFL3-L 억제 세 조건은 해당 16개 열이 모두 0인 것을 CSV에서 확인했다.
- 강화한 위치 기반 고착 검사는 운동 연결을 유지한 30개 궤적에서 모두 PASS다. motor-off 3개는 의도적인 정지를 고착으로 오판하지 않도록 제외했고, 그 조건의 목적에 맞는 운동 차단 검사로 다뤘다.

**제약:** 원래 일부 metrics는 5ms 간격으로 집계되고 CSV/궤적은 100ms 표본이다. 따라서 모든 연속시간 최대·최소 지표를 CSV만으로 독립 재현했다고 주장하지 않는다. 기존 캠페인은 개입 전달/물리 안정성 검사이지 모든 조건의 목표 방향 정확도를 보장하는 시험은 아니다.

```bash
python tools/verify_physics.py --seconds 3 --output verification/fix2_native/gate.json
python tools/verify_navigation.py --jobs 4 --out verification/fix2_native/navigation
python tools/run_physics_campaign.py --out verification/fix2_native/campaign
```

각 명령의 종료 코드와 결과 파일을 확인한다. `reevaluate_evidence.py`의 성공은 **과거 기록의 재평가**이며 위 세 명령의 새로운 실행 결과가 아니다.

## 10. C 확장 판단

이전의 원자료 부재 문제는 해소했다. 동일한 보행/신경 동역학에 대해 자료의 추적성, 개입의 전달, 알려진 고착 실패와 개선 후 탐색을 확인했다. **C 설계·구현을 시작할 B 기준선으로는 사용할 수 있다.**

그러나 C에서 신경 계산기나 물리/감각 경계를 바꾸면 그 C 구성으로 다시 시험해야 한다. 특히 후진은 여전히 설계한 보조 복구 상태기에서 나온다. 그 기여를 전뇌 모델의 자발적 판단으로 혼동하지 말고 향후 on/off 조건과 출력 출처를 구분해야 한다. 전체 뇌, 무제한 장시간 안정성, 실제 생체 타당성, 물리 비행, GPU 성능은 이번 승인의 범위가 아니다.
