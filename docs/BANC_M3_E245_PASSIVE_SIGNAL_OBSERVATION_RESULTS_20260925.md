# E245 결과: 신경·신체 동작을 보존한 감각 전달 관측 완료

E240과 같은 10초 교사 보행에 감각 및 선택 뉴런 관측을 추가했고, 기존 실행과의 일치를 확인했다. 241개 감각 포트, 3,604개 감각 뉴런, 기존 설정의 내부·하행 뉴런 51개와 MN391을 포함한 4,046개 뉴런의 2,001행 자료를 확보했다. **관측 자료가 유효하다는 결과이며, 자율 보행 개선이나 생물학적 기전 복원 결과가 아니다.** M3 목표와 같은 최종 후보의 F1–F8은 미완료다.

## 실제 실행과 검산

단일 원본은 실제 CUDA 전체 BANC158,706nodes에서 신경40,000ticks/물리100,000steps/제어2,000회를 실행했다. 각 제어의 원래 leg/knee/encode/neural/body 호출은 각각 정확히2,000회였다. 첫160RK stage 비교를 control2 종료에 수행하여 control3 이전 통과했고, 전체 신경·신체 상태, MN/명령/tendon/adhesion/clock, trace전2,001행과 native-contact전배열이 E240과 exact였다. 부모 검산에서는 세 stage 전체파일 해시까지 일치했다. whole 비교에서 제외한 항목은 기존 계약의 측정 wall_s뿐이다.

부모가 별도로2,000×241수용기 특징, 이전필터의 float32주입, 필터·물리무릎속도 갱신과 상태 연결을 재계산해 exact 일치를 확인했다. raw q/속도가 이전 control의 실제 신체를 가리키는지도 확인했다. 총15,750개 검사항목을 통과했다. 신호는 `verification/banc-natural-gait-m3-20260919/e245-passive-signals/teacher/signal-raw.npz`에 저장됐다(압축13,220,040B). 각 행의 encode/neural/body/parity유효 mask와 실제시점·포트/신경ID매핑은 별도 metadata에 남았다.

## 검토 중 교정한 사항

실제gpt-6-sol/high가 구현했다. 부모 FIRST에서 실패시점 raw보존, 정리·마감 오류의 성공표시 취소, 첫160stage 비교시점의 세 문제를 발견했고 같은Sol이 첫수정했다. 부모 SECOND에서9생성테스트(2.40초/명령3.291088초)와 명시적Ruff(.098217초)가 통과했다. 부모의 잔여 구현수정은0이다.

원본 실행 뒤 첫 부모 감사는 잘못된 추가 가정에서 중단했다. `navigation.cut=True`는 목표시야만 차단하며 기존 `BancTargetEncoder.drive`는 DNg100두세포에 일정한5000전진입력과 별도20억제포트의−5000배경을 유지한다. 이 가운데 선택된4,046열에는 DNg100두세포만 포함된다. 따라서 비감각열을 모두0으로 요구한 부모 감사가 틀렸다. 기존소스와 snapshot설정을 확인해, 모든선택열의 실제입력이 원래 감각입력+원래 tonic입력과 exact인지 비교하는 별도 recovery감사를 작성했다. 모델·실험자료·F기준·E245비침습성 기준은 바꾸지 않았다. 최초감사와 실패출력을 보존했고, recovery는4.858395초(내부4.618371초)에 통과했다. 최초감사비용3.976195초도 보존했다.

442개 `core_adaptation` 대상은 생물학적CPG목록도, 현재모두적응이0인세포목록도 아니다. MN391개에는 후속motor-adaptation override가 있어358개가양수/33개가0이다. 데이터 분석은 실제주석과 적용설정을 구분해야 한다. 이번 고정관측으로 뉴런별 리듬생성 역할이나 정보손실의 인과원인을 단정하지 않는다.
