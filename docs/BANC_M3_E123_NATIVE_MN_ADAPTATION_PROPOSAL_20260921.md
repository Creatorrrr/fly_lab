서보가 요청을 추적하지 못하는 전역 문제가 주된 원인이라는 근거는 약해졌다. E107에서 이미 노출된 몸통에 다리 내부 교사 형태를 넣었을 때 조건부 보행 주기가 회복됐고, 상대 시점만 바꾼 E106은 실패했다. E122도 다리 내부 모집 파형과 지지 동작의 관계를 우선 개선할 근거를 보탠다. 이로써 인과 기전이나 새로운 생리 모델이 증명된 것은 아니다.

힘줄 비교의 차이는 유지한다. E85는8개힘줄.2상수이고 E121은 실제 LTM출력이다. 다만 E121 여섯 힘줄의 고정창 p50은 .199902892–.199987240, p05는 .198720521–.199804985로 이미 상한.2에 가깝다. 기록만으로 힘줄 영향이 없다고 단정할 수는 없지만 전역 힘줄 gain을 먼저 높일 뚜렷한 근거도 없다.

기존 정적1572가중치의 E119/E120 반복이나 E109의 다리별 membrane tau1–5배 적합으로 돌아가지 않는다. E120은 원래 초기99 제약이 해당 국소 형태 감소 가능량의 최소98.88%를 없앴다는 제한된 결과였다. 그 제약이나 원래 발 궤적20% screen, 전체 F기준을 낮추지 않는다.

다음 우선 검토는 **기존 운동신경의 활동 적응을 다시 사용하여 tonic/phasic 모집의 시간 응답을 바꾸는 가설**이다. E121 기록391MN은 모두 _cell_gain=0이고 zero_adaptation_ids에 포함돼 있다. 기존 AdaptiveRateNetwork/CoreAdaptationNetwork에는 이미 활동 적응 상태와 CPU/CUDA 방정식이 있다. 셀별 적응 미분은 (cell_gain*rate-adaptation)/adaptation_tau_s이며, E121의 비선택 기본 gain8/tau.3s와 선택 MN의gain0을 구분한다. 이는 현재 모델의 공학적 매개변수이며 실제 성체 초파리 MN 적응값을 측정한 자료가 아니다.

부모의 다음 상세 설계에서 먼저 실제 토닉/위상성 기여와 초기 제한에 관련된 해부학적 근육·MN을 정하고, 기존 동역학에 대한 제한된 적응gain 가설의 표현 가능성을 검토한다. E122의 큰 signed 평균만 보고 실패 원인이나 특정 MN을 자동 선택하지 않는다. 예를 들어 RH tibia extensor/flexor의 평균 기여 +3.68744/−3.11074rad는 큰 상쇄가 있음을 보여주지만 어느 쪽을 줄여야 보행이 좋아지는지는 설명하지 않는다. 상수 rest, 기존 pool/moment, 원래 근육·노드·연결, 전체 그래프와 신경 리듬 발생 경로를 유지한다.

실행 전 동결할 항목은 적용할 MN/근육·gain 범위·기존 적응tau 유지 여부, 두 실제 관측 문맥, 기존 미변경 입력·초기99·목표 형태·조건부 fidelity 및 shape 기준, 정확한 계산 횟수와 벽시간이다. gain0이 원래 CPU/CUDA 신경 응답과 저장 미래를 보존하는지 먼저 검증한다. 기록된 입력으로 계산한 조건부 모델과 실제 폐루프 모델을 별도로 계수한다. 원래 소스/몸통/동역학 기준선을 재현하지 못하면 적합이나 실제 후보 검증으로 진행하지 않는다.

외부 경과시간 ramp, 위상/교사 출력 gate, root 이동은 최종 모델에 넣지 않는다. 활동에 반응하는 내부 상태를 도입·변경하더라도 이를 생물학적 기전의 검증으로 이름만 바꾸지 않는다. 기존 상태·해시·저장/복원·motor-cut·CPU/CUDA 일치, 실제 전체158706 BANC10초 F3–F5와 같은 최종 후보의 F6/F7/F8이 모두 필요하다.

현재 E123은 제안과 소스 확인뿐이며 실제 응답/적합/물리/F6/제품변경0이다. E122까지 보수적 공유 비용은 supervisor 최종 저장 포함924.761821초로, 다음 단계의 시작값을925로 올리고 기존988초 ceiling을 유지한다. 남은63초 안에서 수행할 수 있는 첫 사전 진단만 상세 동결하며, 실패한 실행의 한도를 늘리거나 반복하지 않는다. 후속 실제 통합 검증은 별도 사전 자원 계약을 마련해야 한다.

개발 순서는 부모 상세설계→Sol 구현→부모 첫 리뷰→같은 Sol 첫 수정→부모 재리뷰 및 잔여 직접 수정이다. 새 CPU/CUDA 신경 동역학·완전 상태 복원·제약 계산이 함께 필요한 구현은 Sol `xhigh`, 단순 저장자료 도구는 `high`, 작은 국소 수정은 `medium`을 사용한다. 전체 목표는 아직 active이며 E121은 F3만 통과한 미채택 후보다.
