## 아직 연결·교정·제품 반영이 끝나지 않은 범위

- **전신 근육:** 공식 15-MTU는 고정된 왼쪽 앞다리와 작은 접촉 플랫폼까지다. 6다리의 근육·부착점·관절 매핑, 자유로운 전신 이동, 검증된 BANC 연결은 남아 있다.
- **낱눈의 생리학적 위치 대응:** 1,040개 포트로 R1–6 6,678개를 연결했지만 해부학적 열을 721개 모델 낱눈에 투영하는 변환은 공학적 후보다. 독립 광학 등록이 없고, 모호하거나 매핑할 수 없는 1,778개는 감각 입력에서 제외된다. 해당 뉴런 자체의 신경 계산은 유지된다.
- **motion/loom 입력:** 특징 계산은 있으나 별도 직접 신경 포트로 전달할 검토된 매핑은 아직 없다. 낱눈 밝기 입력 도입과 별개의 항목이다.
- **후각 교정:** DoOR 41수용기 연결은 있으나 절대 농도, 신경 입력 이득, 혼합물 상호작용, palp 실제 위치는 미교정이다. 공유 ORN으로 중복되는 네 수용기는 제외했고, 현재 두 물질에서 8개 미측정 수용기-물질 조합이 남아 있다. 물질 미지정 냄새원은 새 화학 수용기 입력에 반영하지 않고 표시한다.
- **CUDA 캠페인 화면 통합:** 모델별 큐는 `run_c_cuda_campaign.py` CLI에 있다. 화면의 기존 독립 캠페인과 단일 CUDA 배치 버튼은 이 새 큐의 관리 화면이 아니다. 복원 중 OOM 대응은 위 E3과 같이 추가 구현이 필요하다.
- **비행 정책·브라우저 연결:** 비행·이착륙은 별도 실험 환경/CLI다. 학습된 비행 조종기, BANC 연결, 현재 보행 화면과의 통합은 없다. 비행 물리는 CPU이며 호출자가 제공하는 Torch 정책이 CUDA를 사용할 수 있다는 인터페이스까지다.
- **검증 범위:** 전뇌 32세계×512채널은 세계당 0.5초와 복원 후 0.05초까지다. 32세계 장시간 실시간 성능을 입증한 결과가 아니다. 전신 실측 root 궤적의 독립 대조와 실제 MPS 장치 검증도 남아 있다.

## 예상되는 복원 거부와 해결된 문제

이전 자동 Retina v1 체크포인트는 `Retinal checkpoint profile mismatch`로 거부된다. 광학 계약이 달라져서 의도적으로 호환을 제한한 결과이며 자동 변환 기능은 없다. 경사면은 낙하 판정 의미가 바뀌어 모델 해시에 `slope-plane-v1`이 추가됐으므로 수정 전 경사면 체크포인트가 호환되지 않는다. 이는 위 E3–E5와 구분해야 한다.

기존 E1(실패한 배치의 추가 진행), E2(전 세계 일시정지 복원의 epoch 감소), 경사면 z<0 오판정, 반복 복안 렌더의 비결정성, 연속 관측 요청 누락·중복, 냄새 물질 되돌리기의 표시 오류, Windows UTF-8 읽기/빌드 오류, FlyBody NaN 초기화·마지막 시간 종료, Warp 옵션 메타데이터 오류는 직전 수정 및 검증 결과가 있다. E5는 실패한 배치가 아니라 **정상 종료한 배치**의 생명주기 문제이므로 E1이 다시 발생했다고 서술하지 않는다.

직전 전체 회귀는 **317개 중 296 통과 / 21생략**이며, 후속 관련 검사 21개는 모두 통과했다. 후속 검사 수는 전체 회귀와 겹치므로 합산하면 안 된다. 생략 21개는 MPS 20개와 별도 CUDA 검증 도구를 사용하도록 한 1개다. 이번에 찾은 세 경계 조건은 이 통과 결과에 포함된 것으로 간주하지 않는다.

우선순위는 캠페인 재개·결과 무결성·종료 상태(E3–E5)를 먼저 보완하고, 13개 지형 정지와 Warp 수치 차이를 분리해 분석하는 것이다. 실시간성·BANC 운동 모집·전신 근육/감각 교정은 각각의 검증 기준을 유지해 후속 작업으로 다뤄야 한다.
