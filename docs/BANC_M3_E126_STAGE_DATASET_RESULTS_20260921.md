# E126 결과: 세 문맥의 전체 native 단계 입력 확보

2026-09-21 KST. [사전 설계](BANC_M3_E126_STAGE_DATASET_DESIGN_20260921.md)의 세 원본 수집과 독립 재구성을 완료했다. 기존 전체 BANC와 신체의 동작을 그대로 유지하며391 운동신경의 전류와69 입력 신경의 masked rate를 기록했다. 이 자료는 다음 근육 적응·기존 연결 가중치 적합에 사용할 수 있다. 새 보행 후보를 선택하거나 자연스러운 보행을 검증한 결과는 아니다. M3 F1–F8은 active/unmet이다.

## 구현과 리뷰

부모가 설계와 실제 graph/calibration 매핑을 확정하고 Sol/gpt-5.6-sol/xhigh가 세 파일을 구현했다. CUDA capture, 두 관측 버퍼, stream 소유권, 복원과 오류 보존을 함께 다루므로 xhigh를 사용했다. 난이도가 낮은 별도 수정에는 medium, 여러 구성 요소의 일반 구현에는 high, 이런 결합 동역학·CUDA 작업에는 xhigh를 적용한다.

부모 첫 리뷰에서 차단 결함을 발견하지 않았고 같은 소스를 독립적으로 실행한6개 테스트가 통과했다. 따라서 수정 요청 없이 원본 검증으로 진행했다. 수정이 필요할 때는 같은 Sol의 첫 수정 뒤 부모가 재리뷰하고 잔여 문제를 직접 고치는 사용자 지정 순서를 유지한다.

`tools/banc_m3_stage_dataset.py`의 StageInputNetwork는 기존 CSR 계산의 drive addition 직후 lane0에서 두 값을 각각 기록한다. 기존 CSR 합산·RK4 계산·Core identity를 유지하며 추가 CSR과 native tick별 CPU 동기화가 없다. 최대160000단계·512MiB를 GPU 할당 전에 검사한다. 생성 stream, 한 번의 arm, 관측 시작 후 restore 거부, 고정된 종료 tick은 E125의 검증된 동작을 재사용한다. E125의20000단계 제한과 기존 소스는 변경하지 않았다.

Sol의 자체 검증은5회의 pytest invocation에서 합계23개 테스트 실행이 통과했다(서로 다른23개 테스트라는 뜻은 아니다). 합성15 CUDA 모델, warmup60/capture30, main50tick/.0125초였다. 부모 확인은 별도로3 CUDA 모델, warmup12/capture6, main10tick/.0025초, 외부2.702196초다. 정상 결과뿐 아니라 초과 기록, 중간 RK4 입력, 다른 stream과 restore 거부, 한 배열의 저장 실패 시 다른 배열 보존을 확인했다. 원본 수집 전에는 실제 graph/body 응답을 실행하지 않았다.

## 원본 수집 결과

E110→E113→E121 순서로 각 문맥을 새 프로세스에서 한 번씩10초 실행했다. 세 번 모두 timeout/retry 없이 종료했고, 각 실행 뒤 부모가 독립적으로 검토한 다음 다음 문맥으로 진행했다.

각 문맥의 observed start,1.1초,10초 전체 StateStore는 원본과 일치했다. 비교에서 실행 wall_s만 제외하며, 신경·신체 상태를 제외하지 않았다. 원래2001 control/body행,2000 운동신경 rate/근육 activation도 일치했다. 160000 native 단계의391 전류·69 source 열이 모두 기록됐고 초과·누락·비유한값은 없었다. 각 control 첫 단계의 source 값은 직전 실제 rate×mask와 정확히 같았다. E110 처음1.2초의 전류도 E125 기록과 같았다.

문맥별 raw `.npy` payload는294400000bytes이며 전체883200000bytes다. 기존2444edge/69source 매핑은 실제 graph의 노드·연결만 포함하며,1572 fit edge를 별도 표시한다. 이전 표본에서 빠졌던83877도 포함됐다. 해당 신경의 실제 masked rate 최고값은 E110147.35698@1.095초, E11327.77472@2.335초, E12127.64528@2.335초다. 이 입력을 지우거나 세 문맥의 가중치가 같다고 가정하지 않는다.

## 단계 전류를 이용한 독립 재구성

세 수집이 모두 통과한 뒤 부모의 NumPy float64 RK4로 gain0 운동신경 응답을 한 번 재구성했다. 실제 BANC와 신체를 다시 진행하지 않았다. 기존 E124의5ms 전류 선형 보간 결과는 저장 파일에서 읽었으며 재실행하지 않았다.

세 문맥 모두 원래 rate RMS/max .5/5Hz, activation .25/2.5Hz, q .001/.01rad, LTM .0005/.005 기준을 통과했다. 가장 큰 rate 오차는 약.00061035Hz, activation 오차는.00015609Hz, LTM 입력 오차는1.3185e-8이다. 저장된 발화율을 정답 잔차로 더하지 않았다.

기존 시작99 기준은 별도로 유지했다. 실제 E110 q RMS.019509365/max.056771518rad는 최대.05 기준에 여전히 실패한다. E113/E121은 q RMS.017374129/max.046263550rad로 기존 시작 기준을 유지한다. 정확한 재구성이 E110의 시작 실패를 통과로 바꾸지는 않는다. E121의 실제 F4/F5 미달, E124의 이전 fidelity/FD 실패, F6 미노출도 그대로다.

## 비용과 증거

전체 실제 main은120000 neural tick/30초,300000 physics tick/30초,6000 control이다. 준비 계산15모델의 warmup600/capture300tick은 main과 분리했다. 원본 세 프로세스의 외부 시간은69.884181+70.313735+70.148482=210.346398초다. manifest까지211.122813초이며 사전 보수적 누적1186.122813/1530초 범위다. 부모 NumPy 재구성은120000 context tick/30 conditional초,6000 decoder 업데이트, 외부5.489691초다. 이 conditional 비용을 실제 신경·신체 비용으로 세지 않는다.

원본 수집324파일과 독립 재구성5파일을 봉인했다. 각 관측의 부모 검토는72/71/71항목과 각1527개 해시 비교를 통과했다. 마지막 저장 자료·수치 검토72항목/329원본해시도 통과했다. 해시 비교 수를 소프트웨어 테스트 수로 세지 않는다. 준비는3 StateStore/2 graph metadata 배열, 모델0/응답0/외부2.273029초였다. 이전 원본과 M2 보존 목록도 일치했다.

주요 증거는 `verification/banc-natural-gait-m3-20260919/`의 `e126-stage-dataset-freeze.json`, `parent-e126-final-source-review.json`, `e126-stage-E110`, `e126-stage-E113`, `e126-stage-E121`, `e126-dense-parent/result.json`, `parent-e126-final-review.json`이다. 각 supervision 디렉터리에 명령·PID·종료·wall·원본 SHA가 있으며 모두 terminal이다. 활성 UI와 서버 상태를 변경하지 않았다.

## 다음 개발

다음은 확보된 전체 단계 입력을 사용하는 CUDA 적응 응답과 전체391 운동신경 감도 검증이다. E125의 선택11MN 검증을 전체391의 성공으로 확대하지 않는다. 통과 후 원래 시작99와 상대·절대 형태20% 기준 안에서 기존1572 연결 효능과96 근육 적응값의 공동 후보를 적합한다. 공통 후보 전류를 계산할 때69 source와 문맥별2444 기존 edge 차이를 반영한다.

이는 저장된 presynaptic 입력 아래의 조건부 계산이다. 적합이 유효해도 실제 전체 BANC·감각·신체의 F3–F5와 같은 최종 후보의 F1–F8을 이어서 검증해야 한다. 현재 fit0,새 보행 후보0,F6노출0이며 전체 목표는 완료되지 않았다.
