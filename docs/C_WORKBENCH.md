# C 실험 도구 개선

2026-09-09. [개선 계획](C_IMPROVEMENT_PLAN.md)을 환경 편집, 신경 관측·개입·기록, 감각 프로파일, 대조 비교 순서로 구현했습니다. 신경·물리 적분 간격은 모두 0.1ms를 유지합니다.

원래 사용 중이던 **32.580모델초, C_SHADOW, MPS, 기존 감각 프로파일**을 새 서버에 복원했습니다. [복원 비교](../verification/c_workbench_20260909/user_restored.json)에서 기존 체크포인트의 모든 공통 상태 필드가 정확히 일치했습니다. 구독 epoch만 재접속 규칙에 따라 증가합니다. 화면은 일시정지 상태로 열려 있습니다.

## 사용 방법

1. [C 화면](http://127.0.0.1:8766/)의 **환경 배치**에서 먹이 냄새원, 위험 냄새원, 물리 장애물을 선택합니다. 좌표를 입력하거나 **장면에서 위치 지정**을 누른 뒤 장면을 클릭하고 **배치 적용**을 누릅니다. 미리보기만으로 세계를 바꾸지는 않습니다.
2. 물체 목록에서 ID를 고르면 위치, 냄새 강도 또는 장애물 반경을 수정하거나 개별 삭제할 수 있습니다. **환경 편집 되돌리기**는 현재 모델 시각에서 최근 환경 편집을 역적용합니다. 모델 시간을 되돌리는 기능은 체크포인트 복원입니다.
3. 환경 이름을 지정해 저장하고 불러올 수 있습니다. 같은 이름은 덮어쓰지 않습니다. 냄새원은 합계 24개, 장애물은 12개까지이며, 장애물의 벽·몸·다른 장애물 침범을 서버가 검사합니다. 높이는 반경에 맞춰 바닥에 놓습니다.
4. 신경 프리셋 또는 검색 결과에서 **관측 집단**, **개입 집단**, **고정 기록 집단**을 각각 지정합니다. DNp09, MDN, 좌·우 DNa02와 현재 프로파일의 감각 집단 프리셋을 제공합니다. 관측 집단을 이름으로 저장할 수도 있습니다.
5. **모델 입력 자극(mV)**, 새 발화 억제, 이후 연결 출력 차단의 시점과 기간을 정해 적용합니다. 시점·기간은 0.005 모델초 단위입니다. 예약·활성·만료·취소 상태와 실제 대상 ID를 확인하고 개입별로 취소할 수 있습니다. 기존 지연 큐에 이미 들어간 신호는 지우지 않습니다.
6. 그래프 대상에서 최대 8개를 고릅니다. 막전위·발화율·원시 발화 래스터가 같은 모델 시간축에 표시되고 개입 구간을 음영으로 표시합니다. 관측은 최대 512개, 표시 버퍼는 뉴런당 1,000표본/최대 15모델초, 래스터는 최대 20,000이벤트입니다. 화면 버퍼 순환과 기록 누락은 구분합니다.
7. **기록 시작** 전에 고정 기록 집단을 확인합니다. 기록 중 관측 집단을 바꾸어도 기록 대상은 유지됩니다. 선택 전압·발화율 100Hz, 몸·감각 10Hz, 운동 명령 200Hz와 선택 발화 이벤트를 저장합니다. 신호를 생성하지 않는 B_COMPAT은 LIF 신호 기록 대상이 아닙니다.
8. 대조 비교에서 기간, 개입 시점, 개입·기록 집단, 자극 세기, 시작 상태, 시드, 반복 수를 지정합니다. 현재 체크포인트 반복은 같은 난수 상태의 재현성 검사입니다. 새 시드 반복은 현재 환경을 사용해 첫 시드부터 1씩 증가시킵니다. 각 대조군·개입군은 같은 체크포인트에서 출발하며 관찰 중인 실험은 보존됩니다.

실제 실행 모드는 상단 설명과 장면의 모드 표시에서 확인합니다. **다음 새 실험 모드·감각 포트** 선택은 새 실험을 만들 때 적용됩니다. 현재 실험은 새 실험 전에 자동 체크포인트로 저장하며, 진행 중인 기록은 먼저 종료해야 합니다.

- C_SHADOW: B가 몸을 구동하고 C를 함께 관측합니다.
- C_STRICT: C 신경 출력을 몸에 적용합니다.
- C_ASSISTED: C 출력에 별도 회피 보조가 개입할 수 있습니다. 적용 출처와 이유를 표시합니다.

## 감각 프로파일과 검증 범위

기존 [평균 냄새 프로파일](../data/fafb783/bindings.json)을 유지하면서 [좌우 먹이·geosmin 실험 프로파일](../data/fafb783/bindings-bilateral-geosmin-v1.json)을 추가했습니다. 새 프로파일을 쓰려면 새 실험의 감각 포트에서 선택합니다. 기존 실험의 신경 상태를 다른 포트로 조용히 변환하지 않습니다. 복원은 체크포인트에 기록된 binding hash와 일치하는 파일을 사용합니다.

| 채널 | 실제 v783 대상 | 입력 단위와 가정 |
|---|---|---|
| 먹이 좌측 | 왼쪽 AN afferent ORN_DM1 35개 | 가상 농도 × 18mV, cap 24mV, 20ms 필터 |
| 먹이 우측 | 오른쪽 AN afferent ORN_DM1 33개 | 같은 계수, 좌우 농도를 별도로 유지 |
| 위험 냄새 | ORN_DA2 39개 | 이 프로파일에서만 geosmin 대체 입력으로 해석. 머리 중심 농도를 양쪽 집단에 동일하게 전달 |

DM1/Or42b 대응은 [DoOR 2.0 원 논문](https://www.nature.com/articles/srep21841), 좌우 후각 처리의 근거는 [Gaudry 등](https://www.nature.com/articles/nature11747), Or56a–DA2와 geosmin 대응은 [Stensmyr 등](https://doi.org/10.1016/j.cell.2012.09.046)에 근거합니다. 개별 ID·세포형·측·AN·afferent 주석은 이번 프로젝트에 보존된 [Codex FAFB v783 자료](https://codex.flywire.ai/faq)와 대조했습니다. 문헌의 기능 대응을 이 시뮬레이션의 행동 성공으로 간주하지 않습니다.

입력 세기·농도 감쇠·필터는 생리 실험에 맞춘 값이 아닙니다. 기존 계수를 유지한 공학적 프로파일이며, 좌우 시냅스 방출 비대칭은 별도로 재현하지 않았습니다. DA2의 측 미지정 1개도 포함하되 양쪽 공통 스칼라 입력이므로 측을 만들어 부여하지 않았습니다. 프로파일의 모든 ID, 근거, 한계, 상위 프로파일 hash를 JSON에 기록했습니다.

- 기존 binding hash: `6350020a1d5fdbd1fee25b95a47f3e02ab13c32bb4d571545b8f97a82387dbbc`
- 추가 binding hash: `a5ad2f98a7b6ff3cec9142e445dbccc75cd94f106da674944f7b69768e4f9b84`
- 운동 출력 binding은 변경하지 않았습니다. stop 집단은 여전히 비어 있습니다.
- 시각·근접·접촉 등은 C 감각 포트에서 미연결입니다. 장애물은 물리·센서에 반영되지만 C_STRICT의 신경 회피 입력이 구현된 것은 아닙니다.

## 행동 해석과 남은 연구

[짧은 출력 진단](../verification/c_workbench_20260909/output_diagnostics_short.json)에서 새 프로파일의 seed 42는 무입력일 때 하행 출력 발화율과 운동 명령이 0이었습니다. 강도 2 먹이 조건에서는 좌우 냄새 센서가 모두 상한 1에 도달하여 좌우 정보가 같아졌고, 0.2초 시점 DNa02 좌/우 발화율은 약 267.36/63.44Hz, 전진 명령은 0, yaw 명령은 −3rad/s였습니다. 이 관측은 **감각장 포화와 출력 해석의 회전 상한 도달**을 보여 줍니다. 지속 회전의 모든 원인을 분리한 결과는 아닙니다. 포화는 화면에 표시하며 강도를 낮춰 좌우 정보가 유지되는 조건을 만들 수 있습니다.

같은 짧은 위험 조건에서 geosmin 포트 입력은 전달되지만 해당 하행 집단의 행동 출력은 0이었습니다. 위험 신호를 전달한 것만으로 회피 성공으로 판정하지 않습니다. 실제 이동은 몸의 전방 축에 투영하여 전진·후진을 따로 계산하므로 회전 중의 몸 이동, 음수 명령, 경로 길이를 혼동하지 않습니다.

비교 결과는 `technical_status`, `task_status`, `biologicalValidation`을 분리합니다. 접촉·체류·궤적은 제어 주기 5ms로 표본화하며 더 짧은 접촉은 놓칠 수 있습니다. 3초 미만 기록의 고착 판정은 `INCOMPLETE_WINDOW`입니다. 회피 해제 후 관측이 2초에 못 미치면 전진 재개 판정도 불완전으로 남깁니다. 먹이 반경 2mm의 진입·체류는 공간 지표이며 섭식·포만감 모델은 없습니다.

다음 연구는 낮은 강도의 좌우 비교, 충분한 기간의 감각 차단·출력 개입 대조, C_STRICT의 지속 회전 원인 분리, stop·후진 출력 검증, 시각·접촉 포트의 실제 대상 검토입니다. 긴 행동 캠페인은 과제 기준을 고정한 뒤 진행해야 합니다. Apple GPU 물리 이식은 [앞선 호환성 검사](C_RUNTIME_OPTIMIZATION.md)의 미지원 조건을 해결하는 별도 단계입니다.

## 저장 형식과 성능

- 새 명령: `update_object`, `delete_object`, `load_environment`, `undo_environment`, `cancel_intervention`. 기존 `place`는 `strength`를 받습니다. 모든 변경 명령은 이벤트 기록과 리플레이에 포함됩니다.
- 조회·저장: `lookup`(ID 512개), `presets`, `cohort_save`, `interventions`(페이지당 최대 200개), `environments`, `environment_save`, `environment_load`.
- 환경 되돌리기는 최대 32회, 종료된 개입 이력은 최근 256개를 체크포인트에 보존합니다. 전체 이벤트는 기록 파일에 남습니다. 현재 예약·활성 개입은 이력 한도와 독립적입니다.
- 구버전 C 체크포인트의 새 메타데이터 필드가 없으면 빈 이력·기존 운동 출력 기록 집단을 사용합니다. 신경·물리 상태는 변환하지 않습니다.
- 대조 비교는 반복당 `initial_checkpoint`, `control/`, `intervention/`, `comparison.json`, 캠페인 전체는 `campaign.json`을 저장합니다. 원시 신호·발화·감각·적용 명령·초기/최종 상태·graph/binding hash·기준을 함께 보존합니다. 실패한 실행도 덮어쓰지 않습니다. 한 요청은 총 20모델초로 제한합니다.
- 래스터·전압·발화율은 FLC3 원자료를 사용합니다. 전압 임계 통과로 발화를 재구성하지 않습니다. 영역 자동 갱신은 5실제초마다 최대 1개 요청만 대기합니다.
- MPS 운동 출력 readout을 관측 집단과 별개로 기존 일괄 전송에 포함합니다. 신경 적분·전달 커널은 그대로이며 표시·기록 발화 집단은 늘리지 않습니다. 최대 1,024개 표시/기록 합집합에 추가 운동 readout을 붙인 실제 MPS 검사에서 발화 시점과 CPU 기준 신호가 일치했습니다.

[동일 체크포인트 교대 성능 측정](../verification/c_workbench_20260909/performance_readout_fix/report.json) 8개 실행에서 신경·몸·센서·명령·기록 값은 이전 커밋과 정확히 일치했습니다. 기본 관측의 0.2모델초 중앙 실행 시간은 이전 2.117초/현재 2.478초, 512개 관측·기록은 이전 1.786초/현재 1.618초였습니다. 이전 실행끼리도 512개 조건에서 1.457~2.115초로 변동했습니다. 따라서 전체 처리율 개선이나 성능 회귀 해소를 확정하지 않습니다. `status=PASS`는 이 비교의 **핵심 상태·원자료 일치** 판정이며 속도 합격을 뜻하지 않습니다. [초기 측정](../verification/c_workbench_20260909/performance_fix1/report.json)과 [실패한 기준선 준비 기록](../verification/c_workbench_20260909/performance/default-0-baseline.log)도 보존했습니다. 안정된 부하에서 반복 수를 늘린 성능 측정은 남은 항목입니다.
