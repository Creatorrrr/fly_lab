# E351 보존 자료 독립 검증 결과

직렬화 오류를 수정한 뒤 보존된 B/I/C 자료를 별도 감사로 검증했다. 과거 E350 실행과 감사의 실패 상태는 유지했다. 원본 신경망·신체·GPU 추가 실행은 없다.

|I|1.552693|2.018704|0.295|{'lf': 0, 'lm': 0, 'lh': 0, 'rf': 0, 'rm': 0, 'rh': 0}|
|C|1.814082|1.672599|0.360|{'lf': 0, 'lm': 0, 'lh': 0, 'rf': 0, 'rm': 1, 'rh': 0}|

C는 각 다리의 기준 형상을 공유 LF 시간으로 구동한 교사 대조다. 전진·미끄럼·연속 전진·건강 기준은 통과했지만, 여섯 다리의 완전 주기 기준은 실패했다. 따라서 H348은 partial_or_inconclusive이며 BANC 학습 후보나 자연 보행 성공으로 채택하지 않았다. C의 인정된 연속 구간은0.5–0.86s와1.18–1.495s다. 다음 E352에서 위상 진행과 발의 왕복 운동이 이 구간 안에서 완성되지 않는 원인을 분리한다.
