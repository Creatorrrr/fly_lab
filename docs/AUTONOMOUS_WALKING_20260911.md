# 감각 자율 보행 구현 — 2026-09-11

`FLYGYM_AUTONOMOUS` 모드를 구현하고 8770 페이지에 연결했다. 좌우 냄새로 먹이에 접근해 멈추거나, 계속 걸으면서 벽을 회피한다. FlyGym의 여섯 다리 CPG·실측 보행 궤적·접촉 보정을 사용하는 공학적 기준선이다. **BANC 신경망 자체의 자율 보행은 아직 달성하지 않았다.** 기존 `C_STRICT`의 연결·신경 파라미터·운동뉴런 구동 경로를 변경하지 않았다.

## 사용

페이지의 행동 선택에서 **계속 걷기·장애물 회피** 또는 **냄새 따라 먹이 찾기**를 고르고 **감각 자율 보행 시작**을 누른다. 새 자유 이동 실험이 시작되며 이전 실험은 체크포인트로 보존된다. **행동 중지/재개**는 물리 시간을 계속 진행하면서 보행 명령을 끄고 켠다. **재생/일시정지**는 시뮬레이션 시간 자체를 제어한다. 먹이 찾기에서는 냄새가 충분히 강해지면 의도적으로 정지하며 화면에 도착 상태를 표시한다.

개발 전 서버의 `C_STRICT` 19.825초 상태는 `artifacts/neural-tendons/checkpoints/checkpoint-96ee9ddf4346`에 보존했다. 수정된 서버에서도 이 체크포인트의 복원을 확인한 뒤 새 보행 실험을 시작했다. 신경 개입·신경 비교 작업은 기존 신경 모드에서 사용한다. 자율 보행의 저장·복원·물리/명령 기록은 사용할 수 있다.

## 제어 경로와 FlyGym 적용

`flylab/autonomy.py`의 정책은 `odor[2]`, `nearRanges[9]`, `contact`만 읽는다. 먹이 좌표나 몸통 위치를 정책에 전달하지 않는다. 감각 생성기는 FlyBody 더듬이 위치에서 역제곱 냄새장을 샘플링한다. 농도·수용체·회피 거리와 구동 강도는 공학적 설정이며 생리 교정을 주장하지 않는다.

좌우 농도 차이가 회전 명령을 만들고, 농도 역치·100ms 체류·히스테리시스가 도착/재출발을 결정한다. 이 명령을 기존 `MotorAdapter`와 `CachedHybridStepper`가 받아 FlyGym `HybridTurningController`를 실행한다. 5ms마다 정책을 계산하고, 0.1ms마다 CPG·걸림/다리 회수 보정과 MuJoCo를 진행한다. 낮은 단계의 접촉·발끝 관측이 여섯 다리의 운동을 보정한다. 몸통 위치를 직접 이동시키지 않는다. 구동 강도는 실제 속도를 보장하는 속도 서보가 아니며 화면 속도는 물리 상태에서 측정한다.

현재 사용 중인 FlyGym 2.1의 `flygym_demo/complex_terrain/hybrid_controller.py`와 `turning_controller.py` 구현을 기존 `flylab/locomotion.py`가 호출한다. FlyBody 전신 모델, 42개 다리 관절, 자유 몸통, `tracking_all` 서보, 8개 힘줄 입력 0.2를 사용한다. `C_STRICT`가 사용하는 신경 기반 힘줄 입력과 구별해 출처를 기록한다.

정책 v1은 벽 모서리에 고착됐다. v2의 반대 부호 CPG 구동도 30초 외력 시험에서 고착됐다. v3은 6mm 거리에서 회피를 시작하고 양쪽 구동을 전진 방향으로 유지하면서 안쪽 보폭을 줄인다. 실패 궤적을 보존했고, 누적 경로 길이만으로 성공 판정하지 않는다.

통과 기준은 실행 전 설정에 저장한다. 연속 보행은 최초 10초 순이동/전진 각각 5mm 이상, 모든 다리의 하중 전환, 유한한 관절 상태, 수직 정렬 0.5 초과, 활성 보행 중 3초 동안 1mm 안에 머무는 구간이 없어야 한다. 도착은 먹이까지 2mm 이내와 마지막 1초 이동 0.5mm 이하가 필요하다. 예정된 중지와 먹이 도착 후 휴식은 고착 판정에서 제외한다. 두 연속 보행 실행에서 각 다리의 하중 전환을 확인했다. 이 검사는 특정 평지·벽 환경의 기능 검증이며 임의 지형·모든 시드·생물 보행의 재현을 입증하지 않는다.

저장 후 두 엔진을 같은 기간 더 진행했을 때 `qpos`, `qvel`, `ctrl`, `qacc_warmstart` 최대 차이는 모두 0이었다. 행동 중지 후 측정 속도는 약 -0.000012mm/s였다. 신경 신호를 계산하지 않는 실행의 구독 목록을 비워 바이너리 신호와 화면 상태를 일치시켰다. 관련 Python 검사 46개 중 43개 통과, 3개 조건부 생략; JavaScript 구문, 기존 신경 상태 표시, 재생 제어 6개 검사도 통과했다. 고착 상태에서 큰 누적 경로가 생겨도 실패로 판정하는 회귀 검사도 포함한다.

실제 브라우저에서 연속 보행·행동 중지·재개와 렌더링을 확인했다. 모델 시간이 13.450→27.130초로 진행되는 동안 행동 중지 상태와 약 0mm/s를 확인했고, 재개 후 이동이 다시 발생했다. `checkpoint-ce9e49195098`에 70.220초 상태를 저장한 뒤 70.270초까지 진행하고, 화면의 복원 버튼으로 70.220초로 돌아왔다. 최종 페이지는 이 상태에서 연속 보행을 재개해 두었다. 수정본 검증 구간에 새로운 브라우저 오류는 없었다. 70초는 중지 구간을 포함한 모델 시각이며 70초 연속 보행의 검증 수치로 사용하지 않는다.


## 남은 신경 개발

`tools/analyze_c_late_motor_activity.py`로 별도 연구 rate 모델의 저장된 E28 자료를 분석했다. 9조건의 5,985개 입력 합을 독립 계산과 비교해 최대 오차 1.42e-12를 확인했다. 입력 종료 후 Fast 운동뉴런이 새로 활성화되는 현상은 단순 출력 필터의 잔류만으로 설명되지 않는다. 흥분·억제 회로의 기여가 자세마다 다르며, 특정 연결의 삭제나 전역 이득 변경을 채택할 근거는 확보하지 못했다.

이 분석은 현재 페이지의 LIF 모델을 새로 적분한 결과가 아니다. `verification/autonomous-walking-20260911/neural-analysis/ANALYSIS.md`에 자료·반례·제약을 기록했다. 신경망을 통한 지속적인 보행에는 세포 동역학과 감각·운동단위 대응의 추가 교정이 필요하다. 반응한 accessory 운동뉴런을 Fast 근육에 임의로 연결하지 않았으며, 적응 동역학이나 새 근육 모델도 아직 채택하지 않았다. 이번 FlyGym 보행 성공을 BANC 자율 보행 성공으로 합산하지 않는다.
