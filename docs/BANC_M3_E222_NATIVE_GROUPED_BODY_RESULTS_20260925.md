# E222 결과: 전체 신경·신체 연결에서 초기 균형 기준 미달

E218의 조건부 적합과 E221의 생성 CUDA 검산을 통과한 반응을 전체 BANC/FlyBody에 연결했으나, **0.2244 모델초에 upright가 0.89981457로 내려가 원래 0.9 기준에서 중단됐다. 후보는 기각하며 보행 개선으로 채택하지 않는다.** 비발 접촉은 0이고 수치 발산이 검출된 경우가 아니다. 마지막 몸통 기울기는 약 25.87도이며, 이를 완전히 쓰러진 상태로 표현하지 않는다.

## 실행과 직접 증거

고정 [설계](BANC_M3_E222_NATIVE_GROUPED_BODY_DESIGN_20260925.md)의 전체 158,706 신경, free 343/fixed 48 MN, 원래 96근육 canonical 전달, 동일 E150 중립 시작을 사용했다. CUDA packed CSR float32와 새 자기 반응/기억 float64를 실행했다. 시간별 teacher/rate replay, 새 학습, solver, 신체/가중치 변경은 없었다.

| 측정 | 결과 |
| --- | --- |
| 실제 신경 진행 | 900 tick, 0.225초 |
| 실제 물리 진행 | 2,244 step, 0.2244초 |
| 온전한 control 기록 | 초기행 포함 45행, 마지막 0.220초 |
| 마지막 upright / 비발 접촉 | 0.8998145695 / 0회 |
| 원본 프로세스 / 재시도 | 1 / 0 |
| 1초 디스크 clone / 10초 보행 / 후속 cut | 도달하지 못함 |

실패한 45번째 control도 advance ledger에 남겼다. 이 control에서 신경 20 tick은 끝났고 물리는 44 step까지 진행했다. 이를 완전한 control이나 10초 성과로 계산하지 않는다. 기존 99행 startup 진단 역시 불완전하다.

원시 증거는 `verification/banc-natural-gait-m3-20260919/e222-native-grouped-body/`의 start, main-control.npz, native-contact.npz, trace.jsonl, control-journal.jsonl, advance-ledger.json, result.json 및 output-manifest.json이다. 프로세스의 실패 exit code는 실제 건강 중단을 반영한다. 부모 감독기의 마지막 성공 assert도 실패했지만 추가 실행은 없었고, 원본 분류는 `measured_native_health_stop`으로 보존됐다.

## 독립 검산과 해석

부모는 저장된 live float32 MN 출력에서 10ms 근육 필터를 별도로 계산했다. 활성 최대차 8.53e-14, 관절 명령 최대차 2.16e-15 rad, 힘줄 최대차 2.78e-17이었다. 원시 dtype/시간/해시와 새 float64 rate의 float32 공개 출력도 일치했다. 따라서 이번 실패를 전달 계산의 반올림 오류로 설명할 근거는 없다.

반면 조건부 E218 예측과 실제 명령의 최대차는 5ms의 0.00061835 rad에서 50ms의 0.051856 rad, 200ms의 0.329497 rad로 커졌다. 실제 44개 control prefix의 예측 대비 명령 RMS 차이는 0.0448012 rad였다. 같은 시각의 흥분·억제 입력 기억도 조건부 기저에서 달라졌다. 이는 저장 입력에서 적합한 반응을 재귀 신경망에 넣었을 때 동일 입력을 유지할 수 없음을 보여준다. 신경 내부 재귀와 이후 몸체 감각 피드백의 기여율까지 이 실험 하나로 확정하지 않는다.

부모 검산은 `parent-e222-output-review.json`, prefix 비교는 `parent-e222-prefix-review.json`에 저장했다. 검산 통과는 실패 측정의 신뢰성을 뜻하며 자연 보행 성공을 뜻하지 않는다.

## 구현·리뷰와 비용

실제 gpt-6-sol/high가 trial/runner와 테스트를 구현했다. 부모 FIRST에서 cut 접촉 기록 혼입과 건강 실패 분류 덮어쓰기를 찾았고, 같은 Sol이 첫 수정을 수행했다. 부모 SECOND에서 관련 17개 테스트와 Ruff가 통과했다. 부모 잔여 소스 수정은 0이다. 생성 mock 테스트의 성공과 위 실제 신체 실패를 분리한다. 소스 검토 기록은 `parent-e222-first-review.json`, `parent-e222-source-review.json`이다.

원본 감독 벽시간은 **23.3999767초**, 최대 개별 RSS 2,527,924,224B/관측 프로세스 합 2,537,222,144B, 추가 GPU 메모리 관측 최대 471,859,200B, 최종 출력 13,460,099B였다. 감독 대상 프로세스는 모두 종료됐다. 구성 warmup 실제 280 tick과 CUDA capture 140 tick은 별도 계측했으며, 900개 과학적 tick에 숨기지 않았다.

원본 보수적 누적은 **5818.539935299679 / 6004초**, 잔여 **185.460064700321초**다. 별도 부모 raw 검산 내부 0.09430초/프로세스 1.23411초, prefix 저장 검산 내부 0.04944초/프로세스 0.40653초, 부모 테스트 프로세스 5.65094초와 Ruff 0.26540초도 비용이다. 구현·정적 리뷰 전체는 완전 계측되지 않았으며 0으로 취급하지 않는다. E221 생성 CUDA 비용과 과거 실패 비용도 보존한다.

## 후속 판단

같은 후보를 다시 실행하거나 기준을 완화하지 않는다. 재귀 피드백을 포함한 적합과, 원래 신경간 발화 동역학을 보존하면서 근육 전달만 바꾸는 별도 가설을 비교한다. 후자는 단순한 모델 이름 변경이 아닌 실제 변환 위치 변경이며 생물학적으로 검증된 기전으로 주장할 수 없다. 다음 시도는 원래 F2와의 일치·실제 변경·새 예측·잔여 비용을 사전에 고정한 뒤 결정한다.

최선 부분 결과 E150과 기존 M2, 활성 UI를 보존했다. F6 확인 자세는 노출하지 않았다. F1–F8 전체는 여전히 미완료이며 finite-goal은 active다.
