# BANC 목표 보행 구현과 검증

이 문서는 `BANC_NAVIGATION_GOAL_PLAN_20260912.md`의 고정 v1 목표에 대한 구현 및 실제 물리 증거를 기록한다. 최종 목표 판정은 아래 완료 상태를 따른다. 단위 검사나 신경 발화 변화만으로 목표 도달을 주장하지 않는다.

## 구현

`BancWalkingSession(navigation=...)`에 선택적 목표 실험을 추가했다. 기존 BANC 기본 보행과 상단 FlyGym 감각 자율 보행은 각각의 구동 경로를 유지한다.

1. `TargetSensor`가 바닥 목표를 몸 기준 방향·거리로 변환한다. 정확한 목표 좌표를 아는 이상적 감각 모델이며 복안의 시각 인식 회로를 재구성한 것은 아니다.
2. `BancTargetEncoder`가 이 관측을 기존 BANC 뉴런의 비주기 입력으로 바꾼다. DNg100 양측에는 일정한 각성 입력을 주고, 회전 시 앞·뒷다리의 IN08A006/IN19A003 중 반대 근육을 억제하는 세포를 선택한다. 근접 시 20개 억제 입력 포트를 함께 활성화한다.
3. 전체 BANC v888 선언 뉴런 158,706개와 연결 11,584,852개를 CUDA에서 계속 계산한다. 20개 입력 포트에서 391개 다리 운동뉴런으로 향하는 **기존 음의 연결**에만 고정 효능 계수 64를 적용한다. 다른 연결과 모든 연결의 존재·전달물질 부호는 유지한다. 이 계수와 입력 전류는 공학적 보정값이며 측정된 생리 수치가 아니다.
4. 운동뉴런 활동을 근육별로 모아 관절 서보와 여섯 발의 장힘줄에 연결한다. Coxa 회전 부호는 실제 물리 분절의 Jacobian으로 정하고, 장힘줄은 말단 힘줄을 구동하므로 첫 발마디에 같은 출력을 중복 적용하지 않는다. 실제 근육 힘·모멘트암을 재현한 모델은 아니다.
5. 정지 요청과 실제 정지를 구분한다. 물리 위치를 5ms마다 기록하고, 목표 반경 2mm 안에서 0.5초 정착 후 1초 경로가 0.5mm 이하인지 별도로 판정한다.

목표 관측은 운동 디코더에 전달되지 않는다. 외부 CPG, 미리 정한 보행 위상·관절 궤적, 주기적 신경 초기화, 루트 위치·회전 보정은 사용하지 않는다. 다리 운동 생성에는 BANC의 재귀 활동과 운동뉴런 출력이 필요하다. 목표 선택·감각·입력 변환에는 위 공학적 모델을 사용한다.

## 재현과 상태

목표 좌표·방향 요청·정지 히스테리시스·최근 물리 기록·목표 감각 차단을 신경·근육·물리 상태와 함께 저장한다. 목표를 바꾸면 목표 정책의 기록만 새로 시작하며 몸과 신경 상태는 유지한다. 기존 저장 상태의 누락된 목표 필드는 목표 기능 없음으로 복원한다.

실험 생성 예:

```python
session = BancWalkingSession(
    graph,
    seed=42,
    parameters={"neural_dt_s": 0.00025, "coxa_geometry": True, "ltm_tendons": True},
    navigation={"target_xz_mm": [6.0, -3.0], "forward_drive": 5000.0},
)
```

좌표는 UI의 절대 X/Z mm이다. 검증기의 목표는 초기 물리 위치에 상대 오프셋을 더하므로 위 예와 값이 정확히 같지는 않다. 생성은 시간을 진행하지 않으며 `advance()` 또는 화면의 BANC 재생으로 진행한다.

검증 명령은 매번 새 출력 폴더를 사용한다.

```powershell
.\.venv\Scripts\python.exe tools/verify_c_banc_navigation.py --out verification/new-navigation-check --experiment LOCAL-CHECK --checks-only
.\.venv\Scripts\python.exe tools/verify_c_banc_navigation.py --out verification/new-navigation-matrix --experiment LOCAL-MATRIX --matrix --seconds 31.5
```

## 직접 확인한 증거

- E23의 같은 초기 상태에서 앞·뒷다리 선택 입력은 2초 동안 왼쪽 -0.25958rad, 오른쪽 +0.40664rad 회전을 만들었다. 모두 넘어짐·비발 접촉이 없었다. 왼쪽은 기준 0.25rad에 가깝다.
- E24에서 같은 왼쪽 입력을 6초 유지했을 때 최종 순회전은 -0.05659rad로 줄었다. 일정 입력에 대한 회전이 항상 일정하게 지속되는 것은 아니다. 이 반대 증거를 보존한다.
- E25 개발용 목표 `(6,-3)`은 6.5초에 반경에 들어갔고 8.0초에 물리 정지가 확인됐다. 최종 거리 1.07549mm, 정지 측정 구간 경로 0.431046mm였다.
- E26b에서 저장 후 0.3초 미래의 신경·물리·근육·목표 상태가 정확히 같았다. 벽시계 측정값만 비교에서 제외했다. 목표 감각 차단은 신경 및 물리 미래를 바꿨고, 운동 차단은 관절 오프셋과 신경 힘줄 요청을 정확히 0으로 만들었다. 연결 전달 전체 차단 후 운동뉴런 최대 활동은 0.0000612 모델 단위로 감소했다. 잘못된 목표 기록 시각은 거부했다.
- 관련 회귀 검사 104개 중 94개 통과, 10개 환경별 검사 건너뜀. 추가로 변경 JS 구문·새 Python 모듈 lint·diff 공백 검사를 통과했다.

## 완료 상태

E27의 고정 여섯 목표 조건이 모두 통과했다. 목표 오프셋은 초기 물리 위치를 기준으로 한다. 표의 도착 시간부터 반경 안에 머물렀고, 1.5초 뒤 정지 확인이 끝났다.

| 조건 | 도착 시간 · 모델초 | 최종 거리 · mm | 정지 측정 경로 · mm | 판정 |
|---|---:|---:|---:|---|
| 정면 `(8,0)`, seed 42 | 7.435 | 0.7420 | 0.4801 | 통과 |
| 왼쪽 `(6,-6)`, seed 42 | 13.250 | 1.2227 | 0.0292 | 통과 |
| 오른쪽 `(6,6)`, seed 42 | 7.460 | 1.1955 | 0.4748 | 통과 |
| 뒤쪽 `(-6,0)`, seed 42 | 20.300 | 1.1980 | 0.0138 | 통과 |
| 정면 `(8,0)`, seed 7 | 7.435 | 0.7420 | 0.4801 | 통과 |
| 오른쪽 `(6,6)`, seed 7 | 7.460 | 1.1955 | 0.4748 | 통과 |

모든 조건에서 넘어짐·비발 접촉·수치 오류가 없었다. CPG 상태는 바뀌지 않았다. 동일 CUDA 설정에서 모델 1초당 실제 약 5.4~5.6초가 걸렸으며 이는 실시간 실행 수준은 아니다.

E28b에서 개발 목표의 정지 상태를 복원하고 현재 몸 방향 8mm 앞의 새 목표를 줬을 때, 몸·신경·근육 상태를 초기화하지 않고 2초에 1.56332mm 순이동했다. 재출발 기준도 통과했다. E28의 첫 실행은 검증 도구의 list 좌표 색인 오류로 무효였고 수정 실행과 구분해 보존한다.

8770 화면의 기존 BANC 체크포인트를 복원해 12.450초에서 12.500초로 정상 진행했다. 같은 개발 목표를 화면에서 생성하고 BANC 재생을 눌러 실제 접근·정지를 확인했다. 15.100초에도 목표 거리 1.036mm, 최근 정지 측정 경로 0.038mm로 정지를 유지했다. 실제 MuJoCo 초파리 렌더와 평면도의 위치·상태를 함께 확인했다.

그 상태를 `banc-b626fb344ba5`로 저장한 뒤 새 목표로 50ms 진행하고 복원했을 때, 시각 15.100초·원래 목표·정지 기록이 돌아왔다. 빈 좌표와 범위 밖 좌표 101은 거부됐다. 복원 시 사용자가 아직 적용하지 않은 입력값도 저장된 목표 값으로 갱신하도록 UI를 수정했다. 확인한 브라우저 오류는 의도적으로 발생시킨 입력 검증 메시지뿐이다.

**고정 v1의 일곱 완료 기준을 모두 충족했다.** 채택 범위는 위 명시적 BANC 평지 목표 실험 프로필이다. 다양한 초기 자세·지형·외란이나 생물학적 목표 탐색 일반화를 검증한 것은 아니다. 이전 실험 실패 및 왼쪽 고정 입력의 한계는 그대로 남는다.

## 화면 사용

현재 8770 페이지에는 목표 `(6.55519,-2.99400)`의 새 실험을 0초에서 일시정지해 두었다. **BANC 재생**을 누르면 진행한다. 시작 상태는 `banc-fa7b03d8366b`, 이미 도착해 정지한 상태는 `banc-b626fb344ba5`로 복원할 수 있다.

다른 목표는 X/Z를 입력하고 **현재 몸에 목표 변경**을 누른 뒤 BANC 재생으로 진행한다. **BANC 목표 보행 실험 만들기**는 검증한 0.25ms 신경 계산·Coxa 방향·장힘줄 설정으로 새 실험을 만든다. 상단의 일반 재생 및 FlyGym 감각 자율 보행은 별도 실험이다.

원본 기록: `verification/banc-navigation-20260912/`. 각 실험의 사전 spec, 코드·모델 해시, 물리 궤적, 결과와 이전 실패를 보존한다. E26 최초 실행은 검증 도구의 numpy 해시 처리 오류로 무효였고 E26b가 수정된 실행이다. 기존 E1–E24의 실패를 새로운 목표 성공으로 재분류하지 않는다.

## 적용 범위

입력 포트와 근육 그룹의 식별은 로컬 BANC v888 원문 주석을 사용한다. 수용체 반응, 신경 적응, 시냅스 효능, 입력 전류, 근육의 위치 서보는 공학적 가설이다. 신경 입력 수치를 측정된 Hz나 mV로 부르지 않는다. Coxa endpoint의 추가 다축 대리 모델(v5)은 E17에서 유용한 회전을 입증하지 못했으며 목표 실험의 기본 설정에 채택하지 않았다.

현재 seed는 사용하지 않는 CPG의 초기 상태에도 영향을 준다. BANC 목표 실험에는 별도의 확률적 신경 초기화를 넣지 않았으므로 seed 7/42 실행을 독립적인 확률 표본으로 해석하면 안 된다. 고정 조건의 재현, 새로운 방향의 성공, 임의 상태·지형에서의 일반화는 구분한다.

8770 업데이트 전 사용자가 보던 상태를 저장했다: 상단 실험 `checkpoint-f3a0f1cf875c`(3.960s), BANC `banc-18a963a526ce`(12.450s). 기존 실행을 복원할 수 있다.
