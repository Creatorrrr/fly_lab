# E215 결과: LM의 기존 필터로 조건부 목표를 만들 수 있음

E215 단일 LM 동적 용량 문제는 Solved로 끝났고 독립 검산을 통과했다. 실제 막 시간상수 두 종류와 10ms 근육 EMA, cap/gate와 근육 소유권을 그대로 두면서 시간마다 자유 forcing을 허용하면, LM main 명령 RMS는 원래 .02655110078627721rad에서 **.003058691973951933rad(88.47998% 감소)**로 줄었다. 속도 RMS는 1.2209126587230492에서 .17665584686262562rad/s, startup RMS/max는 .006148547676252694/.03138308170999543rad다. LM 필요조건을 통과했으며 startup RMS도 참고 한도 .018보다 낮다.

반환 forcing의 실제 최솟값2.7624289574562644e-12, 원래 상한까지 최소 여유.00023550626646049713으로, 사전 허용한 작은 음수/상한 확대 epsilon에 의존하지 않았다. 정규화 activation은 .0002221391264..7241654324다. 두 단계 필터를 독립적으로 다시 계산한 명령 최대 차이는8.881784197001252e-16rad다. 고정 입력 조건에서 LM 목표를 만들 출력 대역폭/해부학적 용량이 있다는 수치 witness이며, 기존 고정16기저 반응식의 LM 한계와 구분된다.

이 결과는 **BANC가 학습한 반응 함수, 여섯 다리의 동시 해, 실제 센서 피드백 또는 자연 보행 성공이 아니다.** 임의 forcing은 진단 전용이다. LM 하나의 성공을 전체 실패의 유일 원인으로 확대하지 않는다. 나머지 다리와 전역 proxy를 동일 필터로 확인한 뒤 반응 표현을 설계할 근거로 사용한다. F1–F8 active/미완료, 후보 채택0, F6미노출, E150 최선/M2/UI 보존.
