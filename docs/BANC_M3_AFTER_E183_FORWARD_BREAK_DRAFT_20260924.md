# E183 이후: 전진이 끊기는 시점의 실제 원자료 분석

E181–E183의 사전 고정 한 순회는 끝났다. LH+.125의 J7.573%/slip.991% 개선은 보존하되 순전진3.189% 감소와 최장 전진 .215초/각 다리 적격 주기0을 함께 유지한다. 다른 후보의 J 개선도 slip 조건을 위반했다. 다음은 같은 theta grid의 반복이 아니라 **지속 전진을 끊는 관측 사건과 신경·근육·접촉의 시차를 구분하는 단계**다. 이 파일은 후속 분석 초안이며 새 original run이나 제품 채택을 허용하는 source gate가 아니다.

우선 E182 theta0와 E183 LH+.125의 이미 검증된3초 raw만 비교한다. 첫0.5초와 공통 [.5,3) 창/20ms Gaussian/0.5mm/s 경계는 변경하지 않는다. E15010초는 파라미터/계측 호환성을 먼저 확인한 경우에만 별도의 장기 관측 자료로 추가하며, 서로 다른 후보의 부분 통과를 합치지 않는다. 새 신경·물리·모델 구성/최적화는0, 초기 분석 CPU1/최대60벽초를 기존 누적4233.282374799717/4994초 안에서 예약하는 안이다. 실패/준비/실제 경과를 포함하고 최종 구체적 계약은 실행 전에 확정한다.

판별할 경쟁 설명은 (a) 하중 지지가 부족한 구간, (b) 지지 발의 이동/높은 slip과 여러 다리 명령의 불리한 조합, (c) 접촉 변화에 앞선 운동 출력·활성 리듬의 변화다. 전진 임계선의 아래 방향 통과를 시간 기준으로 고정하고 각 사건 전후100ms의 실제 전진속도, 여섯 다리 native 하중/지지 수/slip, 관측된 말단 위치에서 구한 속도, MN율·근육활성·명령과 실제 관절의 차이를 같은 축에 놓는다. 원자료의 좌표·다리 순서·5ms 제어와100us contact 시간 정렬 및 이벤트 경계 처리를 먼저 확인한다. 동일한 창에 속하는 이벤트를 중복 독립 표본처럼 세지 않고 표본 수를 명시한다. 이미 같은 data로 후보를 선택했으므로 이 결과는 개발용 진단이다.

현 native-contact에는 `time_s, normal_load_bw, slip_mm_s, slip_valid, nonfoot_contact, upright`만 있고 접선 힘의 방향/다리별 추진 충격량은 없다. 접촉 속도나 slip 크기를 실제 추진력으로 바꾸어 주장하지 않는다. 몸체 segments/legs의 위치 기록도 실제 field 정의를 확인한 뒤 사용한다. 감각→MN→근육의 상관/시차만으로 원인을 확정하지 않는다. 출력이 먼저 달라지는지, 접촉/추종이 먼저 달라지는지 반복 사건에서 관찰하고, 구분이 불가능하면 정확히 어떤 힘·상태 기록이 없는지 명시한다.

다음 결정은 관측 결과에 따른다. 출력 변화가 반복적으로 선행하면 관련된 기존 신경 경로/근육 전달의 제한된 개입을 설계한다. 출력은 유지되는데 지지·발 운동이 바뀌면 원래 몸체/구동/접촉 인터페이스의 검증 또는 개입을 설계한다. 기록 부족으로 구분하지 못하면 native 접선 힘/추진 충격량을 기록하는 최소 관측을 준비하고, 계측이 기존 궤적을 바꾸지 않는 비교와 남은 자원 한도를 실행 전에 고정한다. 어느 경우에도 새 연결/외부 CPG/위상·root 강제를 최종 보행에 추가하거나 F1–F8을 낮추지 않는다.

후속 구현도 부모 설계→actual gpt-6-sol 난이도별 effort 최초 구현→부모 FIRST→같은 Sol 첫 수정→부모 SECOND/잔여 수정 순서다. 결과가 M3 보행을 실제 개선하는 다음 실험으로 이어져야 하며 분석 파일이나 테스트 수를 완료로 세지 않는다. M2/UI/F6는 그대로 보존한다.
