# E265 결과: 상수 보정 뒤 남은 여섯 감각 입력의 시간 변화

E265는 유효한 신경 재현 진단이며 H265를 지지했다. 복원한 여섯 감각 연결과 고정 drive 보정으로 이루어진 S 항이 이번 조건의 중계111970 유효 입력 잔차를 설명했다. 다른428개 입력과 적응의 합 O는 startup에서 `RMS(O)/RMS(D)=0.0033954991`이었다. **새 보행 후보를 만든 결과는 아니며 자연 보행 및 최종 F1–F8은 여전히 미완료다.**

## 고정 비교의 재현과 판정

B는 원래 W0/U0, X는 W6/U0, Z는 W6/U0와 기존 bias32=−0.19308185577392578이다. 각각100controls/.5초를 원래 전체 control0에서 재현했다. 전체 시작·끝 상태, 기존1239개 endpoint, MN391·관측82·core24, 실제 전체 drive의 원래 입력 재구성 및 bank/q19/세근육 출력이 기존 기록과 일치했다. 중계의 전체434개 입력을 관측하기 위해 이전 누락163개를 포함한 union1402를 기록했다.

각 endpoint의 실제 CUDA float32 수신 전류는 독립32lane 합산과 bit-exact였다. 설명용 float64 간선 합과의 반올림 차이를 따로 저장했으며 둘을 같은 값으로 간주하지 않았다. 모든303회 전류 관측 전후 전체 신경 snapshot이 exact였다. 부모는 작성자 판정보다 먼저 원자료에서 상태·드라이브·전류·운동 변환을 재구성했고, 전체3639개 확인을 통과했다.

고정 startup1..99에서 RMS(D)=0.2083050923, RMS(O)=0.0007072998, S의 시간 표준편차=0.2081151525였다. D=S+O를 전101개 endpoint에서 확인했다.

세 시점 모두 S와 D의 부호가 같고, 모든 비율은 사전 기준.2 이하다. 따라서 H265는 supported다. 이 비율을 분산 설명률이나 고유 인과 기여율로 해석하지 않는다. 원래 RK4 중간 stage 전류를 관측한 것도 아니다. E264의 q19 초기 오차 실패는 그대로 유지하며, 이번 지지가 E264 보정 후보를 되살리지 않는다.
