# E233 조건부/실제 신경 출력 차이 결과

첫5ms 실제 fast/slow 기억은 조건부 계산과 exact, effector 최대차5.33e−15, command6.37e−9rad였다. 기억과 effector는 control5(.025초), command는 control6(.030초)부터 사전 허용오차를 넘었다. 시작99행 command 차이 최대.0218584rad, 이후.313340rad까지 커졌다. 이는 같은 control시각의 비교이며 같은 보행 위상 또는 입력 인과 증명은 아니다.

명령 차이를 네 성분으로 나눈 합성 잔차는3.33e−15rad였다. startup의 free effector 동역학 성분 RMS .00085637/max .02185839rad, float32 readout 성분 RMS2.20e−8/max1.65e−7rad, fixed48 및 초기activation 성분은0이다. 단순 readout 정밀도 변경이 주된 차이를 해결한다는 설명은 지지되지 않는다.

부모 설계가 `recorded_command`를 원래 startup 기준으로 잘못 지정한 오류는 [별도 정정](BANC_M3_E233_STARTUP_REFERENCE_AMENDMENT_20260925.md)에 보존했다. 아래는 기존 E197 `loaded_startup_target_command`를 사용해 양쪽을 다시 계산한 값이다. 원래 결과 파일의 startup표는 이 표로 대체해 해석한다.

| 저장 명령 | 기존99행 RMS rad | 최대 rad | 원래 기준 |
|---|---:|---:|---|
| 조건부 E218 | .017999960514 | .039999959940 | 통과 |
| 실제 E224/E225 | .018052184585 | .058065758583 | 실패 |

| 실제 − readout양자화 | .018052184423 | .058065772970 | 실패 |

대수적 성분 제거는 감각 피드백을 다시 실행한 개입이 아니다. 투영6D 기억 거리의 관측 학습최대 초과는1515개 MN×control, 211/343MN,670/1664control이며 전체9D 분포 밖이거나 실패 원인임을 뜻하지 않는다.

같은 실제 Sol/high 첫수정→부모SECOND5생성검사/Ruff→원본 저장분석→독립184검산→부모 잔여 startup기준정정7검사를 거쳤다. E232의 membership검사 실패와 부모 검토 누락을 보존한다. E233 감독10.2185221초/출력79,247,057bytes/최대프로세스RSS977,915,904bytes, 소유PID모두종료. 누적6090.0136165996555/6119초·잔여28.986383400344494초. 독립저장검산1.2244341초, startup정정.1193705초는별도. 새신경/물리/CUDA/fit0, 기술시도는E232포함2다.

다음은 startup.495초의 실제 RK stage E/I/drive 및 effector/기억을 관측하는 최소 실행이다. 먼저 수집기가 계산을 바꾸지 않는지 작은 생성CUDA로 검증한다. E150최선과 기존실패/M2/UI/F6미노출 유지, 전체 F1–F8 미완료.
