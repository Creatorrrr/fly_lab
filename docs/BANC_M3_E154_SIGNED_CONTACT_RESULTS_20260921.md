# E153/E154 같은 명령 재생의 접촉력 결과

E154의 1–2초 body-only 재생은 원래 E150의 anchor+200 control qpos/qvel/ctrl와 모든10000 native time/load/slip/valid/nonfoot/upright에 정확히 일치했다. 부모는 원시 contact frame·wrench·geom 순서에서 힘을 독립 scalar 수식으로 재구성하고 집계를 검산했다. **실제 접촉력의 기술적 측정으로 수용하며, 보행 후보의 개선이나 자연 보행 통과로 수용하지 않는다.**

## 절차와 실패

고정명세의 신체 재생·수치 관측 작업이므로 실제 gpt-5.6-sol/high에 FIRST 구현을 맡겼다. 부모 FIRST review는 생성 실패 시 실행량 누락과 전체 하중의 다리당 평균 표기를 재현했다. 같은 Sol의 FIRST correction 뒤 부모 SECOND review와12 tests/독립242수식/전체 mock 재생이 통과했다. 그러나 실제 E150 trace의 null neural_request를 부모도 사전 schema 검토에서 놓쳤다.

E153 첫 실제 시도는 body1/settling2000/anchorexact 뒤 첫 command 전에 형식 검사로 종료됐다. scientific step0이며 힘 결과가 없다. 원본9파일과 실행 source SHA `71f81c0c6ace551b89051de523c4458be8fb3b8170c74fa12980185c89b7f0f3`를 보존한다. E153을 성공으로 바꾸지 않는다.

부모가 잔여 문제를 직접 수정했다.
