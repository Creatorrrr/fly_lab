# E177 이후 방향 초안: 실제 전류 출처와 운동 전환

E177의 같은 초기 상태 비교는 기술적으로 유효했고,5개 연결을 복원하면187 MN/84근육 출력과 명령이 실제 달라졌다. 그러나 연속 전진 최대.215초와 적격 주기0은 그대로이며, F4/F5와 slip 기준이 미달이다. 모델 밖 CPG/궤적 보정이나 단순 gain sweep으로 이 실패를 우회하지 않는다. F1–F8과 Goal active는 유지한다.

다음 E178의 우선 질문은 **복원된 감각 전류가 실제 MN의 전체 입력에서 어떤 비중과 역할을 갖는가**다. 특히108052/153939는 두 팔 모두 rate/drive/adaptation0, 전체 recurrent current가 항상 음수였다. 이것이 BANC 생물학의 억제 회로 특성인지, rate-model의 transmitter 부호/단위/마스킹/효능 보정 가정인지, 혹은 이미 다른 입력이 지배하는 신경 상태인지 먼저 구분한다. 평균 음수 current만으로 원인 또는 수정 위치를 확정하지 않는다.

후속 사전 계약은 기존 개발 상태의 저장 checkpoint에서 접근 가능한 정확한 시점·전체 rate/output_mask·실제 CSR·세포 및 연결 provenance를 pin한다. 신경·물리 재진행 없이 row별 `weight × masked presynaptic rate`를 재구성해 양·음 합, 주요 source, 부호/단위/보정 이력을 대조한다. 기록되지 않은 presynaptic 값을0으로 채우지 않고, 선택된446cell trace만으로 전체 합을 추정하지 않는다. GPU·CPU 합산 순서의 유한정밀도 차이를 별도 허용 규칙으로 먼저 명시한다. 같은 저장자료를 새 미사용 확인 자료로 부르지 않는다.

가능한 다음 결정도 먼저 고정한다. provenance/단위/부호 변환 오류라면 그 오류만 고치고 같은 초기 상태 비교를 한다. 구현과 모델 가정이 일치한다면 억제 입력만 임의로 지우지 않고, 실제 모집 상태 및 근육 전달에서 지지→스윙 전환이 끊기는 위치를 추가로 확인한다. 감각이 빈약한 시점만 관측됐다면 필요한 관측을 좁혀 별도 비용 계약을 작성한다. 저장 진단 성공은 gait/F6/F7 검증이 아니다.

이 문서는 다음 방향 초안이다. 아직 E178 freeze/source gate/원본 값 분석/신경·물리/fit 실행은 없다. 현재 원본 보수 누적3417.939522700035/3656초를 보존한다. 구현이 필요하면 부모 설계 → 실제gpt-6-sol(범위에 맞춘 effort) → 부모FIRST → 같은Sol첫수정 → 부모SECOND/잔여수정 절차를 유지한다.
