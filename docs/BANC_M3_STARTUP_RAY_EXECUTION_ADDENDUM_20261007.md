# 실제 startup와 단기 보행으로 이어가는 실행 보완안

현재 유한 목표는 전체 BANC 출력으로 자연스러운 보행을 구현하고 기존 F1–F8을 검증하는 것이다. 이 문서는 `BANC_M3_STARTUP_CONSTRAINED_RESEARCH_REFLECTED_20261004.md`의 방법을 유지하면서 최신 사용자의 자율 진행 지시와 실제 실행 상태를 반영한다. 기존 연구·실패·M2/UI·미사용 초기 상태 노출과 기준은 보존한다. 승인 질문이나 새로운 번호별 복구 계층을 만들지 않는다.

현재 완료된 실제 작업은 실행 Source 적용, Ruff 실패와 비용 폐쇄다. CUDA·원본 배열·신체의 이 단계 실험은 아직 실행하지 않았다. 실행 검사 통과를 보행 성공으로 판정하지 않는다. 생성 검사와 현재 실행 Source 연결을 마무리한 뒤 아래 과학 작업을 시행한다.

1. E318의 control0 상태와 control1–300 감각 drive를 현재 resolved neutral SSP와 비교한다. 원본 파일 크기·해시·배열 header·shape·dtype·finite 값, neutral utilization0/resource1 및 그래프·adapter·checkpoint 식별자를 실제 확인한다. 데이터가 대응하지 않으면 새로운 neutral capture가 필요한지 근거로 결정한다.
2. 기존 네 R 창100/164/228/292와 독립 backward16×42를 유지한다. `d=-g/max(abs(g))` 방향 하나와 사전에 봉인한 유한 양의 alpha 목록을 내림차순으로 검사한다. startup 전체99 forward를 별도로 연결하고 요청 alpha와 실제 배포 float32→float64 delta≤0.001을 모두 검사한다. 반올림 후 중복·무변화·nonfinite·부호·unselected edge·palette 위반을 제거한다. 실제 R 개선 규칙과 기존 수치 대응 허용값을 계약에 먼저 고정한다. 시험 후 목록이나 규칙을 변경하지 않는다.
3. 적격 후보 하나와 theta1 대조군을 순차 실행한다. neutral의 기존 신경/adapter 동일성 증명과 candidate의 실제 변경 식별자 증명을 각각 유지한다. 새 lifecycle 함수에서 같은 신체 인스턴스의 control0→99→300을 수행한다. 기존 `run_prefix`의 exactly99 계약은 바꾸지 않는다. 실제99 startup 네 조건을 통과하면 같은 인스턴스를300까지 이어간다.
4. 원본 명령·신경·관절·접촉·native 상태와 일관된 카운터를 저장하고 독립 평가한다. 1.5초 screen은 forward≥1.6790085779712631mm, loaded slip≤1.8026436968249955mm/s, forward bout≥0.3s, 모든 다리의 적격 주기>0, native health와 startup 네 조건이다. 적격이면 같은 후보로10초/F3–F5, 미사용 초기 상태2개/F6, 기존6목표·정지·재시작/F7, block/save와 영상·provenance/F2·F8을 이어간다.

초기 자원안은 별도 Original 추가 배정6000초다. 기존 누적10020.115960899504초, stage126.361초와 사용된 비용·권한 기록을 그대로 유지한다. 기존 global10200에6000을 더한16200초, stage300에6000을 더한6300초이며 새 과학 범위 지역 한도6000초다. 예산을 초기화하거나 기존 실패 비용을 없애지 않는다. 실제 worker는 하나씩 실행하며 자동 재시작을 사용하지 않는다. 이 문서는 아직 resource grant나 실행 manifest를 발급하지 않는다.

첫 계약의 보수적 상한안은 원본 packet 감사120초, ray 후보 계산1200초, candidate 감사120초, neutral body300초, candidate body300초, 두 raw/body 감사 각120초, close/evidence180초다. 합계2460초이며6000초 안에 들어간다는 것은 예약 산술이다. 실제 timing은 미측정이다. wall timeout에는 초기화·CUDA 동기화·저장·정리·도구 최종 반환을 포함하고 실제 full-return을 once 기록한다. 각 단계는 이전 단계가 자연 종료하고 소유권이 해제된 후 진행한다. 오류 후 동일 호출을 그대로 재실행하지 않고 실패와 비용을 남긴다.

해부학 노드·연결 provenance, 선택 edge725849/효능 그룹8547, 신체·마찰·decoder·기존 R normalization을 유지한다. 최종 controller에 외부 CPG·교사·위상·궤적·root 보정을 추가하지 않는다. 작은 손실 개선, startup 적격 또는 단기 screen만으로 F1–F8이나 생물학적 기전의 검증을 선언하지 않는다.

이 보완안은 ROOT 설계다. 실제 Astra/max 검토를 반영한 후 GPT-6.1 Sol이 과학 구현 FIRST를 수행한다. ROOT FIRST, 필요한 경우 같은 Sol의 한 번의 R1, ROOT SECOND와 잔여 수정 순서로 진행한다. 과거 실행 구조 사이클의 사용된 R1을 다시 열지 않는다. 아직 새 과학 구현·원본 실행·보행 검증 결과가 아니다.
