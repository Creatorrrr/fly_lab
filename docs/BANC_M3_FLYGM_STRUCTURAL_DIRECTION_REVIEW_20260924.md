# E199와 병행한 학습 신경 동역학 대안 검토

현재 유한 목표의 F1–F8은 미완료다. E150의 전진 성과와 F4/F5 실패를 보존한다. 이 문서는 외부 연구의 채택이나 재현 결과가 아니라 다음 방법을 고르기 위한 정적 검토다.

## 기존 접근과 달라질 수 있는 가정

E169/E170/E175/E197은 고정된 신경 출력에 대한 제한된 양수 근육 전달 가족이 목표 명령을 충분히 만들지 못함을 보였다. 이 반증은 해당 저장 입력·가족에 한정된다. E123/E128/E134의 신경 gain/시간상수 및 E176/E189의 기존 연결 조정은 같은 스칼라 rate/adaptation 반응식을 유지했다. 일부 시도는 무효 또는 불완전하므로 모두 독립적인 생리 가설 반증으로 세지 않는다.

현재 계획의 불변 조건은 BANC 노드·연결 원자료와 감각→신경→해부학적 운동 출력→물리 경로다. 미측정 세포 동역학 자체는 변경 가능한 모델 가정이다. 따라서 현재 반응식의 계수 조정과, 학습 가능한 신경 내부 상태 전이를 도입하는 대안을 구별해 비교할 수 있다. 후자는 생물학적으로 실측된 세포 모델이라는 주장을 동반하지 않는다.

## 1차 자료에서 확인한 것

[FlyGM v3 논문](https://arxiv.org/html/2602.17997v3)은 신경별 다채널 상태와 학습된 내부 특성, 커넥톰을 따른 정보 전달, 모방학습 후 PPO를 제안한다. 그러나 FlyWire 뇌 모델이며 현재의 전신 BANC가 아니다. 부록 B의 보행 입력에는 reference displacement와 root quaternion이 있고, 출력은 dense decoder를 통한59개 actuator다. 이 구성을 현재 F2의 외부 궤적 입력 금지와391 MN→96근육 소유권을 만족하는 구현으로 간주하지 않는다. 논문에서 제시한 전달물질 부호도 로컬 BANC의 기존 부호 가설과 다르므로 복사하지 않는다.

[저자 공개 저장소](https://github.com/Lunamos/flygnn/tree/79d47cb365a780d893fb4e8a23cdecc60267c7b6)는 API로 확인한2025-09-30 commit이다. v3 논문과 같은 구현임이 확인된 것은 아니다. 연구실 페이지의 Code Coming soon 표기와 달리 이전 공개 코드가 존재하므로 코드 부재라고 기록하지 않는다. pretrained checkpoint 재현은 수행하지 않았다.

공개 [flygnn.py](https://github.com/Lunamos/flygnn/blob/79d47cb365a780d893fb4e8a23cdecc60267c7b6/src/flygnn/flygnn.py#L80)는 trainable 초기 상태를 복제해 매 sequence를 시작하고 각 step의 새 상태를 detach해 저장한다. 같은 파일은 전체 afferent에 dense encoder, 전체 efferent에 dense decoder를 쓰며 edge_weight=None을 전달한다. 정적 검토에서 step이 참조하는 self.edge_attr의 초기화가 이 클래스에 보이지 않는다. 따라서 이 소스를 곧바로 실행 가능한 기준 모델이나 시간축 전체 미분 구현으로 취급하지 않는다. 이 관측은 공개 스냅샷의 코드 검토이며 실제 실행 실패를 재현한 결과는 아니다.

[utils.py](https://github.com/Lunamos/flygnn/blob/79d47cb365a780d893fb4e8a23cdecc60267c7b6/src/flygnn/utils.py#L7)는 PyG GraphSAGE 등으로 상태를 전달한다. [train_post.py](https://github.com/Lunamos/flygnn/blob/79d47cb365a780d893fb4e8a23cdecc60267c7b6/src/flygnn/train_post.py#L66)는 walk_imitation 관측 전체를 flatten한다. 논문의 동역학·부호·입출력 조건을 이 이전 코드만으로 검증할 수 없다. 외부 코드는 설치·실행·제품 통합하지 않았다.

## 다음 설계에 적용할 경계

재사용 가치가 있는 것은 해부학적 연결을 제약으로 두고 미확정 신경 상태 전이를 학습하는 발상이다. 새 후보가 되려면 실제 BANC158706 노드와 기존 CSR 소유권을 유지하고, 감각은 기존 감각 세포에만, 운동 출력은 기존391 MN과96근육에만 연결해야 한다. 외부 시간·위상·기준 궤적·전신 임의 decoder는 실행 입력이 될 수 없다. 교사 신호는 훈련 목적함수에만 둔다.

바로 전체32채널 모델을 학습하는 대신, E199에서 실제 무출력 근육을 판별한 뒤 다음 둘을 비교한다. (1) 인과적으로 필요한 근육의 입력·작동점 교정, (2) 기존 MN의 내부 상태와 반응식을 학습 가능한 국소 모델로 바꾸는 제한된 표현력 시험. 후자를 선택하면 먼저 같은 입력에서 목표 전달·시작 상태 보존·계산 비용을 확인하고, 조건부 적합이 유효할 때만 전체 BANC 및 실제 신체로 돌아간다. 다른 신경의 되먹임이 바뀌므로 저장 입력 성공은 실제 보행 성공이 아니다.

이 검토는 GPU/신경/물리/fit/F6 실행0, M2/UI 변경0이다. 준비·문헌 조사 비용은 원본 실험 비용과 구별하며 미계측을0으로 기록하지 않는다. E199는 별도 사전 설계·30초 예약 아래 진행 중이고, 이후 학습 실험의 입력·식·비교·판정·자원은 실행 전에 별도로 고정한다.
