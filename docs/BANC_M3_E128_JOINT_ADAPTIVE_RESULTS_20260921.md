# E128 공동 적합: 실행 유효, 조건 충족 후보 없음

2026-09-21 · M3/F1–F8 미완료

기존1572 edge 효능과96 근육 적응 gain을 같은 E121 calibration 기준으로 조정하는 E128을 한 번 실행했다. 네 native RK4 단계의 기록 입력에서 계산은 유효했지만, 다리별30초 안에 원래 내부 초기99 조건을 모두 만족하는 후보를 찾지 못했다. 최종 공동 후보·독립 최종 후보 참조·실제 BANC/신체 실행은 하지 않았다. 계산 구현의 통과를 보행 개선으로 취급하지 않는다.

## 구현 및 부모 검토

부모 설계 후 Sol/gpt-5.6-sol/xhigh가 첫 구현을 했다. 첫9 합성 테스트가 통과했지만, 부모의 전역 근육1/부분 근육0 사례에서 초기 q Jacobian 오류0.0132900269가 허용6.7693e-6를 초과했다. 부모는 이 매핑 오류, no-feasible 종료의 list/tuple 오류, 부분 응답·실행량·전송량 기록, 입력 소유 복사, 실제 기록을 사용한 tiny setup의 여섯 문제를 기록했다.

같은 Sol이 첫 수정을 하고21 합성 테스트를 통과했다. 부모 두 번째 리뷰 뒤, 수치 오류가 compact raw 저장 이후 발생해도 전체 부분 응답을 별도 보존하도록 수정했다. CuPy/Torch 인덱스 전송도 명시적으로 계상하고 CUDA에 캐시했다. 이 두 잔여 수정은 부모가 직접 수행했다.

최종23 테스트/Ruff 및 별도 부모 NumPy/CUDA 정류 경계 검증이 통과했다. 독립8 field 최대차2.220446049250313e-16, 연결·gain 결합 방향 미분 최대차1.5746431936136673e-10(허용3.9840798518650424e-5), 분기 bit 일치다. 원본 실행 전1504개 동결 파일 hash를 다시 확인했다. Sol 초기 합성 시도의 일부 원시 로그/총 CUDA 호출량은 보존되지 않았으므로 `synthetic-attempt-costs.json`에서 미확정으로 명시했다. 부모 최종 테스트는 원시 파일과 로그를 보존했다.
