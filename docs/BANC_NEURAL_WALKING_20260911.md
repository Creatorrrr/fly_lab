# BANC 감각 기반 신경 보행 연구 구현

2026-09-11. 기존 `C_STRICT` LIF와 `FLYGYM_AUTONOMOUS`는 보존하고,
별도 `BancWalkingSession`을 추가했다. 이 경로는 준비된 BANC 등록 뉴런 전체의 활동으로
다리 관절 목표를 계산한다. 활동의 변화, 물리적 이동, 보행 과제 통과,
생물학적 타당성을 구분한다.

## 구동 경로

```mermaid
flowchart LR
    A[MuJoCo 실제 다리 각도·속도·하중·접촉] --> B[주석된 감각뉴런 3,604개]
    B --> C[BANC 158,706개 뉴런의 적응 발화율 계산]
    C --> D[다리 운동뉴런 391개의 근육별 출력]
    D --> E[해부학적 근육 표적을 관절 목표로 변환]
    E --> F[FlyBody 위치 서보·접촉 물리]
    F --> A
```

- 원본: BANC v888, 158,706개 뉴런, 11,584,852개 뉴런 쌍 연결.
  그래프 SHA-256은 `9bd8468f5e5e40c3e6daaffde9f444466825ba8e69189f1e347568bff85920ff`.
- 이 bundle의 범위는 `declared_neuronal_roster`이다. 비신경·미분류 객체
  제외 규칙을 가진 준비된 뉴런 명부이며 `graph.full_brain`은 false이다.
  이 구현은 위 콘텐츠 해시로 고정된 명부 전체를 계산하는 연구 경로를
  허용한다. 기존 원본 전체 스냅샷 검증을 통과한 것으로 바꾸지 않는다.
  원본 획득 범위와 제외 규칙은 manifest에 유지하고 관측에도 반환한다.
- 모든 원본 뉴런과 연결을 유지한다. 연구 행렬은 시냅스 수 × 0.03 × 기존
  전달물질 부호이다. ACh는 양수, GABA·glutamate는 음수, 미확정·조절성
  출력은 기존 해석대로 0이다. 원본 카운트·주석·파일을 변경하지 않는다.
- 기본 외부 입력은 실제 다리 감각뿐이다. 선택적 일정 DNg100 입력은
  별도 실험 파라미터이며 기본값은 0이다.
- 42개 다리 자유도 중 41개에 근육 주석 기반 출력이 있다. 오른쪽 중간
  다리 coxa pitch의 누락을 가상의 연결로 채우지 않는다.
- 기존 FlyGym 보행 CPG, 사전 보행 궤적의 시간 진행, 정현파 자극,
  주기적 신경 상태 초기화, 몸통 위치 보정을 사용하지 않는다.
  매 제어 구간에서 CPG 상태 해시가 유지되는지 검사한다.
- 중립 자세는 고정 기준이다. 관절 구동은 공학적 위치 서보이고 힘줄
  입력은 일정한 0.2이다. 이 구현은 측정된 근육 힘 모델이나 전신 운동
  회로를 완성한 것이 아니다.

## 세포 활동과 실제 무릎 방향

`AdaptiveRateNetwork`는 기존 연구용 rate 모델에 연속 활동 적응 상태 `z`를
추가한다. 시간에 따른 보행 위상을 따로 넣지 않는다.

```text
dr/dt = (max(cap * tanh((a/cap)*(input + W*r - threshold - z)), 0) - r) / tau
dz/dt = (adaptation_gain * r - z) / adaptation_tau
```

두 상태를 함께 RK4로 적분한다. 막 시간상수 20ms, 적분 간격 0.1ms,
적응 시간상수 150ms를 사용한다. 적응 크기 0의 CPU 계산은 기존 rate
모델과 일치한다. 입력·출력은 모델 단위이며 LIF의 mV나 실측 Hz와 같지
않다. 개별 BANC 세포의 적응 파라미터를 생리 측정으로 얻은 것은 아니다.

FlyBody의 raw tibia 관절각 증가를 굽힘 증가로 해석하던 방향 문제가
있었다. 새 어댑터는 femur·tibia·tarsus의 실제 위치에서 무릎 굽힘각을
측정하고, MuJoCo Jacobian으로 속도와 관절 방향을 계산한다. 여섯 무릎
모두 `d(flexion)/d(q)`가 약 -1이다. 실제 모델의 ±1e-6rad 유한차분과
해석적 미분을 대조하는 검사를 추가했다. 감각 입력과 flexor 출력에
같은 물리적 방향을 적용했다. FeCO 세부 수용체 조율과 다른 근육의
상대 모멘트 계수는 여전히 명시적인 모델 가설이다.

감각 입력에는 20ms 저역 필터와 한 제어 구간의 지연이 있고, 운동 출력은
30ms 활성화 필터와 ±0.5rad 제한을 거친다. 발 부착은 신경의 발마디 근육
출력과 현재 국소 발 들림으로 결정한다.

## 참고 구현의 경계

[Fly-Brain-AI](https://github.com/neilt93/Fly-Brain-AI)의 커밋
`64bdbaf7bcf6b663d0fbf21d886517ec5c06fafb`를 읽고 비교했다. 해당 공개 데모는
10Hz tripod 정현파를 운동 출력에 섞고, 150ms마다 rate를 축소하며,
공개 실행 경로에서 proprioception 입력을 넘기지 않았다. 따라서 그 데모의
영상이나 ablation 결과를 BANC 회로 자체 보행의 검증 근거로 채택하지 않았다.
코드를 실행하거나 기존 회로 대신 이식하지 않았다.

전체 원자료와 비교 기록은
`verification/banc-neural-walking-20260911/reference-audit.md`에 보존한다.

## 수치·상태·인과 검증

Torch CUDA CSR 연산은 이 환경에서 같은 저장 상태의 미래가 미세하게
달라졌다. 결정성 옵션만으로 없어지지 않았다. 새 경로는 하나의 warp가
하나의 postsynaptic 행을 맡고 고정 순서로 합산하는 CUDA 커널을 사용한다.
부동소수점 atomic 합산을 사용하지 않으며, CPU 독립 행렬곱 및 CUDA 반복
검사로 방향·빈 행·긴 행·출력 마스크를 검증한다.

체크포인트는 rate뿐 아니라 적응 상태, 감각 필터, 운동 필터, 출력 차단,
물리 상태와 두 시계를 함께 저장한다. 복원은 새 세션에서 전체 상태를
검증한 뒤 교체한다. 잘못된 복원은 기존 실험을 덮어쓰지 않는다.

차단 실험은 같은 저장 상태에서 비교한다.

| 차단 | 의미 |
|---|---|
| 감각 | 다리 감각의 외부 입력을 제거 |
| DNg100 | 해당 두 뉴런의 신경망 내부 출력을 제거 |
| 전체 연결 전달 | 모든 presynaptic 출력을 제거 |
| 신경 운동 출력 | 최종 관절 목표의 신경 변화분과 발 부착을 제거 |

마지막 차단에도 중립 자세 서보와 고정 힘줄 긴장도는 남는다. 따라서
이를 모든 물리적 힘의 제거로 해석하지 않는다. 감각 차단 후에도 이미
활성화된 재귀 회로가 잠시 활동할 수 있으므로 즉시 멈춤을 전제하지 않는다.

## 실제 실행 기록

보행 판정은 기존 기준인 10모델초 동안 수평 순이동 ≥5mm 및 몸 방향
누적 전진 ≥5mm를 사용한다. 넘어짐·수치 오류·정지 검사를 함께 보고한다.
기준을 낮추거나 짧은 시험의 이동을 보행 성공으로 바꾸지 않는다.

현재 모든 기록은 `verification/banc-neural-walking-20260911/` 아래에
조건, 소스 해시, 5ms 원자료, 관절·운동뉴런·접촉 배열과 함께 저장된다.
같은 초기 조건에서 출력 세기를 고르는 개발 실험이며 독립 조건의
성공률 추정이 아니다.

| 실제 무릎 방향 교정 후 조건 | 기간 | 수평 순이동 | 판정 |
|---|---:|---:|---|
| 적응 4, 감각 18, 운동 gain 0.003 | 0.4s | 2.175mm | 넘어짐 |
| 적응 4, 감각 18, 운동 gain 0.001 | 10s | 3.558mm | 기준 미달 |
| 적응 4, 감각 18, 운동 gain 0.0015 | 10s | 4.350mm | 기준 미달 |
| 적응 4, 감각 18, 운동 gain 0.002 | 10s | 6.639mm | 보행 기준 통과 |
| 적응 0, 감각 18, 운동 gain 0.002 | 10s | 0.308mm | 정지 검출, 기준 미달 |

최종 기본 후보는 적응 4, 감각 gain 18, 운동 gain 0.002이다.
`physical-geometry-midgain-02`에서 몸 방향 누적 전진은 5.967mm였고
넘어짐·정지·수치 오류가 검출되지 않았다. 10모델초 계산에는 RTX 4080에서
약 204실제초가 걸렸다. 여섯 다리의 마지막 1초 최대 관절 표준편차는
각각 0.186, 0.178, 0.183, 0.192, 0.182, 0.221rad였다. 접촉은 불규칙하며
이동 거리 기준 통과가 실측 tripod 협응을 재현했다는 뜻은 아니다.

외부 하행 입력은 위 조건에서 모두 0이다. 교정 전의 시험과 채택하지 않은
pooling·시간상수 후보도 삭제하지 않았다. 적응이 없는 대조는
`physical-geometry-noadapt-01`이며 몸 방향 누적 전진도 0.250mm에 그쳤다.

`session-final-03`에서는 1.0초의 같은 체크포인트에서 0.3초를 더 계산했다.
그대로 복원한 미래는 rate·적응·입력·출력 마스크, 감각·운동 필터,
MuJoCo 전체 적분 상태에서 최대 차이 **0**이었다. 같은 시작점의 차단 대조는
다음과 같다. 수치는 해당 0.3초 구간의 인과적 영향이며 장시간 행동 성공률이 아니다.

| 대조 | 운동뉴런 최대 차이 (모델 단위) | 다리 관절 최대 차이 (rad) | 차단 확인 |
|---|---:|---:|---|
| 감각 차단 | 45.950 | 0.01616 | 감각이 운동 상태에 영향을 줌 |
| DNg100 출력 차단 | 8.158 | 0.00346 | 하행 직접 자극 0에서도 회로 내 영향 존재 |
| 전체 연결 전달 차단 | 199.907 | 0.44465 | 운동뉴런 최대 활동이 0.0000612로 감소 |
| 최종 신경 운동 출력 차단 | 68.827 | 0.44472 | 신경 관절 목표 변화분 정확히 0 |

최종 신경 운동 출력 차단에서 신경 상태도 달라지는 것은 몸이 바뀌어
다시 들어오는 감각이 바뀌기 때문이다. 차단이 전체 신경 계산을 끈 것은 아니다.
`session-final-02` 이전 결과의 `joint_difference_rad`에는 root 좌표도
포함되는 보고 오류가 있었고, 최종 실행에서는 다리 관절만 비교하도록
수정했다. 원자료와 이전 파일은 보존했다.

수치·감각·서버·기존 자율 보행 관련 unittest **48개 중 47개 통과,
선택 검사 1개 건너뜀**, 새 Python 모듈 Ruff, JavaScript 문법 검사와
C 화면 빌드를 통과했다. CPU 독립 적분 비교와
실제 CUDA 결정성 검사는 보행 실험과 별도로 통과했다.

실제 8770 페이지에서 BANC 생성·재생·일시정지·저장·서버 재시작 후 목록
선택 복원·50ms 진행·전체 연결 전달 차단을 확인했다. BANC 재생 3.5모델초에
순이동 2.016mm였으며, `banc-757d5d9fe381`로 저장했다. 같은 저장 상태에서
50ms 동안 전체 전달을 끊으면 운동신경 평균이 17.36에서 1.42 모델 단위로
줄었다. 검사 후 저장 상태로 복원했다. 기존 기본 실험은
`checkpoint-fc3679888278`의 486.730초 상태로 보존했다.

## 사용 및 재현

기존 C 화면의 **BANC 신경망 보행 연구 · 실험 기능**을 열어
**BANC 보행 실험 만들기 → BANC 재생**을 누른다. 전뇌 계산 때문에
모델 시간은 실제 시간보다 느리게 진행된다. 현재 패널의 몸은 MuJoCo
실제 렌더이며 기존 주요 실험의 몸·시계와 별도로 저장된다.

```powershell
.venv\Scripts\python.exe tools/verify_c_banc_rate_walking.py --out verification/banc-new-walking-run --seconds 10 --case 4:18 --descending-drive 0 --motor-gain 0.002
.venv\Scripts\python.exe tools/verify_c_banc_walking_session.py --out verification/banc-new-session-check
.venv\Scripts\python.exe -m unittest tests.test_c_adaptive_rate tests.test_c_rate_body tests.test_c_banc_walking -q
```

실제 실행은 CUDA Torch·CuPy가 설치된 `requirements-cuda.txt` 환경에서
검증한다. CPU는 수치 검증 경로이며 전체 BANC의 실시간 실행을 보장하지 않는다.
외부 시각·후각에 따른 탐색, 장애물 적응, 실측 여섯 다리 협응의 재현,
회로별 생리학적 타당성은 이 경로에서 검증하지 않았다.
