# E175 이후: 같은 저장 전달 가족의 재적합 중단

전체 목표는 같은 최종 BANC 후보의 실제 F1–F8 통과다. E175는 양수 이력 전달 범위를 증가·감소 양쪽으로 넓혔지만 기존 command 목표와 전체 보호를 함께 만족하지 못했다. 기존 static startup 배제(E174), 증가만 허용한 history 배제(E170), E175의 전체 endpoint 배제는 범위가 다르다. E173 history의 수치 실패와 E174 muscle-only의 미결도 그대로 유지한다. 이 결과를 BANC 자체의 보행 불가능성이나 특정 개별 제약의 인과 효과로 합치지 않는다.

같은 70ms R/F·3개 rate filter·양수 endpoint 범위에서 계수만 다시 찾는 방법은 이번 결과로 정당화되지 않는다. startup 기준을 낮추거나 첫0.5초를 평가에서 빼거나 signed 근육 출력을 넣어 통과시키지 않는다. 저장 신호 적합이 실제 보행 목표가 되어서도 안 된다.

다음 부모 설계에서는 변경할 위치를 **신경 모집 또는 활동 의존 활성 동역학**으로 옮긴다. 두 방향을 구분할 질문은 시작 응답을 보존하면서 지속 운동에 필요한 출력을 현재 운동신경 신호에서 만들 수 있는지, 아니면 BANC 내부 신호의 상태 구별 자체를 바꿔야 하는지다. 전달 계수의 동일 가족을 반복하는 대신, 기존 상태 생성·초기화·감각 입력·운동신경 출력 경로를 코드와 이미 허용된 증거에서 먼저 대조한다. 이력 상태를 더 추가하는 경우에도 특정 시간 이후에 켜지는 외부 gate가 아니라 현재와 과거 신경 활동에 의존해야 한다. 해부학적 provenance를 유지한 신경 동역학 변경은 다른 후보이며 별도 비교가 필요하다.

후속 실험은 정확한 변경 기전 하나 또는 명시한 결합 변경, 같은 baseline·startup·성능 기준, 조건부 성공 뒤 native 일치 및 전체 신경·신체 검증으로 이어지는 결정을 먼저 고정한다. 단순한 tau/gain 탐색을 새 구조로 이름만 바꾸지 않는다. 아직 다음 후보의 식·원본 입력 범위·fit/실행 허용량·source gate는 동결하지 않았고 새 원본 노출/fit은0이다. 이 문서는 다음 설계 질문을 정하며 효과를 주장하지 않는다.

원본 누적3085.011408499908/기존3202초와 과거 실패를 유지한다. 생성/저장 검산 및 별도 작업의 알려지지 않은 비용을0으로 간주하지 않는다. M2, E150 부분 결과, 활성 UI, 미사용 F6와 전체 F1–F8을 보존한다. 개발은 사용자 요청대로 부모 설계→실제 gpt-6-sol 구현→부모 FIRST 리뷰→같은 Sol 첫 수정→부모 SECOND 리뷰 및 잔여 수정 순서로 이어간다. 상태 동역학/수치 적합 구현은 high, 범위가 작은 소스 조사와 연결 작업은 난이도에 따라 effort를 정한다.
