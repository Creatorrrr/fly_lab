# E225: 전진 지속성의 부분 개선, 10초 시험은 시간 제한으로 미완료

E224의 고정 effector 후보를 전체 158,706개 BANC 신경망과 실제 신체에서 3초부터 연장했다. 저장 상태와 연결 지점은 정확히 복원됐고, 시뮬레이션 **8.315초까지 건강 기준을 유지**했다. 다만 내부 실행 75초에 최종 저장용 시간을 남기는 제한에 도달하여 종료됐다. `resource_limited`이며, 전도·수치 오류에 의한 기각이나 10초 완료로 해석하지 않는다.

## 관측 결과와 판정

저장 원자료를 별도로 결합해 같은 0.5–8.315초 구간의 E150과 비교했다. 이는 개발 중간 구간의 기술 통계다. 원래 10초 F3–F5 최종 평가를 대체하지 않는다.

원래 신경 발화와 별도 전류 기반 effector는 계속 따로 기록한다. 이 후보는 원래 MN 발화와 다른 병렬 근육 전달 가설이다. 전진 개선만으로 F2의 신경 구동 계약이나 생물학적 운동 기전 복원에 통과한 것으로 승격하지 않는다. whole disk future / motor cut / F6 / F7 / 제품 채택은 수행하지 않았다.

## 구현과 독립 확인

- 실제 `gpt-6-sol/high`가 두 파일을 구현했다. 부모 FIRST에서 차단 결함을 발견하지 않아 수정 라운드는 불필요했다. 관련 테스트 15개(5.75초)와 Ruff가 통과했다.
- 전체 저장 snapshot과 복원 snapshot을 `wall_s`만 제외해 정확히 비교했다. control600의 원래 neuronal rate, effector와 기억, activation, 관절·tendon 및 trace가 저장 prefix와 byte-exact였다.
- 원본 실행 후 부모의 저장 자료 전용 감사 38개가 통과했다. 원자료 해시·시간축·전달식을 독립 검산했으며 control1664행 / native83150표본을 보존했다. 새 자료는 control1064행(중복 연결 행 포함) / native53150표본이다.
- canonical 전달 독립 최대 오차: activation 8.53e-14, 관절 4.66e-15 rad, tendon 5.55e-17. 원래 neuronal rate와 effector readout의 분리는 일치한다.
- 10초 완료 자료나 최종 checkpoint는 생성되지 않았다. 건강한 자원 중단 시점의 재개 checkpoint를 저장하지 않은 현재 runner의 한계도 남긴다. 8.315초부터 곧바로 재개할 수 있다고 주장하지 않는다.
