# E328: 자연 보행의 다음 수정 대상은 시간 협응과 접촉

E327 실제 신체 후보는 기각 상태를 유지한다. 저장 자료를 분석한 결과 관절은 명령을 작은 오차로 따라가지만 전진이 짧은 구간으로 끊기고, 오른쪽 뒷다리 등의 미끄러짐이 증가했다. 따라서 다음 수정은 명령 형태 손실만 줄이는 방법에서 **운동의 시간 관계와 하중을 받는 발의 접촉을 함께 다루는 학습·검증**으로 옮기는 것이 타당하다. 이것은 다음 방법의 우선순위이며 특정 연결의 인과 효과 또는 보행 개선의 입증은 아니다.

E328은 결과를 이미 본 뒤 수행한 탐색적 저장 자료 진단이다. 새 원본 모델·CUDA·신체·학습 실행은 0이며, F1–F8이나 기존 보행 평가기를 바꾸지 않았다.

후보의 전진 구간은 0.500–0.645, 0.690–0.740, 0.880–1.090, 1.145–1.280, 1.355–1.495초다. 어느 구간도 0.3초에 도달하지 않는다. 따라서 주기 0을 다리가 정지했거나 신경 활동이 없다는 뜻으로 해석하면 안 된다. 기존 평가기가 지속 전진을 먼저 요구한 결과다.

후보의 실제 기하학적 무릎 운동폭(p95–p05)은 LF 62.636°, LM 18.221°, LH 40.699°, RF 56.489°, RM 18.294°, RH 49.783°였다. 이는 짧은 구간의 실제 움직임을 확인하는 값이다. 10초 전체 검증과 적격 구간의 주기·위상·CV가 없으므로 F4/F5 통과로 사용하지 않는다. 이 증거는 관절을 무조건 더 크게 움직이는 교정보다 협응과 접촉을 우선할 이유를 제공한다.

전체 slip 증가는 0.061709972 mm/s다. 오른쪽 뒷다리의 정규화 기여 변화는 +0.053628166, 왼쪽 가운데 다리는 +0.030701434였고 다른 다리의 감소가 일부를 상쇄했다. 시간별로는 마지막 [1.25,1.5)초의 기여 변화 +0.047264811이 가장 컸다. 각 조건의 전체 하중 분모도 달라질 수 있으므로 이 분해는 특정 다리나 뉴런의 인과 책임 비율이 아니다.

독립적인 생성 계산에서는 정지한 명령을 기준 곡선 위의 한 점에 두면 기존 형태 손실이 정확히 0이었다. 명령 표본의 시간 순서를 무작위로 섞어도 손실이 동일했다. 이는 현재 손실의 정의가 시간적 순서나 반복 운동을 측정하지 않는다는 반례다. 정지 명령이 실제 신체 또는 전체 보행 기준을 통과한다는 주장은 아니다.

다음 개발은 다음 순서로 구체화한다.

1. **시간을 구분하는 학습 신호를 먼저 설계한다.** 같은 자세를 반복하거나 시간 순서를 섞은 생성 명령이 올바른 순환 운동과 같은 점수를 받지 않아야 한다. 외부 위상이나 궤적 재생은 최종 BANC 제어 입력에 넣지 않는다. 기존 형태 손실은 보조 진단으로 유지한다.
2. **학습 후보의 선택에 실제 신체를 포함한다.** 시작 네 제약, 지속 전진, 하중 가중 slip, 실제 관절 운동을 동일 후보의 폐루프에서 함께 확인한다. 고정 감각 입력의 신경 손실 개선으로 실제 신체 성과를 대체하지 않는다. 오른쪽 뒷다리와 마지막 구간은 우선 관측 대상이며 별도 개입 검증 전 특정 연결을 임의 보상하지 않는다.
3. **같은 후보의 전체 기준을 확인한 뒤 통합한다.** 10초 F3–F5, 원본 whole 복원과 운동 차단, 미사용 F6 자세, 목표 이동 회귀, 영상 검증을 기존 기준대로 수행한다. 짧은 후보들 사이의 부분 통과를 합치지 않는다.

이번 단계 원본 배정은 누적 9034.148870999521/9060초, 잔여 25.851129000478977초다. 앞선 신체 실행에 필요했던 단회 80초 감독 예약을 새로 확보할 수 없으므로 이 단계에서 추가 원본 실행은 시작하지 않았다. 위 세 항목은 후속 개발 방향이며 새 원본 실행 계약·배정을 완료한 것과 구분한다. 사용자 지정 전체 토큰·시간 예산이 있었다고 해석하지 않으며 과거 실패와 비용은 계속 누적한다. 현재 M3와 자연스러운 보행 목표는 미완료다.
