# E192 이후 방향 검토

E192의90근육 양수 전달 적합은 원래20% 및 startup 보호 기준에 미달했다. 유효한 부정 결과이며 보행 개선이나 해당 가족 전체의 불가능성 증명은 아니다. E191의 기술 실패와 복구 비용을 보존한다. F1–F8, M2/UI, 미사용 F6와 현재4670.873046799719/4994초 누적(잔여323.126953200281초)을 유지한다.

## 즉시 다음 적합으로 선택하지 않는 변경

actual gpt-6-sol/high 읽기 감사와 부모 소스 확인에서, `flylab/c/neuromuscular.py:18–37`의 muscle vector는 측정된 moment arm이 아니라 signed relative position target이다. 선언된17종 중16종은 한 축뿐이며 pleural remotor/abductor만 pitch와 roll 두 축에 걸친다. 단일 축 entry 크기 변경은 근육별 scalar gain과 같다. 실제 동결 matrix의 추가 지원 범위를 숫자로 조사하지 않았으므로17종 선언을 실제96열의 정확한 다축 열 개수로 확대하지 않는다.

E72/E73은 앞 무릎 row gain을, M2-E76은 공통7축 gain을, E78/E80은 RH coxa row gain과 신경 효능을 함께 시험했다. E2/E5는 attachment/adhesion 변경이며 동일 실험으로 뭉치지 않는다. 다축 근육의 축 비율에는 구별되는 자유도가 있지만 현재 코드에는 그 비율을 정할 실측6다리 기하·힘 자료가 없다. 넓은 entrywise 적합을 곧바로 해부학적 교정으로 부르거나 작은 이득 순회를 재시작할 근거는 약하다.

기존 힘 전달 초안(E179 이후/E180 감사)도6다리 Hill 경로·단위 교정 부재로 보류됐고, 활성 강성·감쇠는 이미 실패한 대조가 있다. E177의 RM 감각5연결 복원은 실제 전달 변화에도 최장 전진.215초/적격주기0을 바꾸지 못했다. 그 같은 증폭이나 무발화 세포 제거를 새 해결책으로 반복하지 않는다.

## 다음 설계의 입구

다음은 새로운 계수를 정하기 전에 **현재 실제 감각 인코더의 신호가 어떤 동적 정보를 공급하는지**를 확인하는 제한된 계약 검토다. 활성 경로는 일반 `NeuromuscularAdapter.decode`로 추정하지 않고 `RateBodyAdapter.encode`와 M3 wrapper의 실제 위임·상태를 추적한다. 현재 encode는 물리적 무릎 기하, typed receptor 가설,20ms 수용기 필터와 한 control 지연을 사용한다(`flylab/c/rate_body.py:489` 이후). 타입별 polarity/tuning은 실측 BANC 값으로 확정된 것이 아니다.

검토할 질문은 보행 시작과 이후 구간에서 각 다리의 실제 관절/접촉 변화가 (1) receptor feature, (2) 필터·지연된 세포별 drive, (3) 실제 발화/기존 시냅스 전류, (4) 길항근 출력으로 구분 가능한 형태로 전달되는가다. 기존 E177/E179의 RM 국소 결과와6다리 전체 인코더를 구분한다. 먼저 기존 기록과 source/snapshot으로 어디까지 정확히 재구성 가능한지 확인하고, 필요한 관측이 없으면 그 누락만 명시한 최소 관측 설계를 만든다. 원형과 exact 대응을 확보하기 전에는 clipping 문턱·gain·delay·time constant를 선택하지 않는다.

이 문서는 후속 실행 승인이 되는 freeze가 아니다. 새 후속 원본·fit·신경·신체·F6 실행은0이며 새 예산을 만들지 않는다. 필요한 최소 식·입력·대조·판정·동일 잔여 자원을 구체화한 뒤 기존 부모 설계 → actual gpt-6-sol(난이도별 effort) 구현 → 부모FIRST → 같은Sol첫수정 → 부모SECOND/잔여수정 순서로 진행한다. 전체 자연 보행 목표는 active·미완료다.
