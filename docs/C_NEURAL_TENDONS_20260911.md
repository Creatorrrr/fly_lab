# BANC 신경 출력 → FlyBody 힘줄 — 2026-09-11

힘줄을 선택한 BANC neuromuscular v1/v2/v3 실험에서 신경 발화율이 실제 힘줄 모터 입력을 만든다. 이전 구현의 수동 구동 경로에 신경 해석기를 추가했다. 몸통 고정은 진단에 유용하지만 연결의 필수 조건은 아니다. GPU 신경 계산과 CPU 물리 조합을 검증했다.

## 연결 범위와 근거

| 입력 | 실제 BANC 소스 | 변환과 한계 |
| --- | --- | --- |
| `lf/lm/lh/rf/rm/rh_tarsus` | 같은 다리·좌우의 `long_tendon_muscle` 운동뉴런, 각각 8/9/7/8/8/8개 | 선택된 v1/v2/v3의 근육 집계 출력을 해당 발의 말단 4관절 힘줄로 전달한다. 양의 모터 입력과 네 관절의 동일 토크는 공학적 근사다. |
| `abdomen_pitch` | 좌우 `MNad26` 각 1개 | 좌우 평균 → 양의 pitch 입력. 상하 길항근의 해부학적 대응이 없는 **집단 출력 가설**이다. 음의 pitch를 만드는 가상 운동뉴런을 추가하지 않았다. |
| `abdomen_yaw` | 같은 좌우 `MNad26` | `(오른쪽 − 왼쪽)/2` → yaw 입력. 신경 입력을 두 제어축으로 투영하는 **집단 출력 가설**이며 실제 좌우 근육·모멘트암을 재구성하지 않았다. |

장힘줄 근육의 말단 발톱 구동은 [FANC 원 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC11348827/)을 참고했다. 이를 FlyBody의 네 발마디 회전 모터로 바꾸는 부분은 모델 선택이다. 근육 조직이나 Hill 힘–길이 모델을 구현한 것이 아니다.

현재 BANC v888의 복부 운동뉴런 168개는 모두 `peripheral_target_type`이 비어 있다. 좌우 `MNad26`와 각각의 `left/right_first_abdominal_nerve` 주석을 확인한 두 ID만 집단 실험에 사용한다.

- 왼쪽: `flywire:banc:888:720575941453512499`
- 오른쪽: `flywire:banc:888:720575941436955103`

[MNad26의 VFB 분류](https://www.virtualflybrain.org/term/mnad26-fbbt_20011146/)도 첫 복부 신경 및 복부 1절로의 출력을 기술한다. 이 정보는 FlyBody 복부 2–7절의 pitch/yaw를 구동한다는 근거가 되지 않는다. 현재 변환은 이 차이를 명시한 거친 실험용 투영이다. 다른 복부 운동뉴런 166개와 신경분비 세포를 임의로 길항근에 배정하지 않는다. 같은 표본의 필요한 좌우 주석이 빠지거나 모순되면 해당 연결은 `unmapped`로 남는다.

발마디 힘줄이 있으면 장힘줄 근육의 기존 첫 발마디 위치 목표 기여를 제거한다. 첫 발마디는 `tarsus_depressor_muscle`/`tarsus_levator_muscle`의 위치 서보를 계속 사용한다. 장힘줄 출력의 기존 접착 요청은 명시적인 말초 제어 규칙으로 유지한다. 복부 힘줄의 12개 관절에는 중복 위치 서보가 없다.

전체 힘줄 모델의 표시값은 **위치 66축 중 신경 연결 41축, 힘줄 8입력 연결, 총 운동뉴런 393개 사용**이다. 위치 서보의 나머지 25축과 전체 운동뉴런 중 412개는 별도 매핑 대상이다. 이 작업은 전신의 모든 운동뉴런 연결을 완료한 것이 아니다.

## 실행과 제어권

1. BANC 다리 neuromuscular 프로파일과 `C_STRICT`를 선택한다.
2. 신체는 **FlyBody · 전신**, 힘줄은 **발마디와 복부 · 8입력**을 선택하고 새 실험을 만든다. 기존 프로파일 JSON을 수정할 필요가 없다.
3. 힘줄 패널에서 각 입력의 연결 종류, 현재 신경/수동 제어, 실제 입력·힘·관절각을 확인한다.
4. 신경 집단 프리셋의 `Tendon lf_tarsus long_tendon_muscle` 등을 **개입으로 지정**하고 자극한다. 수동 입력값을 신경 반응으로 오인하지 않도록 현재 제어 모드가 표시된다.

새 실험의 매핑된 힘줄은 신경 모드다. **수동 명령 적용**은 지정한 힘줄만 수동 모드로 바꾸며, **신경 구동으로 복귀**로 되돌릴 수 있다. 복귀 시 이전 수동 입력과 신경 필터를 0으로 정리하고 다음 제어 시각부터 신경 출력이 적용된다.

### 재생했는데 움직이지 않을 때

재생은 현재 신경·물리 계산을 계속한다. 자극을 자동 생성하거나 보행을 시작하는 버튼은 아니다. 몸통이 **고정**이면 공간 이동도 불가능하다. 몸통 선택은 **새 실험**을 만들 때 적용되므로 선택값만 바꿔서는 현재 고정이 풀리지 않는다. 자유 이동으로 바꾸어도 운동 출력이 없는 상태에서 자율 보행이 생기지는 않는다.

화면 위의 운동 활성 표시는 실제 사용 중인 근육 집단 발화율, 중립 자세에 더하는 신경 관절 목표 변화, 신경 모드 힘줄 입력을 보여 준다. 전체 뇌 평균 발화나 위치 서보의 지지 힘만으로 운동 활성이라고 표시하지 않는다. 수동 힘줄 입력은 별도로 안내한다. 하행뉴런의 전진·회전 출력은 BANC 관절 제어에서는 참고값이다.

국소 연결을 확인하려면 `Tendon lf_tarsus long_tendon_muscle` 프리셋을 **개입으로 지정**하고 **30mV / 0.1초** 자극을 적용한 뒤 **한 단계 · 50ms**를 두 번 누른다. `lf_tarsus`의 입력·실측 관절각과 **실제 메시**를 확인한다. 이후 재생하면 자극이 만료되고 잔여 활성도 감쇠한다. 이것은 운동뉴런 직접 자극에 대한 발마디 반응이며, 감각에서 시작되는 자율 보행의 검증은 아니다.

```python
engine.command("body_actuation", {"tendon_inputs": {"lf_tarsus": 0.04}})
engine.step(10)
engine.command("body_actuation", {"tendon_modes": {"lf_tarsus": "neural"}})
engine.step(10)
```

명령 자체는 물리 시계를 진행하지 않는다. 힘·각도는 다음 물리 계산까지 직전 측정값이다. 수동 입력과 같은 힘줄의 신경 모드를 한 명령에서 동시에 요구하거나 이름·범위가 잘못되면 전체 명령을 적용하지 않는다.

`motor_disconnect`, `motorCoupled=False`, 정지 상태는 신경 모드의 입력과 필터를 즉시 0으로 만든다. 명시적인 수동 입력은 신경 연결과 독립적으로 유지된다. 감각 차단은 감각 입력만 제거하므로 직접 운동뉴런 자극은 여전히 힘줄로 전달된다.

200Hz 제어 경계에서 현재 발화율을 읽고 다음 5ms 물리에 입력을 유지한다. 신경 적분에서 새로 생긴 발화는 다음 제어 경계부터 적용한다. 필터 시상수는 30ms이며, 요청값은 `maximum_input * tanh(signed_output_Hz / 100)`이다. 신경 입력 한도는 발마디 `0..0.1`, 복부 pitch `0..0.05`, yaw `-0.05..0.05`다. 이 값은 라디안이나 실측 근육 활성도가 아니다.

매핑·소스 ID·변환 계수·필터 파라미터는 해석기 해시에 포함된다. 체크포인트는 제어 모드와 필터를 보존하며, 복원 시 물리 모터 입력과 필터가 일치하는지도 확인한다. 힘줄을 사용하지 않는 기존 모델의 해시는 유지한다. 신경 연결 전의 수동 전용 힘줄 체크포인트는 새 해석기와 동일 모델이 아니므로 자동 변환하지 않는다.

## 실제 검증

`verification/neural-tendons-20260911/run-02/report.json`과 같은 폴더의 `mapping.json`, 조건별 시계열에 결과를 저장했다. 실제 BANC 158,706개 뉴런, CUDA LIF, CPU MuJoCo, 고정된 FlyBody에서 각 조건을 100ms 실행했다.

- 13조건: 기준선, 여섯 발마디 개별 자극, 복부 좌/우/양측 자극, 운동 연결 차단, 소스 발화 억제, 감각 차단과 직접 운동 자극.
- 11개 방향 응답 검사에서 입력과 실제 관절 반응을 확인했다. 발마디별 말단 평균 각도 변화는 약 `0.230..0.239rad`였다.
- 복부 좌측 자극의 평균 yaw 변화 `-0.00914rad`, 우측 `+0.00842rad`, 양측 자극의 평균 pitch 변화 `+0.01150rad`였다. 모두 같은 시간의 무자극 조건과 비교한 값이다.
- 운동 연결 차단 상태에서는 자극된 뉴런이 발화해도 힘줄 입력이 0이었다. 소스 뉴런의 발화를 억제해도 입력이 0이었다. 감각을 차단한 직접 운동 자극은 전달됐다.
- 몸통 이동 0, 물리 수치 경고와 실험 오류 없음. 활성 신경 필터를 포함한 체크포인트 이후 전개와 수동→신경 전환의 기록 재생이 정확히 일치했다.
- 회귀 검사 386개: 52개 건너뜀, 실패 없음. 신경 힘줄·신체 확장·연결 표의 native 포함 검사 15개 통과.
- 실제 브라우저에서 8/8 연결 표시, 수동 입력 `0.04`의 유지, 신경 모드 복귀, LF 장힘줄 8뉴런 자극 후 입력 약 `0.068` 및 말단 네 관절 약 `0.234rad`를 확인했다. 브라우저 오류는 없었다.

이는 자극에 의해 신경 출력이 물리 구동기에 전달되는지 검사한 결과다. 자연 감각으로 발생한 자발적 보행이나 복부 근육 해부학의 검증 결과가 아니다.
