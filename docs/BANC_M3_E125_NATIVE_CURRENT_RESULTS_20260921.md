# E125 결과: 실제 단계 전류의 재현성과 국소 감도

2026-09-21 KST. [실행 전 설계](BANC_M3_E125_NATIVE_CURRENT_DESIGN_20260921.md)의 두 진단이 범위 안에서 지지되었다. 보행 후보를 변경하거나 M3 F1–F8을 통과시킨 결과는 아니다.

## 실제 CUDA 관측

전체158706 BANC의 원래 E110 시작 상태를 복원하고, 기존 신경 계산 중 이미 계산된391 운동신경의 총 전류를 각 RK4 단계에서 저장했다. 추가 CSR 합산이나 운동 명령 보정은 없다. 1.2초를 한 번 실행해240 control,4800 native neural ticks,12000 physics ticks,19200 단계 전류를 얻었다.

원래 E110과 처음241개 신경·신체 제어 행,240개 motor rate/activation,1.1초 전체 StateStore 상태가 정확히 일치했다. 관측기의 신경 identity와 계산 결과가 유지됨을 실제 전체 회로에서 확인했다. 별도 CPU 계산은 기록한 전류로391 MN만 재구성했다. 원래 발화율 잔차를 보정값으로 넣지 않았다.

관절 명령 최대 오차는99.9729% 감소했다. 사전에 고정한 네 필드의 RMS/최대 오차 한계를 모두 충족했다. 이 결과는 기록 간격과 시점 표현이 원래 재구성 오차의 주요 원인이었음을 해당 구간에서 지지한다. 내부 float32 계산과 float64 재구성의 작은 수치 차이는 남는다. 전체10초·모든 문맥의 검증은 아직 아니다.

재구성 정확도와 보행 품질은 별개다. E110의 원래 초기99 목표 대비 q 최대 오차 약 .056772rad는 .05rad 한계를 여전히 넘는다. E121의 기존 초기99/F3 부분 성공이나 E110의 실패 판정을 수정하지 않았다.

## 다음 개발 결정

채택하는 것은 검증된 연구용 CUDA 전류 관측 기능이다. 다음 적합에는 정확한 native 단계 입력을 사용하고, 감도 검증은 정류 분기 변화와 차분 변화량을 함께 기록한다. 전체 문맥의 fidelity나 감도가 통과했다고 가정하지 않는다.

이미 노출된 E110/E113/E121 문맥을 이용해 전체 구간 입력을 확보하는 단계를 먼저 설계한다. 공통 후보의 가중치를 조건부로 비교하려면 바뀌는 실제 edge의 presynaptic masked rate도 필요하다. 특히 기존 source55에 없는83877 port를 누락하지 않아야 한다. 그 뒤 전체391의 재현성·감도를 확인하고 기존 초기99/형태 기준을 유지한 근육 적응 적합, 실제 전체 BANC와 신체 검증으로 이어간다. 같은 최종 후보의 F1–F8이 모두 충족될 때까지 전체 목표는 active/unmet이다.
