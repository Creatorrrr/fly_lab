# E190 결과: 수직 하강과 제동의 관계는 있으나 일정한 선행 시간은 확인되지 않음

2026-09-24. 저장 원자료 분석1회는 유효하게 완료됐고 부모의 별도 scalar 검산 3178개가 통과했다. **세 고정 사건에서 RM 수직 하강과 제동은 함께 나타나지만, 같은 선행 시간을 가진다는 근거는 일관되지 않다.** 한 연결의 gain 또는 전체 하강 출력을 일괄 줄이는 후보를 자동 채택하지 않는다. 신규 신경·물리·CUDA·모델·fit은0이며 보행 자체가 개선된 실험이 아니다. F1–F8과 goal은 active/미완료다.

## 공동 관측과 실제 차이

E157/E161/E185/E186의 공통1–2초10000 native 표본에서 시간·회전·heading·하중·slip·유효 mask·비발 접촉·upright, RM 요청각과 저장 수직 분해의 소유 시계를 확인했다. E185에는 전체 native qpos/qvel이 없으므로 모든 상태 좌표를 직접 비교했다고 주장하지 않는다.

원본 실행 전에 두 힘 관측기의 소스 집계 순서가 다름을 발견했다. E157은 contact별 정규화 후 합산, E185는 raw segment/leg 합산 후 정규화다. 보충 설계와 v2 freeze에서24836개 contact를 두 원래 순서로 각각 재구성해 자신의 원자료와 exact 비교했다. 두 원래 world-force 값은 실제로112개 원소가 다르며 최대 차이는2.2204460492503131e-16 BW였다. 이를 기계 상태 차이로 오인하거나 사후 허용치로 면제하지 않았다. 두 계산 경로 재현과 기존 공동 관측은 통과했다. 분석 AP는 원래 E185 planar-heading 힘이다.
