# E308 저장된 자원 활성–근육 명령 차이 분해

Root 설계, 2026-09-28. E306 active는 원래 시작 최대 오차 .04rad에 미달했고 같은 SSP의 E307 u0 neutral은 통과했다. 따라서 solver 변경을 미루고 이미 측정한 두 궤적의 명령 차이가 어느 근육·운동뉴런 경로에서 전달됐는지 분해한다. 이 분석은 추가 neural/body 실행이나 새 파라미터 탐색을 하지 않는다. 기존 기록의 관측 끝점을 재계산할 뿐 recurrent network의 뉴런별 인과 효과를 측정하지 않는다.

질문은 (1) 저장된 activation이 실제 관절 명령 차이를 설명하는가, (2) 최대 차이에 기여한 근육과 운동뉴런은 무엇인가, (3) 그 운동뉴런의 관측된 입력 변화가 흥분성 입력 감소인지 억제성 입력 감소/증가인지다. 현재 calibration에서 joint8의 유일한 비영 moment는 muscle19(LM pleural_remotor_and_abductor_muscle)=-4이며, 이 근육은 motor column220/global neuron92104 하나를 갖는다. 이 사실을 결론으로 하드코딩하지 않고 실제 차이·calibration·groups에서 도출해 확인한다. 이 근육 외에도 전체42관절/96근육을 분석해 다른 시작 오차를 숨기지 않는다.

실제 gpt-6-sol / xhigh는 새 `tools/analyze_c_banc_m3_resource_muscle_contrast.py`와 `tests/test_c_banc_resource_muscle_contrast.py`만 구현한다. Root FIRST → 필요 시 같은 Sol R1 → root SECOND → root 잔여 수정. 과거 소스·원자료·UI·M2와 모든 F1–F8은 불변이다. 생성 검사 전 시도 합계30초 / host1.5GiB / CPU1, 실제 saved dataset 계산 및 neural/body/CUDA/fit/solver0회. 구현 단계의 구조 확인 읽기는 가능하나 원본 수치 분석은 root검토 뒤 한 번만 수행한다.

순수 NumPy/JSON/표준 라이브러리와 threadpoolctl만 사용하며 simulation/torch/CUDA/production trial은 import하지 않는다. E306 candidate와 E307 neutral의 trace/activity/native-recruitment-state/recovery-factor-endpoints, 두 producer의 observed-start StateStore 중 adapter/parameters/groups만 읽는다. StateStore는 검증한 manifest와 안전한 NPY leaf를 선택적으로 읽고 model을 만들지 않는다. 같은 adapter hash/그룹·순서·calibration·parameters, 391 motor IDs와 7136 source IDs, 전체101 관측의 control0..100/neural0..2000/physics0..0.5 정렬, complete/available flags와 유한 native dtype를 확인한다. 초기 control0은 decode 실행 전 anchor이므로 절대 명령 재구성은 control1..100에만 판정하고 anchor raw를 별도로 보존한다.

`tools/banc_m3_monotone_recruitment.py`의 실제 decode 식에 따라 q=rest+0.02*(moment@activation), LTM=0.2*tanh(activation[ltm]/10)을 양쪽 저장 activation에서 재구성한다. 명령 재구성 max≤1e-12rad, LTM≤1e-12를 계산 일관성 기준으로 고정한다. 이는 원래 startup/보행 판정 문턱을 변경하지 않는다. 고정 input source SHA와 adapter hash가 다르거나 재구성 기준을 넘으면 유효한 분해 결과로 승격하지 않고 실제 residual을 남긴다. 시간을 적분해 bank/activation을 다시 만들거나 decoder를 실행하지 않는다.

Δ는 항상 active(E306)−neutral(E307)이다. C[t,j,m]=0.02*moment[j,m]*Δactivation[t,m]를 모두 저장하고 sum_m C와 Δq의 residual을 보고한다. .0–.5초 전체 Δq의 최대 time/joint 및 원래99개 startup참조 대비 E306 최대오차 time/joint를 구분한다. 각42관절 최대차이에서 모든96근육 signed contribution을 raw에 남기고 상위5개를 요약한다. 최대차이 지점의 실제 근육 membership으로 관련 운동뉴런들을 도출한다. 변수 근육은 저장 bank/slopes/kappa의 정적 hinge 식으로 각 motor contribution을 재구성하고, fixed muscle은 저장 original_activation 경로임을 표시해 억지로 분해하지 않는다. .0–.5초 motor rate/bank/activation trace와 contribution은 관측 데이터에 한정한다. Signed positive/negative slope와 흥분/억제 시냅스 부호를 혼동하지 않는다.

도출한 주요 근육의 motor ID마다 기존 `e150-native-monotone-body/actual-global-csr.npz` 행을 읽는다. CSR의 각 입력 source를 activity.observed_ids에 매핑하고 전체 포함률과 누락ID를 보고한다. 전체 포함일 때만 float64 `weight32 * (rate_active32-rate_neutral32)` 항을 합산해 관측 끝점의 입력 차이를 분해한다. 원래 음수/양수/0 edge를 구별하고, 가장 큰 signed 입력 기여 및 그 source의 관측 rate/g/R 변화를 함께 기록한다. Source와 motor output mask가 모두1이라는 입력 조건을 실제 checkpoint에서 확인한다. 직접 motor-target resource edge가 없음을 protected roster로 확인하며, 이 조건이 다르거나 source 누락이 있으면 전체 current 재구성 주장을 하지 않는다. Float64 합은 CUDA packed CSR warp의 bitexact current가 아니고, stage current/미분/새 궤적/개별 뉴런 인과 효과도 아니다. 부족한 관측은 명시하고 만들어 채우지 않는다.
