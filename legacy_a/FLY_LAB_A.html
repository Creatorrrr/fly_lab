실제 데이터와 가정을 분리합니다.

기본 배포본에 포함된 실제 연결

Hemibrain v1.2.1의 EPG·PENa·PENb·PEG 발췌입니다. SEISMIC 공개 CSV의 세 구간에서 192개 ROI 행을 취했고, 같은 뉴런 쌍의 ROI 연결량을 합쳐 98개 실제 ID · 177개 방향성 연결 · 시냅스 수 합계 3,747을 포함했습니다. 전체 회로도, 완전한 유도 부분그래프도 아닙니다. 빠진 연결을 연결 부재로 해석하지 마세요.

기본 데이터는 편의상 발췌한 편향된 부분집합입니다. 원본 개별 신경 신호, 신경돌기 형태, 칼슘 영상은 포함하지 않습니다. 출처와 원본 행 번호, 변환 방법은 ZIP의 data와 docs에 있습니다.

설계한 부분

72개 보조 노드: HD 16, GOAL 16, PFL3-L/R 각 16, DN 2, SENSE 4, ALT 2. 이들은 실제 뉴런 ID가 아닙니다. 선호 방향, 부호, 시간상수, 경계 입력, 조향 읽기와 몸 운동은 설계한 모델입니다. 실제 연결량은 제곱근 변환 뒤 수신 노드별로 정규화하며, A에서 모두 흥분성으로 가정합니다.

HD는 단순화된 시각 방향 입력과 자기 회전 감각으로 상태를 적분하는 관측기입니다. 실제 EPG 노드의 모델 활성을 해독해 조향에 사용합니다. 내비게이션은 수평 방향 중심이고, 높이는 별도 센서·제어 모델입니다. 전체 뇌 재현, 학습, 세계 모델, 입체 장면 복원, 공기역학은 구현하지 않았습니다.

신호와 개입의 의미

모든 활성도는 0–1 무차원 모형값입니다. 막전위·발화율·칼슘 형광이 아닙니다. 자극은 모델 입력 추가, 억제는 출력 0 고정입니다. 비교 실험은 이 프로그램의 민감도를 보는 대조 실험이며 실제 광유전학 결과가 아닙니다.

실행과 기록

신경 계산 120 Hz, 몸 갱신 120 Hz, 기록 10 Hz. 최근 120초를 고정 크기 버퍼에 유지합니다. 탭이 숨겨지면 계산을 멈춥니다. 화면 FPS와 시뮬레이션 시간은 다를 수 있습니다. 데이터는 전송하지 않으며 외부 파일은 자동 다운로드하지 않습니다.

실제 자세는 SensorAdapter와 관찰 화면만 접근합니다. NeuralController는 관측된 감각과 자기 상태만 받습니다. 뉴런 ID는 문자열로 유지하여 향후 64비트 FlyWire ID가 손실되지 않게 했습니다.

120 Hz의 A 시간 간격을 B/C의 수치 모델에 강요하지 않습니다. B/C는 자체 하위 스텝과 단위를 사용하고 프레임 경계에서 변환해야 합니다. protocol의 schema와 capability로 이를 명시합니다.

완료되지 않은 B/C를 선택하는 버튼은 없습니다. 자세한 교체 지점, 승인 테스트와 데이터 형식은 ARCHITECTURE.md를 확인하세요.
