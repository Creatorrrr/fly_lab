# E237 저장 입력 재생 복구: 학습 제외 운동뉴런의 변화 분리

E236은 원본 입력 검증에서 중단됐고 수식 재생은 시작하지 않았다. 부모 설계의 “학습 제외48개의 출력은 실제/학습 기록에서 같다”라는 전제가 틀렸다. 부모 SECOND도 이를 놓쳤다. 이48개의 학습 계수가 고정되어 있다는 뜻은 신경 출력이 변하지 않는다는 뜻이 아니다. 저장자료 확인 결과 control6부터 차이가 생기고 최대0.0052928924560546875 rate units다. 42관절에 대한 원래 moment@pool[:,fixed] 투영은 정확히0이지만 힘줄 출력은 별도로 비교해야 한다.

이전 E236 설계, 구현, 테스트, 실패 기록을 그대로 보존한다. 단일 원본 실패1.370345000003초를 포함해 누적6119.524438699667/6214초, 잔여94.475561300333초다. 재생 arm0, 새 신경/신체/CUDA/fit0였고 PID38888/9516/22152는 모두 종료했다. 동일Sol 첫수정과 부모SECOND 이후의 잔여 수정이므로 사용자 작업 방식대로 부모가 이번 복구 코드를 작성한다.

## 바뀌는 조건

E236의 두 입력 arm, 같은 초기값, 동결beta/중심/생리계수, 모든 RK 수식, 원래 startup 목표, 수치 오차 상한, 데이터 순서, partial/raw/manifest 검증은 그대로다. 실제 arm은 실제48개 신경 출력을, 학습 arm은 학습 당시48개 출력을 사용한다. 두 출력이 같다는 잘못된 실행 전 조건을 제거하고 차이의 첫control·최대값·RMS 및 원래 관절 투영을 기록한다. 원래 초기율과 기억 일치 검사는 유지한다.

추가 모델이나 RK 재생 없이, 학습 free343 재생율에 실제48개 출력을 조합한 float32 readout을 하나 더 계산한다. `training-actualfixed32.npz`로 보존하고 activation/관절/tendon을 원래 방법으로 계산한다. 실제 재생과 이 조합의 차이가 free343 입력 변화에 해당하며, 이 조합과 학습 float32 readout의 차이는48개 출력 변화의 효과다. 두 차이의 합은 전체 실제-학습 차이와 수치적으로 일치해야 한다. 분리는 조건부 readout 계산이며 신체 감각 연결의 인과나 실제 폐루프 보행 개선을 증명하지 않는다.

원래 strict startup .018/.04rad 및 tendon .009/.025 기준을 완화하지 않는다. 자연보행/F1–F8 완료나 후보 채택으로 보고하지 않는다. 이 복구가 통과하면 기존 조건부 반응식이 입력 변화에 따라 출력 차이를 재현하는지 판단하고, 이후 같은 신체에서 입력과 목표를 함께 수집하는 방향을 선택한다.

## 실행과 자원

부모가 tools/replay_c_banc_m3_saved_effector_inputs_recovery.py 및 tests/test_c_banc_saved_effector_inputs_recovery.py를 작성하고 생성CPU 검사, 소스 리뷰 후 원본 저장분석1회만 실행한다. 이전과 같은 질문의 기술시도2이며 자동재시도0이다. CPU1/GPU0/신경·신체생성0/물리0/fit0/solver0, 같은2×1980 RK 수식ticks다. 내부75/마감예약10/외부85/감독95초, RSS4GiB/출력256MiB/free2GiB 그대로다. 실행 전 단계 배정만6214→6215(+1)초로 늘려 잔여95.475561300333초에서95초를 예약한다. 원본 및 모든 이전실패 비용을 초기화하지 않는다.

E236 파일을 덮어쓰지 않고 신규 e237-saved-effector-input-replay-recovery에 기록한다. F6 미사용 초기상태, E150 최선, M2, UI 및 전체 목표 기준을 보존한다.
