# E157 전체 접촉 분해 결과

E157 진단 자료는 유효하다. E150의 기존 1–2초 보행 명령을 한 번 재생했고, 10,000개 물리 단계와 양의 접촉 24,420개를 전부 관측했다. 원래 E154의 시간·회전·힘·하중·미끄럼·접촉 자료, E150/E154의 제어 경계 상태가 정확히 일치했다. 보행 명령이나 신경망을 바꾼 실험은 아니므로 개선 효과와 자연스러운 보행의 검증은 아직 미완료다.

이번 전체 구간 관측에서 오른쪽 가운데 다리(RM)의 기여는 끝점만 관측했던 E155와 달랐다. 중단 구간의 RM 지지 접촉점 전방 속도는 하중 가중 평균 +1.210652 mm/s였고, 몸통 6자유도는 −0.368948, 해당 다리 7관절은 +1.580733, 나머지는 −0.001133 mm/s를 기여했다. E155의 제어 끝점 결과를 전체 물리 시간으로 확대해서는 안 된다.

## 주요 관측

중단 구간은 기존 E152의 20ms Gaussian 속도가 0.5mm/s 이하인 제어 구간이다. 이 분류를 각 50개 물리 단계에 반복했다. 새로 계산한 0.1ms 속도 판정이나 완전히 정지한 시간이라는 뜻은 아니다. 표의 속도는 접촉 하중으로 가중했고, 지지 하중은 0.02BW 이상이다.

미끄럼 크기와 부호 있는 전방 성분은 서로 다른 측정량이다. 몸통과 관절 기여의 합에는 표에서 생략한 작은 잔여 자유도 기여도 포함된다. 다리마다 지지하는 표본이 달라 몸통 기여 평균도 다르다.

중단 구간의 RM 뒤쪽 충격량은 −0.028034 BW·s로, 여섯 다리의 뒤쪽 충격량 합 중 **41.1469%**였다. RM 지지 단계 1,727개 중 1,484개(85.9294%)에서 해당 다리의 순 전방 힘이 음수였다. 이 지지·제동 부분집합에서 RM coxa-roll의 전방 기여는 **+2.056825 mm/s**, 그 관절에 할당된 접선 힘×속도 적분은 −0.069787 BW·mm였다.

반면 전진으로 분류된 구간의 RM 지지 접촉에서 같은 coxa-roll의 평균 전방 기여는 **−2.397838 mm/s**였다. 따라서 전체 출력을 일괄 약화하는 것이 좋다고 결론 내릴 수 없다. 접지를 유지한 채 전방으로 복귀하는 동작과 발을 떼는 동작의 상대 시점을 다음 인과 실험의 설계 대상으로 삼는다. 이 관측은 특정 신경 연결 변경의 효과를 증명하지 않는다.

## 구현과 리뷰

부모가 설계했고 실제 `gpt-5.6-sol`/`high`가 첫 구현과 첫 수정을 했다. 고정 접촉 Jacobian 수식과 실패 시 상태 기록을 물리 재생에 결합하는 작업이어서 high를 사용했다. 모델 설정은 기존 에이전트의 실제 설정을 유지했다.

첫 부모 리뷰는 완료된 적분 뒤 관측 실패 시 상태 누락과 저장 native 시간의 허용오차 적용을 재현했다. 같은 Sol이 수정한 뒤 부모 두 번째 리뷰에서 이후 nonfoot 관측 실패 시 반환된 하중·미끄럼이 빠지는 잔여 문제를 찾았다. 요청된 작업 순서에 따라 부모가 그 기록 순서만 수정하고 회귀검사를 추가했다. 첫 구현, 첫 수정, 두 리뷰, 실패 자료와 소스 아카이브를 보존했다.

최종 29 tests와 Ruff/format/compile/CLI가 통과했다. 독립 생성 수치 검산은 2,610항목, 부모의 단계별 실패 주입은 7건이 통과했다. 실제 출력에 대한 별도 검산기는 후보 평가 함수를 가져오지 않고 원시 Jacobian·qvel·힘부터 분해와 7그룹×4부분집합을 재계산했다. **수치 및 파일 무결성 5,700항목이 통과**했으며, 이 개수는 생물학적 실험 반복 수가 아니다. 출력의 가장 큰 비교 오차는 하중합에서 2.274e−13이었다.
