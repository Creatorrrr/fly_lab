# E266 결과: 기존 반대 위치 감각 간선의 단순 복원은 전류 변동을 줄이지 못함

E266은 유효한 저장자료 분석이며 H266은 refuted다. 여섯 SNpp50 간선만 복원한 조건부 추가전류와 기존 SNpp51 간선 한 개까지 원래 count 비율로 복원한 조건부 추가전류는 이 자료에서 같았다. startup 평균을 제거한 RMS 비율은1.0으로 사전 기준≤.2를 충족하지 못했다. 이 방식은 다음 GPU 후보로 올리지 않는다. 모든 opponent 회로나 교정 가능성을 부정하는 결과는 아니다.
