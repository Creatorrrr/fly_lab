# E210 사전 초안: 고정 신경 반응 기저의 제한된 조건부 적합

이 문서는 부모 설계 초안이다. E209 출력의 독립 검산이 통과하기 전에는 동결·원본 실행하지 않는다. F1–F8, 원래 E150 비교 자료, 미사용 F6 상태와 M2/UI 보존은 그대로다. E209는 계산 검증이고, 이 적합도 기록된 입력을 조건으로 하는 학습이다. 실제 전체 BANC–신체 피드백에서 자연스러운 보행을 검증하는 단계와 구분한다.

## 변수와 전달 계약

E209의 입력 scale, prototype 16개, 폭, 16ms 기억, activity gate, 원래 membrane tau/cap와 초기 상태를 고정한다. 자유 MN 343개의 beta 16개씩, 총 5488개만 학습한다. 각 beta는 0..1이다. 고정 LTM MN 48개와 신경·근육 소유권은 바꾸지 않는다. 원래 canonical pool과 10ms activation을 사용한다.

각 다리의 자유 MN은 LF/LM/LH/RF/RM/RH = 61/54/56/62/55/55개이며, 변수는 976/864/896/992/880/880개다. 해부학적 moment에서 각 근육의 영향이 해당 다리의 7관절에만 있는지 실제 자료로 검사한다. 다리 밖 영향이 있으면 아래 독립 문제 분해를 적용하지 않는다.

한 다리의 affine 명령은 `q(t)=q_intercept(t)+A(t)*beta_leg`다. A는 E209 D, 소유 근육, `.02*moment`만으로 만든다. 학습 row는 기존 1824개(100..1923), 속도는 기존 1823쌍, startup은 row1..99다. 시작 row0은 원래 held command이며 학습 변수가 바꾸지 못한다.

## 검토 중인 문제 분해

계산량을 제한하기 위해 여섯 다리를 각각 한 번 푸는 방안을 우선 검토한다. 각 문제는 원래 다리별 command RMS로 정규화한 command 제곱 오차를 최소화한다. beta box, 해당 다리 command/velocity RMS 비악화, startup 각 표본 절대오차 .04, 해당 다리 startup RMS .018 이하를 명시적 제약으로 둔다. 같은 해부학적 문제의 다리별 분해이며 다리별로 다른 모델이나 목표를 고르는 탐색이 아니다.

다리별 startup RMS .018은 원래 전체 startup RMS .018보다 **엄격한 충분조건**이다. 여섯 다리가 이를 만족하면 전체 startup도 만족하지만 역은 성립하지 않는다. 따라서 실패를 원래 전역 문제의 불가능성으로 해석하지 않는다. 이 추가 제한이 후보 생성을 막았다는 증거가 있다면 별도 사전 설계로 전역 startup 제약을 공유하는 문제를 검토한다.

다리별 command/velocity 비악화는 전체 비악화도 보장하지만 전체 command 20% 개선을 보장하지 않는다. 여섯 결과를 합친 후 원래 전체 proxy를 독립 계산한다. 전체 command RMS <= .8*원래 값, 전체·다리별 velocity/다리별 command 비악화, startup RMS .018/max .04, tendon RMS .009/max .025를 모두 평가한다. 실패 시 기준을 낮추지 않는다.

추가 정규화·solver 세부·시간 한도·원본 호출 수는 읽기 감사와 E209 결과를 확인한 후 동결한다. 문서 작성 시점에는 solver 호출 0, CUDA 0, 신체 0이다.

실제 gpt-6-sol/medium 읽기 감사는 원시 전역 command 행렬이 76608×5488, velocity가 76566×5488이며 전역 command 행렬 하나만 약 3.36GB임을 확인했다. 최대 다리 행렬은 12768×992, 약 101MB다. E206의 다리별 augmented Gram 압축을 재사용할 수 있으나 signed weight의 좌표 scale/trust ball은 이번 beta 문제에 적용하지 않는다. 필요한 q/velocity 압축의 고유분해는 최대 993차원이며 여섯 다리에서 각각 수행하므로 이전 2401변수 실행 시간으로 비용을 단정하지 않는다.

감사에서 제안한 다리별 20% q 제약은 채택하지 않는다. 본 초안은 다리별 q 비악화와 총 q 오차 최소화를 사용하고, 전체 20%를 나중에 직접 검사한다. 다리별 startup 제한은 충분조건임을 유지한다. solver 입력의 압축 잔차와 반환된 물리 beta에서 직접 계산한 모든 원래 residual을 함께 검증한다. 새로운 원본 예산은 E209 실측 비용을 반영한 뒤 별도로 사전 배정한다.

## 필수 비교와 다음 단계

원래 신경 출력/새 신경 출력 각각을 E150 monotone decoder와 canonical decoder로 읽은 2×2 대조를 저장한다. 두 경로의 초기 내부 상태와 row0 의미를 보존하고, canonical 변경과 국소 신경 반응 변경의 결합 효과를 명시한다. 실제 scalar 반응과 기저 혼합의 동일성은 E209에서 검증하지만, 이 적합은 새로운 native 신경 모델 통합을 대체하지 않는다.

조건부 후보가 나오면 별도 native 구현에서 실제 signed recurrent 입력, 16ms 기억, 새 phi를 매 RK 단계 계산하고 snapshot/restore와 motor-cut을 확인한다. 고정 48MN은 기록 파일을 재생하지 않고 현재 실제 입력에 원래 식을 적용한다. 전체 BANC와 신체에서 10초 학습 조건을 먼저 검증한 후 F1–F8의 남은 순서로 진행한다. 조건부 실패나 폐회로 실패는 원자료와 자원 사용을 보존한다.
