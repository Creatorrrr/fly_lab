# E124 이후 적합 결정 메모

부모 설계 메모, 2026-09-21 KST. E124 구현과 별개로 작성하며 원본 응답/적합을 실행하거나 허용한 문서가 아니다. E124 결과를 보기 전에 다음 의사결정의 경계를 명확히 한다.

E124의 세 문맥 gain0 재현과 gain1 감도가 모두 유효하면, 다음 변수는 기존96근육별 MN 적응 gain[0,8]이다. native E121 가중치·노드·연결·신체·moment/rest/pool/EMA를 고정한다. 기존 gain0의 입력 분포를 이용한 조건부 최적화이며, gain 변화로 전체 BANC의 재귀 전류가 바뀌는 기울기를 알고 있다는 가정은 하지 않는다. E110/E113/E121은 모두 이미 노출된 개발 기록으로 남긴다.

과거 E110/E113의 source55 기록은 E121의 port 조작을 정확하게 이식하는 데 충분하지 않다. 재구성이 유효할 때 가능한 적합 계약은 **각 실험이 실제로 겪은 세 MN 전류 분포에서 같은 gain 벡터를 시험하는 강건한 조건부 적합**이다. 각 전류가 E121 후보 회로에서 생성됐다는 주장은 하지 않는다. 실제 후보 회로는 E121+gain으로 하나이며 별도의 전체 신경·감각·신체 실험이 필요하다. 이 명시적인 모델 한계와 과거의 source/W113 교차 문맥 결과를 함께 보고한다.

적합을 구체화할 때 필요한 조건은 다음과 같다.

- 기존 E110/E113 own-phase/원래 fixed/common mask·원래99·relative/absolute shape20%를 유지한다. 새 gain0 기준을 추가해 보고할 수 있지만 과거 기준을 대체하거나 실패한 문맥을 제거하지 않는다. 기존 E114 W113 비교와 새 각 문맥 gain0 비교를 모두 두고 더 느슨한 판정을 고르는 방식은 사용하지 않는다.
- E121의 own-phase 표적은 기존 source ID 대응으로부터 준비하고 동결한다. 실제 Thorax-local 보행 주기와 source 위상을 혼동하지 않는다. 오래된 fixed E110 shape 기준도 따로 평가한다.
- 여섯 다리에 분리되는 기존 muscle moment/pool의 해부학적 소유권을 먼저 확인한다. 다리별 약15–17개 gain과 epigraph를 사용하면, 감도는 MN당 하나→근육당 하나의 factor로 조립할 수 있다. 시작99의 signed q/LTM 표본과 RMS 제약을 직접 사용하고, 활성 최대 표본 하나만 잡은 불안정한 근사로 바꾸지 않는다.
- 한정된 SLSQP 실행 수·시간·모든 실제 조건부 평가 수와 실패 보존을 동결한다. 초기 gain0에서 시작하며 고정 기준을 충족한 평가만 선택한다. 96개 float32 native gain으로 변환한 후 하나의 합성 후보 전체를 다시 검증한다. 정류 경계의 미분 불확실성, 입력 표본 오차와 실제 gain 변화량을 비교해 보고한다.
- 조건부 shape/startup 통과 후에만 같은 E121+gain을 전체158706 BANC/CUDA/실제 신체에서 원래10초 평가한다. 첫99 및 F3–F5 기준은 그대로이며, 실패 시 원자료의 현재 입력/근육/접촉/몸통 전진을 따라 원인을 구분한다. 해당 결과 없이 '자연스러운 보행 개선'으로 발표하지 않는다.

E124 재현이 실패하면 기록한5ms 전류와 native.25ms 동역학 사이의 표본화 오차부터 구분한다. 원래 rate를 보정 잔차로 더해 오류를 지우지 않는다. 필요한 다음 대안은 기존 native CUDA 계산 중 이미 계산되는 MN 전류의 더 조밀한 관측이다. 이때 추가 CSR 계산, 동기화, 메모리, CUDA graph 포인터/저장 복원 영향을 별도로 설계하고 한 개발 시작에서 검증한다. 임계값이나 보간을 결과에 맞춰 조정하여 E124를 다시 통과시키지 않는다.

어느 분기에서도 같은 최종 후보의 F1/F2 통합·차단·저장, F3–F5 실제 보행, F6 미노출 두 자세, F7 기존6목표/정지·재시작/M2 slip, F8 원자료·영상·M2 복원까지가 전체 완료 조건이다.
