# E198 결과: 저장 관측에서 침묵 MN의 직접 제한은 입력과 역치

**유효한 저장 자료 진단이다. 보행 개선 후보를 채택한 결과는 아니다.** E150의 같은2000개5ms 경계 관측을391 MN 순서로 정렬하고 native 기록과 정확히 대조했다. 부모가 scalar tanh/fsum 및 직접 정렬한 분위수로 독립 계산해43개 비교를 통과했다.

전체 관측의 MN 균등 평균에서 활성35.2734%, 입력 부족64.1601%, 적응 억제0.5665%로 서로 겹치지 않는다. 포화 표본은1.8958%이며 활성의 부분집합이다. 모든 수치는 MN/시점의 빈도이며 근육 힘, 관절 기여, 물리적 제동의 비율이 아니다. gait에서 phi 항상0인202개와 실제 rate 항상0인196개는 서로 다른 상태량이다. 이전 발화의 감쇠 상태를 즉시0으로 바꾸지 않았다.

## 다음 방법에 주는 근거

현재 MN391개는 모두 a=1, threshold=7.5, cap=200이다. 전체 창에서 phi와 rate가 계속0인196개는 관측한 각 경계에서 I≤threshold였다. 따라서 **같은 저장 입력·상태에서 slope만 키우는 것은 이 세포를 모집하지 못한다**. 이196개 중 최대 원시 입력 I가 양수인 세포는151개, I≤0인 세포는45개다. 최대 I의 min/median/max는−.08962685/.10494643/7.26543951이다. 45개는 같은 고정 상태에서 양수 slope와 음수가 아닌 threshold만으로 활성화할 수 없다. 이는 E198에서 이미 발행한 per-MN 요약을 해석한 것이며, 바뀐 전체 신경망의 미래에 대한 불가능성 주장은 아니다.

침묵 MN을 모두 살리는 것을 새 목표로 만들지 않는다. 일부 운동신경의 미모집은 정상적인 동작에서도 가능하고 동일 근육의 다른 MN이 힘을 전달할 수 있다. E178의 특정 RM 세포 관측도 근육 전체 무활성과 달랐다. 이 결과는 전반적 포화나 적응 억제만을 원인으로 보고 다시 gain/tau를 조정할 근거가 약함을 보여준다. 과거 실패와 함께 볼 때, 다음 설계 질문은 **보행에 필요한 근육의 입력과 모집 범위가 적절한가**이며 a/threshold 또는 입력 효능을 바꾸더라도 기존 보호 조건을 유지한 별도 단일 가설로 검증해야 한다. 고정 순간식의 미분을 전체 미래 궤적 감도로 사용하지 않는다.

실측 slow/intermediate/fast 대응이 없다는 [자료 검토](BANC_M3_AFTER_E197_NEURAL_DIRECTION_REVIEW_20260924.md)도 보존한다. 면적→전기적 생리 변환이나 임의 tonic bias를 채택하지 않았다. 5ms 경계만 관측했으므로 내부20개 신경step의 상태와 표본 사이의 극값을 복원하지 않는다. 자연 보행의 생물학적 동등성을 검증한 결과가 아니다.
