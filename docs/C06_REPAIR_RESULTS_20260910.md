## 행동별 결과와 남은 원인

### BANC 지속 보행: 실패

10초 순이동은 기본 조건 **0.06895mm**, DNg100 자극 조건 **0.45970mm**로, 5mm 전진 기준을 충족하지 못했다. 기본 조건의 다리별 보정 지지 하중 평균은 0.132~0.214 BW이며 기존처럼 다섯 다리의 하중 특징이 1에 고정되지는 않는다. 따라서 입력 포화의 수정과 지속 보행의 성립은 구분해야 한다.

남은 원인은 아직 하나로 확정할 수 없다. 검증되지 않은 동일 LIF 파라미터, 수용체 튜닝, rate→관절 목표 변환, 제한된 감각 입력이 결합돼 있다. 실제 근육의 힘·길이·속도 관계와 모멘트암은 구현되지 않았고, `rm_coxa_pitch`는 해부학적 연결 근거가 부족해 여전히 미연결이다. 원래 제외된 다리 감각 후보 1,479개의 외부 입력 매핑도 이번에 완성하지 않았다. 해당 뉴런의 신경망 계산 자체를 제거한 것은 아니다.

### 직접 출력 제어: 5/5 통과

전진 진단의 시작점을 경기장 대각선으로 옮겨 조기에 벽에 닿는 시험 설계 문제를 수정했다. 기준 시간과 이동·고착 기준은 유지했다. 10초 순이동 **39.48mm**, 접촉 0초, 고착 없음으로 통과했다. 후진은 전방축 이동 **−2.58mm**, 좌·우 회전은 **−1.102 / +1.077rad**였다. 직접 전진 출력 억제 후 재개도 통과했다. 이는 직접 뉴런 자극과 기존 CPG 몸 변환기의 검사이며 자연 보행의 증거가 아니다.

### 좌우 먹이: 왼쪽만 접근 성공, 편향 미해결

새 v6 프로파일에서도 왼쪽 먹이 접근은 통과하고 오른쪽은 실패했다. 두 감각 차단 조건은 정지해 접근에 실패했다. 왼쪽도 이후 벽에 머무르며 **접촉 16.59초·고착 검출**이 있었으므로 안정적인 30초 탐색 성공이 아니다.

고정 감각 검사는 두 시드에서 대칭 입력과 좌우를 바꾼 입력 모두 지속적인 왼쪽 편향을 보였다. 연속 전류 v2는 약한 입력에서 지속 반응이 꺼졌고, Poisson v3은 충분한 입력에서 평균 조향이 주로 약 −0.5rad/s였다. 단순 좌우 부호 변경이나 감도 감소로 해결됐다고 볼 수 없다. 목표 좌표를 읽는 조향 보정, 원래 연결의 대칭화, 한쪽 뉴런의 임의 제거는 도입하지 않았다.

### 정지: 출력 변환은 작동, 자연 회로 재현은 미검증

모든 조건에서 전진 집단에 20mV를 계속 주고, 2.0~3.5초에 정지 집단을 자극했다. 정지 측정은 2.5~3.5초, 재개 측정은 해제 뒤 2초다.

| 조건 | 정지 구간 이동 경로 | 재개 순이동 | 판정 |
|---|---:|---:|---|
| Bluebell + 전진 억제 변환 | 약 0.0000015mm | 7.94mm | PASS |
| Bluebell의 이후 시냅스 전달 차단 + 변환 유지 | 약 0.0000014mm | 7.91mm | PASS |
| Bluebell 변환을 끄고 실제 시냅스 경로만 유지 | 5.26mm | 8.06mm | FAIL |
| Foxglove 자극 | 1.99mm | 7.85mm | FAIL |

이 강제 전진 자극 조건에서는 출력 변환기가 BB 정지 성공을 설명한다. 뇌 내부 억제만으로 자연 정지가 재현됐다는 주장을 뒷받침하지 않는다. 또한 FAFB의 BRK 뇌 분절만으로 VNC 내부의 제동 출력을 복원할 수 없다.

### 위험·장애물 회피: 미승인

위험 입력만 있는 기존 실험의 정지 문제를 피하려고 모든 대조군에 동일한 보행 뉴런 자극을 넣는 **evoked** 검사를 추가했다. 자연 감각만으로 이루어진 실험과 명시적으로 구분한다.

처음 위험원 x=8mm에서는 대조군 최근접 거리가 3.47mm로 접근 기회 기준 3mm를 넘었다. 이를 성공으로 처리하지 않고 `NOT_APPLICABLE`로 남겼다. 위험원을 x=5mm에 둔 새 조건에서는 대조군 최근접 1.52mm로 기회를 확보했지만, 활성 조건은 1.70mm로 **여유 개선 0.18mm**, 체류 0.440초 대 감각 차단 0.555초, 순이동 0.96mm여서 기존 기준에 **FAIL**했다. 기준을 낮추지 않았다.

장애물 활성·장애물 없음·시각/접촉 입력 차단 조건은 **모든 표본의 몸 위치가 정확히 같았다**. 가장 가까운 몸 중심 거리는 2.774mm였으며 원래의 원운동으로 장애물 옆을 지나간 것이다. 새 대조 검사는 `NOT_APPLICABLE`이며 단독 궤적의 PASS를 회피 기작의 증거로 승인하지 않는다.

## 후속 개발 순서

1. **BANC 근육 모델과 국소 회로 검증:** 실제 힘·모멘트암 자료를 확보하고 한 관절의 길이·속도·힘 반응부터 교정한다. 감각 수용체별 입력과 운동뉴런 반응을 독립 검증한 뒤 다리 간 위상과 보행을 평가한다. 임의의 CPG를 추가해 BANC 자율 보행으로 표시하지 않는다.
2. **좌우 신경 동역학 교정:** 대칭·교환·유지 입력을 고정하고 입력 모델, 시냅스 효력, 뉴런 동역학, 하행 readout 집단을 구분해 검증한다. 다른 입력 농도·시드에서 양방향 반응을 먼저 확보한 뒤 먹이 위치를 바꾼 물리 대조로 평가한다.
3. **자연 정지·회피:** 검토한 BB/FG/BRK 회로가 감각으로 모집되고 몸의 출력을 바꾸는 경로를 확인한다. 외부 전진 자극 경쟁 실험과 자연 보행 중 실험을 나눈다. 위험은 geosmin 입력의 제한된 의미를 유지하며, 장애물은 단독 통과가 아닌 대조에 대한 개선을 요구한다.

이 세 단계는 이번 수정으로 통과했다고 선언하지 않는다. 확인된 구현 결함은 수정됐지만 생리 파라미터 교정과 안정적인 자율 행동은 남은 개발·검증 과제다.
