# M2 일반화 판정 수정안 — 사용자 승인됨

사용자가 “승인할게 계속 해줘.”라고 명시적으로 승인했다. 아래 Q3 변경을 현재 M2의 합의된 판정으로 적용한다. 원래 Q3의 미충족과 실패 기록은 보존한다. 이 승인만으로 E34를 바로 적용하지 않는다. 뒤쪽 목표를 포함한 Q4와 최종 실제 연결 Q7이 남아 있다. 파일명의 DRAFT는 승인 전에 공유한 링크를 유지하기 위한 기존 이름이다.

## 수정이 필요한 근거

원래 Q3는 상대 목표 (8,3), (5,-7)mm, seed42 각각에서 유효한 M1 기준선과 비교하고, 두 조건의 평균 미끄러짐을 30% 이상 줄이도록 요구했다. 실제 실행에서 첫 조건의 M1은 2.835초에 넘어졌다. 최소 upright는 0.03415이고, 도달하지 못했으며 RF 하중 표본은 50개로 부족했다. 원래 관측창을 완료하지 못해 그 조건의 개선율과 두 조건 평균을 계산할 수 없다.

기준선 설정은 M1이며 신경 모델과 목표 encoder 식별도 일치했다. 단순 기록 메타데이터 문제가 아니다. 다른 조건에서 별도로 발견한 UI 기록 길이 문제는 원자료를 보존하고 고쳤으나, 이 물리 실패를 고치거나 Q3를 통과시키지는 않는다.

## 승인된 변경 내용

Q3만 다음과 같이 바꾼다.

1. 이미 고정한 두 목표와 seed, 원래 Q2 유효성 기준, 동일 v2 평가기·관측창·접촉 하중 문턱을 유지한다.
2. M1의 품질 관측이 유효한 조건에서는 후보의 미끄러짐이 M1보다 30% 이상 감소하고, 후보도 Q2 및 원래 도달·정지 기준을 통과해야 한다.
3. M1이 물리적으로 실패하여 품질 비교가 불가능한 조건에서는 상대 개선율을 산출하지 않는다. 후보가 넘어짐·몸통 접촉 없이 원래 30초 도달·정지 기준을 통과하도록 요구한다. 기준선 실패와 후보의 절대 성공을 별도로 보고한다.
4. 원래 Q3는 미충족으로 보존한다. 두 목표는 이미 노출되었으므로 이후 재검사는 회귀 확인이며 새 독립 일반화 검증이라고 부르지 않는다. 보고하는 개선율의 범위를 비교 가능한 조건으로 한정한다.

Q1, Q2, Q4, Q5, Q6, Q7은 바꾸지 않는다. 특히 뒤쪽 목표의 허용 시간을 늘리거나 도달 반경을 넓히지 않는다. 실패 조건 제외 평균·실패 뒤 0 보충·관측창 단축으로 원래 Q3를 통과시키지 않는다.

## 현재 후보에 적용하면 달라지는 판정

| 항목 | 현재 E34 증거 | 이 수정안 아래의 의미 |
|---|---|---|
| 개발 목표 | 미끄러짐 35.4% 감소, Q1/Q2 통과 | 그대로 유지 |
| 확인 목표 (5,-7) | 유효한 품질 비교에서 40.6% 감소, 후보 도달·정지 통과 | Q3의 비교 가능한 조건 통과 |
| 확인 목표 (8,3) | M1 넘어짐, 후보 도달·정지 통과 | 상대 개선율 없이 기능 결과만 통과 |
| 여섯 방향 | 다섯 통과, 뒤쪽 목표 실패 | Q4 실패 유지, 최종 채택 불가 |

이 개정은 후보 선택과 완료 판정에 적용하되, 다른 필수 조건을 통과하기 전에는 최종 채택하지 않는다. 현재 8770 모델과 체크포인트는 보존한다.
