# E152 전진 중단과 지지 동작 진단

E150의 반복적인 다리 운동과, 전진이 매 주기 끊기는 현상을 분리해 확인했다. E150은 .5–10초 구간에서 전진 속도 .5 mm/s 아래로 46번 떨어졌다. 전체 창의 보조 분석에서는 각 다리 21–22주기와 낮은 주기 CV(.014–.075)가 관측된다. 그러나 정식 적격 전진 구간은 여전히 최대 .215초이며 F4/F5는 실패다. all-window 수치를 정식 검증 통과로 사용하지 않는다.

| E150 관측값 | 전진 구간 | 중단 구간 |
| --- | ---: | ---: |
| 5 ms 경계 표본 | 1363 | 537 |
| 전진 속도 중앙값 | 2.5485 mm/s | .0163 mm/s |
| 접촉 하중 가중 미끄럼 | 1.7040 mm/s | 2.5539 mm/s |

중단 구간 미끄럼은 전진 구간의 약 1.50배다. 단순히 지지 다리 수만 적은 현상으로 설명하기 어렵고, 뒷다리 및 RM의 하중을 받는 회수 동작이 함께 관측된다. 이것은 인과 판정이 아니다. 발마디 끝 원점의 움직임은 실제 접촉점 힘이나 추진력과 같지 않다. 동일 body/초기 qpos/qvel의 E85는 외부 관절 궤적과 고정 다리 힘줄 .2를 사용하므로, E150과의 비교가 힘줄 효과를 통제하지도 않는다.

부모의 별도 사후 해석(동일 E152 feature만 사용, 원본 재실행0)에서, 중단 중 지지 LH/RH 발 원점은 세계 기준 전방 속도 중앙값 3.9145/4.0331 mm/s와 양수 비율 93.28/95.56%다. 같은 표본의 관절 tracking RMS 중앙값은 .00239/.00335 rad다. 이는 몸 기준 좌표 변화만으로 생긴 통계인지 확인하기 위한 보조값이며, 새로운 채택 기준이나 접촉 힘 방향의 측정은 아니다. 다음 개입 전에 실제 접촉 힘이 추진/제동에 어떻게 분배되는지 확인하는 짧은 동일 명령 재생이 유용하다.

실제 Sol/high 최초 구현 → 부모 첫 리뷰 → 같은 Sol 첫 수정 → 부모 두 번째 리뷰를 완료했다. 최초 CLI 경로, 사전 검사 시간, source gate 조건, 요약 실패 시 raw 보존의 네 문제를 재현하고 교정했다. 생성 테스트13개, 독립 수치130항목, Ruff/format/compile와 직접 CLI가 통과했다. 수정 후 구현 SHA `dc5ce4507c4375221342b502d7378348ec5af22fd372d3169f28be863d69485f`다.
