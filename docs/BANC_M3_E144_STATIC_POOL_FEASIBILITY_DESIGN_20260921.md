# E144 — 초기 자세를 유지하는 정적 근육 내 가중치의 실제 표현력

2026-09-21 · M3 개발용 조건부 진단 · 부모 설계, Sol/high 구현.

E143의 점별 낙관적 오차 하한은 관절33.53%/속도43.15%다. 그러나 시점마다 다른 MN을 골라 얻은 범위라 하나의 정적 가중치가 이를 달성한다는 뜻이 아니다. 부모의 원래99 초기 범위 검산에서는 최소 가능한 RMS.00439237/max.03620841로 기존.018/.04 한도 내 가능성을 배제하지 않았다. 실제 static feasibility는 아직 미검증이다. E142의 F4/F5·엄격초기 실패와 LH/RH 과거 조건부 손실 guard 실패는 유지한다.

H144: 기록된 같은 E142 신호에서 해부학적으로 동일 근육 안의 정규화 가중치 하나를 모든 시점에 공유하여, 초기99의 엄격 기준을 만족하면서 후기 관절 RMS를20% 이상 줄이고 속도 RMS를 악화시키지 않는 정적 제안을 찾을 수 있다. 경쟁 설명은 신호들의 유사성과 시간에 걸친 제약 때문에 점별 낙관적 여지가 실제 고정 가중치로 실현되지 않는다는 것이다. 제한된 탐색에서 미발견은 전체 수학적 불가능성의 증명이 아니다.

대안은 신경 모수의 작은 추가 fitting 또는 근육 힘/동적 전달 모델의 재설계다. 먼저 기존 출력만의 선형 문제를 풀면 새 신경/CUDA/물리 없이 이 읽기 변환 가설을 판별할 수 있다. 초기 상태와 명령속도를 동시에 다루므로 과거 무제약 gain/sum-pooling 반복과 구별된다. 참조 완전 재현을 자연 보행의 필수조건으로 추가하지 않는다.

변경 가능량은 기존391MN→96근육 pool의 양의 가중치다. moment/rest/EMA/근육 멤버십/원래신경 모수/근육별 적응 gain·tau/모든 기록시각과 위상은 고정한다. 6개 long_tendon_muscle 행과 멤버가 하나인 근육 행은 그대로 둔다. 나머지 각 근육의 가중치 합은1, 각 MN의 하한은1e-6/n_members, 상한1이다. 모든 기존 MN의 양의 해부학 지원집합을 보존한다. 비례적 힘 배분은 공학적 인터페이스 가설이며 생물학적 실측값이 아니다. 새로운 edge/외부위상/교사 재생/뉴런 실행을 추가하지 않는다.

입력은 봉인 E143 raw의 b[2000,391], target/mask/인접 pair, 기존 pool/moment/rest/membership/ltm 및 원래 E103 startup-inputs의99표적이다. E142 calibration/anatomy, E143 결과/부모 검산/초기 범위 검산으로 provenance를 확인한다. 모든 b와 현재 decoder 결과는 그대로 재사용하므로 추가 EMA0이다. 1827명령·1826속도쌍을 같은 개발자료로 사용하며 F6 독립 확인으로 부르지 않는다.

각 다리의 가변 MN 열 i와 근육 g(i)에 대해 D[t,j,i]=.02*b[t,i]*M[j,g(i)]. 고정 명령 c는 기록 baseline에서 D*x0를 뺀 값이다. 초기99도 같은 식이다. 속도 설계는 전체 endpoint D와 c의 실제 인접 차이를.005로 나누고 E143의 pair_end-2 행만 고른다. 따라서 q=D*x+c이고 가중치는 모든 시점·관절에 공유된다. 다른 다리의 moment 지원이0임을 검사하고, 여섯 다리를 독립적인 작은 문제로 풀되 최종 후보는 하나의 합성 pool로 다시 검산한다.

다리별 고정 목적함수는 mean((q-target)^2)/max(baseline_command_MSE,1e-12) + mean((qdot-targetdot)^2)/max(baseline_velocity_MSE,1e-12) + 1e-6*mean(((x-x0)/x0)^2). 원래 x0는 균등 평균이다. analytic gradient와 고정 Gram 항을 사용한다. 작은 상대 가중치 prior는 식별되지 않는 방향의 불필요한 이동을 줄이며 최적해/생리학적 가중치의 증명으로 해석하지 않는다.

SLSQP를 다리별 원래 x0에서 최대1회, 총 최대6회 사용한다. maxiter100/ftol1e-10, CPU1, analytic objective/constraint Jacobian, 무작위 시작/스윕/재시도0. 각 근육 row sum1과 양의 bounds 외에 초기99의 모든 관절 표본에 |q-target|<=.04-1e-9를 적용한다. 다리별 초기 RMS 한도는 원래 해당 다리 RMS * ((.018-1e-9)/원래 전체 초기RMS)로 사전 계산한다. 이 비례 배분은 합성 전체RMS<=.018-1e-9를 보장하는 추가 제약이며, 실패가 다른 배분까지 불가능함을 뜻하지 않는다. 원래 전체RMS가0이면 다리별 한도는0이다. tendon행 고정으로 원래99 힘줄 출력은 그대로다.

다리별 평가 호출 최대140, 총840. baseline과 solver가 요청한 각 x의 목적/초기오차/제약 위반/경과시간을 기록한다. 동일 x 캐시를 쓰면 actual objective call과 unique evaluation을 별도로 센다. 9초/다리 soft stop 및54초 전체fit 한도, 전체 내부70초/외부75초/감독80초다. 하나의 원본 프로세스/재시도0, raw64MiB/시작 여유1GiB, CPU1/GPU0, 새 neural/physics/EMA/LP0. 부모 초기 검산 외부.4090214초를 포함해 보수 prior2170+80=2250으로 기존2268/전체2271 범위 안이다. 원본은 부모 source gate 뒤에만 실행한다.

선택은 기록된 실제 평가 중 양의 범위(하한 수치오차1e-12 이내이며 반드시>0), row sum오차<=1e-12, 다리별 초기RMS 한도 및 .04max를 만족하는 고정 목적함수 최저점(동률은 먼저)을 다리별 고른다. 실제 보행 결과를 보고 선택하지 않는다. solver.success/중단원인과 유효 제안 선택은 분리한다. 실패/중단의 raw 및 모든 실제 평가를 보존한다. 선택점의 임의 clipping/정규화/사후 수정은 금지한다. 한 다리에 유효점이 없으면 합성 제안 없음이다.

합성 제안의 판정은 전체 초기99 qRMS<=.018, qmax<=.04, LTMRMS<=.009, LTMmax<=.025, 원래 anatomical pool 지원/합, 고정 tendon 출력 exact, 후기 전체 관절 RMS<=.8*baseline, 속도 RMS<=baseline, 그리고 각 다리 관절/속도 RMS가 각각 baseline을 넘지 않는 것이다. 생성자료/원본 수치 raw를 먼저 저장하고 판정한다. 이 조건을 만족하면 conditional_static_pool_proposal만 내보낸다. 실제 모델/UI 기본값 변경·보행 채택은 하지 않으며 F1–F8은 pending이다. 실제 전체 BANC/신체10초와 원래F3–F5·저장미래를 확인하기 전 자연 보행 개선이라고 말하지 않는다.

구현 파일은 tools/fit_c_banc_m3_static_pool.py, tests/test_c_banc_static_pool.py 두 개다. 기존 동결 파일은 읽기 전용이다. 부모 설계 → 실제 Sol/high 구현 → 부모 첫 리뷰 → 같은Sol 첫 수정(필요할 때) → 부모 두 번째 리뷰 → 잔여 수정은 부모 절차를 유지한다. 새 신경/CUDA 동역학 대신 기존 저장신호의 선형 설계/작은 제약 최적화를 연결하므로 high를 사용한다. 부모는 병행해서 생성자료의 선형식·목적/Jacobian/초기 RMS 배분을 독립 검산한다.

오류는 계산 성공과 구분한다. analysis/result 파일은 조건부 수치 기록이고 전체 process 성공은 정상 종료·감독 한도·부모 원자료 검산이 모두 필요하다. 불완전/저장실패/자원 초과 시 partial 이력과 최초 오류를 보존한다. E143의 close/stat 오류 회귀를 재사용하며, 최종 필수 파일 저장 뒤의 벽시간/byte를 반환해 감독 stdout에 기록한다. 과도한 범용 프레임워크를 만들지 않는다.

SLSQP의 success/종료 조건은 구현 결과이고 후보의 직접 수치 검산을 대체하지 않는다. 공식 API 참조: https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html
