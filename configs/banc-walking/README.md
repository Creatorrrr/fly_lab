# BANC 보행 연구 설정

이 파일들은 명시적으로 선택하는 실험 설정이다. 현재 기본 실행 설정을 변경하지 않는다.

| 파일 | 검증 상태 |
|---|---|
| `e34-candidate.json` | 개발 조건 미끄러짐 35.4% 감소와 진행 기준 통과. 사용자 승인 Q3 개정 조건은 통과하나 후방 도달 실패로 미채택. 원래 Q3 비교 불가는 보존. |
| `e39-candidate.json` | E34 + 앞다리 hair plate 입력. 진행 기준 실패로 거부. |
| `e40-candidate.json` | M1 + 앞다리 hair plate 입력. 미끄러짐 증가로 거부. |
| `e43-candidate.json` | E34 + signed 관절 목표의 빠른 해제. 개발 진행 기준 실패로 거부. 기본 실행은 변경하지 않음. |
| `e44-candidate.json` | 반대 부호 요청만 빠른 해제. 개발 Q1/Q2 통과(34.2% 감소), 후방 목표 31.5초 거리5.78mm로 실패하여 미채택. |
| `e46-candidate.json` | 기존 부착 해제에 필터전 신경 요청의 해제 조건 추가. 미끄러짐36.8% 감소, 접근·이동 속도 기준 Q2 실패로 미채택. |
| `e56-candidate.json` | E34의 비yaw 관절 반응 90→85ms. 미끄러짐37.6% 감소이나 첫 도달7.10초·이동속도61.5%로 Q2 실패, 미채택. |
