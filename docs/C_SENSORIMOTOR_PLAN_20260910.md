# C 감각–운동 개발 계획: 자연 행동과 뇌–VNC–다리

기준 커밋: `0ece4d804c8ea15e232df66363f981c4ac645f53` (C 0.4).
요청 범위는 이전 개발 순서 1번(자연 입력에서 C_STRICT 행동)과
2번(다리 감각과 운동 회로의 폐루프)이다. 아래 계획을 먼저 작성하고 구현한다.
결과는 별도 결과 문서와 `verification/c_sensorimotor_20260910/`에 보존한다.

## 분석

* 무입력 LIF는 모든 뉴런이 휴지막전위로 시작하고 배경 입력도 없어 발화가 0이다.
  이는 실행 속도 문제가 아니다. 자발 보행을 주장하려면 내적 구동 모델과 검증이 필요하다.
* 실제 FAFB/MPS 0.5초 고정 냄새 실험에서 DNg100(DN 보행 후보)은 양측 입력에
  반응했지만 DNp09는 발화하지 않았다. 기존 디코더는 DNp09만 전진에 사용한다.
  다른 출력군을 읽지 않아 발생하는 공백과 신경 모델 자체의 한계를 분리해야 한다.
* DNa02의 200Hz 이상 발화에 기존 0.08 이득을 곱하면 회전이 포화된다.
  운동 출력과 물리 몸의 구동 범위를 함께 교정해야 한다.
* 기존 stop 값의 단순 뺄셈은 정지 입력만으로 후진을 만들 수 있다.
  새 프로파일에서는 전진·후진·회전을 억제하는 정지 게이트를 명시한다.
* BANC 프로토타입은 실제 158,706개 뉴런을 계산하나, 무릎 6 DOF 출력만 있고
  다리 감각 입력과 주 실행기의 저장·개입·관찰 연결이 없다.
* BANC 원자료에는 391개 다리 운동뉴런과 17종 근육 표적, FeCO claw/hook/club,
  접촉 및 변형 감각 주석이 있다. 뉴런 ID/부위는 데이터 기반으로 연결할 수 있지만
  각 뉴런의 선호 관절각·근육 힘·모멘트암은 이 표만으로 확정할 수 없다.

## 구현 순서

1. **행동 출력 보완** — 문헌의 원 ID와 현재 스냅샷의 DNg100/DNg97를 대조하고
   별도 보행 출력 프로파일을 생성한다. 전진·조향 범위와 정지 게이트를 선언하고
   기존 프로파일의 계산과 체크포인트 호환성을 보존한다. 선택된 출력뿐 아니라
   입력→중간 경로→전체 하행 출력의 실측 진단을 저장한다.
2. **정량 행동 계약** — 전진, 후진, 좌우 조향, 정지와 재개, 먹이 접근,
   장애물 및 위험원 대조 평가를 구현한다. 정지는 실제 선행 이동이 있어야 인정하며
   정지 개입의 측정 구간과 해제 이후 재개를 별도로 본다. 정지 상태의 위험원 회피는
   성공이 아니다. 조정용 조건과 고정 평가 조건을 구분하고 실패 원자료를 남긴다.
3. **다리 감각 경계** — MuJoCo 실제 관절각/각속도와 다리별 접촉 힘을 관찰한다.
   동일 BANC 개체의 감각 ID로 입력하고, source annotation과 신호 선택성의 모델
   가정을 분리한다. 모호한 주석은 제외 이유를 기록한다. 감각 차단·한 제어 주기 지연·
   상태 복원·단위와 유한값 검증을 갖춘다. 세계 좌표나 목표 방향은 입력하지 않는다.
4. **전 다리 운동 출력** — BANC의 주석된 근육 운동뉴런을 실제 관절 액추에이터에
   연결하는 명시적 모델을 구현한다. 42 DOF 각각의 커버리지와 미해결 연결을 보고한다.
   위치 목표 변환은 공학적 근육 대리 모델임을 표시한다. 이 경로에서는 기존
   보행 궤적/위상 CPG를 호출하지 않고 신경 출력과 물리 접촉으로 몸을 전진시킨다.
5. **주 실행기 통합** — C_STRICT의 선택 가능한 BANC 프로파일로 연결하여 신경
   모니터링, 감각/운동 개입, 프레임, 기록, 체크포인트와 재개를 함께 사용한다.
   FAFB와 BANC ID를 한 개체인 것처럼 합치지 않는다. 기존 사용자 실험은 보존한다.
6. **실물 계산 검증** — 소형 계약 테스트 → 전체 그래프 MPS 입력 실험 →
   실제 MuJoCo 관절 방향/감각/차단/복원 실험 → 행동 대조 캠페인 → 브라우저 확인.
   신경회로에서 보행 리듬이 발생하지 않으면 연결 완료와 자율 보행 실패를 각각 기록하고
   원자료를 바탕으로 모델 보완을 시도한다. 공학적 보조가 개입한 결과를 자연 행동으로
   승인하지 않는다.

## 고정 판정과 범위

* 보행: 10모델초, 수평 순변위 및 몸 전방 누적 이동 각각 5mm 이상,
  3초 동안 1mm 미만 영역 고착 없음. 물리 고장/관측 누락 없음.
* 먹이: 시작점이 영역 밖이며 30초 내 반경 2mm 진입. 감각 차단 대조 포함.
* 조향: 실제 몸의 누적 회전과 방향, 수평 이동, 넘어짐을 함께 기록한다.
* 정지: 움직임이 있던 대조를 기준으로 0.5초 정착 뒤 1초 경로 0.5mm 이하,
  해제 뒤 2초 내 순변위 및 전방 이동 각각 1mm 이상.
* 폐루프: 다리 측정→선언된 감각 입력→전체 그래프→근육 출력→물리 몸의 모든
  연결에 원시 기록이 있고, 감각/운동 차단 대조와 복원 연속성이 확인되어야 한다.
* 단기 관절 반응은 안정 보행 또는 생물학적 검증을 뜻하지 않는다. 42관절에
  계산 값을 보내는 것도 실제 모든 근육 신경지배를 복원했다는 뜻이 아니다.

## 실행 후 상태

[C 0.5 결과 문서](C_SENSORIMOTOR_RESULTS_20260910.md)에 구현·원자료·남은 조건을 기록했다.
6개 구현 단계의 코드와 도구를 추가하고 실제 실행했으나, 자연 행동의 완료 기준은 부분 충족이다.
FAFB 먹이 접근은 좌측 PASS·우측 FAIL이며, BANC 폐루프 연결 검사는 PASS·자율 보행은 FAIL이다.
준비한 120조건 전체는 아직 실행하지 않았다. 데이터가 없는 근육/감각 가정을 임의로 생물학적 정답으로 확정하지 않는다.
