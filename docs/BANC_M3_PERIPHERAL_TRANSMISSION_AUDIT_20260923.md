# 말초 전달의 사용량 의존 효능: 조건부 후속 가설 감사

E165 원본 방향 진단 전의 읽기 전용 감사다. 실제 gpt-6-sol/high가 관련 식과 1차 자료를 조사했고 부모가 아래 코드와 유충/성체 비행근 논문의 본문·도표 설명을 확인했다. 새 적합·신경·신체 실행은 없다. 가설 채택이나 자연 보행 검증이 아니다.

새 가설로 구분되려면 기존 MN→해부학적 근육 연결에 별도 가용 전달 상태 R을 두고, 같은 MN rate가 지속될 때 전달 rate×R이 사용 중 감소하고 휴지 중 회복하는 곱셈 동역학이 필요하다. 이는 설계 예시이며 실측식은 아니다. `tools/banc_m3_motor_timescale.py:132`의 E123/E138 적응은 MN 발화와 재귀 신경망 자체를 바꾼다. `tools/banc_m3_monotone_recruitment.py:317`의 E148은 기존 5/10/40ms bank에 정적 양수 hinge를 적용한다. E164는 같은 bank의 양의 fast−slow onset이다. M2-E64의 활성 증가/감소별 시간상수는 고정 입력에서 입력값으로 수렴하는 활성 지연이며 사용량에 따른 정상 전달 효능 저하와 같지 않다. E64의 유효한 slip 실패는 `docs/BANC_GAIT_QUALITY_GOAL_PLAN_20260912.md:421`에 보존돼 있다.

[Newman et al., Neuron 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5464967/)의 대상은 유충 NMJ다. 고빈도 입력에서 Ib 촉진과 Is 억제가 구별돼, 모든 MN에 동일한 고갈을 가정할 근거가 되지 않는다. [Kawasaki & Ordway, PNAS 2009](https://pubmed.ncbi.nlm.nih.gov/19706552/)는 성체 간접비행근 DLM의 단기 억제·회복을 측정했다. 다리 NMJ 데이터가 아니다. 해당 논문 그림2의 WT 짝자극 회복에는 빠른/느린 두 성분이 있으며 이 값을 현재 다리 전달 상수로 자동 이식하지 않는다.

[Sustar et al., eLife reviewed preprint](https://doi.org/10.7554/eLife.111371.1)의 발달 단계·근육별 수용체 조성 차이도 전이 가정에 주의를 요구한다. 부모는 DOI 검색 결과의 범위를 확인했고 eLife/PMC 본문 접근은 도구 오류/검증 화면으로 제한됐다. 이 문헌을 성체 보행 다리의 MN별 고갈·회복 상수에 대한 직접 증거로 사용하지 않는다. 읽기 전용 감사에서도 해당 상수의 직접 실측 근거는 찾지 못했다.

현 96근육 위치서보에 도입하려면 rate→방출 사용량, 방출→근육 활성→위치 요청의 추가 공학적 가정이 필요하다. 원래 391→96 소유권·moment 부호, 시작 상태, motor cut, snapshot/restore와 모델 identity를 함께 유지해야 한다. E165가 접지 중 명령 방향의 회수 결함을 뒷받침할 때만 고정된 작은 판별을 후속 설계한다. 명령이 위쪽인데 지지가 남는 결과라면 접촉·구동 동역학의 우선순위가 높다. F1–F8과 전체 목표는 미완료다.
